# 手势收集无形现象｜凝聚成球后释放并让环境回应 — 摘要

## 用途

一名明确成年原创人物在连续行进中停下，先以空手和环境常态建立“不可见”基线，再用双手形成可读收集容器；细线、微粒或波纹只从周边环境向掌心汇聚，压缩成单一可握持核心，人物完成一次释放后让同一物质扩散回城市并改变可见氛围。

## 推荐输入格式

`普通环境中的明确成年主体先展示双手为空 + 双掌稳定定义收集容器 + 至少三处环境痕迹连续汇入并压成单一核心 + 只用一次手势沿既定轴线释放同一物质 + 物质重新分布到同一环境并保持可见回应`

## 必须保留的结构锚点

- Show one adult, ordinary environment and visibly empty hands before collection.
- Form one stable two-hand collection volume before traces appear.
- Use exactly one release gesture and preserve the core's material identity along one axis.
- Distribute the released material back across the same environment and hold the response.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
