# 三角色同拍｜固定阵形与同步转向 — 摘要

## 用途

三个不同主体在稳定场地内同步小动作、共同转向并落在统一终姿。

## 推荐输入格式

`三个可区分主体＋固定间距＋同步转向＋共同停住`

## 可直接改写的简短示例

> 橙、白、钴蓝三台半身高发条测量机器人，哑光蓝绿展示台，各自脚下有圆形标记。

## 必须保留的结构锚点

- 全程恰好三个
- 转向中仍保留左右关系
- 最终都真实着地

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
