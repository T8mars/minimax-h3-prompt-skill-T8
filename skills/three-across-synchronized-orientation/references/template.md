# 三角色同拍｜固定阵形与同步转向 Template

## Mechanism

A stable frontal stage and equal three-across spacing make small synchronized movement readable; coordinated orientation changes refresh the repeated dance while preserving group identity. The source has no additional proven narrative causality.

## Invariants

### inv-01

- Rule: Start with exactly three visibly distinct performers in a stable horizontal formation.
- Purpose: Supports immediate group counting and rhythm.
- Failure if removed: If the row is not established the turns cannot be tracked.

### inv-02

- Rule: Coordinate small movement phrases and at least one shared direction change while retaining left-center-right spacing.
- Purpose: Turns repetition into a readable formation pattern.
- Failure if removed: Uncoordinated figures lose synchronized-group premise.

### inv-03

- Rule: End in a shared planted pose after a final orientation change.
- Purpose: Provides a decisive end state.
- Failure if removed: An arbitrary cutoff leaves the phrase unresolved.
