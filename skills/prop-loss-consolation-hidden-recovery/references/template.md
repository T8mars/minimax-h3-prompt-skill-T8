# 道具复得｜外部夺走、同伴安抚与隐蔽取回 Template

## Mechanism

Establish two characters sharing one desirable prop and one synchronized activity. Let a third party visibly remove the prop and end that activity. Assign materially different reactions to the pair: one shows frustration while the other receives or offers one brief consolation gesture. Reveal that the second character had an already motivated hidden recovery location, retrieve an equivalent functional prop without theft or unexplained appearance, then restore the original shared activity and hold the partnership payoff. The reusable mechanism is shared possession, external loss, asymmetric reaction, consolation, motivated hidden recovery and restored joint use—not the source dogs, breeds, bed, smartphone, woman, paw pose, exact timing, creator identity, watermark or model branding.

## Invariants

### inv-01

- Rule: Show two characters jointly using one desirable prop before it is removed.
- Purpose: Makes both possession and relationship stakes legible.
- Failure if removed: A prop held by only one character weakens the shared-loss premise.

### inv-02

- Rule: Use one visible third-party action to remove the prop and stop the shared activity.
- Purpose: Provides an attributable interruption without ambiguity.
- Failure if removed: An off-screen disappearance cannot support the causal beat.

### inv-03

- Rule: Give the pair different readable reactions and exactly one consolation gesture.
- Purpose: Turns the loss into a relationship change rather than a simple object gag.
- Failure if removed: Identical reactions or repeated comforting flatten role contrast.

### inv-04

- Rule: Recover an equivalent functional prop from a previously plausible hidden location controlled by the partner.
- Purpose: Makes the reversal earned and attributable.
- Failure if removed: A prop appearing from nowhere becomes arbitrary magic.

### inv-05

- Rule: Return both characters to the original joint activity and hold the restored relationship.
- Purpose: Closes the prop and social arcs together.
- Failure if removed: Ending at discovery leaves the shared-use payoff incomplete.
