# 物件仪式增幅｜交付基线、环形锁定与能量释放 — 摘要

## 用途

在同一封闭环境里建立两名成年角色和一件中立物件；物件先被竖直悬停，再由另一角色生成可数环形结构完成校准，能量沿物件自下而上释放，最后双方回到不攻击的稳定关系。

## 推荐输入格式

`一名明确成年原创施术者与一个稳定核心物件 + 至少两级可见环形或分层结构依次附着于物件 + 环境反馈只由物件增强触发且保留固定空间轴 + 能量峰值不转化为无依据的攻击或破坏 + 施术者解除控制后增强结构按相反顺序消退，原物件完整留在终局`

## 可直接改写的简短示例

> 让两名原创成年气象术士在浅水雪松林中相对站立，一根青铜法杖位于两人之间。；第二名术士在法杖下三分之一和上三分之一位置生成恰好两道琥珀校准环。；让圆环和能量消散，法杖落回第一名术士手掌，并以两名成年人各后退一步收束。

## 必须保留的结构锚点

- Exactly two clearly adult characters, one neutral object and one location persist.
- The object enters a stable vertical hover before any energy appears.
- Energy travels continuously along the object's axis and produces one visible terminal change.
- The ritual resolves without an attack, identity swap or unexplained location change.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
