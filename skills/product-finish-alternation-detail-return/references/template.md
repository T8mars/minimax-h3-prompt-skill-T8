# 产品表面交替｜整体基线、微距材质与英雄复归 Template

## Mechanism

先以完整产品和柔软承托面建立轮廓，再在同一角度交替展示中性建模态与成品材质；微距只验证镶嵌、倒角和反光，最后回到完整英雄构图，禁止随机改变结构。 The reusable mechanism preserves causal order, spatial anchors and the final proof while replacing every source-specific person, location, object, wording, choreography and design.

## Invariants

### inv-01

- Rule: One original product geometry and one support surface remain registered throughout.
- Purpose: Establishes the baseline identity, object or geography that every later state must preserve.
- Failure if removed: Without this exact baseline rule, later changes cannot be attributed to the same subject, object or place, so the sequence loses its reference state. Removed rule: "One original product geometry and one support surface remain registered throughout."

### inv-02

- Rule: Material-state alternation changes finish only, never topology, stone count or proportions.
- Purpose: Makes the visible trigger precede and explain the first mechanism response.
- Failure if removed: Without this exact trigger rule, the response appears spontaneously and the central cause-and-effect claim is no longer demonstrated. Removed rule: "Material-state alternation changes finish only, never topology, stone count or proportions."

### inv-03

- Rule: Matched camera angles make every comparison visually valid.
- Purpose: Keeps the middle progression registered instead of allowing an unexplained reset.
- Failure if removed: Without this exact progression rule, the middle can jump to a replacement state and the accumulated result is no longer traceable. Removed rule: "Matched camera angles make every comparison visually valid."

### inv-04

- Rule: Macro views verify countable construction details rather than adding new decoration.
- Purpose: Reconnects the changed or partial state to the established subject and spatial anchor.
- Failure if removed: Without this exact reconnection rule, detail or transformed shots can belong to a different subject or geography and continuity cannot be verified. Removed rule: "Macro views verify countable construction details rather than adding new decoration."

### inv-05

- Rule: The terminal full-product frame restores the opening composition in the finished material.
- Purpose: Turns the terminal hold into observable proof that the mechanism completed.
- Failure if removed: Without this exact terminal-proof rule, the sequence stops on motion alone and never confirms the promised outcome or preserved aftermath. Removed rule: "The terminal full-product frame restores the opening composition in the finished material."

| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- One original product geometry and one support surface remain registered throughout.
- Material-state alternation changes finish only, never topology, stone count or proportions.
- Macro views verify countable construction details rather than adding new decoration.
- The terminal full-product frame restores the opening composition in the finished material.

## Anti-Copy Boundary

- all source faces, bodies, wardrobe, identities and creator-specific character designs
- the source location, set dressing, props, products and exact environmental geometry
- all source words, logos, watermarks, typefaces and brand identifiers
- the source choreography, exact camera path, shot durations and transition timing
- the source palette, signature effects, prompt wording, creator handle and narrative particulars
