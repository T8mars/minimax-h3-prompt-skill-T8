# 光学搜索｜远景线索递进到细节确认 Template

## Mechanism

Keep one constrained optical observer interface visible throughout. Begin on a distant geographic anchor, find one anomalous structural cue, contract the field of view to a subject linked to that cue, stabilize a closer identity proof, then end on one micro-detail that visibly echoes the opening location. Every optical step must answer a narrower evidence question without switching to an omniscient camera.

## Invariants

### inv-01

- Rule: Establish one persistent constrained optical interface and a distant geographic anchor.
- Purpose: Defines observer ownership and the search origin.
- Failure if removed: An unrestricted establishing shot removes the optical-investigation premise.

### inv-02

- Rule: Identify one unusual structural cue inside the same observed geography.
- Purpose: Provides a reason to contract the view.
- Failure if removed: A random zoom without a discovered cue becomes decorative.

### inv-03

- Rule: Move from place evidence to one subject or active carrier linked to the cue.
- Purpose: Turns environment search into a specific target search.
- Failure if removed: Jumping to an unrelated person breaks the evidence chain.

### inv-04

- Rule: Stabilize one closer identity or function proof before the terminal detail.
- Purpose: Prevents the final close-up from becoming contextless.
- Failure if removed: Skipping directly from distant place to detail hides the target relationship.

### inv-05

- Rule: End on one micro-detail that visibly echoes or verifies the opening geographic anchor.
- Purpose: Closes the contraction ladder with proof rather than proximity alone.
- Failure if removed: A close face with no retained location evidence does not resolve the search.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |
