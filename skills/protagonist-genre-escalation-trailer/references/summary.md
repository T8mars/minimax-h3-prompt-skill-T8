# 类型预告｜同一主角跨场景升级到片名 — 摘要

## 用途

以同一核心人物和少数关系锚点贯穿多场景预告：先建立关系，再扩展城市活动与私人压力，随后把冲突升级到公共危险和大尺度奇观，最终用独立片名卡封口；不依赖未转写对白意义。

## 推荐输入格式

`固定主角与关系锚点 + 公共世界扩展 + 私人脆弱阶段 + 物理危险升级 + 独立原创片名终卡`

## 可直接改写的简短示例

> 毛毡植物学家预告从温室友情、河上市集远行与种子库危机，升级到机械果园救援和发光花粉爆发，最后切到独立的原创无字叶片徽记。

## 必须保留的结构锚点

- Introduce one protagonist and one relationship anchor before the location count expands.
- Return to the protagonist while broadening public settings and group size.
- Escalate from interpersonal pressure to visible public physical danger.
- Separate the maximum spectacle from a held, original title lockup.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
