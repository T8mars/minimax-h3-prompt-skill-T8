# 类型预告｜同一主角跨场景升级到片名 Template

## Mechanism

A short trailer can escalate genre without dialogue evidence by repeatedly returning to one protagonist while broadening the world in five causal registers: relationship, public activity, private vulnerability, physical danger and maximum spectacle. A separate final title card closes the promise; recurring faces and objects, not unverified speech meaning, carry continuity.

## Invariants

### inv-01

- Rule: Introduce one protagonist and one relationship anchor before the location count expands.
- Purpose: Gives montage a human identity spine.
- Failure if removed: Unrelated opening faces create a generic clip reel.

### inv-02

- Rule: Return to the protagonist while broadening public settings and group size.
- Purpose: Expands genre scope without losing identity.
- Failure if removed: Pure location montage loses narrative ownership.

### inv-03

- Rule: Insert a quieter private or clinical vulnerability phase before action escalation.
- Purpose: Creates contrast and stakes.
- Failure if removed: Constant action leaves no emotional pressure change.

### inv-04

- Rule: Escalate from interpersonal pressure to visible public physical danger.
- Purpose: Makes spectacle feel earned.
- Failure if removed: An arbitrary explosion has no dramatic ladder.

### inv-05

- Rule: Separate the maximum spectacle from a held, original title lockup.
- Purpose: Closes the trailer as a promise rather than an unresolved scene.
- Failure if removed: No title closure makes the montage feel like an excerpt.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Introduce one protagonist and one relationship anchor before the location count expands.
- Return to the protagonist while broadening public settings and group size.
- Escalate from interpersonal pressure to visible public physical danger.
- Separate the maximum spectacle from a held, original title lockup.

## Anti-Copy Boundary

- Japanese live-action cast
- source taxi nightlife hospital and boxing montage
- burning interior and explosion climax
- source Japanese title typography
- source relationship and action ordering

## Transfer Tests

1. A felt-animation botanist trailer follows one young field researcher from a greenhouse friendship, through a river market expedition, into a quiet seed-bank emergency, then a mechanical orchard rescue and a burst of luminous pollen; it ends on an original wordless leaf emblem.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
2. A monochrome clay radio operator trailer begins with a sibling promise, expands to a crowded floating station, slows in a silent infirmary, escalates to a storm evacuation, and ends after a lightning spectacle on an original embossed signal mark.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
