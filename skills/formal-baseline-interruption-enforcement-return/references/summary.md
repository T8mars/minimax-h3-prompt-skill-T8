# 边界执行｜正式基线—干扰定位—处置—复位 — 摘要

## 用途

先建立正式场合和清楚的秩序维护者，再用群体反应定位一次越界干扰；维护者离开原位、完成单一可见处置并返回，让原本秩序以新的稳定状态恢复。

## 推荐输入格式

`正式群体基线与维护者原位 + 群体反应定位 + 单一干扰物 + 可归因处置 + 原构图复位`

## 可直接改写的简短示例

> 玻璃修复实验室内，穿钴蓝工作服的资深修复师站在白色地面标记上，六名技术员分两排面向暗光文物投影；显示访客包旁的琥珀提示器，同一修复师离开白色标记，沿中央通道走向设备，六名技术员位置保持；同一修复师回到白色地面标记，六名技术员重新面向投影，修复师只做一次克制点头

## 必须保留的结构锚点

- Establish one formal group baseline, one boundary keeper and the keeper's anchor position before the interruption.
- Localize exactly one disturbance through spatially connected group reactions before revealing its source.
- Use one clear, attributable corrective action that removes or neutralizes the source without adding a second conflict.
- Return the keeper to the original anchor and repeat enough of the opening composition to prove restored order.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
