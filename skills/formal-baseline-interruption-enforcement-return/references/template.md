# 边界执行｜正式基线—干扰定位—处置—复位 Template

## Mechanism

Establish a formal group setting, a stable boundary keeper and one readable baseline rule. Introduce a single localized interruption through synchronized reactions before revealing its physical source. Let the same keeper leave the anchor position, perform one attributable corrective action, then return to the repeated baseline composition with a restrained state change. The reusable mechanism is reaction-localized interruption, visible enforcement and compositional return, not the source religious costume, chapel, phone, violent gesture or exact joke.

## Invariants

### inv-01

- Rule: Establish one formal group baseline, one boundary keeper and the keeper's anchor position before the interruption.
- Purpose: Defines the rule and who can enforce it.
- Failure if removed: Without a stable baseline, the intervention reads as random aggression.

### inv-02

- Rule: Localize exactly one disturbance through spatially connected group reactions before revealing its source.
- Purpose: Creates anticipation while preserving understandable geography.
- Failure if removed: A detached reaction montage cannot identify where the problem occurs.

### inv-03

- Rule: Reveal one physical source of interruption and keep it traceable to the same location or participant.
- Purpose: Turns social tension into an inspectable cause.
- Failure if removed: Changing the offending object or location breaks accountability.

### inv-04

- Rule: Use one clear, attributable corrective action that removes or neutralizes the source without adding a second conflict.
- Purpose: Provides a decisive payoff and keeps the mechanism compact.
- Failure if removed: Multiple attacks, arguments or unrelated gags dilute the boundary action.

### inv-05

- Rule: Return the keeper to the original anchor and repeat enough of the opening composition to prove restored order.
- Purpose: Closes the loop through visual evidence.
- Failure if removed: Ending on the removed object or crowd reaction leaves the formal state unresolved.


## Variable Slots

| Slot | Constraint |

| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Establish one formal group baseline, one boundary keeper and the keeper's anchor position before the interruption.
- Localize exactly one disturbance through spatially connected group reactions before revealing its source.
- Use one clear, attributable corrective action that removes or neutralizes the source without adding a second conflict.
- Return the keeper to the original anchor and repeat enough of the opening composition to prove restored order.

## Anti-Copy Boundary

- the source veiled religious figure, black-and-white habit, face paint, cross and altar identity
- the source stone chapel, candles, funeral-like black clothing and attendee faces
- the source handheld phone, throat-level gesture, boot action and window ejection gag
- the source exact reaction order, aisle blocking, compositions and final smile
- any source logos, device marks, religious symbols, implied identities or exact sound cues

## Transfer Tests

1. During an original museum-conservation briefing, a flashing visitor beacon interrupts a silent calibration. Attendees look toward it, the senior conservator places it in a lightproof isolation box and returns to the projection mark before the calibration resumes.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
2. At an original chamber rehearsal, one electronic metronome starts chirping during a held rest. Musicians locate it by gaze, the conductor closes its lid, moves it outside the acoustic shell and returns to the podium for the same raised-baton tableau.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
