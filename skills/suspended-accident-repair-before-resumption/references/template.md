# 冻结修复｜事故悬停、唯一修复者到全域复流 Template

## Mechanism

Establish a normally active environment and one complete target object. Use one attributable accident to separate the object into several visible component families at maximum disorder while suspending all surrounding motion. Keep one clearly defined specialist as the only mobile exception; make the specialist recover the same components in a traceable order, reconstruct the object without replacing it, complete one service transfer, then resume the environment exactly once. The reusable mechanism is baseline object, accident suspension, sole repair agent, traceable component recovery, restored handoff and terminal resumption—not the source bar, couple, cocktail, ice, orange peel, bartender likeness, wardrobe, camera path, watermark, creator identity or model label.

## Invariants

### inv-01

- Rule: Show a complete target object and at least two independent environmental motion classes before the accident.
- Purpose: Creates falsifiable baselines for both object integrity and world motion.
- Failure if removed: Starting after the break makes neither damage nor suspension provable.

### inv-02

- Rule: Use one visible accident to create maximum disorder and suspend all non-specialist motion.
- Purpose: Gives the frozen repair interval one attributable cause.
- Failure if removed: Unrelated cuts or multiple causes weaken the event topology.

### inv-03

- Rule: Keep exactly one clearly defined specialist mobile while all other people and loose components remain suspended.
- Purpose: Makes the repair agent and state rule unambiguous.
- Failure if removed: Multiple active agents turn the scene into ordinary teamwork.

### inv-04

- Rule: Recover separated component families in traceable source-to-destination order and rebuild the same object.
- Purpose: Proves repair rather than replacement or unexplained magic.
- Failure if removed: A new object appearing without component continuity breaks the mechanism.

### inv-05

- Rule: Complete one service handoff before one global resumption in the original geography.
- Purpose: Provides a countable terminal proof that the repair succeeded.
- Failure if removed: Resuming early or ending before transfer leaves the causal chain open.

## Transfer Tests

1. In an orbital greenhouse laboratory, a pressure jolt shatters one seed capsule into shell, gel and seed components while mist, tools and technicians freeze. One adult containment engineer alone gathers each suspended component, rebuilds the capsule in a sterile cradle, returns it to a botanist and releases the whole lab once.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
2. In a kinetic sculpture workshop, one cable snap separates a brass balance instrument into rings, weights and pins while sparks, cloth and assistants freeze. One adult restoration engineer retrieves the same parts in order, reassembles the instrument, places it back on its stand and resumes the workshop once.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
