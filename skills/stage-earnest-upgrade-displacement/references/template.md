# 升级讽刺｜新物登场旧爱被移走 Template

## Mechanism

First make an existing object feel sincerely valued, then bind one restrained subject to it through a specific physical attachment. Introduce the upgrade and remove the valued object in the same spatial event so progress and loss are inseparable. Redirect the surrounding group's genuine enthusiasm to the replacement while the attached subject remains visible but unattended. Finish with completely earnest institutional closure, preserving the unresolved attachment so the satire comes from the image logic rather than a wink or joke.

## Invariants

### inv-01

- Rule: Establish the current object or system as sincerely valued before introducing its replacement.
- Purpose: Makes displacement emotionally legible without explanatory dialogue.
- Failure if removed: If replacement arrives first, the satire is only a product comparison.

### inv-02

- Rule: Bind one restrained character or creature to the current object through a concrete physical attachment action.
- Purpose: Turns abstract preference into visible relationship evidence.
- Failure if removed: Generic smiles give the audience no specific cost to track.

### inv-03

- Rule: Show the replacement entering while the valued object exits in one shared spatial proof.
- Purpose: Makes upgrade and loss causally simultaneous.
- Failure if removed: Separate before-and-after shots hide who or what is displaced.

### inv-04

- Rule: Redirect group approval to the replacement while the attached subject remains visible but socially unattended.
- Purpose: Creates deadpan contradiction without a comedic reaction cue.
- Failure if removed: If the group notices or apologizes, the institutional certainty collapses into ordinary drama.

### inv-05

- Rule: End with an authoritative promotional closure that remains completely sincere and does not resolve the attachment.
- Purpose: Lets institutional optimism certify the absurdity instead of commenting on it.
- Failure if removed: A wink, angry reaction or explanatory joke releases the tension and weakens the satire.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original, stable subject or group with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical or social consequence. |
| sound_family | An original hierarchy of diegetic cues supporting state changes. |

## Required Human-Facing Anchors

- 先证明旧物被真诚珍爱
- 用一个具体身体动作锁定依恋
- 新物进入与旧物移走必须同镜同时发生
- 群体掌声转向新物且不回应被移走者
- 结尾保持制度化真诚并保留未解决依恋
