# 升级讽刺｜新物登场旧爱被移走 — 摘要

## 用途

先建立对旧物的真诚依恋，再让升级与移走同时发生；群体把掌声转向新物，最后用完全认真的制度化终态保留未解决的反差。

## 推荐输入格式

`被珍爱的旧物 + 一个具体依恋动作 + 新旧同时进出 + 群体掌声转移 + 真诚但不解决依恋的终态`

## 可直接改写的简短示例

> 纸艺温室里，毛毡园丁珍爱旧雨量计，折纸知更鸟在底座筑巢；自动气象塔进入时旧雨量计同时被推出，知更鸟仍随旧物离场，园丁真诚鼓掌，最后停在无文字的太阳徽记终态。

## 必须保留的结构锚点

- 先证明旧物被真诚珍爱
- 用一个具体身体动作锁定依恋
- 新物进入与旧物移走必须同镜同时发生
- 群体掌声转向新物且不回应被移走者
- 结尾保持制度化真诚并保留未解决依恋

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
