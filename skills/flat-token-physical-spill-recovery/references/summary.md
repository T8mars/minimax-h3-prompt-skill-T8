# 平面物件落地｜打断表演与收拾恢复 — 摘要

## 用途

稳定平面布局中，图形落成实体打断动作，人物收拾后继续原活动。

## 推荐输入格式

`表演者＋原创平面图形＋实体掉落＋收拾恢复`

## 可直接改写的简短示例

> 米白排程板、六个无品牌彩色圆点、一名素蓝罩衫的成年纸偶表演者、小托盘。

## 必须保留的结构锚点

- 先建立稳定平面布局
- 图形落成实体并打断活动
- 收拾后回到同一人物动作

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
