# 地貌变形揭示｜局部异常到巨体逼近 — 摘要

## 用途

先让环境异常看起来仍像地貌，再只揭出一个身份特征；随后用高位或远景证明完整几何及其对环境的尺度影响，最后回到低位视点完成一次近距离逼近。

## 推荐输入格式

`环境局部异常 + 单一身份特征 + 高位完整几何证明 + 环境尺度影响 + 低位近距离逼近`

## 可直接改写的简短示例

> 盐碱滩先出现像地貌的隆起，只显出琥珀观察窗；高位镜头证明它是巨型移动气象舱，最后回到低位让舱体越过测量站近旁。

## 必须保留的结构锚点

- Open on an environmental deformation that can still be mistaken for terrain.
- Reveal one identifying feature while withholding most of the body.
- Use one high or wide view to prove the complete geometry and its environmental consequence.
- Return to a lower viewpoint for one bounded proximity breach.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
