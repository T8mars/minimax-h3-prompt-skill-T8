# 扁平角色字卡轮转｜同一企鹅贯穿多种运动语法 Template

## Mechanism

Establish one original stylized character through stable silhouette, palette, face marks and a compact original name field. Rotate through at least four graphic modules that change layout logic—such as triptych, circular text, extruded word track, single-word action card and shallow grid space—while introducing no more than one new short word or identity field per module. Bind each word-bearing module to one readable character action and preserve the same identity anchors through scale, flatness and depth changes. Include one explicit repetition or identity-verification phase, then return from detail fragments to the full character and the original name field. The reusable mechanism is identity-locked module rotation, action-to-word binding, recurring graphic anchors and character-to-wordmark closure—not the source penguin, crest, vest, stripes, words, logo, palette, layouts, choreography, watermark, creator identity or timing.

## Invariants

### inv-01

- Rule: Establish one stylized character with stable silhouette, palette, face marks and a compact original name field.
- Purpose: Provides enough identity anchors for aggressive graphic variation.
- Failure if removed: A single color or generic body shape cannot sustain continuity.

### inv-02

- Rule: Use at least four modules with genuinely different layout logic while limiting each to one new short word or field.
- Purpose: Creates variety without sacrificing reading speed.
- Failure if removed: Palette-only changes add no structural progression; dense copy becomes noise.

### inv-03

- Rule: Bind every word-bearing module to one readable character action on or through the typography.
- Purpose: Connects the performer to the information system.
- Failure if removed: A floating character beside unrelated text produces no causal design.

### inv-04

- Rule: Preserve identity through flat cards, macro scale and shallow 3D space, including one repetition or verification phase.
- Purpose: Proves the same character survives format changes.
- Failure if removed: Unmotivated redesign or missing verification makes continuity uncertain.

### inv-05

- Rule: Return from fragments or details to the full character and original name field for a stable hold.
- Purpose: Closes the module carousel into one identity statement.
- Failure if removed: Ending on an abstract insert leaves the character and title unresolved.
