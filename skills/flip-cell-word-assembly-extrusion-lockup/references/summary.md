# 翻片矩阵字标组装｜像素激活、平面组字、厚度长出与卡片收束 — 摘要

## 用途

固定翻片矩阵从局部激活扩散成完整单词，平面字形随后长出厚度、分层和少量点色，所有组件保持注册并回弹落稳，最后缩入简洁品牌卡。

## 推荐输入格式

`Establish one fixed cell matrix, one exact short word and a neutral unflipped baseline. + Propagate local cell activation until the complete flat word is readable without misspelling. + Grow registered letter depth, layers and one accent while preserving every character position. + Use bounded extrusion and recoil so modules return to a stable aligned state. + Compress the resolved dimensional word into one clean card and hold the exact lockup.`

## 可直接改写的简短示例

> 展示原创小方形陶瓷砖墙，全部哑光象牙色并固定在正交网格；预先声明准确单词【MAKER】，但尚不显示字母。；所有瓷砖注册不变，字母砖长成浅陶瓷浮雕；只在字母 A 上方增加一个小琥珀方块。；拉远，完整浮雕字变成锈色背景上的小象牙工坊卡；准确【MAKER】与一个琥珀方块停住，不加其他文字。

## 必须保留的结构锚点

- Establish one fixed cell matrix, one exact short word and a neutral unflipped baseline.
- Propagate local cell activation until the complete flat word is readable without misspelling.
- Use bounded extrusion and recoil so modules return to a stable aligned state.
- Compress the resolved dimensional word into one clean card and hold the exact lockup.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
