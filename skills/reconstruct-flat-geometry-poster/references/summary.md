# 平面重组｜几何节奏品牌片 — 摘要

## 用途

稳定剪影与几何母题被反复拆解重组，在高密阶段后短暂停顿并收束为既有图形族。

## 推荐输入格式

`单一几何母题 + 稳定剪影 + 反复拆解重组 + 高密阶段 + 短暂停顿 + 既有图形收束`

## 可直接改写的简短示例

> 以珊瑚螺旋为唯一母题，稳定潜航器剪影贯穿；螺旋反复拆成声呐弧线和路线图，在高密数据阶段后短暂停顿，最终重组为同一图形族的徽记。

## 必须保留的结构锚点

- 只有一个几何母题
- 主体剪影稳定
- 拆解与重组多次发生
- 高密后留短暂停顿并用既有图形收束

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
