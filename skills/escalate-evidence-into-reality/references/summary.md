# Evidence Ladder Crosses into Reality — 摘要

## 风格与机制

稳定现实与一个有边界的证据载体先产生可核对的矛盾；载体连续两次更新同一个可计数变量，而现实暂时不变。只有当递进达到最接近或最关键状态后，变化才跨出载体进入现实，并留下一个清晰物理结果。

## 适用范围

- 信息差悬疑、轻惊悚、奇观、喜剧、技术谜题或产品证明
- 依靠扫描仪、传感器、地图、样本、仪表、录音或显示介质推进的短片
- 需要 15 秒内完成“提出规则—验证规则—升级—兑现”的概念

## 不适用范围

- 只有一次随机反转、没有重复验证
- 一开始现实就变化，证据载体只是装饰
- 只把来源的照片、怪物或恐惧表演换成别的名词

## 使用方法

1. 先选一个稳定现场和能重复检查的证据载体。
2. 选择一个只能沿单一方向推进的变量，并明确两次更新。
3. 至少同时改变载体、场景、类型、变化物理、运镜、声音和情绪收束中的六项。
4. 先做因果地图，再分别编译 MiniMax H3 与 Seedance 2.0。
5. 最后检查：现场锚点是否稳定、两次更新是否可比较、现实是否延迟跨界、反应是否晚于证据。

## 可变槽位

| 槽位 | 约束 |
|---|---|
| live_baseline | 可被重复核对、空间锚点清楚的稳定现场。 |
| evidence_carrier | 有边界的传感器、地图、录音、样本或显示介质；不要复用来源的相机与即时照片。 |
| advancing_variable | 距离、数量、颜色、裂纹、波形或生长状态，至少变化两次。 |
| verification_action | 人或机器重复比较载体与现场的动作。 |
| boundary_crossing | 被表示的状态影响现实的单一、物理可读时刻。 |
| emotional_register | 由新概念决定的惊悚、惊奇、喜剧、温柔或技术紧张。 |
| camera_grammar | 按信息优先级设计的新覆盖方式，不复刻来源镜头序列。 |
| sound_family | 载体提示、更新提示、短暂重置与物理结果组成的声音层级。 |
