# 未来证据｜异常闯入现实 — 摘要

## 用途

稳定现实中，同一证据载体连续更新，最后异常内容延迟跨入现实。

## 推荐输入格式

`有边界的证据载体 + 稳定现实 + 同一变量连续2次更新 + 延迟跨界 + 一次反应`

## 可直接改写的简短示例

> 温室里的黄铜叶片扫描器连续吐出两张状态纸条，第二张显示尚未出现的霜纹；短暂停顿后霜纹从纸面蔓延到真实叶片，园艺师只后退一步。

## 必须保留的结构锚点

- 现实基线稳定
- 同一证据载体至少两次更新
- 异常先在证据内出现
- 跨界延迟发生且只有一次克制反应

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
