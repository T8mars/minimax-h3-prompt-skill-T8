# 分层接力｜小物体穿越多区域完成传递 — 摘要

## 用途

在同一可读空间建立多个相连区域，让一个小物体从首位角色出发；物体通过可见表面改变路线，后续见证者持续追踪，最终交给自主载体，并以全景闭合完整接力。

## 推荐输入格式

`至少3个分层区域 + 1个可数物体 + 2次路线改变 + 后段重定向 + 自主载体终点`

## 可直接改写的简短示例

> 垂直种子库中，一枚琥珀胶囊从上层分拣臂出发，经过透明滑道与机械叶门两次改道，最终落入自主种植车。

## 必须保留的结构锚点

- Show at least three connected zones in one readable geography.
- Launch one countable token from a clear first participant.
- Keep the same token visible through a later witness zone and into its descending segment.
- End with an autonomous final carrier and a wide path closure.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
