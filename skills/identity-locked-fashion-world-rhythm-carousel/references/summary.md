# 时装世界节拍轮转｜同一成年角色跨风格、静默与英雄收束 — 摘要

## 用途

同一明确成年时装角色以稳定脸、发型和比例贯穿多种风格世界；每段只改变服装、配饰、文字或舞台系统，并用一次静默留白后恢复全节拍，最终回到成熟英雄造型。

## 推荐输入格式

`Establish one clearly adult original fashion subject with at least three stable identity anchors. + Rotate distinct style modules while changing only declared wardrobe, accessory, palette and typography variables. + Bind every module to subject action, camera movement and foreground motion while preserving identity. + Insert one authored low-density pause after the maximum-intensity phase. + Return prior modules as a compressed recall and finish on the same adult in one stable hero frame.`

## 可直接改写的简短示例

> 钴蓝工作室内锁定一名明确成年银发街头服装设计师，脸、短发和修长比例稳定；一枚超大透明搭扣擦过镜头后揭示她直视镜头。；先做三联身份核验，再进入深紫外模块，让少量原创短词在人物后方环绕；脸、发型和身体比例不变。；镜头穿过之前原创材质样本的拼贴，落到同一成年人的精致钴蓝英雄造型；只显示准确终局文字【MAKE IT YOURS】并停住。

## 必须保留的结构锚点

- Establish one clearly adult original fashion subject with at least three stable identity anchors.
- Rotate distinct style modules while changing only declared wardrobe, accessory, palette and typography variables.
- Insert one authored low-density pause after the maximum-intensity phase.
- Return prior modules as a compressed recall and finish on the same adult in one stable hero frame.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
