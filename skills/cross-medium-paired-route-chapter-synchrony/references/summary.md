# 跨媒介旅伴路线｜地标换章、同步动作与共同终姿 — 摘要

## 用途

固定一名成年真人和一名成年二维原创旅伴，两者保持不同材质却共享方向、节拍与地标路线；每章由一次同步手势或步态证明同场，最终以共同动作结束而非互相替换。

## 推荐输入格式

`一名明确成年真人原创角色和一名明确成年二维原创旅伴 + 两种材质身份始终分离 + 至少三个由可见载体连接的路线章节 + 每章一次同步动作与一致行进方向 + 至少一次交替前景遮挡证明共享深度 + 终局共同操作同一目的地对象`

## 可直接改写的简短示例

> 配对原创真人成年植物调查员和明确二维的成年地图师：真人佩戴红围巾与帆布挎包，动画旅伴为海军蓝短发、黄色外套和墨线阴影。；路线圆盘擦拭切换到峭壁小路、室内市场和盐湖码头；每章都保留两种身份、向右路线和一次同步本地动作。；两人在山顶观测站共同转身、触碰同一投影地图，并肩完成一步，在准确原创标题【TWO MEDIA / ONE ROUTE】下结束。

## 必须保留的结构锚点

- One clearly adult live-action identity and one clearly adult illustrated identity retain different media signatures throughout.
- Every location change preserves paired travel direction and follows a visible shared transition carrier.
- Alternating foreground occlusion proves shared depth without merging faces, bodies or rendering media.
- The terminal frame reunites both adults, one destination object and one exact original route title in a shared action.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
