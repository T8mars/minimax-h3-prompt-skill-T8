# 空中群集｜近表面转向到稳定落地 — 摘要

## 用途

始终跟住一个主体，近表面改变方向后拉宽重建地理，最后真实落地。

## 推荐输入格式

`单一领衔主体＋空中群集＋近表面转向＋终点落地`

## 可直接改写的简短示例

> 阴天海上风机测试区，一台橙色主巡检无人机、三台深色辅助无人机、带黄色安全桅杆的甲板、橙边降落垫。

## 必须保留的结构锚点

- 领衔主体始终可追踪
- 宽景重建方向和深度
- 最后接触面与余动可见

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
