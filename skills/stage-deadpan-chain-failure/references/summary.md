# 反差喜剧｜越从容越失控 — 摘要

## 用途

正式场合中连锁失控不断升级，但主体始终镇定，反差本身构成笑点。

## 推荐输入格式

`正式场合 + 附着负担 + 至少2次连锁后果 + 可见失效 + 主体始终从容`

## 可直接改写的简短示例

> 糕点师在颁奖展示中背着巨大的糖艺帆，帆先扫倒装饰塔，再扯翻展示布，最后糖船断裂；他始终面带微笑完成鞠躬。

## 必须保留的结构锚点

- 正式场合与沉着主体
- 负担始终附着主体
- 至少两次因果连锁
- 失效可见但主体不慌

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
