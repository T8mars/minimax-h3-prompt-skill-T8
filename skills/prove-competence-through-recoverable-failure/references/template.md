# 角色登场｜失误后借身体特征破局 Template

## Mechanism

Introduce one original character through habitat, wake behavior and locomotion before assigning a skilled task. Let the first technical attempt create a visible recoverable failure, then make the character use one identity-defining body feature as a practical reasoning or control instrument. The success state must visibly answer the failure and end in a clean competence pose with the changed object.

## Invariants

### inv-01

- Rule: Establish habitat, intimate reaction and locomotion before the technical task.
- Purpose: Builds personality and physical rules before judging skill.
- Failure if removed: Starting at the workbench reduces the character to a decorative technician.

### inv-02

- Rule: Show one skilled task with a readable intermediate state.
- Purpose: Makes later failure specific and inspectable.
- Failure if removed: An unexplained accident cannot prove what changed.

### inv-03

- Rule: Keep the failure recoverable and preserve the same task object.
- Purpose: Supports causal repair instead of reset magic.
- Failure if removed: Replacing the object erases the consequence.

### inv-04

- Rule: Use one identity-defining body feature as a practical tool in the solution.
- Purpose: Makes character design causally meaningful.
- Failure if removed: If any generic tool solves the problem, the body design is only ornament.

### inv-05

- Rule: End with the repaired or transformed object and a restrained competence pose together.
- Purpose: Provides visible proof of learning and success.
- Failure if removed: A reaction without the result cannot close the task.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair whose role is readable without source identity. |
| setting | A materially new setting with fixed spatial anchors and no source-specific surface. |
| carrier_or_token | One visible material, prop or symbolic anchor that carries the causal mechanism. |
| state_change | A sequence of visible, causally ordered changes rather than decorative montage. |
| camera_grammar | An information order that proves each change without copying source shot boundaries. |
| payoff | A held final state that resolves or recontextualizes the setup. |
| sound_family | An original hierarchy of visible-action sounds; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Establish habitat, intimate reaction and locomotion before the technical task.
- Show one skilled task with a readable intermediate state.
- Use one identity-defining body feature as a practical tool in the solution.
- End with the repaired or transformed object and a restrained competence pose together.

## Anti-Copy Boundary

- Ayotl name and source folklore attribution
- source turtle-like creature, shell markings and color design
- hammock wake-up, floating gears, crystal experiment and source equations
- the exact source workshop, explosion, self-writing surface and hero pose

## Transfer Tests

1. A translucent paper-moth meteorologist wakes in a folded drawer, assembles a prism barometer, loses its calibration in a gust, uses its patterned wings as a projection screen to map airflow, then condenses and presents one rain bead.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, carrier_or_token, state_change, camera_grammar, payoff, sound_family
2. A clay axolotl archivist crawls from a damp ceramic niche, aligns a singing scroll cylinder, cracks its pitch ring, uses the sensory frill along its head as a live resonance meter and restores one stable glowing tone.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, carrier_or_token, state_change, camera_grammar, payoff, sound_family
