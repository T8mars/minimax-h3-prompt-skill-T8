# 角色登场｜失误后借身体特征破局 — 摘要

## 用途

先用居所、醒来反应和移动方式建立原创角色，再让技术任务发生可恢复失误；角色把自身独特身体特征当成工具完成破局，并以成果同框收束。

## 推荐输入格式

`原创角色居所与移动 + 技术任务 + 可恢复失误 + 身体特征破局 + 成果同框`

## 可直接改写的简短示例

> 半透明纸蛾气象员在黄铜气象塔醒来，校准棱镜气压计时遭遇阵风失误，随后用翼脉投影诊断气流并修复，最后托起一颗雨珠。

## 必须保留的结构锚点

- Establish habitat, intimate reaction and locomotion before the technical task.
- Show one skilled task with a readable intermediate state.
- Use one identity-defining body feature as a practical tool in the solution.
- End with the repaired or transformed object and a restrained competence pose together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
