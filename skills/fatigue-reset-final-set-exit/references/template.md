# 疲劳回场｜短恢复后完成困难末次并离开 Template

## Mechanism

Lock one observational camera on a bounded work area, the adult performer and the unfinished task. Begin after prior effort with visible fatigue in posture and breathing. Allow one short recovery action using a small object, then require the performer to put that object away and voluntarily re-engage the same task. Show at least two directly comparable controlled repetitions, make the final repetition visibly harder without unsafe form, then release the load safely. End with one restrained self-evaluation, a deliberate exit and an empty held workspace. The reusable mechanism is fatigue proof, bounded reset, voluntary return, comparable repetition, difficult last effort, safe release and empty-frame closure—not the source woman, gym, black sportswear, bottle, bench, cable machine, exact exercise, body, autofocus behavior, camera height, timing, creator identity or unsupported model mapping.

## Invariants

### inv-01

- Rule: Lock one observational camera on an adult performer, bounded workspace and unfinished task.
- Purpose: Creates a fair before-and-after carrier without editorial assistance.
- Failure if removed: Changing views can hide resets or skipped work.

### inv-02

- Rule: Prove prior fatigue through posture and breathing before one bounded recovery action.
- Purpose: Gives the return meaningful effort cost.
- Failure if removed: A fresh performer makes the final task ordinary.

### inv-03

- Rule: Put the recovery object away and visibly re-engage the same task by choice.
- Purpose: Marks the causal boundary between rest and renewed work.
- Failure if removed: Remaining in rest or cutting into action removes agency.

### inv-04

- Rule: Show at least two comparable controlled repetitions and one visibly harder final repetition without unsafe form.
- Purpose: Builds a readable exertion ladder and terminal challenge.
- Failure if removed: Uncountable montage or dangerous strain weakens proof.

### inv-05

- Rule: Release safely, perform one restrained self-check, exit and hold the empty workspace.
- Purpose: Closes effort, evaluation and departure in one observable chain.
- Failure if removed: Camera follow or celebration removes the quiet completion evidence.
