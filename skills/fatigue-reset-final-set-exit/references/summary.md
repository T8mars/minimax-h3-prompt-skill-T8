# 疲劳回场｜短恢复后完成困难末次并离开 — 摘要

## 用途

用固定观察机位先证明角色已疲劳，让一次短暂恢复动作把呼吸和注意力拉回任务；角色随后主动重返同一工作负荷，完成至少两次可比较的控制重复和一次明显更困难的末次，释放负荷后只做克制自我确认并离开，空场保留完成证据。

## 推荐输入格式

`固定观察机位、成年执行者与未完成任务 + 可见疲劳和呼吸 + 1次有边界的短恢复并收起恢复物 + 主动回到同一任务 + 至少2次可比较控制重复和1次更难末次 + 安全释放、自我确认、离场与空工作区停留`

## 可直接改写的简短示例

> 成年舞台技师坐在航空箱上喘息，前臂压膝；卷盘、地面标记和未亮绿色指示灯同框；她转向同一手动卷盘，双脚踩回标记点，双手握住既定手柄；她释放张力，确认绿色指示灯，小幅满足呼气后离开；空航空箱、卷盘和绿灯稳定停留

## 必须保留的结构锚点

- Lock one observational camera on an adult performer, bounded workspace and unfinished task.
- Prove prior fatigue through posture and breathing before one bounded recovery action.
- Show at least two comparable controlled repetitions and one visibly harder final repetition without unsafe form.
- Release safely, perform one restrained self-check, exit and hold the empty workspace.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
