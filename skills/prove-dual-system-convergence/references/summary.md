# 双系统碰撞｜同时证明两种规则 — 摘要

## 用途

先分别建立两个对立系统的独立规则，再让它们一次汇聚形成持久第三状态。

## 推荐输入格式

`系统A材质/规则 + 系统B材质/规则 + 分别建立 + 一次汇聚碰撞 + 双方共同形成的第三状态`

## 可直接改写的简短示例

> 实验台左侧是会结晶的液态玻璃，右侧是会脉动的磁性沙；分别证明各自规则后，它们只汇聚一次，形成同时透明且持续脉动的悬浮晶格。

## 必须保留的结构锚点

- 两个系统先独立成立
- 材质或运动规则明确不同
- 只发生一次关键汇聚
- 第三状态同时保留双方证据

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
