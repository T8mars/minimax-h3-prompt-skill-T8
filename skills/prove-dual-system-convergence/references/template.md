# 双系统碰撞｜同时证明两种规则 Template

## Mechanism

Establish two systems separately with distinct color, material physics, motion cadence and starting zones. Alternate equal proof beats while their spatial distance decreases, align them on one readable axis, permit exactly one convergence event, and end on a third shared result that neither system produced alone.

## Invariants

### inv-01

- Rule: Give each system an independent establishing proof.
- Purpose: Prevents color alone from carrying identity.
- Failure if removed: Immediate collision makes the systems interchangeable.

### inv-02

- Rule: Keep material physics and cadence distinct before convergence.
- Purpose: Makes alternation informative.
- Failure if removed: Shared motion grammar erases opposition.

### inv-03

- Rule: Reduce one visible spatial gap across matched views.
- Purpose: Creates measurable progress.
- Failure if removed: Random angles obscure whether convergence is approaching.

### inv-04

- Rule: Allow only one terminal meeting event.
- Purpose: Protects anticipation and causal clarity.
- Failure if removed: Repeated clashes dilute the payoff.

### inv-05

- Rule: Leave a persistent third-state consequence.
- Purpose: Proves both inputs affected the result.
- Failure if removed: A flash followed by reset provides no outcome evidence.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original subject or system whose identity remains stable. |
| setting | A new setting with fixed spatial anchors. |
| escalation_variable | One visible variable that changes in countable causal stages. |
| performance_rule | A restrained behavior rule that makes the mechanism legible. |
| camera_grammar | A coherent information order that does not copy source shot boundaries. |
| payoff | One clean physical or graphic consequence. |
| sound_family | A new hierarchy of diegetic cues supporting state changes. |

## Required Human-Facing Anchors

- 两个系统先独立成立
- 材质或运动规则明确不同
- 只发生一次关键汇聚
- 第三状态同时保留双方证据

## Anti-Copy Boundary

- two female elemental warriors
- fire magic versus ice magic
- ruined stone arena at sunset
- weapons, petals and the source mid-air collision pose

   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
