# 计划对照｜固定分镜条见证执行升级 — 摘要

## 用途

让一条静态计划板持续可读，执行区按计划顺序逐步完成动作，并用不断累积的现场变化证明执行正在推进；最后让实际结果与计划末项形成可读闭合。

## 推荐输入格式

`持续可读的计划板 + 独立执行区 + 计划顺序推进 + 至少三项可见状态变化 + 计划与终态同框`

## 可直接改写的简短示例

> 原创极地微缩观测站内，左侧五格黄铜任务计划条始终完整可读，右侧较大执行区建立陶瓷勘测自动机、三座冰晶站、倾斜透镜和折叠信标；自动机支撑身体并把透镜旋到正确轴线，冰面出现一条细琥珀反射；左侧计划条仍固定；信标发出一道稳定蓝白光柱并与计划条最后一格对齐；自动机、三座完成站和完整计划条同框停留

## 必须保留的结构锚点

- Establish one persistent planning artifact and one separate execution field in the opening.
- Advance the execution field while keeping the planning artifact unchanged and readable.
- Accumulate at least two further state changes while preserving subject identity, route and plan visibility.
- Hold a terminal result with the persistent plan still visible for direct comparison.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
