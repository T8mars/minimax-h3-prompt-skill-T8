# 计划对照｜固定分镜条见证执行升级 Template

## Mechanism

Keep one compact planning artifact continuously visible and spatially stable while a larger execution field performs the planned stages in order. Let the execution accumulate real state changes and increasing consequence while the plan remains unchanged as an audit reference, then hold a terminal result that can be compared directly with the plan's final duty.

## Invariants

### inv-01

- Rule: Establish one persistent planning artifact and one separate execution field in the opening.
- Purpose: Creates an explicit plan-versus-result comparison.
- Failure if removed: A hidden or late plan turns the sequence into ordinary action footage.

### inv-02

- Rule: Advance the execution field while keeping the planning artifact unchanged and readable.
- Purpose: Makes progress measurable against a stable reference.
- Failure if removed: Changing both layers together destroys the audit relationship.

### inv-03

- Rule: Convert one planned action into a visible physical consequence inside the execution field.
- Purpose: Proves that the plan is being realized rather than merely displayed.
- Failure if removed: Decorative motion without consequence cannot establish execution.

### inv-04

- Rule: Accumulate at least two further state changes while preserving subject identity, route and plan visibility.
- Purpose: Builds escalation without losing correspondence.
- Failure if removed: Disconnected spectacle makes plan and result impossible to compare.

### inv-05

- Rule: Hold a terminal result with the persistent plan still visible for direct comparison.
- Purpose: Closes the plan-to-execution evidence chain.
- Failure if removed: Removing the plan before the result abandons the defining proof.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Establish one persistent planning artifact and one separate execution field in the opening.
- Advance the execution field while keeping the planning artifact unchanged and readable.
- Accumulate at least two further state changes while preserving subject identity, route and plan visibility.
- Hold a terminal result with the persistent plan still visible for direct comparison.
