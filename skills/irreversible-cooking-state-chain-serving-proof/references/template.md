# 烘焙状态链变体｜面团、铺料、入炉、成品与分享连续证明 Template

## Mechanism

This is an evidence variant of the existing irreversible cooking state chain. Lock one original clearly adult cook, one kitchen, one dough or base, one tray and visible hand or tool anchors. Move through at least five irreversible food states, one operation per beat, while preserving outline, topping distribution, residue and container continuity. Oven or heat transitions must return the same tray and a plausibly changed version of the same item. End with the same serving and one restrained taste by the same adult. Do not copy source woman, kitchen, pizza, ingredients, recipe, lighting, camera or timing.

## Invariants

### inv-01

- Rule: Lock one clearly adult original cook, one base material, tray, kitchen and hand anchors.
- Purpose: Creates identity and material continuity.
- Failure if removed: Changing tray or hands makes the item unverifiable.

### inv-02

- Rule: Apply exactly one irreversible operation per beat.
- Purpose: Keeps state progression readable.
- Failure if removed: Hidden multi-step jumps weaken causality.

### inv-03

- Rule: Preserve outline, residue and topping or component distribution between states.
- Purpose: Proves the same item continues.
- Failure if removed: Rearranged components imply a replacement.

### inv-04

- Rule: Return the same tray after heat with plausible color, volume and texture change.
- Purpose: Makes cooking transformation credible.
- Failure if removed: A different tray or impossible state breaks material proof.

### inv-05

- Rule: End with the same serving and one restrained taste by the same adult.
- Purpose: Closes process with human proof.
- Failure if removed: An unrelated plated beauty shot loses continuity.
