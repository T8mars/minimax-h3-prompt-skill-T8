# 空场异常｜物质扩张与片名停留 — 摘要

## 用途

先建立有序空场和一个物件，再让单一材质异常扩散并留给标题空间。

## 推荐输入格式

`有序空场＋锚定物件＋单一异常＋原创片名`

## 可直接改写的简短示例

> 无人小天文台、一台黄铜望远镜、其下的一张纸质星图；望远镜目镜处出现唯一连续霜线。

## 必须保留的结构锚点

- 异常有起点
- 变化后证据持续存在
- 标题不被误写成异常产物

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
