# 移动兑现｜载具跃迁到生活结果 — 摘要

## 用途

用极短篇幅把载具身份、出发、性能跃迁、地理抵达和人的最终使用结果串成一条因果链；技术奇观必须被具体生活结果兑现，结尾不能停在无目的飞驰。

## 推荐输入格式

`载具与起点 + 1次改变通行方式的能力跃迁 + 可追踪路线 + 抵达物微距 + 人物实际使用结果`

## 可直接改写的简短示例

> 河上医疗小艇离开太阳能诊所，展开水翼穿越芦苇浅水区，抵达淹水村庄；微距展示冷却药剂胶囊，最后由护士把胶囊装入受损幼苗培养器。

## 必须保留的结构锚点

- Establish the carrier and departure point before accelerating the route.
- Use one visible capability upgrade that changes how the carrier traverses space.
- Present the delivered object or service in tactile close detail at arrival.
- End with a beneficiary visibly using the result.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
