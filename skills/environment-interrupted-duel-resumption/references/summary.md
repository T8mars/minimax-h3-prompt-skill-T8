# 环境介入对决｜攻防交换、外力中断与原位复战 — 摘要

## 用途

先在同一危险环境中建立两名成年对手和可读攻防轴，让风、雨和载体摇摆逐步改变脚步；一次强烈环境事件必须同时打断双方，双方恢复站位后沿原轴继续交锋。

## 推荐输入格式

`两名明确成年原创对手和固定攻防轴 + 可见环境运动持续改变双方脚步与平衡 + 一次强烈外部事件同时中断双方且地理不重置 + 两人从可见受阻位置恢复 + 沿原轴重新交锋并保持未决，不虚构胜负`

## 可直接改写的简短示例

> 把两名明确成年原创对手置于雨夜飞艇维修桥：穿青铜护甲的工程师持短矛，对面石板灰外套的导航员持钩杖。；逐步加强横风与桥面滚转，后续每个动作都需要可见脚步修正，并让手触碰同一护栏。；两人从原位置起身，重新构成中心线并再交换一轮兵器，随后在准确原创标题【BRIDGE WEATHER】下保持未决。

## 必须保留的结构锚点

- Two clearly adult original opponents, one fixed conflict axis and three environmental anchors establish the duel.
- Every attack, evade and block remains readable while environmental force progressively changes balance.
- Both adults recover from visible post-interruption positions before any renewed attack begins.
- The terminal exchange returns to the original axis and remains unresolved without inventing a winner.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
