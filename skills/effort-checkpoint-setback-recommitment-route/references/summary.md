# 训练复投｜计时检查触发受挫后重新上路 — 摘要

## 用途

先用持续路线动作证明真实投入，再切到一个可量化检查点；检查结果触发短暂失望和生理残余，但角色不直接获得能力升级，而是完成一个有限恢复动作、重新面向同一路线，并以黄昏停留和坚定表情把失败转化为下一轮承诺。

## 推荐输入格式

`成年训练者持续定向努力 + 同目标的第二种机械动作 + 努力后才出现的可量化检查点 + 受挫生理残余 + 1次有边界恢复 + 重返同一路线 + 实际重置与未来承诺而非瞬间胜利`

## 可直接改写的简短示例

> 明确成年的学员穿中性橙色训练夹克，沿长标记通道拖动配重水带，脚步、肩部负荷和急促呼吸可读；完成两段努力后，她只查看一次数字计时器；未达阈值后面部紧张、眼睛湿润，急促呼吸仍在；她只喝一次水，盖好瓶盖，收紧两只手套并稳定望向同一通道

## 必须保留的结构锚点

- Prove sustained effort in one directional physical task before showing a result.
- Add a second mechanically different exercise that serves the same objective.
- Keep brief physiological residue through one bounded recovery action, then visibly re-enter the same route or task.
- End with a practical reset and steady commitment, not an immediate victory or power upgrade.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
