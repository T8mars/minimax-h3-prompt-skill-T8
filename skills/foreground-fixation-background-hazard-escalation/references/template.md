# 前景执念对抗背景灾难｜危险升级但微小任务不断线 Template

## Mechanism

Lock one original clearly adult protagonist and one small repeatable foreground task in a dangerous environment. Keep the task object visible and the hands or gaze continuously recoverable while background hazards escalate through at least three distinct proximity levels. Let each hazard force only the minimum physical adjustment required for survival, then return the adult to the identical task before the next escalation. Reserve the largest body displacement for one near-contact event without letting the task object disappear or change state. End after the hazard passes with the adult visibly resuming the same task, proving that fixation—not invulnerability—is the comic constant. The reusable mechanism is foreground task persistence, background-scale escalation, minimal avoidance, one near-contact peak and immediate behavioral reset—not the source man, face, armor, phone, battlefield, arrows, fire, exact camera, gestures, creator identity or timing.

## Invariants

### inv-01

- Rule: Establish one clearly adult original protagonist and one small repeatable foreground task before hazards escalate.
- Purpose: Provides a stable behavioral baseline against which danger can be measured.
- Failure if removed: Starting with chaos makes the fixation unreadable.

### inv-02

- Rule: Escalate at least three hazards from background activity to near contact while keeping their direction legible.
- Purpose: Builds a proximity ladder rather than random spectacle.
- Failure if removed: Equal-intensity hazards create no comic progression.

### inv-03

- Rule: After each hazard, return hands and gaze to the same task object.
- Purpose: Makes fixation a repeated action instead of a one-time prop joke.
- Failure if removed: Switching tasks breaks the behavioral pattern.

### inv-04

- Rule: Use the minimum avoidance needed until one near-contact peak causes the largest body displacement.
- Purpose: Preserves contrast while giving the escalation a climax.
- Failure if removed: Large reactions too early flatten the ladder.

### inv-05

- Rule: End with the adult resuming the task after danger passes, not celebrating or defeating the threat.
- Purpose: Closes on behavioral persistence rather than heroics.
- Failure if removed: A victory pose changes the mechanism into action competence.
