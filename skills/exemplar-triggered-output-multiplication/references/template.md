# 样本倍增｜机器开启后连续输出同类群体 Template

## Mechanism

Place one unmistakable exemplar beside or on a closed production device and keep both readable. Use one visible trigger, then require the device to expose a separate output threshold before any result appears. Release matching instances one at a time through that same threshold while the exemplar remains unchanged as a comparison anchor. Accumulate the outputs in visible space and finish with exemplar, device, threshold and group readable together.

## Invariants

### inv-01

- Rule: Establish one identity exemplar and one closed production device in the same readable frame.
- Purpose: Defines what the outputs must match and where they originate.
- Failure if removed: Without an exemplar, repeated outputs have no identity reference.

### inv-02

- Rule: Use one visible trigger and show a distinct output threshold opening before the first result.
- Purpose: Creates an auditable machine-state transition.
- Failure if removed: Results appearing before the threshold opens look arbitrary.

### inv-03

- Rule: Release one matching instance through the threshold while keeping the exemplar unchanged.
- Purpose: Proves the first multiplication event.
- Failure if removed: Replacing the exemplar with the output is transformation, not multiplication.

### inv-04

- Rule: Repeat one-at-a-time outputs through the same threshold and accumulate them in visible space.
- Purpose: Makes quantity growth countable and causal.
- Failure if removed: A sudden crowd cut hides the repeated production rule.

### inv-05

- Rule: Hold exemplar, device, open threshold and accumulated outputs together.
- Purpose: Closes identity and scale verification in one frame.
- Failure if removed: Ending on the crowd alone discards origin proof.
