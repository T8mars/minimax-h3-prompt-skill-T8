# 标志入境｜穿行世界后回收到原形 Template

## Mechanism

Open on one compact emblem whose geometry, palette and directional cue become the construction rules of an inhabitable world. Move through at least two spatial proofs, include one readable occupant or functional checkpoint, then perform one large scale change that gathers the world's repeated geometry. Reconstruct the same opening emblem from those visible components and hold it as the terminal state.

## Invariants

### inv-01

- Rule: Begin with one compact emblem that clearly defines geometry, palette and direction.
- Purpose: Creates a traceable generative rule.
- Failure if removed: A generic abstract opening cannot govern the later world.

### inv-02

- Rule: Expand the emblem into a navigable environment using repeated versions of its own components.
- Purpose: Proves world construction rather than a logo cutaway.
- Failure if removed: Unrelated buildings and colors break lineage.

### inv-03

- Rule: Include one readable inhabitant or functional checkpoint inside the expanded world.
- Purpose: Gives the journey a concrete spatial stop.
- Failure if removed: Pure fly-through spectacle lacks an interior proof.

### inv-04

- Rule: Use one major scale change to gather the environment into a simplified global form.
- Purpose: Prepares a causal return to the origin.
- Failure if removed: A random zoom-out does not explain reconstruction.

### inv-05

- Rule: End by rebuilding and holding the same opening emblem from visible world components.
- Purpose: Closes the geometric loop.
- Failure if removed: A new logo or unrelated title card discards the accumulated world.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |
