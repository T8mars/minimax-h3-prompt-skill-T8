# 连续变线｜逐层防守到垂直终结 — 摘要

## 用途

先固定球场、球与篮筐关系，让持球者连续穿过多层可见防守门，每次用不同路线变化解决空间问题；最后只做一次垂直篮筐动作，并用人群反应与共享场地收束。

## 推荐输入格式

`稳定主体与手持物 + 固定终点 + 至少3道可见空间门 + 每次不同变线 + 单次垂直终结 + 不虚构比分的反应终态`

## 可直接改写的简短示例

> 轨道温室快递无人机携带发光种子胶囊，依次压低、变线和侧滚穿过三道不同风幕，只借最终上升气流完成一次上方对接；两名植物学家隔窗反应，结尾不出现比分或胜负文字。

## 必须保留的结构锚点

- Establish one stable carrier, handled token and fixed terminal goal before escalation.
- Use at least three visible spatial gates, each requiring a different route change.
- Use the last route opening for one decisive vertical terminal action.
- End on visible witness reaction and shared geography without asserting an unshown numerical result.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
