# 连续变线｜逐层防守到垂直终结 Template

## Mechanism

Build a short action proof around successive spatial gates: establish one carrier, one handled token and a fixed terminal goal; let each visible blocker force a different route change while preserving shared geography; convert the final opening into one decisive vertical terminal action; then hold a separate witness reaction without inventing an unshown numerical result.

## Invariants

### inv-01

- Rule: Establish one stable carrier, handled token and fixed terminal goal before escalation.
- Purpose: Creates a measurable route problem.
- Failure if removed: Without all three anchors, later movement reads as disconnected athletic montage.

### inv-02

- Rule: Use at least three visible spatial gates, each requiring a different route change.
- Purpose: Turns progression into spatial problem solving.
- Failure if removed: Repeated identical dodges do not create escalating proof.

### inv-03

- Rule: Preserve the carrier, token and terminal direction across every route change.
- Purpose: Maintains action continuity.
- Failure if removed: Losing the token or goal axis breaks the causal route.

### inv-04

- Rule: Use the last route opening for one decisive vertical terminal action.
- Purpose: Converts horizontal escalation into a readable payoff transition.
- Failure if removed: Multiple terminal attempts diffuse the climax.

### inv-05

- Rule: End on visible witness reaction and shared geography without asserting an unshown numerical result.
- Purpose: Keeps the ending evidence-bounded.
- Failure if removed: A scoreboard or victory claim would exceed the visible proof.
