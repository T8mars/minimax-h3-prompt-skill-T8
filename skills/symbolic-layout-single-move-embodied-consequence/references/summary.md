# 符号布局单步改写｜空间揭示、手部决策与实体后果 — 摘要

## 用途

从贴近符号阵列的低位穿行开始，让观众先把小型布局当作世界；随后揭示一个与布局绑定的巨大实体，一只外部之手只改变一个关键标记，最后用实体的单一状态变化证明这一小步已改写更大系统。

## 推荐输入格式

`从原创符号阵列内部低位穿行 + 揭示与阵列绑定的更大实体或系统 + 外部手或操纵器进入且周围标记保持稳定 + 只移动一个可识别标记并显示接触 + 以更大系统的单一克制状态变化证明后果`

## 可直接改写的简短示例

> 镜头贴近桌面，在磨砂玻璃透镜标记之间低位前行，远处全尺寸灯塔引擎保持沉睡；一名明确成年技术员的绝缘手套从上方进入，悬停在一枚黑曜石透镜盘上，其余标记完全不动；全尺寸灯塔引擎只打开一只光圈，向同一室内投射一束白光，并保持改变后的状态

## 必须保留的结构锚点

- Travel through an original symbolic layout at marker height before revealing its larger system.
- Bind the layout to one much larger entity, machine or environment in a single wide reveal.
- Change exactly one clearly identifiable marker and show contact.
- End on one restrained state change in the bound system.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
