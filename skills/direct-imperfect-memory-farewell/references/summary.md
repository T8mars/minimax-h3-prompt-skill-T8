# Imperfect-Memory Farewell Take — 摘要

## 风格与机制

一个并不完美的连续观察者，在日常空间里迟一步发现已经做事的主体；镜头耐心保留几个没有表演感的小动作，再由一个外部环境信号改变主体目标。临近离场时只发生一次对摄影者的短暂回应，随后主体沿已建立路线离开，录像以一次由操作者注意力造成的轻微失误收束。

## 适用范围

- 家庭录像、生活切片、怀旧记忆、温柔告别、低强度 found-footage
- 需要无对白建立人物关系和情绪的 15 秒单镜头
- 依靠环境、日常动作和摄影者存在感推进的短片

## 不适用范围

- 全程摆拍或不断看镜头
- 模拟缺陷始终满强度，遮住关键动作
- 外部信号与离场没有因果关系
- 只把来源交通场景换成另一个车站

## 使用方法

1. 先建立可连续拍摄的日常空间和出口。
2. 给主体安排至少两个地点原生的小动作。
3. 选择一个真实进入空间、会改变目标的外部信号。
4. 把唯一一次眼神、点头、手势或玩笑放在离场前。
5. 让失焦、过曝、变焦或落幅失误对应摄影者的真实修正。
6. 同时改变地点类别、人物关系、日常动作、信号机制、媒介格式和离场行为。

## 可变槽位

| 槽位 | 约束 |
|---|---|
| memory_medium | 一个年代明确、缺陷克制的消费级记录媒介。 |
| everyday_place | 支持单镜头路线的连贯日常空间。 |
| subject_identity | 外观、服装和与摄影者关系稳定的原创人物。 |
| routine_actions | 两到三个地点原生的小动作。 |
| external_cue | 一个可见或可听、能改变目标的环境事件。 |
| acknowledgment | 临近离场的一次眼神、点头、手势或共同玩笑。 |
| exit_path | 穿过已建立空间的连续离开路线。 |
| operator_mistake | 可读的失焦、变焦、构图或结束失误。 |
