# 日常任务到呼吸复位｜前景过渡、静坐微动与继续离场 — 摘要

## 用途

同一明确成年人先完成一个普通触觉任务，再由前景物或建筑边界把动作段过渡到静坐段；人物只做一次慢呼吸、微笑与细微头发衣料变化，摄影克制推进。复位完成后，人物沿既定方向重新起身离场，证明静默不是终点。

## 推荐输入格式

`一名明确成年原创主体以至少三项身份锚点先完成一个普通触觉任务 + 用一个真实前景物、门框或建筑边缘过渡到独立休息地理 + 准确展示一次慢呼吸和至少两项头发、服装、植物或光线微响应 + 呼吸期间摄影只做克制慢推或静止 + 同一成年人复位后沿既定方向穿过可见出口`

## 可直接改写的简短示例

> 原创明确成年夜班烘焙师佩戴铜色发夹、海军蓝围裙和白色袖条，在暖色服务走廊把一个面粉袋扎紧；触觉结扣完整完成。；成年人坐在石台上，铜发夹、海军蓝围裙和白袖条不变；先建立香草、悬挂布和一个服务门，再进入静止。；同一成年人起身，恢复从左向右行走，带着面粉袋标签穿过已建立服务门；不复制来源女人、白布、自行车、长椅、蕨类、砖门和准确构图。

## 必须保留的结构锚点

- Lock one clearly adult original subject and complete one ordinary tactile task before rest.
- Use one natural foreground or architectural edge to transition into a distinct rest geometry.
- Restrict camera movement during the breath to one slow push or hold.
- After rest, resume the same adult's movement and cross a visible exit threshold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
