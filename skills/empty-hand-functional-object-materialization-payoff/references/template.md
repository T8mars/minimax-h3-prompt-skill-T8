# 显物兑现｜空手基线到道具功能与终态回扣 Template

## Mechanism

Establish one adult subject, both visibly empty hands and one stable environment before any effect. Use exactly one attributable trigger to assemble one functional object in readable stages between the same hands; keep subject identity, hand ownership and geography continuous. Require immediate functional use, then let one environmental variable accumulate in response to that use. End with the object still present and one secondary state change visibly tied to the completed action. The reusable mechanism is empty-hand proof, staged materialization, functional payoff and terminal callback, not the source man, suit, guitar, electricity, roses, fog, petals, exact orbit, creator wording or model branding.

## Invariants

### inv-01

- Rule: Show both hands empty long enough to establish one unambiguous baseline.
- Purpose: Makes later materialization visually provable.
- Failure if removed: Beginning with effects or a hidden hand turns appearance into an assumption.

### inv-02

- Rule: Use one visible trigger and one staged assembly path for a single object.
- Purpose: Gives object formation an attributable cause and readable continuity.
- Failure if removed: Instant replacement or multiple unexplained objects becomes a generic transformation montage.

### inv-03

- Rule: Keep the same subject, hand ownership and environment continuous while the object forms.
- Purpose: Prevents identity or prop swapping from faking the mechanism.
- Failure if removed: A cut to another holder breaks causal ownership.

### inv-04

- Rule: Make the completed object perform its defining function immediately.
- Purpose: Converts materialization into narrative utility.
- Failure if removed: A formed but unused prop is only spectacle.

### inv-05

- Rule: End with the object still present and one function-linked secondary state change.
- Purpose: Provides persistent proof and a terminal callback.
- Failure if removed: Making the object vanish or adding an unrelated makeover abandons the causal chain.
