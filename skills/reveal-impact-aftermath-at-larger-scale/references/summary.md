# 冲击后揭示｜从私密困境到城市尺度真因 — 摘要

## 用途

先在狭小受保护空间建立私密困境，再让巨大外力突然移动承载体；局部撞击与长停留反应证明后果，最后广角揭示城市尺度真因。

## 推荐输入格式

`受困主体 + 外力移动承载体 + 局部撞击证明 + 反应停留 + 广角真因揭示`

## 可直接改写的简短示例

> 玻璃修复师在狭小修复舱内固定器皿，压力波把整舱推过被淹大厅；撞上软缓冲后长停留反应，最后揭示中庭上方巨型水族箱破裂。

## 必须保留的结构锚点

- Begin with an intimate confined baseline before the large event.
- Let one external force visibly displace the established carrier.
- Hold one post-impact reaction after motion stops.
- Reveal the larger cause only after local consequence is clear.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
