# 实体字台表演｜人物接触、标点搬运与新词接力 — 摘要

## 用途

把巨型原创字形作为真实舞台结构，成年人必须以倚靠、穿越或搬运标点证明物理接触；一个可拆组件完成转场后，人物和造型变化但字形规则保持。

## 推荐输入格式

`成年表演者＋实体字形舞台＋可拆组件＋新词接力`

## 可直接改写的简短示例

> 两名成年舞者、泡棉字词、可滚动圆点、两个原创短词。

## 必须保留的结构锚点

- 字形必须表现真实物理接触
- 一个组件承担换章
- 最终恢复完整可读字标

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
