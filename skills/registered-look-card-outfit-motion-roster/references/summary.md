# 时装定版卡｜同一模特、造型轮换与动作证明 — 摘要

## 用途

锁定同一成年模特和注册版式，每套造型先以全身卡建立，再用一步或转身证明衣物运动；卡片编号只承担比较，终局把多套造型汇成同一系列。

## 推荐输入格式

`同一成年模特＋固定造型卡＋多套服装＋动作证明`

## 可直接改写的简短示例

> 成年原创模特、四张注册造型卡、青色外套、沙色套装、钴蓝裙装、铜色工装。

## 必须保留的结构锚点

- 人物身份与卡片版式不变
- 每套服装有独立动作证明
- 终局并排比较全部造型

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
