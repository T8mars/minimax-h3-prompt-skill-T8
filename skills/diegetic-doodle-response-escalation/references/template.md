# 画内涂鸦｜现实互动逐步绘出隐藏世界 Template

## Mechanism

Use an embodied observer and one responsive subject to author a diegetic drawing layer through visible real-world actions. Each interaction must add one new surface-anchored symbol that echoes the local object or motion, and later symbols must reuse or connect earlier marks. Escalate from single icon to route, hidden figure and local reflection, then end wide enough to prove the accumulated drawings have become one coherent environment-wide system.

## Invariants

### inv-01

- Rule: Establish one embodied observer, one responsive subject and the first surface-bound drawing triggered by visible interaction.
- Purpose: Defines who authors the graphic layer and where it belongs.
- Failure if removed: Unmotivated floating stickers make the effect decorative.

### inv-02

- Rule: Use a second real action to extend the drawing rule onto a different local surface or route.
- Purpose: Proves that the graphic response follows physical behavior.
- Failure if removed: Repeating the same icon over the same hand never builds a world.

### inv-03

- Rule: Let accumulated drawings direct attention toward one hidden or newly opened area.
- Purpose: Turns symbols into spatial storytelling.
- Failure if removed: Random icons with no search function cannot hand off to discovery.

### inv-04

- Rule: Reveal one new local figure or motif that visibly inherits an earlier line family.
- Purpose: Creates graphic continuity across separate interactions.
- Failure if removed: A completely unrelated illustration breaks the accumulated system.

### inv-05

- Rule: End on a wider view where prior symbols connect into one coherent environment-wide drawing layer.
- Purpose: Pays off local marks as a transformed world.
- Failure if removed: Ending on a single sticker or close-up leaves the escalation incomplete.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Transfer Tests

1. In an original glasshouse, a first-person botanist follows a brass maintenance beetle. Touching a dew valve creates one cyan leaf glyph, the beetle rolling a seed capsule draws a route line, opening a propagation drawer reveals an ink moth, and the final wide links leaves, routes, valves and weather symbols across the entire greenhouse skeleton.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family

A tap on a star block creates a stitched orbit mark, the rover's wheel draws a constellation path, opening a supply pouch reveals a paper fish motif, and the final cabin wide connects all marks into a navigable story-world map.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
