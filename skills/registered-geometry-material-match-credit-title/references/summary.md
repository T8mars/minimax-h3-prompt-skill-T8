# 几何注册匹配片头｜平面路径、实体面板与终局印记 — 摘要

## 用途

先建立可精确注册的二维线网和一个颜色锚点，让书写工具沿网格揭示第一条职员表；在同一构图接缝处把线网匹配成实体孔阵并揭示第二条职员表，随后让同一颜色锚点吸收一个关键物件、发生一次实体开裂，最后把材质铺满画面并稳定承载原创主标题。

## 推荐输入格式

`至少三个稳定几何交点与一个颜色锚点 + 工具动作揭示第一条原创职员表 + 相同屏幕坐标精确匹配到不同实体材质 + 光或阴影揭示第二条原创职员表 + 颜色锚点接收一个主题物并发生一次触觉变化 + 材质铺满并稳定承载原创主标题`

## 可直接改写的简短示例

> 俯拍象牙等高线，三个稳定交点和琥珀测量点先清楚出现；钢制制图笔沿线揭示原创文字 CREATED BY LENA ORR；回到俯拍浅色注册面，一枚原创黄铜音叉位于同一琥珀圆形锚点中心；琥珀陶瓷纹理铺满画面并平整成标题底，大型原创文字 NORTH ARRAY 清楚显现并稳定停留

## 必须保留的结构锚点

- Establish at least three stable geometry intersections and one color anchor before the first credit.
- Reveal one short original credit through a tool action while preserving the geometry.
- Return the color anchor around one original motif object and perform one tactile transformation.
- Fill the frame with the transformed material and hold one large original master title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
