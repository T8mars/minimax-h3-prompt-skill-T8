# 形态奇观｜平面升级到现实 — 摘要

## 用途

同一载体从平面、空间、体积一路升级到环境峰值，再回到原位留下残留。

## 推荐输入格式

`现实锚点 + 单一载体 + 平面→空间→体积→环境峰值 + 回到原位的残留`

## 可直接改写的简短示例

> 桌上的咖啡杯保持原位，蒸汽先变成平面线条，再成为空间丝带和立体水流，扩展成充满房间的雾海，最后回到杯口只留一滴发光水珠。

## 必须保留的结构锚点

- 同一载体贯穿
- 形态按维度升级
- 峰值改变环境
- 回到初始锚点并留下残留

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
