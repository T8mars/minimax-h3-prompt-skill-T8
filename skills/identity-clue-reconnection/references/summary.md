# 身份线索回连｜局部累积到主体确认 — 摘要

## 用途

先用一致的局部线索建立身份，再回到已见过的面部标记完成确认。

## 推荐输入格式

`主体＋三项可复认的局部线索＋最终回连`

## 可直接改写的简短示例

> 原创成年海上灯塔维修员；深蓝工作服、普通透明护目镜、沾盐手套、腕部罗盘、肩部安全绳全程固定。晨光下同一座海上灯塔和同一盏信标。

## 必须保留的结构锚点

- 同一主体
- 局部线索相互一致
- 结尾回连已见标记

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
