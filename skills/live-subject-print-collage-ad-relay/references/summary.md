# 实拍印刷层接力｜人物、商品细节与字卡共同推进 — 摘要

## 用途

先用一名明确成年主体和一套稳定服装锚点建立实拍身份，再让撕纸边缘、印刷纹理和短字卡依次进入同一画面。每个拼贴层都必须与人物动作、服装部件或环境转场发生可见交接，而不是盖住主体；镜头在全身、材质微距、图形海报和多人陈列之间改变职责，最后把前面出现的身份、细节和短语汇总成一张清楚停留的终局版面。

## 推荐输入格式

`明确成年原创广告主体与至少三项稳定身份/服装锚点 + 统一纸张/撕边/墨色系统通过动作、细节或注册边缘进入 + 全身证明与至少两个材质微距接力 + 至少两种明显不同海报版式但身份和信息层级不漂移 + 短字只解释相邻证据 + 汇总已证明人物、细节和文字形成终局广告页并停留`

## 可直接改写的简短示例

> 成年现场工程师在港口工作间穿石板灰夹克，青色技术纸边与肩线对齐并揭示“海岸就绪”；同一成年人经过风力测试架并收紧袖口，动作拉出撕纸遮罩，把全身姿态转换成双栏海报；人物肖像、三个已证明细节和“现场验证”汇总为单张广告页并停留

## 必须保留的结构锚点

- Establish one clearly adult original subject with at least three stable identity and wardrobe anchors before the first print conversion.
- Use one coherent print-material system and let each new layer enter through a visible action, detail or registered spatial edge.
- Use at least two substantially different poster layouts while preserving subject, wardrobe and message hierarchy.
- Gather previously proven subject, details and concise messages into one final held campaign sheet.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
