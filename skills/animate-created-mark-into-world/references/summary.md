# 画中物成真｜小光点变奇观 — 摘要

## 用途

被创作的小标记获得自主性，跨出实体边界，扩张并改变真实环境。

## 推荐输入格式

`被创作的小标记 + 获得自主性 + 越过实体边界 + 扩大/复制 + 改变环境`

## 可直接改写的简短示例

> 刺绣布上的银色小鹤先眨眼，随后从布面跨出，复制成一群微光纸鹤，绕舞台飞行并重新点亮整片空间。

## 必须保留的结构锚点

- 起点明确是被创作的标记
- 先出现自主动作
- 必须跨过真实边界
- 扩张后改变环境而非只放大

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
