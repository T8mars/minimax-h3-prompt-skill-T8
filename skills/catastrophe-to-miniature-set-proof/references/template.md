# 灾难幻象拆台｜环境吞没、尺度破绽与微缩片场证明 Template

## Mechanism

先让列车、海岸与建筑共享一个可信地理，再让巨浪沿同一轴线逐层吞没铁路和街区；水雾遮满画面后揭开微缩布景、轨道摄影机、操作人员与水槽，让最后一层明确解释前面的灾难效果。 The reusable mechanism preserves causal order, spatial anchors and the final proof while replacing every source-specific person, location, object, wording, choreography and design.

## Invariants

### inv-01

- Rule: One fictional geography and at least three repeated scale anchors are established before the hazard grows.
- Purpose: Establishes the baseline identity, object or geography that every later state must preserve.
- Failure if removed: Without this exact baseline rule, later changes cannot be attributed to the same subject, object or place, so the sequence loses its reference state. Removed rule: "One fictional geography and at least three repeated scale anchors are established before the hazard grows."

### inv-02

- Rule: The catastrophe advances through the same geography in a readable order rather than resetting locations.
- Purpose: Makes the visible trigger precede and explain the first mechanism response.
- Failure if removed: Without this exact trigger rule, the response appears spontaneously and the central cause-and-effect claim is no longer demonstrated. Removed rule: "The catastrophe advances through the same geography in a readable order rather than resetting locations."

### inv-03

- Rule: One full-frame physical occlusion bridges the fictional event to the production layer.
- Purpose: Keeps the middle progression registered instead of allowing an unexplained reset.
- Failure if removed: Without this exact progression rule, the middle can jump to a replacement state and the accumulated result is no longer traceable. Removed rule: "One full-frame physical occlusion bridges the fictional event to the production layer."

### inv-04

- Rule: The revealed set contains at least three legible production cues that causally explain the preceding effect.
- Purpose: Reconnects the changed or partial state to the established subject and spatial anchor.
- Failure if removed: Without this exact reconnection rule, detail or transformed shots can belong to a different subject or geography and continuity cannot be verified. Removed rule: "The revealed set contains at least three legible production cues that causally explain the preceding effect."

### inv-05

- Rule: A monitoring layer preserves the opening fiction and confirms the miniature-to-image relationship.
- Purpose: Turns the terminal hold into observable proof that the mechanism completed.
- Failure if removed: Without this exact terminal-proof rule, the sequence stops on motion alone and never confirms the promised outcome or preserved aftermath. Removed rule: "A monitoring layer preserves the opening fiction and confirms the miniature-to-image relationship."

## Anti-Copy Boundary

- all source faces, bodies, wardrobe, identities and creator-specific character designs
- the source location, set dressing, props, products and exact environmental geometry
- all source words, logos, watermarks, typefaces and brand identifiers
- the source choreography, exact camera path, shot durations and transition timing
- the source palette, signature effects, prompt wording, creator handle and narrative particulars
