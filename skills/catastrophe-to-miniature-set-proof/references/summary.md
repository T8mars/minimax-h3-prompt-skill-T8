# 灾难幻象拆台｜环境吞没、尺度破绽与微缩片场证明 — 摘要

## 用途

先让列车、海岸与建筑共享一个可信地理，再让巨浪沿同一轴线逐层吞没铁路和街区；水雾遮满画面后揭开微缩布景、轨道摄影机、操作人员与水槽，让最后一层明确解释前面的灾难效果。

## 推荐输入格式

`一个真实尺度灾变状态与可辨认地标 + 灾变过程保持空间因果连续 + 摄影机沿同一轴线逐步拉远并揭示尺度边界 + 场景被证明属于完整微缩装置 + 人手或工作台与模型同框完成终局验证`

## 可直接改写的简短示例

> 建立原创银色单轨列车穿过微缩沙漠天文台的完整地理：一条红色峡谷、三座白色圆顶与固定从左向右的路线。；尘墙依次越过第一座圆顶、吞没轨道，并把一块轻质天线板推向镜头；人物或车辆身份都不改变。；揭示桌面峡谷、两台受控扬尘机、一条运动控制轨道和三名明确成年工作人员剪影；一块监视器保留开场单轨画面，并显示准确短问句【HOW BIG?】。

## 必须保留的结构锚点

- One fictional geography and at least three repeated scale anchors are established before the hazard grows.
- The catastrophe advances through the same geography in a readable order rather than resetting locations.
- The revealed set contains at least three legible production cues that causally explain the preceding effect.
- A monitoring layer preserves the opening fiction and confirms the miniature-to-image relationship.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
