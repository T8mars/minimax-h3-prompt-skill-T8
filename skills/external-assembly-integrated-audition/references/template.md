# 外部装配｜逐件安装到整机动作验收 Template

## Mechanism

Keep one subject and assembly station spatially fixed while a visibly larger external operator installs components in a deliberate order. Alternate local contact proof with repeated whole-subject state checks so every addition accumulates. Reserve fine calibration for after the main silhouette is complete, then require one integrated movement audition that demonstrates all installed parts together before the final hold.

## Invariants

### inv-01

- Rule: Establish one stable subject, assembly station and unmodified baseline.
- Purpose: Provides a state reference for every addition.
- Failure if removed: Without a baseline, later parts cannot be attributed to the operator.

### inv-02

- Rule: Install major components one at a time and return to a whole-subject check after each stage.
- Purpose: Makes accumulation inspectable.
- Failure if removed: A montage of close-ups hides whether parts coexist.

### inv-03

- Rule: Use local contact proof for fine calibration only after the primary structure is complete.
- Purpose: Separates structural assembly from detail tuning.
- Failure if removed: Early fine detail weakens the state ladder.

### inv-04

- Rule: Complete all small functional or decorative components before testing motion.
- Purpose: Prevents the audition from introducing unexplained changes.
- Failure if removed: Late unseen additions break causality.

### inv-05

- Rule: End with one integrated movement audition and a held complete state.
- Purpose: Proves the assembled system works together.
- Failure if removed: A static beauty pose cannot validate integration.
