# 外部装配｜逐件安装到整机动作验收 — 摘要

## 用途

让大尺度外部操作手逐件改变一个稳定主体，每次安装都先用近景证明接合，再回到全身状态确认累积结果；完成细节校准后，必须用一段完整动作测试证明所有部件能共同工作。

## 推荐输入格式

`稳定基础主体 + 分阶段外部装配 + 接合近景与全身复核 + 细节校准 + 整机动作验收`

## 可直接改写的简短示例

> 原创轨道仪器工坊内，一具掌心大小的铜质躯干立在空白校准标记上，两只大型象牙色维修手套安装双腿行走底座；主轮廓完成后，手套安装一支压力探针，并让面罩对齐三条刻度，不新增大型结构；自动机走三步、只展开一次双翼并用探针测量一条可见气流带，所有部件保持连接，最后完整定格

## 必须保留的结构锚点

- Establish one stable subject, assembly station and unmodified baseline.
- Install major components one at a time and return to a whole-subject check after each stage.
- Complete all small functional or decorative components before testing motion.
- End with one integrated movement audition and a held complete state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
