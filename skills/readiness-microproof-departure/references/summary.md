# 载具启程｜微观检查累积到离场证明 — 摘要

## 用途

先建立载具与操作者，再用多个局部检查镜头逐项证明准备状态；一次明确激活把静态部件转成联动运动，最后以远景离场证明整套系统已投入使用。

## 推荐输入格式

`原创操作者与载具 + 至少3项不同准备检查 + 1次明确激活 + 至少2个组件联动 + 广角持续离场证明`

## 可直接改写的简短示例

> 花粉技术员在轨道温室依次检查风标、种子鼓锁扣和磁力脚板，只激活一次巡检车；轮舱与种子鼓联动后沿玻璃轨道启程，并以穿越两段种植舱的高位广角收束。

## 必须保留的结构锚点

- Establish one operator and one inactive carrier in a shared frame.
- Give each close insert a different readiness job rather than repeating beauty details.
- After activation, show at least two components responding in the same causal direction.
- End with sustained travel in a wider spatial proof, not another static close-up.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
