# 载具启程｜微观检查累积到离场证明 Template

## Mechanism

A readiness-to-departure sequence works as a causal proof ladder: establish one operator-carrier pair, isolate several different readiness checks, trigger one visible activation, show components responding together, then leave enough wide travel evidence to prove the carrier has entered service.

## Invariants

### inv-01

- Rule: Establish one operator and one inactive carrier in a shared frame.
- Purpose: Creates a stable identity baseline before detail coverage.
- Failure if removed: Without the baseline, later inserts can look like unrelated machines.

### inv-02

- Rule: Give each close insert a different readiness job rather than repeating beauty details.
- Purpose: Turns montage into accumulated evidence.
- Failure if removed: Repeated decorative close-ups do not prove increasing readiness.

### inv-03

- Rule: Use one decisive visible activation cue that changes the carrier state.
- Purpose: Separates checking from operation.
- Failure if removed: Without a state change the sequence remains a showroom montage.

### inv-04

- Rule: After activation, show at least two components responding in the same causal direction.
- Purpose: Makes the mechanism feel integrated.
- Failure if removed: A single glowing part does not prove system operation.

### inv-05

- Rule: End with sustained travel in a wider spatial proof, not another static close-up.
- Purpose: Confirms deployment and gives the ladder a physical result.
- Failure if removed: A final detail shot leaves departure unproven.
