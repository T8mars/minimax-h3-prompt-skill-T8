# 时尚密度复位｜身份锁定、拼贴回顾与英雄主标 Template

## Mechanism

A clearly adult identity remains locked while action-led foreground carriers rotate through multiple coordinated fashion-and-graphic worlds; visual density climbs to overload, abruptly resets to a sparse full-character interval, then prior states return as a compact collage recap before one simple hero wordmark closes the campaign.

## Invariants

### inv-01

- Rule: Lock one clearly adult original character with at least three stable identity anchors before the first style switch, and preserve those anchors through every wardrobe and layout module.
- Failure if removed: If face, age read, silhouette or signature anchors drift, the montage becomes unrelated models instead of one campaign identity proving range.

### inv-02

- Rule: Every style module must change at least two coordinated channels among wardrobe, palette, layout, prop system and camera duty; a palette swap alone does not count.
- Failure if removed: If only color changes, the progression feels like a filter reel and loses the sense of distinct fashion worlds.

### inv-03

- Rule: Use visible foreground objects, graphic edges or character gestures as motivated handoffs between modules so action, camera and graphic transition occur in the same beat.
- Failure if removed: If modules are connected by arbitrary cuts, the sequence keeps surface variety but loses causal flow and tactile momentum.

### inv-04

- Rule: Escalate visual and typographic density to one peak, then insert a substantially sparser full-character interval before the recap.
- Failure if removed: Without the sparse reset, constant maximal density flattens the rhythm and makes the final escalation feel no stronger than the middle.

### inv-05

- Rule: After the reset, visibly recap at least three earlier states as image fragments or registered panels before resolving to one simple hero lockup.
- Failure if removed: If the hero card arrives without a recap, the ending reads as a disconnected poster rather than a payoff that gathers the campaign's prior evidence.

### inv-06

- Rule: Limit each module to one short original copy unit and preserve a clear subject-copy hierarchy, especially in the held final frame.
- Failure if removed: Dense or malformed copy competes with the character, harms legibility and repeats the source prompt's own stated typography weakness.


## Variable Slots

| Slot | Constraint |
|---|---|
| adult_identity | One original clearly adult subject with at least three stable face, hair, silhouette or accessory anchors. |
| style_modules | At least four worlds that each change two or more coordinated channels, not palette alone. |
| transition_carriers | Foreground props, graphic edges, fabric, gestures or registered panels that motivate each handoff. |
| density_peak | The highest-load module where movement, copy and graphic layers converge without hiding identity. |
| sparse_reset | A full-character low-density interval with restrained camera and effects. |
| recap_system | Contact sheets, specimen cards, panels or fragments that visibly quote at least three earlier states. |
| copy_units | One original short word or phrase per module, plus one simple final name hierarchy. |
| hero_lockup | A held final frame that resolves the stable subject, campaign name and one concise proposition. |
| sound_arc | Original modular beat families, a restrained reset texture and a decisive return cue; complete silence is optional, not required. |

## Required Human-Facing Anchors

- 第一轮切换前先锁定一名明确成年原创角色的至少三项身份锚点，并在全部模块中保持一致。
- 每个造型模块至少同时改变服装、版式、道具、色彩或镜头职责中的两个通道；纯换色不算新模块。
- 所有模块切换都由前景物、图形边、布料或角色手势完成可见交接，并在一个峰值后插入显著低密度的完整人物段落。
- 复位后必须回顾至少三个此前已经出现的状态，再清场到人物、原创名称和一句主张都清楚的英雄主标。

## Anti-Copy Boundary

- Do not use SOLVÉRA, KAWAII IS POWER, any source Japanese/Chinese slogans, Ima Studio or confusingly similar wording.
- Do not reproduce the source heroine's face, hairstyle, body proportions, anime design or exact outfit sequence.
- Do not reuse the Harajuku kawaii accessory inventory, exact pink/cyan/lavender/black/white/hot-pink order or exact source typography layouts.
- Do not reproduce the exact source timing, triptych design, collage geometry, poses, camera path or soundtrack.
- Do not treat the user prompt's self-evaluation sentences as generation instructions or observed evidence.
