# 时尚密度复位｜身份锁定、拼贴回顾与英雄主标

Create a new execution from the reusable mechanism, not a surface reskin of any reference video.

## Workflow

1. Read [references/summary.md](references/summary.md) for fit, input slots, and the concise starting example.
2. Read [references/template.md](references/template.md) completely before drafting.
3. Preserve the user's subject and objective, then fill every missing identity anchor, style module, transition carrier, density reset, recap, copy, sound, and hero-lockup slot.
4. Treat these anchors as mandatory:

- 第一轮切换前先锁定一名明确成年原创角色的至少三项身份锚点，并在全部模块中保持一致。
- 每个造型模块至少同时改变服装、版式、道具、色彩或镜头职责中的两个通道；纯换色不算新模块。
- 所有模块切换都由前景物、图形边、布料或角色手势完成可见交接，并在一个峰值后插入显著低密度的完整人物段落。
- 复位后必须回顾至少三个此前已经出现的状态，再清场到人物、原创名称和一句主张都清楚的英雄主标。

5. Change source-specific people, wardrobe, props, palette, text, layouts, exact timing, sound family, and brand surface together.
6. Compile MiniMax H3 and Seedance 2.0 independently; do not leak one model's field syntax into the other.
7. Silently verify anchor coverage, identity continuity, copy legibility, density contrast, recap provenance, and anti-copy distance before returning final prompts.

## MiniMax H3

- Use the current official H3 task grammar and language profile.
- Separate integrated visual action, overall soundscape, and non-diegetic music or explicit silence.
- Use timestamps only to make event order executable; keep shots consecutive and duration-safe.

## Seedance 2.0

- Define the stable adult identity once and preserve event order, motivated handoffs, sound intent, and overall duration.
- Use an ordered multi-shot structure for this complex mechanism.
- State overall duration once; do not copy H3 field labels or per-shot timecodes.

## Output

Return one concept sentence, the filled slots, an anchor-coverage check, one MiniMax H3 prompt, one Seedance 2.0 prompt, and a short anti-copy validation note.

## Non-Negotiable

- A subject-only request is underspecified. Preserve that subject and complete the mechanism.
- Do not omit the sparse reset or use random new images in the recap.
- Do not reuse source people, brands, slogans, exact storyboard, signature props, exact palettes, or recognizable graphic surfaces.
