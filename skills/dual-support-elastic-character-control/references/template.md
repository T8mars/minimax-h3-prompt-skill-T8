# 双支座弹性偶｜控制器驱动形变复位 Template

## Mechanism

Bind two simple graphic characters to two continuously visible physical supports. Change only one measurable support parameter at a time so the pair first demonstrates a shared response, then an asymmetric independent response, then a third materially different relation test. The order, axis and controller may change across instances; character identity and support ownership must remain readable until both supports stabilize into a legible paired state.

## Invariants

### inv-01

- Rule: Establish two distinct graphic characters, each visibly bound to one stable physical support.
- Purpose: Creates independent ownership before deformation.
- Failure if removed: Floating characters with no support cannot make gesture causality readable.

### inv-02

- Rule: Change one measurable support parameter and make both characters answer through a readable shared response.
- Purpose: Defines the first causal response rule without prescribing compression or an axis.
- Failure if removed: Changing body shape without a matching support change feels arbitrary.

### inv-03

- Rule: Change a different parameter asymmetrically so one character responds while both bindings remain intact.
- Purpose: Proves independent control inside the duet.
- Failure if removed: Applying identical changes to both sides never demonstrates separate ownership.

### inv-04

- Rule: Apply a third materially different support relation or controller path without repeating the prior response.
- Purpose: Shows a reusable control grammar rather than one canned deformation sequence.
- Failure if removed: Repeating the same axis and order makes the middle a surface routine.

### inv-05

- Rule: Synchronize both supports and finish with two legible characters still attached to their original sides.
- Purpose: Restores the relationship after extreme deformation.
- Failure if removed: Losing a face, swapping sides or ending as abstract ribbons breaks identity closure.
