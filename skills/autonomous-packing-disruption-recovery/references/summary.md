# 自主收纳回路｜物件逐层入箱、空间扰动与闭合恢复 — 摘要

## 用途

固定房间、床面和旅行箱的注册关系，先逐件建立衣物从散置状态到分区入箱的可见路径；装满后用一次空间扰动打散局部秩序，再让同一批物件沿可追踪路径恢复，并以同一旅行箱完整闭合收尾。

## 推荐输入格式

`一个可读自动包装系统与连续物料路线 + 至少三类物件按固定规则折叠、分拣或入盒 + 一次局部阻塞打乱但不重置既有状态 + 系统沿可追踪步骤恢复运行 + 终局用完整包装、剩余路线和稳定节拍证明闭环`

## 可直接改写的简短示例

> 建立原创森林绿野外设备箱，打开在工作台上；灰色折叠地图、铜色线缆、蓝色手套、琥珀仪表与奶油夹克分别位于周围五个固定区域。；琥珀仪表锁入中央泡棉槽，奶油夹克折叠覆盖顶部；任何扰动发生前，先明确证明完整装箱基线。；只反向执行被扰动物件的路径，让所有物品回到已验证仓位；同一设备箱只闭合一次，并保持准确小标【FIELD READY】，不增删设备。

## 必须保留的结构锚点

- One fixed container, one stable room or table and a countable set of objects establish the baseline.
- Each object follows a visible one-at-a-time path into one persistent compartment before the next object moves.
- The disruption may displace objects but cannot replace, duplicate or erase the container or inventory.
- Recovery retraces displaced relations and ends with the same container closed once in a stable frame.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
