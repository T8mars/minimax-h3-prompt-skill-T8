# 平面角色越界｜桌面基线、实体世界互动与来源回归 — 摘要

## 用途

先锁定平面界面、角色和图标关系，再让同一角色跨越屏幕边界进入具纵深的实体世界；互动结束后沿可辨路径回归原界面，身份与布局均得到回证。

## 推荐输入格式

`平面角色＋共享边界＋实体世界互动＋界面回归`

## 可直接改写的简短示例

> 成年天气信使、靛蓝地图界面、盐沼、发光测量标记。

## 必须保留的结构锚点

- 角色跨媒介身份不变
- 只通过一个可见边界穿越
- 返回后界面仅发生有因果的变化

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
