# 私密夜间仪式｜物件收尾、细节路线与同场回归 — 摘要

## 用途

在同一私密夜间空间先建立明确成年人物与一个正在进行的个人仪式；人物完成并放下核心物件后，镜头沿手、肩、服装、步伐和家具接触组成连续细节路线，最后回到同一房间和同一成年人已安定的状态。

## 推荐输入格式

`一名明确成年原创主体与一个私密固定空间 + 一件被克制释放的个人物件 + 至少两个沿物件表面推进的材质细节证据 + 一条连续离开与返回路线 + 终局回到原空间并保留仪式后的状态`

## 可直接改写的简短示例

> 原创成年电台档案员独处于午夜录音间，保持铜色短发、靛蓝工作衫和银色耳扣；桌上只有一台卷盘录音机与陶瓷茶杯。；连续细节路线从她扣好磁带盒开始，依次连接耳扣、卷起的袖口、肩包带和离开桌面的靴子。；回到开场轴线的较宽画面，同一成年人安静坐定，录音机关灯、耳机放下、磁带盒闭合；不出现他人、来源水印或复制字幕。

## 必须保留的结构锚点

- One clearly adult identity, one private room and one active ritual object establish the baseline.
- The adult visibly completes and releases the ritual object before the camera begins the detail route.
- Body movement and tactile contacts form one traceable route from the object station to a resting zone.
- The final wide return preserves person and geography while proving the ritual object is inactive and the adult has settled.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
