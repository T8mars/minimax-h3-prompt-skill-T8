# 多人攻势接力｜独立入场后同步收束 — 摘要

## 用途

先建立稳定的中央威胁几何与外围团队，再让不同成员以独立入场路线完成各自证明动作；角色职责清楚后才允许路线重叠，最终以同步投入而不是混乱群殴收束。

## 推荐输入格式

`固定中央挑战 + 至少3个角色/系统 + 各自独立入场路线与职责 + 延迟的高位路线 + 同步收束`

## 可直接改写的简短示例

> 三台原创温室服务机分别从地面、玻璃墙和上方处理同一根结；每条路线先独立证明职责，最后同步拉、稳、冷并完成收纳。

## 必须保留的结构锚点

- Establish one spatially persistent challenge field and the full team before any individual entry.
- Give the first participant one complete entry path and proof action.
- Delay the most displaced entry until earlier roles are readable.
- End with synchronized commitment while preserving each participant's route identity.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
