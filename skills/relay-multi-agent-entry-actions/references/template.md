# 多人攻势接力｜独立入场后同步收束 Template

## Mechanism

Establish one persistent central threat geometry and a team outside it, then give distinct team members separate entry arcs and proof actions while the threat remains spatially stable. Escalate from single entries to overlapping paths only after each role is readable, and end with a synchronized multi-agent commitment rather than an unstructured melee.

## Invariants

### inv-01

- Rule: Establish one spatially persistent challenge field and the full team before any individual entry.
- Purpose: Makes later routes comparable.
- Failure if removed: Opening on a close strike hides team geography.

### inv-02

- Rule: Give the first participant one complete entry path and proof action.
- Purpose: Defines the relay rule.
- Failure if removed: Several simultaneous first actions create noise.

### inv-03

- Rule: Give a second participant a materially different route or action responsibility against the same field.
- Purpose: Builds complementary evidence.
- Failure if removed: A repeated route is only a costume swap.

### inv-04

- Rule: Delay the most displaced entry until earlier roles are readable.
- Purpose: Creates a visible escalation in route geometry.
- Failure if removed: An early overhead entry spends the strongest spatial change too soon.

### inv-05

- Rule: End with synchronized commitment while preserving each participant's route identity.
- Purpose: Converts separate proofs into coordinated payoff.
- Failure if removed: An unstructured crowd obscures who contributes what.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair whose role is clear without source identity. |
| setting | A materially new setting with fixed spatial anchors and no source-specific location. |
| causal_carrier | One object, route, mark or device that visibly carries the causal chain. |
| state_change | Five ordered states with observable handoffs, not a decorative montage. |
| camera_grammar | A new proof-oriented information order that does not copy source shot boundaries. |
| payoff | A held final consequence that resolves or recontextualizes the setup. |
| sound_family | An original hierarchy of story-world cues supporting each visible change. |
