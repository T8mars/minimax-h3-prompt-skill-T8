# 场所反制｜追踪威胁与环境物件接力 Template

## Mechanism

Establish one clearly adult protagonist, public route and forward movement as a bookend carrier. Let one recurring non-graphic threat follow the protagonist into at least two functionally distinct interior locations. In each location, reveal a unique inventory of visible local objects before conflict, then allow the protagonist to use only that location's inventory for one distinct defensive redirection. Preserve the same protagonist, threat identity and travel direction across locations, and return to the original public route after the final defense. End with stable gait and gaze rather than another attack. The reusable mechanism is public-route identity carrier, recurring threat, location inventory foreshadowing, distinct local defense, continuous escape and route return—not the source woman, red hair, white outfit, masked attacker, city, supermarket, cosmetics store, groceries, rainbow fabric, beauty products, broken glass, exact combat, camera, creator identity or model claim.

## Invariants

### inv-01

- Rule: Establish one adult protagonist, public route and forward movement before the threat appears.
- Purpose: Creates an identity and direction carrier for the bookend.
- Failure if removed: Opening inside conflict removes the route comparison.

### inv-02

- Rule: Use one recurring non-graphic threat across at least two functionally distinct interiors.
- Purpose: Links the episodes into one pursuit rather than unrelated fights.
- Failure if removed: Different unexplained threats fragment the causal chain.

### inv-03

- Rule: Show each location's unique inventory before it becomes part of the defense.
- Purpose: Makes environmental use fair and readable.
- Failure if removed: Unseen tools appearing at impact feel arbitrary.

### inv-04

- Rule: Use only local inventory for one materially different defensive redirection in each interior, then continue moving.
- Purpose: Makes place function drive action variation.
- Failure if removed: Repeating the same generic attack wastes the location change.

### inv-05

- Rule: Return to the opening public route with stable identity, direction, gait and terminal gaze.
- Purpose: Closes geography and proves continuity after escalation.
- Failure if removed: Ending in another interior leaves the route unresolved.
