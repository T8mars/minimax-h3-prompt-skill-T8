# 微观到世界｜生态线索扩张与片名 — 摘要

## 用途

从微小生态证据扩到建成环境和世界尺度，最后停在原创片名。

## 推荐输入格式

`微观线索＋中景环境＋世界远景＋原创片名`

## 可直接改写的简短示例

> 极地冰芯、显微镜显示器、同一块实物样本、成年野外研究员、短冰道和小型研究站；琥珀色标记从显微图连到实物样本标签，再连到冰原俯瞰图。

## 必须保留的结构锚点

- 同一线索跨尺度
- 空间逐级扩大
- 片名在最终尺度稳定可读

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
