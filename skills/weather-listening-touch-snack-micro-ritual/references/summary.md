# 天气微仪式｜听觉准备、触雨确认与食物收束 — 摘要

## 用途

固定同一成年人物与雨棚边界，用帽檐、耳机、伸手接雨和一次咬食组成由听觉到触觉再到味觉的微仪式；镜头只在关键接触后收近。

## 推荐输入格式

`成年人物＋天气边界＋听觉准备＋触觉与味觉收束`

## 可直接改写的简短示例

> 成年果园工人、木棚、雨幕、有线耳机、红李子。

## 必须保留的结构锚点

- 同一人物与屋檐边界持续
- 先听觉准备再伸手接雨
- 只以一次咬食完成微仪式

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
