# 路线揭幕｜重复通道依次亮出原创反应场景 — 摘要

## 用途

让同一条移动通道反复回场，每次用经过物形成完整遮挡，再在同一空间位置揭出一个独立原创反应场景；每个场景只保留一次清楚关系变化和短暂停顿，随后回到通道继续接力，最后用新的原创场景收束。

## 推荐输入格式

`重复通行路线 + 固定揭幕区 + 每次完整移动遮挡 + 不同全成年原创反应场景 + 场景之间回到同一路线 + 完整终态反应`

## 可直接改写的简短示例

> 原创博物馆走廊、铜色地面标记和石墨灰自动展务车从左向右行驶；第二次遮挡后，两名成年建筑师交换一件白色折叠模型，其中一人反向展开，两人出现不同期待并停顿；最后一次车辆通过后，三名成年人共同检查安全的导览器，只完成一次共享惊讶确认并停留

## 必须保留的结构锚点

- Establish one recurring route and one repeatable reveal zone before the first tableau.
- Use a physically motivated object to create a complete visual occlusion before every reveal.
- Return to the same route between tableaux while preserving direction and environmental anchors.
- End on a fully readable original reaction with no unfinished wipe.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
