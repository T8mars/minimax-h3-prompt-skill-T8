# 图形复位｜身份卡与动作证明交替 — 摘要

## 用途

从一次紧凑的身份激活开始，让稳定的图形身份复位与短促的实拍动作证明交替出现；后段提高动作难度，最后把峰值动作轮廓收回到一帧完整主体锁定图中。

## 推荐输入格式

`同一原创角色或机器 + 固定图形身份卡 + 至少2段不同动作证明 + 图形复位分隔 + 后段能力升级 + 动作轮廓回收到最终全身锁定`

## 可直接改写的简短示例

> 一台原创折叠式轨道救援无人机先以白色陶瓷装甲、铜色关节和单一红色图标完成身份激活；石墨灰技术卡复位身份，再分别用抓取漂浮器材和抬起外部护板证明两项能力；最后把无人机与护板的斜向轮廓收回到最终全身技术卡中。

## 必须保留的结构锚点

- Begin with one compact identity activation before showing the complete subject.
- Establish one clearly different graphic reset mode that preserves subject silhouette and proportions.
- Raise physical demand in the later action proof while keeping the same defining silhouette and direction cues.
- Carry the peak action contour into the final graphic state and hold a complete-subject lockup.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
