# 图形复位｜身份卡与动作证明交替 Template

## Mechanism

Open on one compact identity activation, then alternate a stable graphic reset mode with short physical proof scenes. Each reset must re-establish the same subject through recurring silhouette, proportion or layout anchors, and each action block must answer one new capability question without changing identity. Reserve the last reset to absorb the peak action contour and resolve it into a held complete-subject lockup.

## Invariants

### inv-01

- Rule: Begin with one compact identity activation before showing the complete subject.
- Purpose: Creates a recognition cue that later resets can verify.
- Failure if removed: Opening on the finished full-body card removes the identity question and weakens later confirmation.

### inv-02

- Rule: Establish one clearly different graphic reset mode that preserves subject silhouette and proportions.
- Purpose: Provides a stable comparison baseline between moving proof scenes.
- Failure if removed: If the reset redesigns the subject or uses unrelated layouts, the sequence becomes a generic montage.

### inv-03

- Rule: Alternate reset and action so every action block proves one distinct capability while the next reset restores identity legibility.
- Purpose: Lets physical escalation accumulate without hiding subject drift.
- Failure if removed: Uninterrupted action loses the verification rhythm; uninterrupted cards provide no capability proof.

### inv-04

- Rule: Raise physical demand in the later action proof while keeping the same defining silhouette and direction cues.
- Purpose: Creates escalation that remains auditable against the prior reset.
- Failure if removed: A weaker or unrelated second action feels like repetition rather than progression.

### inv-05

- Rule: Carry the peak action contour into the final graphic state and hold a complete-subject lockup.
- Purpose: Converts motion into a readable terminal identity result.
- Failure if removed: Ending on motion blur, an isolated word or a cropped body denies final verification.

| Slot | Constraint |

| setting | A new setting with fixed spatial anchors and no source-specific surface. |
