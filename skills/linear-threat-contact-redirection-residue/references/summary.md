# 直线威胁改道｜接触截获、轨迹弯折与残留确认 — 摘要

## 用途

先建立攻击者、目标与直线威胁路径，被攻击者必须在可见接触点截获能量并连续弯折轨迹；威胁离开目标后以烟尘或灼痕证明改道结果。

## 推荐输入格式

`两名成年对手＋直线威胁＋接触改道＋残留证明`

## 可直接改写的简短示例

> 水库决斗场、两名成年信号决斗者、琥珀光束、弧形灼痕。

## 必须保留的结构锚点

- 威胁先形成清楚直线路径
- 改道从可见接触点开始
- 新轨迹与残留共同证明结果

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
