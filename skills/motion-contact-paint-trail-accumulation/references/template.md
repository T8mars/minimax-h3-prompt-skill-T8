# 动作留痕｜接触旋转逐步绘出群舞色场 Template

## Mechanism

Establish one bounded performance floor and two or more clearly adult performers with stable identities and spacing. Escalate choreography from upright coordination into readable floor contact and rotation. Bind one distinct visual mark family to each performer's actual contact or movement path; marks persist and accumulate instead of appearing before the motion. Use an overhead proof to reveal the combined path history, then return to a complete standing formation while the accumulated field remains visible. The reusable mechanism is motion-authored trace accumulation and terminal formation proof, not the source dancers, school-inspired clothing, city plaza, crowd, breakdance sequence, exact orange-pink-cyan palette, paint shapes, framing, creator identity or model branding.

## Invariants

### inv-01

- Rule: Establish one bounded floor and stable adult performer identities before marks appear.
- Purpose: Creates a spatial and identity baseline for later trail ownership.
- Failure if removed: Starting inside a completed color field makes causality unreadable.

### inv-02

- Rule: Escalate from upright coordination to at least two readable floor-contact or rotation actions.
- Purpose: Gives mark generation distinct physical causes.
- Failure if removed: Random cuts or airborne gestures cannot prove surface-authored traces.

### inv-03

- Rule: Assign one persistent visual mark family to each performer and bind it to actual paths.
- Purpose: Keeps multi-performer history separable.
- Failure if removed: Shared undifferentiated splashes detach the result from individual motion.

### inv-04

- Rule: Accumulate marks monotonically and reveal the combined path history from above.
- Purpose: Turns choreography into a legible graphic record.
- Failure if removed: Resetting marks between actions removes temporal evidence.

### inv-05

- Rule: End with all performers back in a complete formation while the accumulated field remains.
- Purpose: Preserves both agents and result for terminal proof.
- Failure if removed: Ending only on abstract paint replaces the performance instead of resolving it.
