# 单目标逃生｜前后灾害交替逼近 — 摘要

## 用途

终点始终可读，身后封闭与前方危险交替出现，以一次恢复和近失结果证明推进能力。

## 推荐输入格式

`主体 + 可见终点 + 身后封闭 + 前方危险 + 一次全身恢复 + 近失结果证明`

## 可直接改写的简短示例

> 维修无人机朝可见气闸前进，身后隔板依次关闭，前方机械臂横扫；它完成一次全身翻转恢复，擦过护盾后进入气闸。

## 必须保留的结构锚点

- 单一终点持续可读
- 前后危险交替而非同时混乱
- 有一次完整恢复动作
- 近失结果可见并证明保护能力

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
