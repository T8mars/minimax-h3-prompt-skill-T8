# 单目标逃生｜前后灾害交替逼近 Template

## Mechanism

Keep one destination visible while a single operator advances along a constrained route. Alternate obstacles from behind, ahead and the side so each requires a different physical adaptation without changing the goal. Reserve one deliberate control action for the endpoint, then prove success with a near-miss protective state that visibly intercepts the pursuing hazard.

## Invariants

### inv-01

- Rule: Show the destination before the first obstacle.
- Purpose: Keeps every adaptation goal-directed.
- Failure if removed: A hidden target turns the sequence into generic running.

### inv-02

- Rule: Alternate obstacle direction across at least three vectors.
- Purpose: Prevents repetitive chase beats.
- Failure if removed: All hazards from behind produce one-note escalation.

### inv-03

- Rule: Preserve one travel direction and recover after each disruption.
- Purpose: Maintains spatial and causal readability.
- Failure if removed: Direction resets make progress impossible to measure.

### inv-04

- Rule: Require a physical endpoint control action.
- Purpose: Lets the subject cause the outcome.
- Failure if removed: Automatic rescue removes agency.

### inv-05

- Rule: Prove the control with a visible near-miss interception.
- Purpose: Closes the causal chain.
- Failure if removed: A cut to safety does not show why the subject survived.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original subject or system whose identity remains stable. |
| setting | A new setting with fixed spatial anchors. |
| escalation_variable | One visible variable that changes in countable causal stages. |
| performance_rule | A restrained behavior rule that makes the mechanism legible. |
| camera_grammar | A coherent information order that does not copy source shot boundaries. |
| payoff | One clean physical or graphic consequence. |
| sound_family | A new hierarchy of diegetic cues supporting state changes. |

## Required Human-Facing Anchors

- 单一终点持续可读
- 前后危险交替而非同时混乱
- 有一次完整恢复动作
- 近失结果可见并证明保护能力

## Anti-Copy Boundary

- geothermal reactor catwalk and lava eruptions
- helmeted plant technician
- falling industrial pipes and steam jet
- large wheel control and blast shield
