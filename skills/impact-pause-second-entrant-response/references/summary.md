# 冲击停顿｜第二角色入场与近景确认 — 摘要

## 用途

局部冲击固定空间，短暂停顿后第二角色入场回应，最终以主角近景确认。

## 推荐输入格式

`固定空间＋一次冲击＋警觉停顿＋第二角色回应`

## 可直接改写的简短示例

> 洁净工业测试厅、红框校准区、一块轻质泡棉测试块、两台外形不同的自动巡检机器人。

## 必须保留的结构锚点

- 冲击位置清楚
- 第二角色在停顿后入场
- 主角最终身份可辨

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
