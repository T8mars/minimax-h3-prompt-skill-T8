# 表面生长｜沿既有几何扩散并回收到手作载体 Template

## Mechanism

Place one recognizable real carrier in frame, let a colored line trace existing geometry before spreading into icons or material marks without erasing the silhouette, use the same line family to bridge to new carriers, then collect the accumulated journey into one handmade keepsake and close it physically.

## Invariants

### inv-01

- Rule: Begin the mark by tracing existing carrier geometry.
- Purpose: Binds intervention to the real surface.
- Failure if removed: A floating overlay feels disconnected.

### inv-02

- Rule: Spread marks while preserving the carrier silhouette.
- Purpose: Keeps transformation readable.
- Failure if removed: Full occlusion destroys before/after comparison.

### inv-03

- Rule: Use one consistent line or material family across carriers.
- Purpose: Creates montage continuity.
- Failure if removed: Unrelated styles feel like separate effects.

### inv-04

- Rule: Change carrier while retaining the mark behavior.
- Purpose: Proves portability of the rule.
- Failure if removed: One surface cannot demonstrate a transferable system.

### inv-05

- Rule: Collect the journey into a handmade keepsake and physically close it.
- Purpose: Creates a loop from world surface to held object.
- Failure if removed: A final random landmark adds no structural payoff.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair whose role is clear without source identity. |
| setting | A materially new setting with fixed spatial anchors and no source-specific location. |
| causal_carrier | One object, route, mark or device that visibly carries the causal chain. |
| state_change | Five ordered states with observable handoffs, not a decorative montage. |
| camera_grammar | A new proof-oriented information order that does not copy source shot boundaries. |
| payoff | A held final consequence that resolves or recontextualizes the setup. |
| sound_family | An original hierarchy of story-world cues supporting each visible change. |

## Required Human-Facing Anchors

- Begin the mark by tracing existing carrier geometry.
- Spread marks while preserving the carrier silhouette.
- Change carrier while retaining the mark behavior.
- Collect the journey into a handmade keepsake and physically close it.

## Anti-Copy Boundary

- source world landmarks and neon crayon doodles
- Eiffel Tower, Big Ben, Colosseum, Opera House and pyramids
- source globe sketchbook and closing hand
- the exact travel-icon order and drawings

## Transfer Tests

1. Industrial ceramic prototypes receive one copper embroidery thread that follows seams, grows into functional stitch diagrams across several objects, then resolves into a physical swatch book that a gloved hand closes.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, causal_carrier, state_change, camera_grammar, payoff, sound_family
2. Across one continuous black-ice field, projected fissure light follows existing cracks, repeats as weather symbols around a circular basin, then gathers into a full-scale beacon whose segmented ring rises and mechanically locks into a stable aggregate state.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, causal_carrier, state_change, camera_grammar, payoff, sound_family
