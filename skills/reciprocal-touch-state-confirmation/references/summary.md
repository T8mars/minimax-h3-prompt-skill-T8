# 双向接触｜动作回应与状态确认 — 摘要

## 用途

一方轻触之后另一方主动回应，再以独立状态信号证明关系变化。

## 推荐输入格式

`两个主体＋首次接触＋反向回应＋状态信号`

## 可直接改写的简短示例

> 一位成年灯光技师、一盏固定在地面的黄铜机械追光灯、空舞台上的白色定点；只用一套设备。

## 必须保留的结构锚点

- 主动与回应次序清楚
- 状态信号独立可见
- 结束时两主体仍可区分

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
