# 人屏同尺度书写｜既有字面、实体补笔与完成姿态 Template

## Mechanism

先建立成年人、巨型显示面和未完成文字的尺度关系，再让人物用实体书写工具沿同一表面补齐可见笔画；每次身体移动都对应一段新增墨迹，完成后离开接触点并回到全景，用人物、工具和完整原创字面共同证明结果。 The reusable mechanism preserves causal order, spatial anchors and the final proof while replacing every source-specific person, location, object, wording, choreography and design.

## Invariants

### inv-01

- Rule: One clearly adult operator, one fixed display and one incomplete exact text establish the baseline.
- Purpose: Establishes the baseline identity, object or geography that every later state must preserve.
- Failure if removed: Without this exact baseline rule, later changes cannot be attributed to the same subject, object or place, so the sequence loses its reference state. Removed rule: "One clearly adult operator, one fixed display and one incomplete exact text establish the baseline."

### inv-02

- Rule: Every new stroke begins only after visible tool-to-surface contact at a registered location.
- Purpose: Makes the visible trigger precede and explain the first mechanism response.
- Failure if removed: Without this exact trigger rule, the response appears spontaneously and the central cause-and-effect claim is no longer demonstrated. Removed rule: "Every new stroke begins only after visible tool-to-surface contact at a registered location."

### inv-03

- Rule: Existing letters, display frame and operator identity remain unchanged while the missing text is completed.
- Purpose: Keeps the middle progression registered instead of allowing an unexplained reset.
- Failure if removed: Without this exact progression rule, the middle can jump to a replacement state and the accumulated result is no longer traceable. Removed rule: "Existing letters, display frame and operator identity remain unchanged while the missing text is completed."

### inv-04

- Rule: The tool is visibly released or capped before the operator leaves the writing surface.
- Purpose: Reconnects the changed or partial state to the established subject and spatial anchor.
- Failure if removed: Without this exact reconnection rule, detail or transformed shots can belong to a different subject or geography and continuity cannot be verified. Removed rule: "The tool is visibly released or capped before the operator leaves the writing surface."

### inv-05

- Rule: The final wide proves adult, tool and complete readable original message together.
- Purpose: Turns the terminal hold into observable proof that the mechanism completed.
- Failure if removed: Without this exact terminal-proof rule, the sequence stops on motion alone and never confirms the promised outcome or preserved aftermath. Removed rule: "The final wide proves adult, tool and complete readable original message together."


## Variable Slots

| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- One clearly adult operator, one fixed display and one incomplete exact text establish the baseline.
- Every new stroke begins only after visible tool-to-surface contact at a registered location.
- The tool is visibly released or capped before the operator leaves the writing surface.
- The final wide proves adult, tool and complete readable original message together.

## Anti-Copy Boundary

- all source faces, bodies, wardrobe, identities and creator-specific character designs
- the source location, set dressing, props, products and exact environmental geometry
- all source words, logos, watermarks, typefaces and brand identifiers
- the source choreography, exact camera path, shot durations and transition timing
- the source palette, signature effects, prompt wording, creator handle and narrative particulars
