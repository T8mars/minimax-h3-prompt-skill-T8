# 信息接力｜稳定载体穿越多种实体媒介 — 摘要

## 用途

固定一个可追踪人物或载体，让一组相关但不断推进的短信息依次进入性质明显不同的实体媒介；每次转换都由人物动作或镜头路线触发，并用新的材质物理证明信息链连续，最终在新的终端媒介中完成清楚锁定，而不是回到起点。

## 推荐输入格式

`稳定载体 + 相关且递进的原创短信息序列 + 至少三种物理媒介 + 载体触发的因果交接 + 各媒介镜头证明 + 新终端媒介定格`

## 可直接改写的简短示例

> 原创北极测绘实验室内，一辆手掌高钴蓝巡检车驶入浅色地面光栅，四条白色轨迹依次亮起并在车下拼成准确英文大写单词 SCAN；纸带进入黑色铁磁流体台，巡检车按下一枚钴蓝触点，五组流体脊线升起并组成准确英文大写单词 NORTH，磁性峰值与倒影可见；巡检车停在淡色天窗下的玻璃板旁，准确英文大写单词 VERIFIED 以青色霜刻清晰保持，后方光栅、纸带和流体站作为已完成步骤可辨

## 必须保留的结构锚点

- Establish one stable carrier and the first concise original message state before the first medium change.
- Advance a related sequence of short messages through at least three media with visibly different material behavior.
- Change camera duty to prove each medium's physics while keeping the carrier or consequence traceable.
- Resolve the final message state in a new terminal medium and hold it without returning to the opening state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
