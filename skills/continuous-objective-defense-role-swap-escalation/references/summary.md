# 连续目标防御｜固定核心、双角色接力与威胁环升级 — 摘要

## 用途

把一个持续可见的核心目标作为空间原点，用不停机的环绕和贴身跟随在敏捷防守者、重型伙伴和逼近敌群之间转移注意力；每次角色接力都要继承上一动作的方向或结果，威胁从外圈逼近到贴身再扩散为环境状态，最终以共同防线和核心状态收束。

## 推荐输入格式

`一个可持续找回的发光目标 + 成年机动精确角色与成年重型控场角色 + 连续镜头内至少3次方向/遮挡/结果接力 + 至少1个工具效果从发出到命中 + 威胁由外圈压到近身再改变环境 + 双角色与目标状态同框收束`

## 可直接改写的简短示例

> 镜头在月面温室内连续下降到高耸琥珀种子核心；成年白色压力服侦察员沿缆索落下，成年石墨外骨骼工程师面对远圈孢子无人机；镜头跟随一枚标记飞镖从侦察员发射器穿过开放空间，完整命中领头无人机；再沿冲击残余移动到工程师肩侧；镜头连续后退到较宽移动停留，两名成年人在核心旁重新站位；洁净风口把可见蓝色气流向外推过残余敌圈，琥珀核心稳定

## 必须保留的结构锚点

- Keep one objective's position and visual signature recoverable through the entire continuous path.
- Use one mobile precision defender and one heavy space-control defender with distinct functions.
- Track at least one projectile or tool effect from launch to visible impact.
- Escalate the threat ring and finish with both roles plus the objective state visible.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
