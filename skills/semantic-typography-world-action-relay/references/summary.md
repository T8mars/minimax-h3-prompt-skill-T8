# 机械语义字场变体｜成年角色让齿轮、弹簧与倒带成为文字 — 摘要

## 用途

同一明确成年角色以触碰、转身和回望触发钟面、齿轮、弹簧与倒带短词；文字真实咬合进机械空间，失序升级后回到同一人物和零点结论。

## 推荐输入格式

`Establish one clearly adult original subject, three identity anchors and one continuous world axis. + Bind each decisive action to exactly one short original semantic word that appears only after the action begins. + Make each word occupy, divide, reflect or redirect the physical environment rather than float as a subtitle. + Escalate typography scale and spatial depth while preserving identity, travel direction and readable action. + Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.`

## 可直接改写的简短示例

> 原创铜绿剧院吊杆塔中，一名明确成年舞台技术员穿炭灰连体服站在固定吊索网格内；脸、剃短发和中轴稳定。；她转动手轮，准确短词【LIFT】成为咬合齿轮；她释放弹簧，准确短词【TURN】盘绕一个滑轮，每个词只承担一种职责。；她按下一个红色复位按钮；所有缆绳回到标记，准确终局词【HOME】在机械归零时围住同一成年肖像。

## 必须保留的结构锚点

- Establish one clearly adult original subject and a clockwork coordinate system before text moves.
- Require one visible subject action before each exact word engages a mechanical duty.
- Escalate mechanical scale or disorder while preserving subject identity and the same coordinate system.
- Return every mechanism to a readable zero state around the same adult identity anchor.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
