# 机械语义字场变体｜成年角色让齿轮、弹簧与倒带成为文字 Template

## Mechanism

Establish one clearly adult original subject and a clockwork coordinate system before text moves. Require one visible subject action before each exact word engages a mechanical duty. Assign each word one distinct pendulum, gear, spring, rewind or loop behavior. Escalate mechanical scale or disorder while preserving subject identity and the same coordinate system. Return every mechanism to a readable zero state around the same adult identity anchor. The reusable mechanism is the ordered baseline, trigger, continuity, controlled escalation and terminal proof—not the source identities, brands, wording, locations, props, exact styling, choreography, camera path, creator identity or timing.

## Invariants

### inv-01

- Rule: Establish one clearly adult original subject and a clockwork coordinate system before text moves.
- Purpose: Makes the baseline measurable before the mechanism changes it.
- Failure if removed: Without the baseline, later change has no trustworthy reference state.

### inv-02

- Rule: Require one visible subject action before each exact word engages a mechanical duty.
- Purpose: Binds the first visible change to a specific cause rather than decoration.
- Failure if removed: Without a visible trigger, the transition reads as an arbitrary edit.

### inv-03

- Rule: Assign each word one distinct pendulum, gear, spring, rewind or loop behavior.
- Purpose: Preserves identity, material or spatial continuity through the middle transition.
- Failure if removed: Without continuity, the sequence becomes unrelated montage or identity drift.

### inv-04

- Rule: Escalate mechanical scale or disorder while preserving subject identity and the same coordinate system.
- Purpose: Raises intensity or information while retaining the same readable grammar.
- Failure if removed: Without controlled escalation, the middle either plateaus or turns into noise.

### inv-05

- Rule: Return every mechanism to a readable zero state around the same adult identity anchor.
- Purpose: Provides a terminal proof that resolves the mechanism instead of merely stopping.
- Failure if removed: Without terminal proof, the promised result or reversal remains unverified.
