# 见证释放｜封闭近景—外部尺度—双视图证明 — 摘要

## 用途

先在封闭空间中用近距离见证者建立异常，再让见证者的指向或动作把镜头释放到外部；完整展示环境尺度现象后，以不同于来源表面的双视图同时保留见证者和现象，形成尺度与反应的共同证明。

## 推荐输入格式

`封闭近景见证者 + 固定开口中的局部现象 + 指向动作 + 可见边界释放镜头 + 独立环境宽景 + 新几何双视图`

## 可直接改写的简短示例

> 原创深海观测舱内，一名潜水员靠近圆形承压舷窗，窗外暗钴蓝海水中只有一条细青色发光生物丝带可见，琥珀仪表和凝露建立封闭环境；潜水员把摄影舱锁入机械套筒并推动滑架，镜头穿过干式套筒、越过透明承压边界后固定到外部导轨，不穿越实体墙面；主体画面继续显示完整管水母带和观测舱，右下小圆窗同步显示潜水员扶住控制台并观看，两个尺度同时停留，不使用竖向分屏

## 必须保留的结构锚点

- Establish one close witness inside a bounded enclosure and one partially visible external phenomenon through a fixed opening.
- Use one visible directional action by the witness to transfer attention toward the external phenomenon.
- Give the phenomenon one unobstructed environment-scale view without the witness dominating it.
- End with a simultaneous dual proof of witness response and environmental phenomenon using a new composite geometry.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
