# 成品先现的组件语法｜首秒爆拆、材质章节与符号化复归 Template

## Mechanism

Show one complete original constructed object at frame zero and make the first second the fastest, clearest disassembly event. Preserve a fixed component order and assign each major component one visually distinct material or manufacturing grammar in later slower chapters. Reintroduce the complete object briefly between at least two chapters as an assembly-memory anchor. Progressively abstract the same components from objects into dots, bands, rings or outlines while preserving their order and color identity. End by recombining the simplified components into one original identity mark rather than merely returning to the opening product. The reusable mechanism is whole-first hook, maximum-speed disassembly, one grammar per component, intermittent whole-memory, progressive abstraction and mark-level reassembly—not the source burger, ingredients, Japanese copy, palette, patterns, logo, exact motions, creator identity or timing.

## Invariants

### inv-01

- Rule: Show the complete original object at frame zero before any parts separate.
- Purpose: Gives the audience an assembly memory and immediate hook.
- Failure if removed: Starting with fragments delays recognition.

### inv-02

- Rule: Make the first second the single fastest disassembly and preserve component order.
- Purpose: Concentrates attention while keeping the system legible.
- Failure if removed: Repeated equally fast explosions create noise.

### inv-03

- Rule: Assign each major component one distinct slower material or making grammar.
- Purpose: Turns parts into meaningful chapters rather than debris.
- Failure if removed: Reusing one motion for every part flattens identity.

### inv-04

- Rule: Return briefly to the whole between at least two chapters while color and order remain stable.
- Purpose: Refreshes the memory map across abstraction.
- Failure if removed: Without returns, later graphic parts lose their object relation.

### inv-05

- Rule: Abstract and recombine components into one original mark, not simply the opening object.
- Purpose: Converts demonstration into brand-level closure.
- Failure if removed: A literal loop adds no final conceptual gain.

## Anti-Copy Boundary

- the source hamburger, bun, patty, cheese, lettuce, sauce, seeds and exact shapes
- the source Japanese text, logo, slogans and all typography layout
- the source cream, red, yellow, green and black palette, dots, stripes, rings and patterns
- the source explosion, pouring, dripping, ingredient chapters, camera sequence and 15-second timing
- the source creator identity, MiniMax H3 claim and quoted prompt fragment
