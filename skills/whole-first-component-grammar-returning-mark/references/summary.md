# 成品先现的组件语法｜首秒爆拆、材质章节与符号化复归 — 摘要

## 用途

首帧先展示完整成品并在第一秒做最大速度爆拆，随后不急着复原，而是让每个核心组件进入一种独立的材质或制造语法；完整成品作为记忆锚点间歇回归，最终所有组件从实体层压缩成简化轮廓并组成原创标记。

## 推荐输入格式

`第0帧完整原创构造物先出现 + 第一秒完成唯一最大速度爆拆且组件顺序不变 + 各主要组件分别获得一种较慢且不同的材料或制造语法 + 至少两章之间短暂回到完整成品刷新装配记忆 + 组件逐步符号化并重组为原创身份标记而非简单恢复开场产品`

## 可直接改写的简短示例

> 完整奶油钴蓝露营灯立即出现，第一秒灯罩、透镜、电池、底座横向高速分离；透镜只折射一道琥珀光，完整灯体短暂回归后电池精确充满三格；简化部件组成 LUMA 信标标记，结尾只出现准确【LUMA】

## 必须保留的结构锚点

- Show the complete original object at frame zero before any parts separate.
- Make the first second the single fastest disassembly and preserve component order.
- Return briefly to the whole between at least two chapters while color and order remain stable.
- Abstract and recombine components into one original mark, not simply the opening object.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
