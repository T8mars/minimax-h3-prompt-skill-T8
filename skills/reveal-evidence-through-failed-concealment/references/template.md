# 第一视角查岗｜遮挡失效到摆烂收口 Template

## Mechanism

Keep one embodied first-person observer continuous while a subject attempts several visible concealments. Each intervention must expose a deeper, independently readable contradiction; camera height and proximity change only through the observer's body, and the payoff is a visible turn from active concealment to stopping the concealment and settling back into the workstation state rather than another reveal.

## Invariants

### inv-01

- Rule: Use one continuous embodied first-person observer whose height and distance changes come from physical movement.
- Purpose: Makes discovery feel participatory and spatially honest.
- Failure if removed: Third-person cutaways break the inspection logic.

### inv-02

- Rule: Require at least two concealment attempts that each expose a deeper contradiction.
- Purpose: Turns defense into causal escalation.
- Failure if removed: Random reveals do not form a proof ladder.

### inv-03

- Rule: Keep every evidence layer spatially nested inside one stable work area.
- Purpose: Lets viewers understand how each object hid the next.
- Failure if removed: Geographically unrelated clues feel edited rather than discovered.

### inv-04

- Rule: Hand off from object proof to a sustained facial or bodily reaction.
- Purpose: Converts evidence into a social consequence.
- Failure if removed: Ending on a screen leaves the human payoff unresolved.

### inv-05

- Rule: End with a visible behavior change rather than a third reveal.
- Purpose: Provides a distinct acceptance or refusal state.
- Failure if removed: Continuous escalation without a state change has no closure.

   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
