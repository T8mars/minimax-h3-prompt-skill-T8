# 个人设备状态开关｜普通环境在佩戴后进入表演模式再归稳 Template

## Mechanism

Establish one clearly adult original subject, one personal device and an ordinary environment baseline. Use one visible device-wear or activation action as the sole switch into the heightened state. Change performance, camera rhythm and bounded environmental accents while preserving identity and geography. Keep surrounding public behavior plausible so the private state remains legible by contrast. Return camera and subject motion to a stable baseline in the same environment, with device state visibly resolved. The reusable mechanism is the ordered baseline, trigger, continuity, controlled escalation and terminal proof—not the source identities, brands, wording, locations, props, exact styling, choreography, camera path, creator identity or timing.

## Invariants

### inv-01

- Rule: Establish one clearly adult original subject, one personal device and an ordinary environment baseline.
- Purpose: Makes the baseline measurable before the mechanism changes it.
- Failure if removed: Without the baseline, later change has no trustworthy reference state.

### inv-02

- Rule: Use one visible device-wear or activation action as the sole switch into the heightened state.
- Purpose: Binds the first visible change to a specific cause rather than decoration.
- Failure if removed: Without a visible trigger, the transition reads as an arbitrary edit.

### inv-03

- Rule: Change performance, camera rhythm and bounded environmental accents while preserving identity and geography.
- Purpose: Preserves identity, material or spatial continuity through the middle transition.
- Failure if removed: Without continuity, the sequence becomes unrelated montage or identity drift.

### inv-04

- Rule: Keep surrounding public behavior plausible so the private state remains legible by contrast.
- Purpose: Raises intensity or information while retaining the same readable grammar.
- Failure if removed: Without controlled escalation, the middle either plateaus or turns into noise.

### inv-05

- Rule: Return camera and subject motion to a stable baseline in the same environment, with device state visibly resolved.
- Purpose: Provides a terminal proof that resolves the mechanism instead of merely stopping.
- Failure if removed: Without terminal proof, the promised result or reversal remains unverified.
