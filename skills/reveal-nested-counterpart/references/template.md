# 程序错位｜扫描到实物双确认 Template

## Mechanism

Place one visibly mis-scaled subject inside a familiar step-by-step procedure and require sincere compliance. Let each successive checkpoint expose a different physical fit failure while the subject preserves dignity. Use imaging to reveal a nested counterpart inside one bound container, then physically expose the same counterpart and hold both scales plus the main subject's reaction so the physical reveal independently confirms the scan.

## Invariants

### inv-01

- Rule: Use a procedure with immediately recognizable ordered checkpoints.
- Purpose: Lets the audience predict normal behavior.
- Failure if removed: An unfamiliar process cannot create clear mismatch.

### inv-02

- Rule: Keep the subject sincere and restrained throughout compliance.
- Purpose: Makes the absurdity deadpan.
- Failure if removed: Deliberate clowning weakens the procedural contrast.

### inv-03

- Rule: Escalate through different fit failures rather than repeated alarms.
- Purpose: Adds new evidence at each step.
- Failure if removed: One repeated mismatch becomes monotonous.

### inv-04

- Rule: Reveal the nested counterpart first through an imaging device while it remains inside the same bound container.
- Purpose: Creates the first inspectable proof before physical confirmation.
- Failure if removed: Immediate emergence removes the scan-to-physical double-proof structure.

### inv-05

- Rule: Physically expose the same counterpart and hold a visible reaction with both scales present.
- Purpose: Independently confirms the scan without inventing a function or explanation.
- Failure if removed: A screen-only ending can still be read as a scan error; an off-screen reveal cannot prove identity continuity.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original subject or system whose identity remains stable. |
| setting | A new setting with fixed spatial anchors. |
| escalation_variable | One visible variable that changes in countable causal stages. |
| performance_rule | A restrained behavior rule that makes the mechanism legible. |
| camera_grammar | A coherent information order that does not copy source shot boundaries. |
| payoff | One clean physical or graphic consequence. |
| sound_family | A new hierarchy of diegetic cues supporting state changes. |

## Required Human-Facing Anchors

- 主体与程序尺度明显失配
- 至少三个不同失配证明
- 扫描先于实物揭晓
- 实物必须是扫描中的同一对象且两种尺度同框

## Anti-Copy Boundary

- full-size T-rex at airport security
- tiny sunglasses and snakeskin purse
- metal detector, security wand and baggage scanner
- miniature T-rex emerging from the purse

## Transfer Tests

1. An oversized clockwork parade elephant follows a museum intake, submits a tiny tool chest, fails measuring fixtures, then x-ray reveals six folded paper moths that physically emerge from the same chest and hover beside the elephant.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
2. A giant soft-plastic delivery mascot enters a passport-photo booth; thermal imaging reveals three miniature badge mascots inside its hollow badge, then the same badge opens and the three figures step out while both scales hold in frame.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
