# 程序错位｜扫描到实物双确认 — 摘要

## 用途

超尺度主体认真执行熟悉程序，扫描先揭示嵌套对象，随后同一对象实体出现完成双确认。

## 推荐输入格式

`超尺度主体 + 熟悉程序 + 3个不同尺度失配 + 扫描先显示嵌套对象 + 同一对象实体出现并同框`

## 可直接改写的简短示例

> 巨型纸艺飞蛾认真通过行李安检，托盘、传送带和扫描门连续出现尺度失配；屏幕先显示箱内的小纸蛾，开箱后同一只小纸蛾实体飞出，与大飞蛾同框。

## 必须保留的结构锚点

- 主体与程序尺度明显失配
- 至少三个不同失配证明
- 扫描先于实物揭晓
- 实物必须是扫描中的同一对象且两种尺度同框

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
