# 墨烟试装升级｜日常基线、遮挡换装与黑白合流 — 摘要

## 用途

先以日常全身造型建立一名明确成年人物，再让同一条可追踪流体载体反复遮挡并揭示受控造型变化；服装密度从休闲逐级升至礼服，中段用面部近景重新核验身份，结尾让两种载体分支合流为一套清楚的双色英雄造型。

## 推荐输入格式

`Establish one clearly adult original subject, a readable everyday full-body baseline and one continuously traceable transformation carrier before the first style change. + Use each carrier crossing as the visible cause of exactly one declared styling change while preserving face, age, body proportions, pose axis and studio geography. + Escalate styling in ordered density levels from practical clothing to tailored and sculptural looks without changing every visual channel at once. + Insert one bounded portrait checkpoint that re-verifies stable identity anchors before the terminal full-body phase. + Split the carrier into two visibly distinct branches, then recombine them into one stable two-part hero design and hold the completed result.`

## 可直接改写的简短示例

> 象牙色无影棚内，一名明确成年栗发展览设计师穿沙色工具连体服正面站立；椭圆脸、齐肩卷发与修长比例稳定，一条宽钴蓝织物带从画面左侧进入，并始终作为唯一换装载体。；同一织物带只增加一条铜色边缘，并在人物后方扩成清楚空间层；依次揭示原创钴蓝雕塑晚装与铜色点缀礼服，只提升轮廓体积，不改变成年身份和影棚轴线。；载体分成钴蓝与铜色两支，两支都必须围绕同一成年人连续可追踪；它们在中心合流并形成一套原创非对称钴蓝铜色英雄套装。织物带清场，完整全身结果停留一秒，不出现标志和文字。

## 必须保留的结构锚点

- Establish one clearly adult original subject, a readable everyday full-body baseline and one continuously traceable transformation carrier before the first style change.
- Use each carrier crossing as the visible cause of exactly one declared styling change while preserving face, age, body proportions, pose axis and studio geography.
- Insert one bounded portrait checkpoint that re-verifies stable identity anchors before the terminal full-body phase.
- Split the carrier into two visibly distinct branches, then recombine them into one stable two-part hero design and hold the completed result.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
