# 力量反差｜小体型用杠杆反制 — 摘要

## 用途

先证明巨大质量差与可用支点，让重型对手完整承诺攻击，小体型主角进入转弯半径并用杠杆重定向动量，最后形成非致命控制。

## 推荐输入格式

`巨大重型对手 + 小型主角 + 提前可见支点 + 重型攻击承诺 + 近身预判 + 杠杆重定向 + 非致命控制`

## 可直接改写的简短示例

> 小型回收机器人面对巨型货运装载机，先让磁缆和系柱可见；等待装载机完整挥臂后钻入转弯半径，借第二次挥动和磁缆杠杆把机械臂安全压在地面。

## 必须保留的结构锚点

- 开场先证明质量差和可用支点
- 重型对手必须先完整承诺动作
- 至少一次冲击证明动量和恢复成本
- 反转只能来自杠杆与重定向
- 结尾非致命且支点因果仍可见

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
