# 切线成字｜材料变化与可读停留 Template

## Mechanism

A first sparse line operation produces a material effect; additional line actions physically change the same substrate so a readable original word emerges from its geometry, followed by a deliberate title hold and new ending state.

## Invariants

### inv-01

- Rule: Begin with one visible line operation on a stable material surface, with no fully formed title yet.
- Purpose: Makes the first intervention and baseline readable.
- Failure if removed: Starting with the word removes the material-to-type reveal.

### inv-02

- Rule: Later line operations cause bounded physical material changes that accumulate into legible negative or positive letter geometry.
- Purpose: Connects graphic motion to object construction.
- Failure if removed: If letters simply fade in, the line actions become decorative and causal coherence disappears.

### inv-03

- Rule: Hold the resulting original word long enough to read and give it a deliberate ending state.
- Purpose: Makes the typographic payoff functional.
- Failure if removed: A blurred or instantly shattered word fails as a title, even if material effects look impressive.


## Variable Slots

| Slot | Constraint |
|---|---|
| material | One stable original substrate with consistent physical properties. |
| line_operation | Sequential visible marks/cuts/unpicking actions, first one before title. |
| bounded_change | Only affected material changes at each line. |
| letter_formation | Readable new word emerges from physically traceable result. |
| title_hold | Final typography readable, not random glyphs. |
| ending_state | Purposeful resolution distinct from copied source explosion. |
| sound | Original material-specific sounds, not source audio attribution. |

## Required Human-Facing Anchors

- 操作与材料反应同框
- 字形由同一材料形成
- 可读停留与后续终态分开

## Anti-Copy Boundary

- No weapon/titanium wall, bright orange metal sparks, source word 'BLADE', exact metal fragment choreography or terminal blast.
- Do not copy the live-page creator prompt or treat it as hash-bound canonical prompt evidence.
- No sudden after-effect text overlay that ignores the earlier material operations.
