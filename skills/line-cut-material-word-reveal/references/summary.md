# 切线成字｜材料变化与可读停留 — 摘要

## 用途

数次线性操作改写同一材料，让原创字形从物理变化中形成。

## 推荐输入格式

`原始材料＋线性操作＋原创短字＋终态`

## 可直接改写的简短示例

> 深蓝摄影棚一整块透明冰和下方透明接冰托盘；三道琥珀色局部热裂线依次发生，最终真实负空间显示英文 LIFE。

## 必须保留的结构锚点

- 操作与材料反应同框
- 字形由同一材料形成
- 可读停留与后续终态分开

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
