# 感官封闭｜人群静止点到异地恢复 — 摘要

## 用途

先让稳定主体成为高速群流中的静止参照，再用一次主动封闭感官的动作建立触发；镜头持续靠近并让环境运动加压，只在主体完全静止时发生一次全画幅换境，最后用同一身份、轴线和恢复动作证明空间已改变。

## 推荐输入格式

`稳定主体与独立流动环境 + 一次完整感官封闭 + 环境继续运动 + 单次全画幅换境 + 同身份在新空间恢复动作`

## 可直接改写的简短示例

> 原创深海维修码头内，一名陶瓷潜水员稳定站在标记平台中央，三台维修无人机和悬挂工具车独立穿行；无人机速度感增强，潜水员低头闭眼并完全静止，主体轴线始终居中；同一潜水员出现在安静海藻苗圃，打开系绳种荚托架并把一枚种荚释放进水流，停留证明新环境持续

## 必须保留的结构锚点

- Establish one stable subject against independently moving surroundings before the trigger.
- Use one deliberate bilateral or otherwise complete self-sealing gesture without changing location yet.
- Replace the whole environment only once through a bounded full-frame perceptual wash while preserving the subject axis.
- Restore the same identity in a materially different location and show one resumption action under the new physics.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
