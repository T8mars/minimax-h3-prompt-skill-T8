# 叙事拆幕｜情绪场景连续退到片场与监看层 — 摘要

## 用途

先让一个完整情绪表演和可触碰道具建立可信虚构世界，再以同一动作锚点开始连续退镜；画面依次露出布景边界、灯架与工作人员，随后让同一场景进入监看屏幕，最后用极短问题卡把观众从剧情接受切换到媒介判断。

## 推荐输入格式

`完整可信虚构场景与成年表演者 + 1个实用光或道具锚点 + 表演动作不丢失的连续后退 + 至少3项制作线索 + 原画面进入监看层 + 1句极短原创判断终卡`

## 可直接改写的简短示例

> 成年白灰宇航员穿过重复冰肋走向一枚青色导航圆盘，呼吸和戒备视线可读，片场设备完全不可见；手套尚未接触时镜头持续后退，宇航员、圆盘和抬手关系不变；越过破损舱壁后露出微缩冰洞、两台造雪风机和运动控制轨道；切为纯黑，只显示原创短问句“REAL ENOUGH?”并停留

## 必须保留的结构锚点

- Earn belief through one coherent fictional scene and emotionally legible performer before exposing construction.
- Use one practical prop or light and one performer action as continuous registration anchors during the retreat.
- Show the original fictional image inside a monitoring or capture layer after the physical set reveal.
- Finish with one compact audience-facing judgment prompt and no new exposition.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
