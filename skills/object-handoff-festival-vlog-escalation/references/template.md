# 节庆物件接力｜品尝、游戏、奖品到高空景观逐级升级 Template

## Mechanism

Lock one original clearly adult vlog subject with stable face, handheld distance and route direction. Build at least four event chapters, and require one acquired, used or carried object from each chapter to motivate the next: a food or token proves arrival, a game action earns a prize, the prize or gaze leads to a larger environmental spectacle, and the subject carries a visible residue into farewell. Escalate scale from hand to stall to crowd or sky, then return to the same selfie relation. The reusable mechanism is object-motivated chapter relay, action-result proof, scale ascent and same-subject farewell—not the source woman, clothing, festival, food, ring toss, plush, fireworks, locations, creator identity or timing.

## Invariants

### inv-01

- Rule: Lock one clearly adult original vlog subject, stable handheld distance and one route direction.
- Purpose: Maintains personal continuity.
- Failure if removed: Changing narrator or route makes unrelated tourism clips.

### inv-02

- Rule: Use at least four chapters and let one acquired, used or carried object motivate each transition.
- Purpose: Creates causal chapter links.
- Failure if removed: Location-only cuts become a postcard montage.

### inv-03

- Rule: Show one action-result pair for any game, purchase or exchange.
- Purpose: Proves how the object was obtained.
- Failure if removed: An unexplained prize breaks the route.

### inv-04

- Rule: Escalate visual scale from hand to stall or activity to a larger environmental event.
- Purpose: Builds an earned climax.
- Failure if removed: Starting at sky scale leaves no progression.

### inv-05

- Rule: Return to the same selfie relation with at least one accumulated object or residue for farewell.
- Purpose: Closes the personal route.
- Failure if removed: An anonymous spectacle ending loses the narrator.
