# 静态人像转义｜微表情改写前段含义 — 摘要

## 用途

让近静镜头留出观察时间，再用少量可见状态变化改变读法。

## 推荐输入格式

`成年主体＋稳定环境＋一个后段可见变化`

## 可直接改写的简短示例

> 原创成年跑者，一条雨后空旷终点跑道，灰色跑步夹克，右手攥着一张无品牌号码布；人物和场地保持固定。

## 必须保留的结构锚点

- 主体与机位稳定
- 后段变化清楚但克制
- 变化重释前段静止

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
