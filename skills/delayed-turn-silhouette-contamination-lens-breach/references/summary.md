# 延迟转身惊变｜固定走廊、轮廓污染与贴镜突破 — 摘要

## 用途

固定走廊中先让成年人物背对镜头保持普通基线，再以一次缓慢转身建立面孔；黑色发丝或烟影从肩部连续扩张，表情和轮廓逐级异变，最终只发生一次贴近镜头的突破。

## 推荐输入格式

`一名明确成年原创人物背对固定正面镜头 + 一个空间注册不变的窄通道 + 只转身一次建立同一面孔 + 异常材质沿肩部、面部和头顶至少三档连续扩张 + 身份和身体比例不变 + 克制停留后只发生一次可见接触式贴镜突破`

## 可直接改写的简短示例

> 锁定明确成年原创夜班档案员：齐黑短发、灰蓝外套、黄铜钥匙，站在狭窄奶油色档案走廊远端，固定正面镜头中背对观众。；哑光墨色边缘从衣领连续生长为三段：肩线、下颌线、头顶拱形；全部书架和顶灯保持固定。；停留一拍后，她只快速向前走三步并用持钥匙的手覆盖镜头，必须在完全接触时才切断。

## 必须保留的结构锚点

- One clearly adult identity, one fixed frontal corridor and one back-facing baseline precede all threat cues.
- Exactly one complete turn establishes the face before silhouette contamination begins.
- Expression and outline escalate without face replacement, body mutation or geographic reset.
- Only one terminal lens breach follows a restrained hold and ends on visible contact.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
