# Threshold-to-Passage Field Inspection — 摘要

## 风格与机制

先用远景确定一个真正有后果的入口或路线；一次明确剪辑跨过阈值，随后以较长的连续跟随把抽象环境变成身体可感的通行过程。队员、灯光与工具在路线中协调移动，一个局部材料或环境信号打断前进；检查之后只展示可见的路线状态，不把未证实的诊断写成事实。

## 适用范围

- 野外考察、工业巡检、地下设施、后台技术、救援准备和科学纪录
- 需要“尺度建立—进入—连续通行—局部检查—继续/暂停/改向”的 15 秒短片
- 强调空间、材料、工具与人机协同的写实场景

## 不适用范围

- 开场只是无关风景 B-roll
- 进入后频繁跳切、路线方向不可判断
- 用一个线索直接宣称危险、安全或诊断结果，却没有画面证据

## 使用方法

1. 先画入口、路线和终点的简图。
2. 给每个队员、灯或工具分配单一职责。
3. 选择一个符合材料与环境物理的局部信号。
4. 只展示检查动作和可见后续路线状态；未知就保持未知。
5. 至少改变环境类别、团队拓扑、工具关系、信号物理、运镜载体和结尾状态。

## 可变槽位

| 槽位 | 约束 |
|---|---|
| threshold_environment | 有尺度上下文的入口、舱口、树冠、腔室或通道。 |
| field_team | 一至三个角色、动物或机器，职责和轮廓稳定。 |
| route_geometry | 可真实通行且有方向锚点的连续路线。 |
| reveal_light | 能揭示材料层次的头灯、UV、灯笼、反射光或移动阴影。 |
| local_cue | 合理的气流、振动、湿度、声音、颗粒或结构变化。 |
| inspection_action | 不依赖文字的指示、测量或物理反应。 |
| post_inspection_route_state | 检查后的继续、暂停或改向；诊断不是默认结论。 |
| camera_carrier | 与环境匹配的航拍、缆索、身体、机器人或手持路线。 |
