# 庆典词语实体化｜一词一动作一材质结果的逐章升级 Template

## Mechanism

Lock one original clearly adult host through face, hair or costume anchors and one repeatable stage axis. Rotate at least four celebration modules. Each module may introduce only one original short word, one prop and one host action; the action must visibly transform the word into a matching physical state such as extinguished smoke, inflated volume, unfolded paper, scattered confetti or illumination. Repeat two identity or layout anchors while material scale grows from handheld to stage-wide. End by gathering the host, selected prop residue and one original greeting mark. The reusable mechanism is one-word-one-prop-one-action materialization, scale escalation and host-led lockup—not the source performer, pink hair, words, props, stage layouts, typography, creator identity or timing.

## Invariants

### inv-01

- Rule: Lock one clearly adult original host with at least three identity anchors and one stable stage axis.
- Purpose: Keeps a narrator through rapid modules.
- Failure if removed: Changing host identity makes disconnected cards.

### inv-02

- Rule: Use exactly one new original short word, one prop and one action per module.
- Purpose: Protects causality and readability.
- Failure if removed: Several words or props in one beat create visual clutter.

### inv-03

- Rule: Make the host action physically transform the word into a matching material state.
- Purpose: Turns typography into an event.
- Failure if removed: Static text beside performance remains decorative.

### inv-04

- Rule: Repeat at least two host or layout anchors while material scale grows.
- Purpose: Connects handheld and stage-wide chapters.
- Failure if removed: Unrelated layouts lose escalation.

### inv-05

- Rule: End with host, selected material residue and one original greeting mark together.
- Purpose: Collects modules into a final identity.
- Failure if removed: A text-only card loses the performer and prior events.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Lock one clearly adult original host with at least three identity anchors and one stable stage axis.
- Use exactly one new original short word, one prop and one action per module.
- Repeat at least two host or layout anchors while material scale grows.
- End with host, selected material residue and one original greeting mark together.

## Anti-Copy Boundary

- source pink-haired performer, face, costume, microphone and cane
- source words CHEER, HURRAY, SURPRISE, WISH, HAPPY, PARTY, SHINE, FUN and CONGRATS
- source candles, balloons, party cannon, flowers and theater props
- source typefaces, colors, layouts and exact action-to-word pairings
- source MiniMax H3 thread prompt, music, timing and creator identity
