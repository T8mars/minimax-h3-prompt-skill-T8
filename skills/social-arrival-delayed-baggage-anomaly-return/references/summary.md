# 入住迟到异样｜先完成社交接纳再揭示行李异常 — 摘要

## 用途

先让新来者以礼貌动作和普通行李完成可信抵达，再让既有成员在同一室内形成正常接纳基线；等社交关系成立后，才用连续的行李局部插镜揭示彼此呼应但不同的异常痕迹，最后返回仍未察觉的群体，让信息差成为结尾张力。

## 推荐输入格式

`成年新来者携至少2个普通容器完成礼貌抵达 + 与至少2名既有成员形成接纳基线 + 接纳后才出现至少3种相关但不同的容器异常线索 + 不完整揭示原因且不攻击 + 返回仍未察觉的群体`

## 可直接改写的简短示例

> 成年快递员站在三只密封样本舱之间，单手按胸并完整鞠躬；样本舱此时都保持普通关闭状态；珊瑚色舱盖下冷凝水鼓动两次；银色封条下只压出一根紫色细丝并收回；回到完全相同的三人宽景，他们继续入住说明，样本舱仍在视线外

## 必须保留的结构锚点

- Complete one polite arrival action before displaying any abnormal container detail.
- Show the newcomer accepted by at least two established residents in one stable shared space.
- Withhold the complete hidden cause and avoid a direct attack or confrontation.
- Return to the same group while the secret remains outside their attention.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
