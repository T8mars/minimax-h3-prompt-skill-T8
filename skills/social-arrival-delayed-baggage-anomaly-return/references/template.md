# 入住迟到异样｜先完成社交接纳再揭示行李异常 Template

## Mechanism

Stage an original newcomer with at least two ordinary-looking containers and complete one polite arrival action before showing any anomaly. Establish a stable social-acceptance frame with existing residents. Only then enter a delayed evidence phase: use at least three container close-ups, each revealing a different but related physical sign while withholding the complete hidden cause. Return to the same accepted group without letting them resolve the secret, so the audience retains one clear informational advantage. The reusable mechanism is normal arrival, social acceptance, delayed object anomaly and unaware-group return—not the source characters, faces, outfits, suitcases, fingers, chains, seals, room, horror motifs, camera, creator identity or timing.

## Invariants

### inv-01

- Rule: Complete one polite arrival action before displaying any abnormal container detail.
- Purpose: Lets normality earn the later rupture.
- Failure if removed: An immediate anomaly removes the delayed-recognition effect.

### inv-02

- Rule: Show the newcomer accepted by at least two established residents in one stable shared space.
- Purpose: Creates a social baseline and a consequence for the hidden evidence.
- Failure if removed: Without acceptance, the close-ups are merely object design.

### inv-03

- Rule: Reveal at least three different but related physical clues across two or more containers.
- Purpose: Builds a patterned secret without fully explaining it.
- Failure if removed: One clue can read as decoration; identical clues do not escalate.

### inv-04

- Rule: Withhold the complete hidden cause and avoid a direct attack or confrontation.
- Purpose: Preserves suspense through controlled uncertainty.
- Failure if removed: A full creature reveal resolves the question too early.

### inv-05

- Rule: Return to the same group while the secret remains outside their attention.
- Purpose: Locks in audience-character information asymmetry.
- Failure if removed: Ending on an object close-up lacks the social consequence.
