# 整机激活证明｜总览、部件旋转与能量回证 — 摘要

## 用途

以完整装置建立结构基线，再依次进入齿环、管线与核心的局部动作；能量只在机械接触和旋转之后出现，最终回到整机证明所有变化属于同一设备。

## 推荐输入格式

`完整装置＋部件联动＋能量阈值＋整机回证`

## 可直接改写的简短示例

> 暗场磁力压力机、铜环、冷却管、青色核心、一次聚焦脉冲。

## 必须保留的结构锚点

- 整机先保持静止可读
- 部件按机械关系启动
- 能量出现后回到整机证明

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
