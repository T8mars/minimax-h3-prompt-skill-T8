# 人物装备归属｜局部切片到全身动作 — 摘要

## 用途

人物与工具先同框，再逐项核对细节，最后用一次动作证明归属。

## 推荐输入格式

`人物＋工具＋三个细节＋一次完整动作`

## 可直接改写的简短示例

> 一名明确成年的女性雪崩搜救训练员；石板灰和橙色工装、左肩无线电、右手手套、同一支无品牌探杆。训练坡面与标记区全程不换。

## 必须保留的结构锚点

- 人物与工具先建立关系
- 细节保持同一设计
- 动作和全身姿态回证归属

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
