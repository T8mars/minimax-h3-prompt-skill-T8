# 气闸异境｜物理异常后空间崩坏 Template

## Mechanism

Lock one ordinary enclosed room, one occupant and one inert witness object. After one ordinary operation or control check, make the enclosure accumulate visible physical evidence, use one brief blackout without resetting geometry, then open the threshold onto an impossible exterior while the unchanged witness object remains inside so the reveal reads as a rule break rather than a location cut.

## Invariants

### inv-01

- Rule: Lock one familiar enclosed-room geometry before the anomaly begins.
- Purpose: Creates a stable rule baseline.
- Failure if removed: A changing room cannot prove which rule broke.

### inv-02

- Rule: Place one ordinary operation or control check before the physical anomaly.
- Purpose: Creates a familiar action baseline and directs attention inside the locked room.
- Failure if removed: Starting with unexplained material effects weakens the ordinary-to-impossible escalation.

### inv-03

- Rule: Make the enclosure accumulate physical evidence before the threshold opens.
- Purpose: Proves the event is not merely a display glitch.
- Failure if removed: An instant portal lacks escalation and material causality.

### inv-04

- Rule: Preserve one inert witness object across the interruption.
- Purpose: Binds both states through continuity.
- Failure if removed: If everything changes, the reveal can read as a location cut.

### inv-05

- Rule: Hold the impossible exterior and unchanged interior together after the occupant is absent or displaced.
- Purpose: Creates a complete rule-break proof.
- Failure if removed: A quick exterior insert cannot establish spatial contradiction.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |
