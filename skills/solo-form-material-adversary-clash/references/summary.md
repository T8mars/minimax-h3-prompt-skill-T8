# 独演成敌｜动作材质凝成对手后碰撞 — 摘要

## 用途

先用单一主体的完整动作建立可辨招式与材质签名，再让环境材质积累并凝成独立对手；中后段通过一次空间跃迁把双方拉入正面对抗，最后引入第二能量材质完成碰撞并回到主体可读终态。

## 推荐输入格式

`单体招式与材质签名 + 环境材质凝成独立对手 + 空间跃迁建立对抗 + 第二能量材质碰撞 + 主体可读终态`

## 可直接改写的简短示例

> 原创玻璃沙漠黎明，一名气流工程师站在悬空窑桥旁，用黄铜共振环完成一整套螺旋动作，透明压力折射沿路径留下清楚轨迹；团块凝成透明四足晶体对手，沿一端接近悬桥；工程师从另一端进入，双方路线、桥面和距离共同可读；碎片与钴蓝光退去，工程师落在远端平台，以开场可读方向握住共振环，并稳定最后一圈透明压力轮廓

## 必须保留的结构锚点

- Establish one subject's complete movement signature and its material trace before an opponent appears.
- Accumulate the same environmental material around the subject before it gains agency.
- Reserve a contrasting second material for one late clash peak.
- After the collision, restore one readable subject state with the signature action or tool still identifiable.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
