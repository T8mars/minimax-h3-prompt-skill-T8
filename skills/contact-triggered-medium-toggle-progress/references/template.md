# 触控换媒｜接触触发、状态推进与成品回归 Template

## Mechanism

Lock one bounded workspace, one primary object and one visible contact tool. Every time the tool touches the object or its immediate support, toggle the registered region between photoreal action and a materially distinct illustrated medium. Preserve object orientation, support geometry and surrounding anchors across each toggle, while advancing one irreversible construction or preparation state after every transition. End by returning to photoreal reality with the completed object and all accumulated evidence visible. The reusable mechanism is attributable contact, registered medium toggle, irreversible progress, anchor continuity and real finished payoff—not the source hand, blue stylus, bread, egg, pan, French toast, berries, syrup, black-yellow drawing style, exact camera, timing, creator identity or model labels.

## Invariants

### inv-01

- Rule: Establish one bounded workspace, one primary object and one visible contact tool in reality.
- Purpose: Defines the registered region and causal trigger.
- Failure if removed: An unseen trigger makes the medium switch arbitrary.

### inv-02

- Rule: Toggle medium only at visible tool contact and preserve object registration across the boundary.
- Purpose: Makes every transformation attributable and comparable.
- Failure if removed: Cuts between unrelated layouts lose contact causality.

### inv-03

- Rule: Alternate between photoreal and one clearly different illustrated medium at least twice.
- Purpose: Proves a repeatable two-way system rather than a single effect.
- Failure if removed: One-way conversion does not establish a toggle grammar.

### inv-04

- Rule: Advance one irreversible build or preparation state after every toggle without resetting earlier progress.
- Purpose: Turns medium change into narrative progress.
- Failure if removed: Cosmetic switching alone is a filter demo.

### inv-05

- Rule: Return to photoreal reality with the completed object and original anchors visible.
- Purpose: Closes both medium and progress arcs.
- Failure if removed: Ending in illustration leaves real completion unproven.
