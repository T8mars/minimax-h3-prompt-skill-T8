# 疲惫姿态接力｜地点物件承接同一身体状态 — 摘要

## 用途

锁定同一明确成年人物与疲惫身体状态，让多个地点物件依次成为支撑面；每次换地点都保留服装、包袋和下坠姿态，最终在最意外容器中安静停住。

## 推荐输入格式

`同一成年人物＋持续疲惫状态＋多地点支撑物＋意外终点`

## 可直接改写的简短示例

> 成年公园测绘员、帆布包、坡道、秋千、台阶、训练球推车。

## 必须保留的结构锚点

- 服装包袋与人物身份不变
- 疲惫姿态跨地点连续
- 支撑物变化不得造成身份替换

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
