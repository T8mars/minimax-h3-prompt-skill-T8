# 实用整理确认关系｜接触、退开与双向微反应 — 摘要

## 用途

把两名明确成年角色锁在同一安静空间，先建立一项真实可见的服装或装备不整，再让帮助者用一次连续、功能明确的双手动作完成调整。接触结束后必须退开，并分别给被帮助者与帮助者一个克制微反应；结尾回到两人同框，用整理后的物件和稳定姿态证明准备完成，不能依赖未经验证的对白语义。

## 推荐输入格式

`两名明确成年原创角色、一个可见服装或装备问题和稳定共用轴线 + 帮助者只用一次连续双手动作完成可核验调整 + 完成状态出现后停顿并退开 + 接触结束后两名成年人分别给出不同克制微反应 + 回到共同构图且完成物件与稳定姿态同时可见 + 不依赖未经验证对白语义`

## 可直接改写的简短示例

> 成年舞台经理与成年歌手在后台同框，歪斜麦克风和偏离接缝的线缆清楚可见；麦克风垂直、线缆贴平、夹扣闭合，经理停一拍后双手离开并退一步；经理小幅点头，随后两名成年人回到同框，舞台侧光与麦克风完成状态共同停留

## 必须保留的结构锚点

- Establish two clearly adult original roles, one visible irregularity and one stable shared camera axis.
- Use exactly one continuous, functionally clear two-hand adjustment.
- Give both adults different restrained microreactions only after contact ends.
- Return to a shared composition where the finished item and stable postures remain visible.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
