# 技艺递进｜原料变形到成品特写 Template

## Mechanism

Turn craft into a visible proof ladder: establish one raw material, perform several functionally different manipulations that progressively change its length, topology or organization, cross one irreversible processing threshold, assemble the result, and end on a macro finished-state proof that visibly inherits features created earlier.

## Invariants

### inv-01

- Rule: Establish one raw material and its maker before complex manipulation.
- Purpose: Gives viewers a stable before state.
- Failure if removed: Opening on spectacle removes the transformation baseline.

### inv-02

- Rule: Use at least three functionally different manipulations that visibly change the same material.
- Purpose: Makes skill cumulative rather than repetitive.
- Failure if removed: Repeated tossing without distinct material effects is only flourish.

### inv-03

- Rule: Keep the material identity and work-surface geography continuous across the manipulation ladder.
- Purpose: Lets viewers connect each phase causally.
- Failure if removed: Unmotivated material substitutions break the proof.

### inv-04

- Rule: Cross one visible irreversible processing threshold before the result assembly.
- Purpose: Separates preparation from completion.
- Failure if removed: A finished object appearing without a threshold feels swapped in.

### inv-05

- Rule: End on a macro finished-state proof that retains visible evidence of earlier transformations.
- Purpose: Closes the causal ladder with a verifiable result.
- Failure if removed: A wide beauty shot alone hides whether the material work mattered.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Transfer Tests

1. A solar-sail conservator starts with one bundle of translucent plant fiber, draws it into ribbon, splits and braids a lattice, tensions it over a frame, heat-seals it once, then ends on a macro proof of the finished light-filter membrane.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
