# 功能问答闭环｜人物疑问由设备状态完成证明 — 摘要

## 用途

先让提出疑问的人与正在运行的设备同框，形成清楚的功能缺口；再切到第二位人物查看一个远程状态载体并作出可见回应，最后返回原空间，让设备状态变化和提问者反应共同承担证明，而不是只靠字幕或口头宣称。

## 推荐输入格式

`人物与运行设备同框提出功能疑问 + 第二名成年人查看独立状态载体并回应 + 不依赖小字UI或指定对白 + 返回原设备空间 + 1项机器状态变化与1项人物反应共同闭环`

## 可直接改写的简短示例

> 成年温室主管站在灌溉机架旁，琥珀待机灯和三根透明空管清楚可见；她抱臂看向画外同事；另一工作台的成年农艺师查看掌心状态牌，只点按一次并做克制确认手势；主管放开一只手并放松表情，绿色灯、三根满管和人物反应同时停留

## 必须保留的结构锚点

- Open with the questioner and the relevant operating device visible in one spatial relationship.
- Use a second adult and one separate status carrier as an independent response channel.
- Return to the opening device space after the response.
- Change one device state and one human response before the final hold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
