# 轮廓接力｜闪光换形后完成攻势闭环 — 摘要

## 用途

先用武器与披风轮廓建立动作基准，再通过可数的落地姿态推进；一次中央闪光只负责换形交接，新形态以能量弧与腾空段得到证明，最后回到可读的落地终态。

## 推荐输入格式

`原创动作主体 + 清楚工具轮廓 + 2个落地动作几何 + 1次遮挡换形 + 效果动作与位移证明 + 落地终态`

## 可直接改写的简短示例

> 陶窑维修自动机以长夹具和隔热盾建立轮廓，完成两种落地维修姿态；一次蒸汽遮挡后显出冷却配置，沿服务轨切开接缝，再落地于密封窑门旁。

## 必须保留的结构锚点

- Establish one countable full-body action silhouette and its tool before escalation.
- Advance through at least two materially different grounded action geometries.
- Prove the later state through both a committed effect action and a displaced body path.
- End on a readable grounded state that recalls at least one opening silhouette anchor.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
