# 轮廓接力｜闪光换形后完成攻势闭环 Template

## Mechanism

Stage one graphic action display as a sequence of countable full-body proof states: establish a weapon-and-cape silhouette, vary grounded attack geometry, use one central flash to hand off into a visibly different form state without asserting identity continuity, prove the new state through one energy arc and one airborne passage, then return to a readable grounded endpoint.

## Invariants

### inv-01

- Rule: Establish one countable full-body action silhouette and its tool before escalation.
- Purpose: Creates a comparison baseline for later proof poses.
- Failure if removed: Beginning with a flare makes the form change unreadable.

### inv-02

- Rule: Advance through at least two materially different grounded action geometries.
- Purpose: Shows action progression rather than a decorative pose loop.
- Failure if removed: Repeated near-identical poses create no escalation.

### inv-03

- Rule: Use exactly one occluding transition to hand off between visible form states without claiming hidden identity continuity.
- Purpose: Keeps the transformation evidence-bounded.
- Failure if removed: An unmarked form swap looks accidental; claiming identity exceeds the visible proof.

### inv-04

- Rule: Prove the later state through both a committed effect action and a displaced body path.
- Purpose: Makes the new state operational rather than cosmetic.
- Failure if removed: A costume-only reveal lacks a functional proof.

### inv-05

- Rule: End on a readable grounded state that recalls at least one opening silhouette anchor.
- Purpose: Closes the action display as a complete arc.
- Failure if removed: Ending mid-flight leaves the state chain unresolved.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair whose role is clear without source identity. |
| setting | A materially new setting with fixed spatial anchors and no source-specific location. |
| causal_carrier | One object, route, mark or device that visibly carries the causal chain. |
| state_change | Five ordered states with observable handoffs, not a decorative montage. |
| camera_grammar | A new proof-oriented information order that does not copy source shot boundaries. |
| payoff | A held final consequence that resolves or recontextualizes the setup. |
| sound_family | An original hierarchy of story-world cues supporting each visible change. |

## Anti-Copy Boundary

- source monochrome armored heroines
- spiral spear and white cape
- source black void and exact attack poses
- the exact masked-to-female form sequence
