# 工序递进｜多层处理到揭膜验收 Template

## Mechanism

Lock one treatment surface and orientation, apply distinct tools or materials where each step changes the state needed by the next, accumulate a readable covering layer, perform one late removal or rinse, then use a separate inspection action to verify the stable finished surface.

## Invariants

### inv-01

- Rule: Establish one stable treatment surface and baseline before application.
- Purpose: Makes later changes comparable.
- Failure if removed: Starting mid-process hides the initial condition.

### inv-02

- Rule: Give each tool or material a distinct visible duty.
- Purpose: Turns montage into a causal procedure.
- Failure if removed: Random tools provide no process logic.

### inv-03

- Rule: Keep intermediate layers relevant to the next step.
- Purpose: Builds cumulative preparation.
- Failure if removed: Resetting the surface destroys progression.

### inv-04

- Rule: Use one late covering-layer removal as the decisive reveal.
- Purpose: Concentrates accumulated work.
- Failure if removed: Several repeated peels weaken the event.

### inv-05

- Rule: Verify the finished surface with a separate inspection action.
- Purpose: Proves a stable result.
- Failure if removed: Ending during removal leaves completion untested.
