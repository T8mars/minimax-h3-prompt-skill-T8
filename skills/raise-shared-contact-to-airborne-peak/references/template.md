# 双人递进｜共享接触从地面升到空中峰值 Template

## Mechanism

Establish two visually distinct roles at different depths, let the nearer role trigger a continuous exchange whose shared contact height rises in readable stages from ground to one joint aerial apex, then return both roles to a grounded held relationship without inventing a winner.

## Invariants

### inv-01

- Rule: Establish two stable roles and a readable depth or distance gap before contact.
- Purpose: Makes the initiating commitment and later convergence legible.
- Failure if removed: Starting in a tangled exchange removes the baseline and makes escalation hard to read.

### inv-02

- Rule: Use one committed approach to create the first low shared contact state.
- Purpose: Provides a measurable contact baseline rather than random action.
- Failure if removed: If the first event has no shared contact, later height changes have no reference point.

### inv-03

- Rule: Raise contact amplitude or altitude through at least one intermediate exchange while role identity stays stable.
- Purpose: Turns repetition into a visible escalation ladder.
- Failure if removed: Contacts at one unchanged height feel repetitive rather than progressive.

### inv-04

- Rule: Reserve one shared airborne or otherwise clearly highest joint event as the apex.
- Purpose: Gives the ladder a single unmistakable peak.
- Failure if removed: Several equal peaks flatten the hierarchy and dilute the climax.

### inv-05

- Rule: Return both roles to a grounded or baseline plane and hold their post-apex relationship without asserting an unsupported result.
- Purpose: Closes the height arc and preserves source uncertainty.
- Failure if removed: Ending during the apex feels truncated; declaring a winner invents evidence.


## Variable Slots

| Slot | Constraint |
|---|---|
| role_pair | Two original stable roles with visibly distinct silhouettes or functions. |
| initial_gap | A readable depth, distance or level separation before the first shared action. |
| contact_carrier | One original object, signal or task that both roles visibly affect. |
| height_ladder | At least low, intermediate and peak shared states with continuous causal handoffs. |
| apex_realization | One unmistakably highest joint event, not repeated spectacle. |
| camera_grammar | Proof-oriented framing that compares the baseline, intermediate rise, apex and return. |
| end_relationship | A held post-apex relationship that does not claim an unsupported winner or diagnosis. |
| sound_family | Original story-world cues that distinguish low, rising, apex and settling phases. |
