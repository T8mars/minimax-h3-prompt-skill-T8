# 雨夜追逐｜街巷近战到机车脱身 — 摘要

## 用途

追逐先建立方向，中段用一次近身阻断改变节奏，再把主体交接到更快载具完成脱身。

## 推荐输入格式

`被追主体 + 单一追逐轴线 + 一次紧凑阻断 + 立即步行→更快载具交接 + 持续加速结尾`

## 可直接改写的简短示例

> 盐碱地科研信使被两台勘测车追赶，窄沟槽中只做一次反撬夹臂，随后立即踏上沙地滑板并沿原轴持续加速。

## 必须保留的结构锚点

- Establish one readable pursuit axis before any combat.
- Use one narrow threshold to compress the lead and threat.
- Complete an immediate, visible foot-to-faster-carrier handoff after the encounter.
- End with sustained carrier acceleration along the established travel direction.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
