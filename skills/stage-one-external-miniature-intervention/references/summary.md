# 微缩介入｜外部物只进入一次 — 摘要

## 用途

静态标准物先校准微缩尺度，内部日常稳定后，不同外部执行物只进入一次并改变局部状态。

## 推荐输入格式

`静态标准物开场校准 + 微型日常 + 校准物保持不动 + 不同外部执行物只进入一次 + 局部状态改变与反应同框`

## 可直接改写的简短示例

> 一枚静止登山扣校准高山气象站的微缩尺度，小维修员继续日常作业；随后一把真实尺寸镊子只进入一次，扶正天线，局部状态改变与小人的反应同时可见。

## 必须保留的结构锚点

- 静态标准物先校准尺度
- 微型日常先稳定建立
- 外部执行物与校准物不是同一物
- 外部物只介入一次且结果与反应同框

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
