# 感官体验｜对象建立—质感证明—试用反应—终态兑现 Template

## Mechanism

Establish one stable user and one complete experience object in the same frame. Before showing approval, isolate a tactile, material or functional close-up that visibly proves what the object does. Return to the same user for a complete first-use reaction chain, include one readable reset or relief action, then add a different detail for a second proof. End by repeating the opening relation with a clearly changed terminal object state and a settled user. The mechanism is objective proof to embodied reaction to terminal-state confirmation, not the source person, dish, market or exact food-vlog coverage.

## Invariants

### inv-01

- Rule: Establish one stable user and the complete experience object together before the first trial.
- Purpose: Defines who is testing what and provides an initial state.
- Failure if removed: Opening on a macro detail alone removes identity and completion context.

### inv-02

- Rule: Show one independent close tactile, material or functional proof before relying on the user's reaction.
- Purpose: Makes the claim inspectable rather than testimonial.
- Failure if removed: A reaction without object proof can feel staged or unsupported.

### inv-03

- Rule: Return to the same user for a complete first-use action, visible physical response and one reset or relief behavior.
- Purpose: Turns material evidence into embodied consequence.
- Failure if removed: Cutting away before the response or omitting the reset leaves the experience incomplete.

### inv-04

- Rule: Add a second proof that uses a different object component, scale or action.
- Purpose: Broadens the demonstration and prevents one-gimmick repetition.
- Failure if removed: Repeating the first insert at the same scale adds no new evidence.

### inv-05

- Rule: Repeat the opening user-object relation with a visibly changed terminal object state and a settled user.
- Purpose: Closes the test through before-after evidence.
- Failure if removed: Ending on a bite, hand or isolated smile does not prove what happened to the object.
