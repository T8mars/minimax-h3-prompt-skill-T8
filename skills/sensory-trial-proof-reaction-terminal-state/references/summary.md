# 感官体验｜对象建立—质感证明—试用反应—终态兑现 — 摘要

## 用途

先让体验者与完整对象同框建立期待，再用独立微距证明质感；第一次试用后保留身体反应与缓冲动作，随后用第二个细节补充体验，最后以对象耗尽和体验者稳定状态共同兑现。

## 推荐输入格式

`稳定体验者与完整对象 + 独立微距质感证明 + 第一次试用/身体反应/缓冲 + 不同第二证明 + 改变后的对象终态`

## 可直接改写的简短示例

> 暖灯笼夜市中，穿青绿色亚麻衬衫的成年旅行者与一整锅蜜汁根茎蔬菜同框；先低头观察，再看一次镜头并拿起黄铜夹；同一旅行者完成第一口，咀嚼后抿嘴呼气、用手扇口两次，再从透明杯只喝一口薄荷水；铜锅只剩一条蜜汁痕迹，两只小碗仍在原位；同一旅行者放下透明杯、放松并向镜头微笑一次

## 必须保留的结构锚点

- Establish one stable user and the complete experience object together before the first trial.
- Show one independent close tactile, material or functional proof before relying on the user's reaction.
- Add a second proof that uses a different object component, scale or action.
- Repeat the opening user-object relation with a visibly changed terminal object state and a settled user.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
