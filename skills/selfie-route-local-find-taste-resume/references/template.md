# 自拍路线小发现｜街行、侧看、品尝与带物继续 Template

## Mechanism

Maintain one original adult traveler in a plausible handheld selfie relationship with continuous route direction, face scale and background parallax. Let one visible gaze or head turn motivate a local discovery within the same environment. Show the acquired object clearly, complete exactly one use or taste action and hold an unforced bodily reaction long enough to read without prescribed speech. Return the traveler to the same route carrying a changed state or takeaway object. The reusable mechanism is selfie-route continuity, gaze-motivated local discovery, sensory proof and resumed travel—not the source woman, face, clothing, city, bakery, pastry, street, dialogue, gestures, camera path, creator identity or timing.

## Invariants

### inv-01

- Rule: Keep one adult traveler, selfie distance, route direction and background parallax stable before the discovery.
- Purpose: Establishes authentic continuous UGC geography.
- Failure if removed: An unmotivated location jump makes the clip feel assembled rather than lived.

### inv-02

- Rule: Use a visible gaze or body turn to motivate the local discovery.
- Purpose: Connects environment attention to the next subject.
- Failure if removed: A detached storefront insert has no traveler-driven cause.

### inv-03

- Rule: Show the acquired object and complete exactly one use or taste action.
- Purpose: Provides direct experience proof instead of promotional assertion.
- Failure if removed: Holding an object without using it leaves the discovery unresolved.

### inv-04

- Rule: Preserve one readable bodily reaction without depending on exact dialogue.
- Purpose: Makes the sensory result observable and evidence-backed.
- Failure if removed: Prescribed words or exaggerated reaction can replace rather than prove the experience.

### inv-05

- Rule: Resume the same route while carrying a changed state or takeaway object.
- Purpose: Closes the detour and returns the traveler to forward motion.
- Failure if removed: Ending at the product close-up loses the travel structure.
