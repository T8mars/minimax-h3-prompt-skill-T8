# 帅气展示瞬间失手｜单次事故与社交收尾 — 摘要

## 用途

先让一名明确成年角色在熟人面前主动摆出可读的自我展示意图，再用一段连续动作把自信逐级抬高。只允许一次清楚的物理失误打断表演，必须完整展示失衡、落地与后果；旁观者先作克制反应，表演者随后以一个简短恢复动作承认尴尬，笑点由社会关系闭合而不是只靠摔倒。

## 推荐输入格式

`两名明确成年原创角色、共享视线与主动展示意图先建立 + 一个连续动作短语逐步提高幅度或难度 + 只发生一次有可见原因的失误且完整显示失衡、落地与后果 + 旁观者先作克制反应 + 表演者用一个简短尴尬恢复动作承认失败 + 双方保持空间连接并稳定收尾`

## 可直接改写的简短示例

> 成年快递员在自行车旁面对成年调度员，调度员视线清楚落在表演者身上；前轮碰到柔软停车挡块，半转动作直接变成侧向失衡；快递员接受帮助、单膝起身并整理肩带，调度员克制微笑

## 必须保留的结构锚点

- Establish two clearly adult original roles, a shared sightline and the performer's deliberate competence-display intent before the risky move.
- Build one continuous movement phrase whose amplitude or difficulty visibly increases.
- Let the observer react before the performer begins the social recovery.
- End on one restrained recovery gesture that acknowledges failure while both roles remain spatially connected.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
