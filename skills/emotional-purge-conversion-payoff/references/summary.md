# 情绪物证清空｜低谷表情、旧物处置与价值回报 — 摘要

## 用途

先用同一成年人物的泪痕和旧照片建立关系低谷，再让她把照片装入一个可追踪袋子、发现可变现物件并完成柜台交易；现金结果必须来自已展示物件，终局情绪由悲伤转为释然。

## 推荐输入格式

`一名明确成年原创主体与一组可见旧情绪载体 + 主体主动完成一次不可逆的整理或舍弃动作 + 该动作直接触发一个现实可验证的价值转换流程 + 中间用物件、空间与人物反应连续证明因果关系而非突然幸运 + 终局让主体以新的情绪状态和明确获得物返回，旧载体不再复位`

## 可直接改写的简短示例

> 以一名原创成年钟表师开场：眼含泪水，身旁有六张照片和一个黑色收纳袋。；她注意到黑袋旁的一只铜色机械钟盒，拿起并确认三处黄铜配件。；钟表师收到明确款项，呼气一次，并以暖色插画肖像收束，手持收据而非已丢弃照片。

## 必须保留的结构锚点

- One clearly adult protagonist and one disposal container persist.
- The emotional low is evidenced before any solution appears.
- Payment follows a completed inspection and cannot appear from nowhere.
- The final relief preserves memory of the preceding causal chain.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
