# 静态群像异常升级｜表情异变、空间击穿与贴脸威胁 — 摘要

## 用途

从安静群像与单一普通人物开始，用局部表情异常把注意力锁到同一身份；随后让摄影机和群体空间发生一次强制位移，短暂留出空场作为后果证据，最后让已异变人物以相同身份锚点从深处逼近并占满镜头，完成从社会安全到直接威胁的四级升级。

## 推荐输入格式

`安静成年群体、焦点身份和稳定空间先建立 + 局部特征异常但至少三项身份锚点不变 + 一次可追踪空间冲击打破秩序 + 同一环境短暂空场并隐藏焦点人物 + 同一异变身份从既定纵深轴逼近镜头并保持`

## 可直接改写的简短示例

> 四名成年研究员围坐钢桌，苔绿夹克、透明面罩和橙色右腕标锁定焦点技术员；压力脉冲让椅子和摄影机沿地面线侧移一次；不透明面罩的同一技术员从远端走近，直到面罩占满画面

## 必须保留的结构锚点

- Establish a calm adult group, one focal identity and stable room geometry before any anomaly.
- Change one localized feature while preserving at least three identity anchors.
- Hold the established environment briefly while withholding the focal adult.
- Return the same altered adult from depth and end on increasing proximity rather than a new effect.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
