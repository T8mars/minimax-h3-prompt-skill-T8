# 材质字效｜霜花成字再归位 Template

## Mechanism

Start from a calm material baseline, generate one localized disturbance from that same material, assemble the disturbance into one short readable word, hold it long enough for verification, then let gravity or flow dissolve every letter back into the original surface. The ending must visually match the opening state closely enough to support a clean loop.

## Invariants

### inv-01

- Rule: Establish a calm baseline using one clearly identifiable material.
- Purpose: Provides a measurable before state.
- Failure if removed: Without a baseline, the return cannot be judged.

### inv-02

- Rule: Form every letter from the same disturbed material.
- Purpose: Keeps typography inside the physical world.
- Failure if removed: A digital overlay breaks causal coherence.

### inv-03

- Rule: Use one short word and hold it long enough to read.
- Purpose: Makes the transformation communicative.
- Failure if removed: Long text or a brief flash becomes illegible.

### inv-04

- Rule: Dissolve the word through the same material law that formed it.
- Purpose: Creates a reversible physical system.
- Failure if removed: A fade-out bypasses the material logic.

### inv-05

- Rule: Return camera and surface close to the opening state.
- Purpose: Supports a seamless visual loop.
- Failure if removed: A changed ending removes the satisfying reset.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- 先保持无字的固定材质基线
- 所有字母由同一材质形成
- 全片只出现一个可读短词
- 用同一材料法则完成溶解
- 镜头和空间锚点回到开场状态

## Anti-Copy Boundary

- source lake sunrise
- the word MORNING
- source water-letter shapes
- source horizon composition
