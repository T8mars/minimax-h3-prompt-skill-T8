# 材质字效｜霜花成字再归位 — 摘要

## 用途

固定竖直玻璃先建立清晰基线，霜晶从同一表面长成一个短词，保持可读后融成真实水珠，最终恢复开场窗口形成闭环。

## 推荐输入格式

`固定镜头 + 单一材质基线 + 同材质形成1个短词 + 可读停留 + 同一物理法则溶解 + 回到开场`

## 可直接改写的简短示例

> 夜间温室竖直玻璃保持清晰，霜晶沿四条成核路径形成 THAW，短暂停留后由下方暖风融成水珠流走，最后恢复同一铜锁扣和虚化叶片构图。

## 必须保留的结构锚点

- 先保持无字的固定材质基线
- 所有字母由同一材质形成
- 全片只出现一个可读短词
- 用同一材料法则完成溶解
- 镜头和空间锚点回到开场状态

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
