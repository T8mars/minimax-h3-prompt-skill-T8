# 角色板验真变体｜眼部钩子、全身转面、细节宏观与英雄卡

## 用途

以虚构非人偶角色的眼部极近景建立身份，再通过正侧背转面、服装和道具细节、全身舞台及英雄卡重复核验；所有模块改变版式而不改变角色锚点。

## 推荐输入格式

`固定角色板 + 同一原创主体 + 至少4种不同验证职责 + 广角/近景双证明 + 最终对照`

## 可直接改写的简短示例

> 以原创明确非人发条飞蛾信使的一枚青绿色六边形镜眼极近景开场；锁定镜眼、靛蓝翅缘和一个铜色触角关节。；准确展示同一非人设计的正面、左侧和背面转台视图；翅膀数量、镜眼形状、铜关节、信封和比例不变。；回到象牙卡上完整不变的飞蛾和信封；只显示准确原创名称【NIX COURIER】并停住。

## 必须保留的结构锚点

- Establish one original fictional nonhuman doll character with at least three stable visual anchors in an extreme detail.
- Pull back to a complete silhouette and repeat the same anchors inside a clear identity card.
- Use detail macros and one stage transformation to test the same identity across scale and lighting.
- Return to the complete unchanged character and one original name field in a stable hero card.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
