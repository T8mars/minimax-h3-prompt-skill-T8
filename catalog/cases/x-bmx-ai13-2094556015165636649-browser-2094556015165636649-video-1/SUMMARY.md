# 仪式黑场复位｜期待微笑、吹灭中断与冷光回归

## 用途

用固定正面构图和一根蜡烛建立成年人物的温暖仪式期待，吹灭动作立刻让空间完全黑场；随后同一人物和同一桌面在冷亮环境回归，表情由期待转为失落，完成因果反差。

## 推荐输入格式

`一名明确成年原创主体与一个可识别的庆祝或启动仪式 + 预期触发物在完成前建立等待 + 一次有因的突然黑场中断仪式 + 同一空间以不同光温回归并保留中断痕迹 + 人物、触发物和改变后的状态共同停留`

## 可直接改写的简短示例

> 成年夜间档案员居中坐在一块小点心和一根高蓝蜡烛后，空间为小型琥珀阅览室。；她只吹一次，火焰与全部室内实用灯同时熄灭，只留原位余烬渐暗。；她在未点燃蜡烛旁低下视线停留一拍，不重启仪式，也不增加他人。

## 必须保留的结构锚点

- One adult, one ritual object and one fixed frontal composition establish the expectation.
- A single visible blow causes both flame extinction and room blackout.
- The return preserves person, object and composition while changing the lighting regime.
- The final subdued performance externalizes the interrupted expectation without explanatory copy.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
