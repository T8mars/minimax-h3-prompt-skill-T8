# 和风角色谱系｜纹样框架、身份符号与群像归档

## 用途

固定一套和风图鉴框架和字段顺序，让多个成年原创角色逐一以面孔、姿态、职责物与主题符号完成登记；每人只占一个清楚槽位，终局把全体角色聚合为可比较群像。

## 推荐输入格式

`固定人物区/标题/字段顺序/计数器 + 至少5个编号原型 + 每个原型同步改变主色/轮廓/姿态微动作/职责图标 + 界面全程不滑动 + 最终编号档案稳定停留`

## 可直接改写的简短示例

> 建立固定靛蓝纸质档案框，包含人物槽、职责图标、两项字段和编号印章，用于六名明确成年原创山地氏族角色。；桥梁守卫、草药裁判、钟铃信使、档案潜水员和风暴谈判者沿用相同字段顺序，每人只改变脸、轮廓、姿态和一件职责物。；六名成年角色围绕原创标题【RIDGE COVENANT】完成终局谱系，全部编号和职责图标仍可读。

## 必须保留的结构锚点

- One fixed roster frame, field order and numbered progression remain registered throughout.
- Every clearly adult original character changes face, silhouette, pose and one role object together.
- Recurring palette and ornament preserve the taxonomy while role evidence changes.
- The terminal ensemble includes every established adult with readable number and duty symbol.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
