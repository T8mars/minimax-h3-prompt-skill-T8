# 拼贴舞姿字效｜黑白红角色、海报墙与短词接力

## 用途

锁定黑白红角色，让撕纸墙、屏幕框、透视地字和巨型竖排短词随姿态变化接力；每章保持三色系统，终局回到完整人物与总句。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 锁定原创成年动画贝斯手：白色短发、青色眼纹和炭黑外套，置于撕裂灰纸隧道。；同一脸进入黑色监视器边框，准确短词【WAIT】仍在身后可读。；完整人物回到海报墙，准确总句【HOLD THE LINE】停留。

## 必须保留的结构锚点

- One adult animated identity anchors every format.
- A visible pose change precedes each typography module.
- Text stays exact and readable despite perspective.
- The final card restores the complete character and master line.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
