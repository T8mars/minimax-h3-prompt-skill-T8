# 岸边任务回路｜营地准备、带物行进、浪击恢复与返回

## 用途

先让成年人物在固定营地完成一项带工具的晨间准备，再携带同一器具沿清楚路线走到水边；一次海浪打断任务后，人物保持器具并恢复站立，随后沿原方向返回营地。

## 推荐输入格式

`一名明确成年原创主体、一个固定营地和一件持续携带的工具 + 出发前完成一项可见准备动作 + 沿可追踪路线抵达环境边界 + 只发生一次外部扰动并保留工具与身份 + 人物恢复后沿既有路线回到同一营地终态`

## 可直接改写的简短示例

> 建立明确成年原创岛屿生态学家：黑发扎起、宽松沙色衬衫、橄榄短裤和银色取样壶，日出时位于帆布海滩棚旁。；水线处只放低取样壶一次，宽景中持续保留帐棚、脚印和海岸方向。；她站稳、检查盖紧的取样壶，并沿同一串脚印返回帆布棚，终局宽景同时包含成年人物与营地。

## 必须保留的结构锚点

- One clearly adult subject, one carried tool, one camp anchor and one shoreline route establish the task.
- A complete preparation action precedes departure with the same tool.
- Exactly one environmental interruption causes a readable brace while tool possession and identity persist.
- The subject visibly recovers and returns along the established route to the same camp terminal state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
