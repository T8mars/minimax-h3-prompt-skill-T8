# 晨间自拍视频压缩｜卧室问候、饮水、换装与出门

## 用途

以手持自拍视频持续锁定同一成年人物，按卧室问候、厨房饮水、换装束发、地面准备和户外步行压缩晨间流程；每次地点切换都由脸部或手势接力。

## 推荐输入格式

`稳定主体与目的地 + 单职责短动作 + 姿态/手中物/方向接力 + 累积准备状态 + 单向路线 + 终点结果动作`

## 可直接改写的简短示例

> 手持晨间自拍视频锁定原创成年博物馆讲解员：黑色短发和银色耳扣，起始于小公寓。；人物穿锈红工作夹克回连，固定同一耳扣并装入一张折叠地图。；户外保持同一身份和夹克，她挥手一次、转向前方并走向博物馆入口。

## 必须保留的结构锚点

- One adult identity and handheld selfie carrier persist through all routine chapters.
- Each location change uses a visible face, hand or prop handoff.
- Wardrobe change is bounded and preserves the same face, hair and body proportions.
- The final outdoor movement proves departure from the private routine into a destination route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
