# Luminous Anomaly Materialization Loop

让一个低信息量的小异常沿单一载体连续生长：从平面痕迹变为空间形体，再变成体积材质；接触峰值把视觉语法传播到环境锚点，随后异常收缩为接近开场位置的残留。

## 核心机制

A small anomaly leaves a low-information real anchor as one continuously tracked carrier, escalates from flat trace to spatial figure to volumetric material, uses a contact peak to distribute its visual grammar across ordinary environmental anchors, then contracts into a reduced residue that returns to an opening-equivalent location.

## 视觉与节奏风格

写实环境中的连续奇幻材质变换；载体可追踪；接触峰值清楚；从微弱痕迹到体积高潮再回落。

## 适用范围

- 魔法、能量、材质或品牌视觉的连续变形
- 需要首尾呼应但不做完全复位的 15 秒特效短片
- 可围绕一个真实载体和数个环境锚点展开的概念

## 不适合

- 无载体、无传播路径的全屏随机特效
- 只放大粒子数量而没有状态变化的效果展示

## 使用方法

1. 先阅读 [Creative DNA](./creative-dna.json)，保留其中的因果不变量。
2. 重新选择人物、环境、道具、色彩、动作、声音与结尾，避免复刻来源视频表面。
3. 根据目标模型选用 [MiniMax H3 提示词](./prompts/minimax-h3.md) 或 [Seedance 2.0 提示词](./prompts/seedance-2.0.md)。
4. 将现成提示词视为已验证实例，不要只替换名词；新概念至少改变四个可变槽，并再次检查因果、连续性与反复制边界。
5. 在 GitHub 直接查看 GIF，或在 Electron 桌面版播放媒体包中的完整 MP4（含声音）；需要作者上下文时打开原帖。
