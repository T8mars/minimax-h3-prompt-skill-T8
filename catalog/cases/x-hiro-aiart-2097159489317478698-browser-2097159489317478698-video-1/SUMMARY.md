# 单人舞台动作链｜全身节拍、近脸回应与终拍回位

## 用途

锁定同一成年动漫舞者、白色文字 T 恤、宽腿裤和圆形天空舞台；全身步法与手臂动作连续推进，中段收紧到眨眼近脸，再回到全身完成最后一个抬膝与侧步。

## 推荐输入格式

`单人表演者 + 巨大空场 + 远景起势 + 近景表达 + 一次受控倒地 + 俯拍确认 + 连续复起`

## 可直接改写的简短示例

> 让一名原创成年动画电台主持人以全身景站在晴空下的圆形屋顶舞台。；不切镜地从全身推进到胸像，面容、白色【RADIO DAY】T 恤和天际线保持注册。；拉回全身，完成一次向左侧步，双脚落回开场中心标记收束。

## 必须保留的结构锚点

- One clearly adult character, wardrobe and stage persist.
- The body phrase remains continuous and countable.
- Only one wink marks the performance peak.
- The final full-body stance returns to the opening center mark.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
