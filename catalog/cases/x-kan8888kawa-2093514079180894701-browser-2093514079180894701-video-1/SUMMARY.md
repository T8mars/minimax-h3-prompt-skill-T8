# 近距威胁接触链｜单体打击、抓握挣脱与逃跑转接

## 用途

先在近距离建立一名成年逃生者与单个威胁，用短动作和可见接触逐步脱困；当威胁数量增加时，动作目标从击退切换为逃跑，并沿同一走廊轴线完成转接。

## 推荐输入格式

`固定中央挑战 + 至少3个角色/系统 + 各自独立入场路线与职责 + 延迟的高位路线 + 同步收束`

## 可直接改写的简短示例

> 一名成年温室守卫持蓝色软杆，面对一台故障训练人偶。；每次接触都让人偶移出标记地块，下一动作才开始。；同一守卫沿温室中线向镜头撤退，人偶群在身后追随。

## 必须保留的结构锚点

- One adult and one close threat are established before contact.
- Each combat unit has a readable beginning, contact and displacement.
- Threat multiplication visibly changes the objective to escape.
- The same route axis carries the final pursuit.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
