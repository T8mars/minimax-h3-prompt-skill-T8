# 体型不对称追逐｜窄路规避、武器转向与临界对峙

## 用途

用同一雨夜屋顶路线明确小型敏捷角色与巨型重装威胁的尺度差；躲避先证明速度优势，随后角色主动转身把逃跑改写为临界对峙。

## 推荐输入格式

`大小尺度明确的两主体 + 共享地面 + 巨体承诺动作 + 小体型可见变线 + 无虚构胜负的共享终态`

## 可直接改写的简短示例

> 成年屋顶递送员持窄琥珀信号棒，前方是银雨中的高大维护机。；两处通风箱和一个缺口迫使递送员完成清楚横向规避。；递送员在末端接点插下信号棒并转身，维护机同时抵达门槛。

## 必须保留的结构锚点

- Two roles have visibly different scale and mobility.
- One continuous route remains recoverable.
- Distinct color or prop anchors preserve each role.
- Flight converts into a readable confrontation threshold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
