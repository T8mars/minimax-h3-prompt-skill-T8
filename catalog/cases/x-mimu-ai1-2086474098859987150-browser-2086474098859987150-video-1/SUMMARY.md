# Evidence Ladder Crosses into Reality

让稳定现实与一个有边界的证据载体产生可核对矛盾；载体沿同一变量连续更新两次，现实暂时保持不变，直到最终状态跨出边界并留下清晰的物理结果。

## 核心机制

A bounded evidence carrier contradicts a stable live baseline, updates one countable variable twice, then converts represented change into one delayed physical consequence.

## 视觉与节奏风格

信息优先的递进结构；稳定空间锚点；两次可比较更新；长时间保留负空间；跨界后只给一个清晰结果。

## 适用范围

- 悬疑、惊奇、技术谜题、喜剧和产品证明
- 以传感器、地图、样本、录音或显示介质推动的短片
- 需要在约 15 秒内完成规则建立、升级与兑现的概念

## 不适合

- 载体每次随机显示无关内容
- 现实过早变化，或只把来源的照片与威胁换名词

## 使用方法

1. 阅读 [Creative DNA](./creative-dna.json)，先重建稳定基线、同一参照物与两次更新。
2. 至少同时改变载体、场景、类型、运镜、声音、变化物理和结尾。
3. 直接查看 [MiniMax H3](./prompts/minimax-h3.md) 与 [Seedance 2.0](./prompts/seedance-2.0.md) 已验证实例。
4. GitHub 查看 GIF；Electron 媒体包播放完整有声 MP4；作者上下文见原帖。
