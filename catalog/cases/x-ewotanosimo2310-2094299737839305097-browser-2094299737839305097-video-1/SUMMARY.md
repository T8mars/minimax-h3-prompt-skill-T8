# 水光造境｜面具舞者聚球、绘阵与浮岛展开

## 用途

人物先沿云海中的一条光迹到达，手势把同一水光聚成球并绘出圆阵；圆阵再扩展为有路径、瀑布和拱门的浮岛庭园，终局回到同一人物证明造境者。

## 推荐输入格式

`普通环境中的明确成年主体先展示双手为空 + 双掌稳定定义收集容器 + 至少三处环境痕迹连续汇入并压成单一核心 + 只用一次手势沿既定轴线释放同一物质 + 物质重新分布到同一环境并保持可见回应`

## 可直接改写的简短示例

> 一名成年面具制图师沿银雾光迹下降到云上黑色反光圆盘。；她把光带聚成一个琥珀光球，再释放三圈同心地图环。；同一制图师回到路径入口，完整庭园与原圆盘保持注册。

## 必须保留的结构锚点

- One figure and one material family anchor creation.
- Gestures visibly collect before release.
- Environment features inherit the released ring geometry.
- The final frame reconnects creator, origin disk and complete world.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
