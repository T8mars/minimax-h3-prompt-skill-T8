# 工序递进｜多层处理到揭膜验收

## 用途

固定同一处理表面，让不同工具或材料逐步改变下一步所需状态；晚段只揭除一次覆盖层，最后用独立检查动作证明稳定结果。

## 推荐输入格式

`固定处理表面 + 多工具单一职责 + 层层累积 + 单次揭除 + 两种独立验收`

## 可直接改写的简短示例

> 原创博物馆修复台上，裂纹象牙色陶瓷面具固定在炭灰支架，修复师先干刷清除裂纹网灰尘；扫描器经过修复区，透明保护涂层只沿已验证裂纹刷开，每件工具只负责一种动作；斜掠光扫过陶瓷，修复师再用小放大镜从第二角度检查，两个证明后保持稳定修复面

## 必须保留的结构锚点

- Establish one stable treatment surface and baseline before application.
- Give each tool or material a distinct visible duty.
- Use one late covering-layer removal as the decisive reveal.
- Verify the finished surface with a separate inspection action.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
