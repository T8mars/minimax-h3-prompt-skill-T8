# 角色板验真｜跨栏全程身份锁定

## 用途

固定角色板持续在场，运动区用起跑、侧面、俯拍、正面和关键动作逐层验证同一人物。

## 推荐输入格式

`固定角色板 + 同一原创主体 + 至少4种不同验证职责 + 广角/近景双证明 + 最终对照`

## 可直接改写的简短示例

> 固定角色板不变；太阳帆维修员在上方实景依次完成准备、侧面攀梯、俯拍穿越、近景缆线抓取和最终部署验证。

## 必须保留的结构锚点

- Keep one compact original identity board readable throughout.
- Give each live phase a different verification role.
- Include one wide comparison and one close deformation-heavy skill proof.
- Hold a final live result beside the unchanged board.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
