# 并肩晨路记忆｜脚步、近触与未完成情绪回望

## 用途

两名明确成年朋友沿同一晨间道路并肩前进，脚步、蒲公英、笑容和交换视线构成记忆碎片；双手接近但不触碰，未完成动作成为情绪终点。

## 推荐输入格式

`观察者媒介 + 日常人物/地点 + 两个日常动作 + 外部信号改变目标 + 一次回应 + 有动机录制失误`

## 可直接改写的简短示例

> 两名明确成年的研究生研究员在日出时并肩走向山丘观测站。；两人交换一次玩笑和各一次侧望，前方观测站保持居中。；用一次眼部近景，再回到两名成年人沉默走向同一观测站。

## 必须保留的结构锚点

- Both subjects are clearly adult.
- One route and destination persist.
- The near-touch remains intentionally incomplete.
- The final return keeps the emotional question unresolved.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
