# 手绘能量接管｜实景载体换形、动作贴合与整屋改写

## 用途

一条可追踪手绘能量贴合手持实景运动，依次变成浮游生物、织物符号、鱼形与列车轨迹；每次换形都由接触触发，最终从局部线条扩散为整屋星空涂鸦。

## 推荐输入格式

`现实第一视角互动 + 首个画内线稿回应 + 连续表面路径 + 至少三类响应图形 + 真实空间与完整绘制世界同框`

## 可直接改写的简短示例

> 从一个原创深夜维修亭开始，以克制手持漂移拍摄，不出现图形效果。；让丝带鳐依次触碰悬挂电缆、工具袋和风扇，变成绳结、鱼和轮子，同时保留一条紫色尾迹。；让电车轨迹扩散成星图，在保持实景几何注册的同时重绘全部墙面和物体。

## 必须保留的结构锚点

- One continuous hand-drawn carrier persists.
- Every form change follows visible contact.
- Escalation moves from local object to room scale.
- The final graphic world preserves the original physical layout.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
