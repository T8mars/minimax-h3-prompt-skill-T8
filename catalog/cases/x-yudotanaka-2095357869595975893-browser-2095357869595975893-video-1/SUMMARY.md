# 动画角色城市轮播｜身份锚点、场景换装与起点回归

## 用途

锁定同一成年动画人物的粉色发型、绿眼和身体比例，让城市、昼夜与服装在多个章节切换；每次变换后先证明完整人物，终局回到与开场呼应的夜间街口。

## 推荐输入格式

`固定主体身份与镜头关系 + 至少四个材质/版式不同的风格世界 + 每阶段改变两项风格通道 + 递增密度 + 可读身份终态`

## 可直接改写的简短示例

> 锁定明确成年原创动画声音工程师：紫色齐短发、金色眼睛、小方形耳扣和稳定身体比例，位于钴蓝雨夜路口。；沿用同一转身载体，依次进入琥珀市场与锈色街装、绿色地铁站与海军蓝工装外套、浅色雪巷与炭灰羽绒服。；最终转身回到钴蓝雨夜路口和开场深色夹克，准确原创标题【SAME SIGNAL / NEW CITY】出现。

## 必须保留的结构锚点

- One clearly adult original identity retains face, hair, eye color, accessory and body proportions across all chapters.
- A single repeated full-turn carrier precedes every location and wardrobe change.
- A complete front-facing verification pose follows every transition before another change begins.
- The terminal chapter returns to the opening environment and wardrobe under one exact original title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
