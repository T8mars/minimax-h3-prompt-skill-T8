# 陶杯手作工序｜拉坯、描花、成组与晨光洗手

## 用途

同一成年动画陶艺师在暖光作坊完成拉坯塑形、杯体稳定、蓝花描绘和成组摆放；终局从成品桌自然过渡到门外水池洗手，以可见泥水残留证明工序完成。

## 推荐输入格式

`固定处理表面 + 多工具单一职责 + 层层累积 + 单次揭除 + 两种独立验收`

## 可直接改写的简短示例

> 一名明确成年的动画陶艺师在晨间暖光中用同一陶轮塑造一只茶杯。；在同一只烧制后的杯子上画一枝蓝色枝条和五朵小花，近景保持稳定。；跟随她穿过开门走到水池，在流水下洗去双手可见陶泥。

## 必须保留的结构锚点

- One clearly adult craftsperson and one workshop persist.
- Each craft stage visibly changes the object.
- The group shot proves a finished series.
- Hand washing follows and confirms the completed process.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
