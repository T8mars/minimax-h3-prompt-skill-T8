# 连续拉远尺度揭危｜小型载体、扩张暗区与临界停留

## 用途

先用一个持续前进的小型载体作为尺度锚点，镜头不切地逐步升高并后退；一个起初像普通暗纹的环境异常必须保持中心关系并不断占据更大画幅，载体的航迹、速度和尺寸持续可读，最终在进入不可逆临界区之前停留，让尺度和危险都由同一连续镜头证明。

## 推荐输入格式

`小型移动载体先建立方向速度与轨迹 + 摄影机全程不切地持续升高后退 + 载体与异常保持同一坐标关系 + 异常从模糊纹理成长为占据主要画幅的清楚危险 + 撞击或消失前停留且载体仍可读`

## 可直接改写的简短示例

> 高位近距后跟小型橙色维护车沿银色轨道前进，身后留下细窄蓝色检测灯带；前方暗色圆区起初像反射错位，随后边缘和深度逐渐连成清楚结构；极远景保持，维护车仍在内部暗缘之外继续前进，不展示撞击、消失或新视角

## 必须保留的结构锚点

- Establish one small moving carrier with heading, speed cue and trail before the anomaly is legible.
- Use one uninterrupted camera retreat and elevation change with no reveal cut.
- Grow the anomaly from ambiguous texture into a coherent hazard occupying more of the frame.
- Hold before impact or disappearance with the carrier still readable.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
