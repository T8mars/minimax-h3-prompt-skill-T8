# 触屏造型切换｜固定界面、手势触发与人物实装

## 用途

把固定手机界面作为连续舞台，每次真实手势只改变一个明确槽位；文字、颜色与装饰先在界面响应，再由同一人物完成对应造型实装。

## 推荐输入格式

`固定选择菜单 + 固定数据区 + 固定主视窗 + 至少4个原创对象 + 每次可见选择 + 同步字段更新 + 一个定义动作`

## 可直接改写的简短示例

> 打开原创室内设计应用，固定房间卡片中站着同一成年建筑师。；第一次滑动只切换浅木材质，房间同步更新。；最终切换为钴蓝方案，同一人物与固定控件共同完成对照。

## 必须保留的结构锚点

- A persistent interface frame survives every transition.
- Each gesture changes only one named slot.
- The same adult subject remains identity-locked.
- The final state retains controls for direct comparison.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
