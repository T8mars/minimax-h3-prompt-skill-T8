# 单物微距英雄片｜材质证据、轮廓确认与静态收束

## 用途

围绕单一产品做由近到远的材质证明：先展示操作件与高光，再逐步扩展到完整轮廓、底座反射和稳定英雄构图，全程不引入无关人物。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 极近特写原创台灯的黄铜调光钮与斜切玻璃环。；在炭黑到琥珀渐变背景中居中展示完整台灯。；完整原创台灯进入对称英雄构图，以一圈暖边光停留，不出现文字。

## 必须保留的结构锚点

- One product remains the only hero object.
- Evidence expands from control detail to full silhouette.
- The reflective base confirms shape and finish.
- The final centered frame holds long enough for recognition.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
