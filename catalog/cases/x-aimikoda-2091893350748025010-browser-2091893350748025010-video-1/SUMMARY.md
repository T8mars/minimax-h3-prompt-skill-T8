# 单线织世｜一根材料分叉建景再回收到原创标记

## 用途

先把一根材料线和承载面锁定，再让它连续分叉、染色并把沿途结构建成可读地貌；所有新元素必须从仍可追踪的同一线束生长，不能凭空换景。密度达到峰值后，让支线按相反顺序回收并组成全新原创名称或徽记。

## 推荐输入格式

`单一材料线与承载面先清楚建立 + 所有分叉、颜色、结构和地貌都从可追踪母网生长 + 至少三个视觉不同区域共享同一基底并保持节点证据 + 密度峰值后沿既有路径反向回收而非溶解 + 同一材料最终组成一个全新短名称或徽记并稳定持有`

## 可直接改写的简短示例

> 微距打开：一条铜迹从哑黑电路板的石墨接触垫生长，先看清纤维状金属纹理和唯一材料起点，尚无建筑。；摄影机升到斜俯宽景，三个相连微缩区域生长：风港、阶梯数据花园和射电观测站，共享同一黑色基板与铜线网络。；电流反向，外围铜线沿原路径回收，区域折叠回线路，同一材料重新组成原创短标 GRIDMINT；清楚停留，不使用来源标志和文字。

## 必须保留的结构锚点

- Establish one material filament and one substrate before any world appears.
- Keep the parent network and every major junction traceable as branches construct new regions.
- At peak density, reverse movement along already established paths instead of dissolving the world.
- Resolve into one new original short name or emblem and hold it clearly.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
