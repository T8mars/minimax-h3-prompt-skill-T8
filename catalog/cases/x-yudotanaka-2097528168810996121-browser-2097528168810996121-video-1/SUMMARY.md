# 棒球跑垒闭环｜击球、接球、裁判手势与滑垒庆祝

## 用途

锁定同一成年动漫击球手、白色七号球衣和同一球场；击球后沿垒线持续奔跑，外野手接球与裁判手势并行制造压力，人物最终滑入本垒并以举臂庆祝结束，不虚构比分。

## 推荐输入格式

`固定双人对阵信息条 + 先交代动作轴线 + 同一小物体发出/接回/反击/决胜 + 每次切镜继承方向/击打侧/重心 + 1次俯视重校 + 可见得分结果和双方反应`

## 可直接改写的简短示例

> 一名明确成年的动画击球手身穿十一号球衣，在本垒击中一球。；外野手接住同一球，高位镜头同时保留跑者、垒包和传球路线。；完成一次脚先滑入本垒，随后起身举起双臂，队友作出可见反应；不展示比分。

## 必须保留的结构锚点

- One clearly adult player and jersey persist.
- The same ball links hit and fielding.
- Exactly one slide completes the route.
- Celebration follows arrival without inventing a score.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
