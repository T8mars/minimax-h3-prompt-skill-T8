# 双角色片头汇合｜独立署名、前景擦镜与主标题收束

## 用途

让两名成年角色先在独立信用章节中建立身份，再用交通工具、门框与花束完成前景交接；两条人物路线最终在同一海岸轴线上汇合并进入主标题。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 原创悬崖电车先横过画面，成年陶艺师出现在青绿色工作室门口，准确署名【MARA VALE】。；电车边缘、门框和地图卷完成三次有动机的前景擦镜，两张脸、服装和道具保持注册。；两人与海面、灯塔共同停在准确原创标题【TIDE BETWEEN US】下。

## 必须保留的结构锚点

- Each adult receives one distinct identity-credit entrance.
- Foreground objects motivate every chapter handoff.
- Separate routes visibly converge into one shared axis.
- The final master title holds with both adults and the destination.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
