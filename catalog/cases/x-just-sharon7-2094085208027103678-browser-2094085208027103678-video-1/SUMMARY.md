# 音频界面字卡变体｜成年角色、波形、耳机与动作模块

## 用途

同一成年动画角色以薄荷双发髻、橙色耳机和藏蓝橙夹克保持身份；播放界面、波形、音量环、下落字、跑跳、编号肖像和圆环破碎按动作分章，最后人物站在完整原创播放主标前。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 奶油色原创媒体面板先输入准确短词【SYNC】，随后显出原创明确成年声音编辑：钴蓝辫发、琥珀耳机、石墨夹克与薄荷波形徽章。；一次向前奔跑穿过轮廓字【FLOW】，直接衔接受控滑行动作沿藏蓝播放条前进；不出现额外角色或替换服装。；成年人穿过落定碎片，在同心圆中停止；准确完整主标【SYNC / KEEP THE BEAT】同框并保持全部文字可读。

## 必须保留的结构锚点

- One clearly adult identity and at least four appearance anchors precede every interface module.
- Each module is triggered by one visible body or headphone action and introduces no more than one exact short word.
- Boot and portrait-grid proofs verify the same character before the terminal movement.
- The final lockup reunites the adult, settled fragments, recurring rings and one readable original master mark.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
