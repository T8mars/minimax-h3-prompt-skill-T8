# 静谧手作循环｜缝合推进、茶歇停顿与原位恢复

## 用途

在固定窗边构图中，用手部针线推进作为隐性进度钟；人物完成一段缝合后饮茶停顿，再把杯子放回并恢复同一手作任务。

## 推荐输入格式

`同一工艺物 + 一个只增不减的材料变量 + 4个阶段 + 成品揭晓`

## 可直接改写的简短示例

> 原创成年船帆修补师坐在固定海港窗边桌前，面前是一块赭色布与金属杯。；第三针后放下布料，只从同一杯子安静饮水一次。；在先前终点之外完成最后一针，并以原构图中的持续工作状态停留。

## 必须保留的结构锚点

- One fixed workspace and task object remain registered.
- Repeated craft actions create visible progress.
- Cup and tool return to their original locations.
- Work resumes beyond the previous progress point.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
