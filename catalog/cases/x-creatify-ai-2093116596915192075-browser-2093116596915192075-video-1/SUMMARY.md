# 饮品欲望证明链｜包装出现、液体微距与饮用反馈

## 用途

让单一饮品包装先建立识别，再用原料微距、倒杯和真人饮用依次证明质地、流动与愉悦；最后以多包装阵列和短标语收束。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 暖石台面先建立原创【VELA】燕麦可可纸盒。；VELA以一条连续液流倒入带棱透明杯。；三盒VELA与装满的玻璃杯组成终局，准确短句【SMOOTH ENERGY】停留。

## 必须保留的结构锚点

- The package is identified before ingredient spectacle.
- Macro ingredients visibly relate to the beverage.
- An adult user reaction follows the serving proof.
- The final pack array and exact short line hold together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
