# 单次投掷地质反应｜冰块基线、火山接触与烟雾回灌

## 用途

在持续可定位的直升机舱口建立成年实验者和一块巨冰，人物只投掷一次；冰块进入火山口后依次触发中心冷点、熔岩涡旋、爆发与烟柱，最后烟雾回到机舱形成因果闭环。

## 推荐输入格式

`静态标准物开场校准 + 微型日常 + 校准物保持不动 + 不同外部执行物只进入一次 + 局部状态改变与反应同框`

## 可直接改写的简短示例

> 一名成年火山学家在勘测飞机舱口托住一块大型蓝色矿物块，下方是铜色地热喷口。；接触后在中心形成一个蓝色冷却圆盘，外围铜色液体环开始旋转。；回到同一飞机舱口，白色烟柱到达后，火山学家在门框后下蹲一次。

## 必须保留的结构锚点

- One clearly adult operator, one aircraft and one inert block persist.
- The block is released exactly once and remains traceable to impact.
- The crater or vent geography never resets during escalation.
- The terminal cabin response is caused by the same plume.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
