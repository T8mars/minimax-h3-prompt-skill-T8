# 海边口播实证｜人物直视、包装举证与一次使用

## 用途

以同一成年口播者、海滩和自拍机位建立可信基线；人物举起一罐产品、让正面包装可读，做一次短促使用或体验反应，最后回到直视镜头的产品结论。

## 推荐输入格式

`出镜测评者 + 未开封产品 + 完整内容展示 + 一个产品专属微距证据 + 一次完整使用 + 产品与反应同框`

## 可直接改写的简短示例

> 一名原创成年徒步向导在明亮湖岸手持自拍口播，同一岸线始终位于身后。；镜头轻微靠近，人物面部和完整罐体在同一画面中保持可读。；以直视镜头收束，【CITRUS NORTH】仍在脸旁，湖面地平线保持不变。

## 必须保留的结构锚点

- One clearly adult host, one package and one location persist.
- The package front is shown before the experiential claim.
- The reaction follows use and remains physically restrained.
- The final frame reconnects host, package and environment.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
