# 熟悉物件内藏世界｜透明揭示、下潜进入与来源回证

## 用途

先把普通物件作为尺度基线，再让局部透明揭示内部世界；镜头沿同一开口下潜、在内部完成空间证明，最后用原物件结构回证来源。

## 推荐输入格式

`熟悉物件＋内部世界＋进入开口＋来源回证`

## 可直接改写的简短示例

> 黄铜桌面按键、微缩植物车站、透明键帽、同一开口下潜。

## 必须保留的结构锚点

- 先建立普通物件尺度
- 内部世界从原物件内显出
- 结尾回证仍在原容器内

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
