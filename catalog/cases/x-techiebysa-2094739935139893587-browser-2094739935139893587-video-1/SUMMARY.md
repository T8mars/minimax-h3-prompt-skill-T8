# 梗图选择器变体｜固定菜单、点击切换与发送反馈

## 用途

固定应用框架、左侧选项栏、当前高亮和发送按钮持续不变；可见光标每次只选择一个反应类型，主画布随即换成对应人物、配色、短文案和定义动作，最后一次发送反馈证明所有变化来自同一选择系统。

## 推荐输入格式

`固定选择菜单 + 固定数据区 + 固定主视窗 + 至少4个原创对象 + 每次可见选择 + 同步字段更新 + 一个定义动作`

## 可直接改写的简短示例

> 建立一个原创反应卡应用：固定藏蓝标题栏、左侧五个中性选项、一条青柠高亮、中央卡片，以及右下角准确按钮【发送卡片】。；只点击一次【大胆胜利】；整个界面保持不变，一名原创成年运动员进入卡片、举起一只拳头，并连续转化成橙色插画胜利肖像。；光标移到【发送卡片】并只点击一次，在未改变的最终卡片旁停留一个绿色已发送勾号；不能再出现额外选择或人物。

## 必须保留的结构锚点

- One fixed interface, one ordered option rail, one current highlight, one result canvas and one send control establish the baseline.
- Every visible click changes exactly one selection state before the corresponding subject and graphic language update.
- Each result has one distinct readable reaction action rather than a passive portrait or unrelated montage.
- The terminal send acknowledgement preserves the last selected result and proves one complete input-to-output loop.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
