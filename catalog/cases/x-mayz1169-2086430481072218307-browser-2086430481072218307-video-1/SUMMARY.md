# 平面重组｜纸艺无障碍示例

同一平面重组机制的纸艺无障碍说明变体；用于扩展证据，不新增下拉选项。

## 核心机制

Build a flat poster world around one dominant geometric motif and one stable protagonist silhouette. Repeatedly fracture and reconstruct the layout through hard-edged crops, diagrams, negative space and key states; peak information density before a short contrastive operational tableau, then resolve established graphic families into one original closing system.

## 推荐输入格式

`单一纸艺母题 + 稳定人物剪影 + 4段状态重组 + 高密验证 + 路线徽记收束`

## 简短示例

> 以折纸坡道为母题，轮椅使用者剪影保持稳定；四段纸艺依次建立入口、三种通行状态、高密验证和受阻平台，最终折出坡道并收束为路线徽记。

## 必须保留的结构锚点

- 复用平面重组模板而非新模板
- 四段纸艺节奏
- 人物剪影稳定
- 高密验证后用同一图形族收束

## 使用方法

1. 先保留用户主体和目标，再按推荐格式补齐场景、事件链、镜头和结果。
2. 阅读 [Creative DNA](./creative-dna.json)，重新实例化变量，不做来源表面换名词。
3. 分别查看 [MiniMax H3](./prompts/minimax-h3.md) 与 [Seedance 2.0](./prompts/seedance-2.0.md) 的已验证实例。
4. GitHub 使用 GIF 快速预览；Electron 媒体包播放完整有声 MP4。
