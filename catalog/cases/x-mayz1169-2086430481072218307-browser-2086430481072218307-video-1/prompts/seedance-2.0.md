# 平面重组｜纸艺无障碍示例 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：生成一支原创纸艺无障碍疏散图解：以折叠走廊和疏散椅剪影为核心，纸板通过竖向铰链重组路线状态，在空置受阻平台短暂停顿，再由单次坡道折叠收束成无障碍路线徽记。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
主体定义：疏散椅：紧凑深蓝平面剪影，轮弧和握把特征全程稳定；折叠走廊：四条赭色纸带，以竖向纸铰链改变平面布局；状态标记：一个青色终点方块与两枚触觉圆点。
镜头1：暖白纸面固定俯视，纸层向外翻开；四条赭色走廊纸带围绕同一深蓝疏散椅剪影建立路线，青色终点方块和触觉圆点出现；纯平面纸艺，不形成写实楼梯空间；赭色、深蓝、暖白与单一青色；<纸铰链展开><触觉点轻响>。
镜头2：纸板沿竖向铰链连续折叠；同一疏散椅依次呈现停驻、下坡和平台三个状态，门扇弧与扶手纸带围绕它重组；所有状态由纸折完成，不使用横向数字面板滑动；纸纤维与青色状态点连续；<三次纸折><轮弧摩擦>。
镜头3：俯视高密纸层翻转；楼梯斜线、门净空弧、转移圆、握把缺口和安全区纸块快速叠加，同一疏散椅剪影保持不变；每次翻折只改变一个通行状态；保持四色限制；<密集纸片翻转><状态点击>。
镜头4：画面大幅留白后一次中心折叠；空置受阻平台短暂停顿，一条折叠坡道旋转对齐；走廊纸带、轮弧、触觉点和青色终点随后折成原创无障碍路线徽记；受阻状态与最终收束合并为同一长段；暖白留白、赭色纸带、青色终点；<近静音><坡道折锁><四次柔和收束>。
整体风格与画质：原创触感纸艺无障碍动态图解，赭色深蓝暖白与单一青色，真实纸纤维、竖向铰链和平面折叠；采用四段纸艺节奏完成建立、三状态重组、高密验证以及受阻平台到路线徽记的合并收束，不使用横向数字面板滑动或五段图表编排。
约束：保持四条走廊纸带、同一疏散椅剪影和青色终点方块连续；只使用纸艺铰链和折叠，不形成写实三维空间或数字UI；采用四段信息节奏，最后一段同时包含受阻平台与单次坡道解决；结尾只复用已建立的纸艺几何，不生成可读标题、Logo和水印。
```
