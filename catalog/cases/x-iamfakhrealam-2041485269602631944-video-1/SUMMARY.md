# 巨体攻防｜共享空间中的连续闪避

## 用途

在不切断地理关系的连续镜头中，让巨体用慢而重的承诺动作占据空间，小体型主体则靠侧移、俯身和绕行依次穿过负空间；双方始终可定位，结尾保留持续对峙而非虚构胜负。

## 推荐输入格式

`大小尺度明确的两主体 + 共享地面 + 巨体承诺动作 + 小体型可见变线 + 无虚构胜负的共享终态`

## 可直接改写的简短示例

> 掌上巡检车在明亮纸厂穿越三条标记通道，巨型吊臂缓慢横扫占据空间；巡检车只靠等待、变线与收低传感杆通过，结尾保持双方运行，不宣称胜负。

## 必须保留的结构锚点

- Establish the full scale difference and a common ground plane before the first exchange.
- Give the large body one slow committed movement that visibly occupies a route.
- Preserve both participants and the ground axis through each recovery.
- Hold the final shared state without inventing defeat, rescue or alliance.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
