# 纪实跟拍｜屋顶日常到镜头致意

## 用途

拍摄者先像偶然发现一样接近日常人物，再用同一观察距离记录几项朴素动作；外部线索改变人物目标，人物只对镜头做一次简短回应，最后以带有手持误差的离开完成记忆感。作为既有纪实偶遇模板的新证据，不新增选择器。

## 推荐输入格式

`观察者媒介 + 日常人物/地点 + 两个日常动作 + 外部信号改变目标 + 一次回应 + 有动机录制失误`

## 可直接改写的简短示例

> 原创夜间植物温室里，拍摄者绕过一张植床，发现年长园丁已经在擦玻璃冷凝水，开场不看镜头；侧门旁服务铃响起，园丁停止检查并看向铃，镜头短暂呼吸对焦；园丁离开，白平衡从荧光绿漂到钠灯琥珀色，对焦在门开始关闭后才落稳，留下空温室

## 必须保留的结构锚点

- Begin with an observer discovering a subject already inside an ordinary routine.
- Use recurring environmental landmarks to keep several small actions in one readable geography.
- Allow exactly one restrained acknowledgment of the observer.
- End with departure and at least one mild operator imperfection still visible.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
