# 倒地翻盘动作弧｜受压基线、近身脱困与站立回稳

## 用途

明确两名成年角色和同一和室空间，先建立主角倒地受压，再通过一次抓腕、转身和扫腿形成连续脱困；冲突必须非血腥，终局主角站稳、威胁倒地并停止攻击。

## 推荐输入格式

`稳定主体与中断目标 + 可读困境 + 因困境主动靠近的外部压力 + 至少两个准备微证据 + 单一能力链破局 + 回到原载体继续路线`

## 可直接改写的简短示例

> 让一名原创成年递送员倒在软垫训练场，一名穿护具的成年教练靠近。；近景展示一次非血腥扣腕，再用转肩把教练的力量带过身体中线。；递送员起身后退一步，保持平静防守姿态，教练示意训练结束。

## 必须保留的结构锚点

- Both participants are clearly adult and remain distinct.
- The action is a non-graphic controlled training exchange.
- Only one takedown occurs in the unchanged room.
- The final state ends aggression and restores stable spacing.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
