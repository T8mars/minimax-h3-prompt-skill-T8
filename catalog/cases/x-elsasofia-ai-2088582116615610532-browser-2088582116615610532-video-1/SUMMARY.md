# 场所反制｜追踪威胁与环境物件接力

## 用途

用一个公共路线建立主角身份和运动方向，让同一追踪威胁在至少两个功能不同的室内场所重复出现；主角每次只能调用当前场所独有的可见物件完成一次不同反制，随后继续前进，最终回到开场公共路线并以稳定身份、步态和视线结束。

## 推荐输入格式

`成年主角、公共路线与前进方向 + 同一非血腥威胁跨至少2个功能不同的室内场所 + 每处先展示专属物件库存 + 每处只用本地物件完成不同反制 + 连续离开 + 回到原公共路线稳定结束`

## 可直接改写的简短示例

> 穿栗红外套、佩金属徽章的成年交通检查员稳定向前走，尚无威胁；她沿同一方向离开，保持同一成年面孔、外套、徽章和无人机外壳，背景过渡到自行车工坊；同一检查员保持原方向和稳定步态前行，最后只给一次冷静视线

## 必须保留的结构锚点

- Establish one adult protagonist, public route and forward movement before the threat appears.
- Use one recurring non-graphic threat across at least two functionally distinct interiors.
- Use only local inventory for one materially different defensive redirection in each interior, then continue moving.
- Return to the opening public route with stable identity, direction, gait and terminal gaze.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
