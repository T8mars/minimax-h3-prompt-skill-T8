# 雪地技巧递进｜装备基线、第一视角加速与腾空峰值

## 用途

先用头盔、雪镜和雪板建立成年运动员，再由第一视角滑行切到外部跟拍；直线加速、上杆、落地与跳台腾空逐级提高难度，单一大跳作为终局峰值。

## 推荐输入格式

`持续基础动作 + 3种高级技能 + 每次不同功能机位 + 节奏/接触声连续 + 回到基础动作`

## 可直接改写的简短示例

> 一名明确成年的原创单板教练收紧红色雪镜，并在标记起点检查一块黑色雪板。；切换到低位后跟，保持头盔、雪镜和影子一致，接近一根黄色滑杆。；加速冲向一座白色跳台，只腾空一次，并让抓板剪影在太阳前停留后开始下降。

## 必须保留的结构锚点

- One clearly adult original athlete and one equipment set persist.
- Difficulty increases from preparation to glide, rail and jump.
- A stable landing separates intermediate proof from final peak.
- Exactly one large airborne action closes the sequence.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
