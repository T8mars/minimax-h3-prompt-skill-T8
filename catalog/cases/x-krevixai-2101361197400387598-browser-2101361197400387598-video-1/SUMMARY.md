# 固定人台逐层着装｜衣物投送、层级闭合与触感验收

## 用途

锁定一个无身份人台，衣物按下装、内搭、外套和配件的功能层级依次到位；第一人称双手只负责投送或整理，最终用触摸和全身轮廓证明完成。

## 推荐输入格式

`固定人台＋有序服装层＋操作者双手＋成品验收`

## 可直接改写的简短示例

> 中性无脸人台、长裤、衬衫、马甲、外套、窄领带。

## 必须保留的结构锚点

- 人台比例全程不变
- 衣物按功能层级到位
- 终局同时证明轮廓与材质

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
