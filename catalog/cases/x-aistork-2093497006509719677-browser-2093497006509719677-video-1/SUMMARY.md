# 固定地点历史建造｜年份阶梯、施工累积与地标完成

## 用途

锁定同一地点的俯视构图与边界，用可读年份推进空地、拆建、基础、主体和完成状态；每个年代只能继承前一状态，两个地点分别完成后再并列比较。

## 推荐输入格式

`稳定主体 + 边界清楚的转换带 + 新旧状态同框 + 单向累积覆盖 + 载体退出后的完整结果`

## 可直接改写的简短示例

> 固定原创河岸图书馆地点的航拍坐标，显示准确年份【1970、1995、2010、2020、2028】。；同一图书馆依次出现框架、屋顶和完成立面，周边背景继承。；两个完成的公共地点分屏，准确短句【TWO PLACES / ONE CITY】停留。

## 必须保留的结构锚点

- Each site uses one fixed recoverable coordinate.
- Exact dates advance monotonically.
- The second site repeats the same state grammar independently.
- The final view compares two completed locations without coordinate drift.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
