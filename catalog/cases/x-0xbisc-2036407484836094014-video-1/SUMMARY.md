# 技艺递进｜原料变形到成品特写

## 用途

先给出单一原料，再用功能不同且难度递增的手部操作连续改变其形态；一次明确热处理完成不可逆转折，随后快速装盘，并用成品微距证明前面所有动作得到结果。

## 推荐输入格式

`单一原料 + 至少3种功能不同的形变操作 + 1次不可逆加工 + 成品组装 + 保留前序痕迹的微距终证`

## 可直接改写的简短示例

> 太阳帆修复师把同一束植物纤维拉伸、分条、编织并张紧到六边形框，只热压一次完成封合，最后用微距证明成品膜仍保留拉伸、编织和封合痕迹。

## 必须保留的结构锚点

- Establish one raw material and its maker before complex manipulation.
- Use at least three functionally different manipulations that visibly change the same material.
- Cross one visible irreversible processing threshold before the result assembly.
- End on a macro finished-state proof that retains visible evidence of earlier transformations.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
