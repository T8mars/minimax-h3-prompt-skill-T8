# 身份机体跃迁｜同一特征跨陆空载具升级

## 用途

先建立一个可辨认身份，再让其核心特征连续嵌入功能等级逐步提升的移动机体；每一阶段都同时保留身份锚点和新机体的可见功能，最后跨入新的运动类别并以完整混合体收束。

## 推荐输入格式

`身份锚点 + 至少三种移动机体 + 每阶段保留身份并增加可见功能 + 跨运动类别升级 + 完整混合体终态`

## 可直接改写的简短示例

> 原创极地研究舱内，一枚石墨色传感圆盘放在冰面，正面三角琥珀标记和侧面三点签名同时亮起一次；采样器在窄裂隙前压缩并接入双滚轮缆车，身份标记保持朝前，滚轮沿张紧钢索横越裂隙；最终气象探针以宽风翼、稳定翼和原传感面完整滑翔，琥珀身份锚点与空中功能同时可读

## 必须保留的结构锚点

- Establish one identity motif with at least two stable visual anchors before machine integration begins.
- Show the motif physically merging with the first mobility body rather than cutting to a finished replacement.
- Escalate through another mobility realization with a visibly different affordance.
- Finish with one larger mobility-class change and hold identity plus function together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
