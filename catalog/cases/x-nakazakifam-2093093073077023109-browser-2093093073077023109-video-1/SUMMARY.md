# 双层表演语义同步｜真人锚点、图形回应与关键词推进

## 用途

固定上层真人表演者作为身份锚点，下层图形空间逐词回应其表情或动作；每个关键词只触发一种印刷或墨迹反应，双层在终句同步收束。

## 推荐输入格式

`稳定原创表演者 + 3至4句原创歌词 + 每句语义图形行为 + 人物始终可辨 + 逐句升能 + 清字后的表演释放`

## 可直接改写的简短示例

> 上层固定一名成年电台主持人，下层固定抽象纸质波形场。；一次小幅挥手触发准确短词【REACH】，一条墨线横向延伸。；双层共同收束到主持人静止凝视与准确终句【STAY TUNED】。

## 必须保留的结构锚点

- One live performer remains registered in a stable band.
- Each exact keyword follows one readable performance cue.
- Typography never obscures the identity anchor.
- Both bands resolve on one final performer-and-line state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
