# 道具复得｜外部夺走、同伴安抚与隐蔽取回

## 用途

先让两个角色共同使用一个高价值道具，再由外部角色明确夺走；让两位角色分别出现失落和安抚反应，随后由同伴从早已建立的隐蔽位置取回同类道具，恢复共同活动并以默契终态收束。

## 推荐输入格式

`双角色共同使用道具 + 第三方明确夺走 + 不同失落反应 + 一次同伴安抚 + 有铺垫的隐蔽位置取回替代道具 + 恢复共同活动`

## 可直接改写的简短示例

> 两个成年角色编码的原创月面勘测机器人共同查看透明路线板，沙色机体的关闭胸部舱格同时可见；钴蓝机体闪一次琥珀错误灯并侧开，沙色机体低头，只完成一次安抚触碰；两者共同激活备用路线板并恢复规划姿势，以同步确认停留

## 必须保留的结构锚点

- Show two characters jointly using one desirable prop before it is removed.
- Use one visible third-party action to remove the prop and stop the shared activity.
- Recover an equivalent functional prop from a previously plausible hidden location controlled by the partner.
- Return both characters to the original joint activity and hold the restored relationship.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
