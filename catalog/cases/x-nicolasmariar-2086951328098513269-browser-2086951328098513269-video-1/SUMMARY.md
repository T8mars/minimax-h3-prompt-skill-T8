# 气闸异境｜物理异常后空间崩坏

## 用途

先锁定普通密闭空间与遗留物，普通操作后让室内积累物理异常，再经短黑场开向不可能异境，用遗留物证明空间连续。

## 推荐输入格式

`锁定密闭空间 + 普通操作检查 + 室内物理异常 + 连续见证物 + 不可能外部`

## 可直接改写的简短示例

> 极地去污气闸完成常规冲洗检查后，暖赭色细沙从密封墙缝侵入；短暂断电后舱门外变成阳光荒漠峡谷，原位红色仪器箱证明空间连续。

## 必须保留的结构锚点

- Lock one familiar enclosed-room geometry before the anomaly begins.
- Place one ordinary operation or control check before the physical anomaly.
- Preserve one inert witness object across the interruption.
- Hold the impossible exterior and unchanged interior together after the occupant is absent or displaced.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
