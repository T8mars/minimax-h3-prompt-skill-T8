# 窗台入境回环｜静态黑猫、月夜疾走与原位归返

## 用途

一只可辨黑猫从月夜窗台静止基线出发，穿过室内并跃入星空尺度；月亮、窗框和蓝色光线持续回声，最后回到原窗台完成闭环。

## 推荐输入格式

`现实锚点 + 单一载体 + 平面→空间→体积→环境峰值 + 回到原位的残留`

## 可直接改写的简短示例

> 一只银色狐狸摆件静置在蓝光观测窗台，圆月位于上方。；银狐穿过一个圆形开口跃入星空，耳朵、尾巴和银色毛皮保持。；让星路折回圆形开口，银狐回到开场窗台的准确姿态。

## 必须保留的结构锚点

- One nonhuman subject retains exact identity.
- The opening sill and moon define the return target.
- Repeated geometry links room and star world.
- The final frame matches the opening position with one small residual glow.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
