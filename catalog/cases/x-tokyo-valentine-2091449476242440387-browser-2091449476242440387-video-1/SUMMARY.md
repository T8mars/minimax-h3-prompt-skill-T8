# 语义字场动作接力｜成年角色每次行动生成一个空间短词

## 用途

同一明确成年角色在连续空间里完成动作，每个动作只生成一个与行为或心理相关的巨大短词；文字成为可穿越、遮挡或反射的环境结构，最终回到同一身份终局。

## 推荐输入格式

`Establish one clearly adult original subject, three identity anchors and one continuous world axis. + Bind each decisive action to exactly one short original semantic word that appears only after the action begins. + Make each word occupy, divide, reflect or redirect the physical environment rather than float as a subtitle. + Escalate typography scale and spatial depth while preserving identity, travel direction and readable action. + Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.`

## 可直接改写的简短示例

> 原创雨夜船坞中，锁定一名明确成年铜发路线工程师，穿深蓝长外套、持黄铜测量杆，沿固定左右方向移动。；她穿门奔跑、转动绞盘并跨过栈桥；准确短词【TURN】和【CROSS】分别从绞盘辐条与桥栏生成，每个动作只对应一个词。；回到雨水玻璃中的脸部倒影；之前字构在她身后对齐，只让准确终局词【CHOOSE】与同一成年肖像锁定。

## 必须保留的结构锚点

- Establish one clearly adult original subject, three identity anchors and one continuous world axis.
- Bind each decisive action to exactly one short original semantic word that appears only after the action begins.
- Escalate typography scale and spatial depth while preserving identity, travel direction and readable action.
- Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
