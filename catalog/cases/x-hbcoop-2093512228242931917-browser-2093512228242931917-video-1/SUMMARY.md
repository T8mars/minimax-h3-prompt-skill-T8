# 单工作位微表演｜控制确认、视线转移与静默待命

## 用途

在单一工作位锁定一名成年操作员、控制器和外部环境，通过手部调整、仪表反馈与一次视线转移证明状态确认；不虚构登船或超现实事件，终局保持克制待命。

## 推荐输入格式

`两名明确成年原创角色、一个可见服装或装备问题和稳定共用轴线 + 帮助者只用一次连续双手动作完成可核验调整 + 完成状态出现后停顿并退开 + 接触结束后两名成年人分别给出不同克制微反应 + 回到共同构图且完成物件与稳定姿态同时可见 + 不依赖未经验证对白语义`

## 可直接改写的简短示例

> 成年潮汐站操作员坐在紧凑黄铜玻璃控制台前，窗外是月光海面。；流量杆移动一格，指针停到下一条标记区间。；同一人物、流量杆、仪表和安静海面共同保持待命。

## 必须保留的结构锚点

- One adult operator, workstation and external view remain fixed.
- One practical adjustment is small and visible.
- A nonverbal check confirms readiness without dialogue claims.
- The terminal state remains calm, stable and operational.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
