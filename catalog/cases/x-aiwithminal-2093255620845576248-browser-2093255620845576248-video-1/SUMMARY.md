# 近身能量格斗｜受围起势、接触闪光与逐敌清场

## 用途

先建立被多人包围的空间压力，让主角手部能量从一次受击或蓄力中出现；每次电光只跟随可见接触，敌手按空间顺序退出，最终主角独立站稳。

## 推荐输入格式

`明确成年原创主体、可读对手和稳定地面关系先建立 + 每次先完整承诺物理轨迹并真实接触 + 能量、尘屑、毛发、布料或灯光只在接触后局部短促响应 + 通过对手数量和反馈半径升级但轮廓始终清楚 + 终局效果归零并在同一空间稳定持有主体`

## 可直接改写的简短示例

> 一名成年仓库电工站在标记地面通道上，四台成年尺度训练无人机逼近。；一次掌部改向和一次低踢，每次可见接触只产生短蓝弧，并让一台无人机退出通道。；电弧完全停止，同一电工独自站在四台停机无人机旁。

## 必须保留的结构锚点

- One pressured arena and all opponents are established.
- Energy appears on a bounded body part before first contact.
- Opponents exit the active lane in readable order.
- Effects cease and one stable terminal state remains.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
