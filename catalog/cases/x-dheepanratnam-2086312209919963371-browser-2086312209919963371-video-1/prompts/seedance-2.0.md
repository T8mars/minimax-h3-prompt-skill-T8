# Layered Field-Guide Illustration Comes Alive — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应更换人物、场景、道具、色彩、动作和结尾，不要只做名词替换。

## Prompt

```text
任务：文本生成新视频。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：完全锁定的垂直俯拍单镜头；空白深靛蓝图纸上先出现淡灰石墨定位十字和大弧线，只确定中央轨道观测站与三个径向仪器臂的位置，边栏暂时留空；主体图位于中央，四周预留图例与剖面框；纸张、桌面和阴影全程不移动；冷白光台均匀透光，深靛蓝纸面与淡灰草线形成低对比；<安静制图室底噪><轻柔石墨划纸声>。
镜头2：保持同一俯拍，不缩放不旋转；白色精密制图线沿同一坐标覆盖草线，依次闭合中央环、三个仪器臂、支撑桁架和小型太阳能板；主轮廓完成后再出现剖面排线和尺寸箭头，先前痕迹全部保留；所有结构严格注册，不换图、不漂移、不遮挡；白线清晰但不发光，纸张纤维仍可见；<干燥技术笔尖摩擦声>。
镜头3：继续锁定俯拍；半透明青色先填入传感与居住区域，随后低饱和琥珀色填入供能路径；色层沿纸纤维轻微扩散并在边缘沉积，但始终落在已完成的白色线框内；中央结构先完成，边栏仍不启动；青色与琥珀色克制、哑光、无霓虹和数码辉光；<湿画笔掠过纸面><纸纤维吸水声>。
镜头4：同一固定机位；边栏的图例符号、无文字剖面缩略图和校准刻度逐区出现，每次只激活一个预留框；不得出现可读单词或数字；附加信息只占边栏，不遮挡中央观测站；维持既有冷白、深蓝、青色与琥珀色；<短促笔触><轻微纸张回弹>。
镜头5：锁定终态并停留；完成的蓝图完全静止，中央环旁一个很小的空心白色圆形状态标记变成实心琥珀色，并以平面印刷图形的方式缓慢脉冲两次；墨线不凸起，纸张不动；只有局部状态标记变化，其他所有区域冻结；脉冲只是颜色密度变化，不产生光晕或投影；<两次低而精确的电子滴答>，环境声轻柔收束。
整体风格与画质：高品质实体微距制图摄影，深靛蓝建筑蓝图、白色制图墨线、淡石墨草线、克制青色与琥珀色水洗，纸张纤维真实，未来感来自设计语言而非霓虹特效；全程空间注册稳定，每一层按因果顺序累积；线条与色区清楚，边栏不抢主体，最终脉冲保持二维平面属性。
约束：不得出现鸟、树枝、自然史书页、古董纸张、手写段落、物种名或源画面版式；不得出现真实品牌、Logo、可读文字、数字、字幕、水印或页码；不得切镜、移动、旋转、缩放或改变纸张透视；不得让观测站变成立体物体、飞离纸面或产生霓虹辉光。
```

## 使用检查

- 保留因果机制，不复刻来源视频的人物、品牌、对白、构图和标志性效果。
- 核对主体身份、空间关系、动作先后与最终状态是否稳定。
- 需要明显不同的新用途时，返回 [Creative DNA](../creative-dna.json) 重新实例化可变槽。
