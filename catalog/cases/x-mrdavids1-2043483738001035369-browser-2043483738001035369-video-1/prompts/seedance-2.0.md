# 显物兑现｜空手基线到道具功能与终态回扣 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：一名原创成年天文台技术员穿石板灰工作服站在深色矿物平台上，先清楚展示双手空无一物；只轻点一次铜质腕扣，琥珀磁片在同一双手之间分段装配成折叠黄铜风琴测量器。技术员立即转动小型刻度轮，平台周围黑砂依次升起三圈可数环带；完成时铜粉只在同一件工作服上留下窄条标记，完整测量器仍稳定握在手中。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：克制环绕全身景；原创成年天文台技术员站在深色矿物平台，双手张开并清楚空无一物，铜质腕扣和三圈平整黑砂可见；先锁定同一人物、双手、服装和空间基线，禁止提前出现道具；石板灰、深黑矿物与少量铜色；<低风底噪><手套轻动>。
镜头2：收紧到双手和上身；技术员只轻点一次腕扣，琥珀磁片沿可追踪短路径飞来，在同一双手之间机械展开成一件折叠黄铜风琴测量器；仅一个触发、一个道具，人物身份和手部所有权连续；克制琥珀磁光与黄铜折片；<一次腕扣轻响><磁片装配>。
镜头3：保持中近景并侧向跟随；完整测量器锁入双手，技术员立即转动刻度轮，第一圈黑砂同步升起；同框证明手部动作、道具功能和首次环境回应；黄铜刻度高光与黑砂边缘；<刻度轮转动><第一圈砂粒升起>。
镜头4：缓慢扩到平台全貌；技术员继续同一测量动作，第二圈和第三圈黑砂依次升起，测量器与人物不变；环境变量只增不减且严格可数；三层黑砂高度与稳定琥珀核心；<连续机械脉冲><砂粒层层响应>。
镜头5：回到稳定中景并停留；刻度轮到达终点，铜粉只在同一件石板灰工作服上形成一条窄标记；完整测量器仍握在手中，三圈黑砂稳定；道具持续存在并留下与功能相关的单一终态回扣；稳定铜色终光；<轮轴止动><铜粉落定><余响消退>。
整体风格与画质：原创触感科学幻想影像，成年天文台技术员、哑光石板灰工作服、深色矿物平台、折叠黄铜仪器、克制琥珀磁力、黑砂回应和连贯实体材质；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
