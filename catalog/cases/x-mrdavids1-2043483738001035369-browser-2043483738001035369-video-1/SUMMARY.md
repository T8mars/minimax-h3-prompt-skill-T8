# 显物兑现｜空手基线到道具功能与终态回扣

## 用途

先用清楚的空手和稳定人物建立不可争议的基线；单一触发后让关键道具通过可追踪的分段装配出现，人物立即用它完成可验证功能，环境随使用逐步回应，结尾让道具持续存在并留下一个与功能相关的终态变化。

## 推荐输入格式

`明确成年主体 + 双手空无一物基线 + 单次触发 + 单一道具分段装配 + 立即功能兑现 + 环境累积回应 + 道具持续存在与终态回扣`

## 可直接改写的简短示例

> 原创成年天文台技术员站在深色矿物平台，双手张开并清楚空无一物，铜质腕扣和三圈平整黑砂可见；完整测量器锁入双手，技术员立即转动刻度轮，第一圈黑砂同步升起；刻度轮到达终点，铜粉只在同一件石板灰工作服上形成一条窄标记；完整测量器仍握在手中，三圈黑砂稳定

## 必须保留的结构锚点

- Show both hands empty long enough to establish one unambiguous baseline.
- Use one visible trigger and one staged assembly path for a single object.
- Make the completed object perform its defining function immediately.
- End with the object still present and one function-linked secondary state change.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
