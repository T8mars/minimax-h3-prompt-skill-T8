# 公共兑现｜席间期待—揭晓—群体释放—登台锁定 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创海底研究穹顶内，先以宽景建立玻璃礼堂、桌席和发光标本台，再收紧到同桌等待的四名海洋工程师。投影屏揭示他们的珊瑚礁修复方案入选，团队拥抱首席工程师；她沿同一条人群通道走到标本台，最后手持小型活珊瑚胶囊，与后方恢复中的珊瑚礁监测画面共同定格。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：高位宽景缓慢推进；承压玻璃礼堂内布满琥珀桌灯，前方只有一个发光标本台，窗外深青海水与远处珊瑚结构可见；先建立公共场合、观众规模和终点；海底科学典礼，无品牌与明星图像；<穹顶低鸣><遥远水流>。
镜头2：切稳定桌席中景；银色辫子首席工程师、圆眼镜材料专家、光头潜水员和带铜色助听器的年长技师同桌等待，只交换克制微笑；建立揭晓前的小群体关系基线；四人面孔、服装和桌位稳定；<轻声交谈><玻璃杯轻触>。
镜头3：切标本台宽景再立即回桌席近景；投影只显示原创珊瑚礁修复图与四个简洁头像，回到同桌时四人同步显出惊讶，首席工程师用手停住一次呼吸；把公开揭晓传递为同一群体的可见反应；无可读品牌或奖项文字；<短促提示音><人群吸气>。
镜头4：手持中景连续跟随；团队拥抱首席工程师，她拿起一个珊瑚胶囊盒站起，沿鼓掌同事让出的同一条过道走向已建立的标本台；把认可转化为可追踪的共同释放与路线；银色辫子、胶囊盒和路线不漂移；<掌声渐强><连续脚步>。
镜头5：正面舞台近景并停留；同一工程师打开盒子、在麦克风旁举起一枚小型活珊瑚胶囊，后方实时珊瑚画面亮起新生息肉；只保留可见说话动作，不指定台词；用人物、认可物和公共终点共同锁定；暖台灯、深青背景和胶囊细节；<掌声收低><清澈双音收束>。
整体风格与画质：原创写实海底科学典礼，承压玻璃建筑、深青色海水、琥珀桌灯、克制纪录片表演、稳定人物连续性和优雅公共活动调度；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
