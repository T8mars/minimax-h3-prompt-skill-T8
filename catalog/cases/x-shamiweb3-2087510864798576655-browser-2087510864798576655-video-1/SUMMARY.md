# 异客日常化｜多项普通任务累积到黄昏返回

## 用途

先用一个一眼可识别的非常规访客制造钩子，随后不解释其来历，而让同一身份锚点依次完成驾驶、取物、烹饪、护理和园艺等互不重复的普通任务；每段都以可见结果落地，最后回到与开场相同的住宅边界和夜间静止状态，让荒诞前提被日常秩序逐步正常化。

## 推荐输入格式

`原创非常规访客与普通门槛 + 稳定身份锚点 + 至少4项非重复日常任务 + 每项熟悉工具/完整动作/可见结果 + 世界正常响应 + 仅1次日夜变化 + 回到开场门槛并克制回应`

## 可直接改写的简短示例

> 半透明维护机器人带稳定琥珀胸灯和三指机械手抵达门槛，向管理员克制示意，货运三轮车在旁；机器人用小扳手校正风向标直到箭头随风自由转动，再把三封信分别放入三个匹配格口；机器人停好同一车辆，把密封包裹放上管理员桌，进入充电壁龛并向观察者闪烁一次琥珀胸灯后静止

## 必须保留的结构锚点

- Establish one original extraordinary visitor at an ordinary threshold before the route begins.
- Keep the same identity anchors across at least four non-repeating mundane tasks.
- Let the world respond normally and avoid explaining the visitor's origin.
- Use one day-to-night transition and return to the opening boundary with a restrained acknowledgment.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
