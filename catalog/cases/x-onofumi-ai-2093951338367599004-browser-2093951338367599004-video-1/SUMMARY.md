# 蓝色动漫宣传字卡｜角色锁定、冲击姿势与标题复归

## 用途

同一成年动画角色用挥拳、跑动、落地和蹲姿驱动蓝黑白漫画爆炸、格纹和短标题；局部脸部与靴子必须回连完整人物，终局回到同一主标题海报。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 锁定原创成年动画打击乐手：珊瑚卷发、绿眼、黑色连体服和象牙靴，置于米色平面。；跑动交叉步连接一次受控落地，触发黑色放射线和准确短词【HOLD】。；人物回到准确标题【CORAL SIGNAL】下方，小字【ONE NIGHT ONLY】停留。

## 必须保留的结构锚点

- One adult animated identity anchors all graphic chapters.
- Each graphic burst follows one readable action.
- Detail crops reconnect to the complete character.
- The final title frame restores the complete character and the opening graphic language.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
