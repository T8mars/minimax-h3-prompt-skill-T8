# 水墨兵器接力｜轮廓成形、招式交接与烟墨消散

## 用途

把黑墨当作角色和招式的共同载体：每名成年战士由墨雾成形，完成一个清楚动作后以同一运动轨迹消散并交接给下一轮廓。

## 推荐输入格式

`原创动作主体 + 清楚工具轮廓 + 2个落地动作几何 + 1次遮挡换形 + 效果动作与位移证明 + 落地终态`

## 可直接改写的简短示例

> 暖色宣纸上，靛蓝颜料形成一名成年剪纸信号员。；第二道扇弧形成成年长绸杆表演者，不硬切。；鼓击波向外扩成渐淡靛蓝水洗，最终只剩一枚小圆印。

## 必须保留的结构锚点

- One monochrome medium governs every figure.
- Each adult figure completes one readable action.
- Mass and silhouette escalate without mixing identities.
- The final wash resolves to one bounded mark or empty field.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
