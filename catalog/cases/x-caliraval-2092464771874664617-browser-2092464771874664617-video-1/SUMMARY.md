# 度假自拍定位｜迎面讲述、设施转向与脸部回连

## 用途

同一成年旅行者以手臂距离自拍边走边讲述，背景从绿篱、泳池到滑梯依次显现；一次转身把设施纳入同框，最终近脸回连身份和完整目的地。

## 推荐输入格式

`同一成年自拍主体与固定路线 + 一次目光或转头动机发现 + 一个地方物品的完整嗅闻或品尝动作 + 克制身体反应且无广告台词 + 手持结果继续原路线`

## 可直接改写的简短示例

> 以手臂距离自拍跟随一名成年海洋向导沿海岸研究站小径前进。；一次受控侧转揭示完整潮汐实验室，行进方向不变。；回到完整正脸，潮汐实验室和水道仍在身后注册。

## 必须保留的结构锚点

- One adult identity, selfie distance and walking direction remain fixed.
- Background evidence accumulates rather than jumping between locations.
- A secondary facility appears within the same geography.
- The final face view retains enough destination context to prove the route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
