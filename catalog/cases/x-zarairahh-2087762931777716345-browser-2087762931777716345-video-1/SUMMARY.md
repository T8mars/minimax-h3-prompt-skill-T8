# 标志入境｜穿行世界后回收到原形

## 用途

先把一个简洁标志当作入口和几何规则，进入由其形状、色彩与方向构成的三维世界；经过环境、角色与一次尺度跃迁后，所有结构必须可追溯地重新折回同一个标志。

## 推荐输入格式

`稳定标志 + 三维世界展开 + 中心角色动作 + 一次尺度跃迁 + 同一标志精确回收`

## 可直接改写的简短示例

> 一枚原创铜质罗盘玫瑰只旋转一次并锁定，四片叶瓣展开成实体水道，镜头穿入奶油色玻璃温室；种子保管自动机转动一次阀门，水脉同时传到四条通道，地面仍能读出罗盘结构；已建立的塔叶、骨架、阀块和水道依次向内折叠，精确重建开场同一铜质罗盘玫瑰，不出现新文案

## 必须保留的结构锚点

- Begin with one compact emblem that clearly defines geometry, palette and direction.
- Expand the emblem into a navigable environment using repeated versions of its own components.
- Use one major scale change to gather the environment into a simplified global form.
- End by rebuilding and holding the same opening emblem from visible world components.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
