# 单次决策兑现｜准备—执行—后果—回归

## 用途

先把单一高压威胁建立清楚，再把准备、校准和一次不可逆决策拆开证明；动作发生后必须显示可见后果，并回到执行者或责任主体完成结果确认与终版锁定。

## 推荐输入格式

`威胁或失效状态 + 责任主体 + 准备动作 + 校准确认 + 一次决定性动作 + 可见后果 + 主体或结果终版锁定`

## 可直接改写的简短示例

> 原创高山雪崩观测站，蓝灰清晨中一段不稳定雪檐悬在小型研究站上方，红色测量杆和空置承雪槽清楚证明距离与尺度；她旋转黄铜张力环，直到两道刻线对齐且一个实体绿色指示点稳定，不触发主动作；研究站前方已安全畅通，冰川学家放下锚柄、确认稳定坡面并站在无文字六边形安全标志旁保持

## 必须保留的结构锚点

- Establish one dominant external threat or failure state before the actor commits.
- Separate preparation from execution with one visible readiness action.
- Execute one decisive action and show one directly attributable material consequence.
- Return to the actor or outcome owner and hold a final lockup after the consequence.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
