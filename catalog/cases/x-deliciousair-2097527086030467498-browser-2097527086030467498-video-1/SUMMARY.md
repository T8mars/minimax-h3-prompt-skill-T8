# 雪板公园能力展示｜航拍建场、连续道具与摘镜回标

## 用途

航拍先建立雪板公园和粉色品牌障碍，同一成年雪手随后连续完成刻滑、跳台和栏杆动作；板、服装与粉色设施保持身份锚点，终局回到人物摘下雪镜微笑，不重复动作。

## 推荐输入格式

`装备接触特写 + 稳定表演者 + 连续能力动作 + 同空间见证反应 + 第二参与者挑战交接`

## 可直接改写的简短示例

> 从空中建立一座高山训练公园，青柠色障碍重复出现，并显示一条路线。；低机位跟拍雪手越过圆形雪脊完成一次受控跳跃，并落回同一路线。；短暂回到完整路线，再切至同一成年雪手摘下雪镜一次并对镜头微笑。

## 必须保留的结构锚点

- One clearly adult rider, board and park persist.
- Each feature is established before use.
- Landings occur on the same route.
- The face reveal belongs to the same rider.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
