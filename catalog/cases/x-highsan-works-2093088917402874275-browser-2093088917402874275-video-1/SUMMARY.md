# 单人舞台动作链｜固定空间、连续舞姿与终拍锁定

## 用途

在一个固定白色舞台中锁定同一成年动漫舞者，以连续可读的躯干、手臂和步伐动作推进；镜头克制，最终回到完整站姿并定格。

## 推荐输入格式

`单人表演者 + 巨大空场 + 远景起势 + 近景表达 + 一次受控倒地 + 俯拍确认 + 连续复起`

## 可直接改写的简短示例

> 原创成年舞台技术员戴青色耳机、穿橙色工具夹克，站在固定浅色排练地面。；连续完成两个步伐姿势，脸、耳机、夹克和地面标记不变。；同一人物回到正面平衡站姿，干净停留一拍。

## 必须保留的结构锚点

- One adult identity is established in full body.
- The stage and floor registration remain fixed.
- The largest movement occurs only once.
- The same subject returns to a readable held stance.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
