# 辣面双人试吃｜同步入口、热感升级与牛奶解围

## 用途

锁定两名成年动漫食客、两只固定面碗和正面对称机位；二人同步夹面入口后，脸红、冒汗和呼吸反应逐级增加，彼此对视确认共同困境，终局外部双手同时递入牛奶完成解围。

## 推荐输入格式

`稳定体验者与完整对象 + 独立微距质感证明 + 第一次试用/身体反应/缓冲 + 不同第二证明 + 改变后的对象终态`

## 可直接改写的简短示例

> 让两名明确成年的动画美食评论员正面对称坐好，各自面前一碗红汤面。；两人的脸红、三滴可见汗珠和紧张呼吸分三阶段增强。；两只画外手分别在每只碗旁放一杯牛奶；两名评论员各喝一次并明显放松。

## 必须保留的结构锚点

- Two clearly adult diners and two bowls persist.
- Only one synchronized bite initiates the test.
- The shared look precedes relief.
- Two matching relief objects complete the terminal state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
