# 产品证据变体｜场景结果到机理再回人群 — Seedance 2.0

## Prompt

```text
任务：文本生成一支原创15秒短片：从人群结果切到产品身份，再给出一次清楚的材质或机理证明，返回更广的人群结果并以稳定产品终态收束；复用既有产品证据状态机。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：办公室稳定广角；原创工作室里三名员工因红色空气指标暂停工作，开窗后指标仍不变；保持同一原创空间与因果锚点；光线随状态变化但保持连续；<空调底噪><窗扣>。
镜头2：产品三分之二近景；独立展示无品牌文字的空气监测净化器、进气口、滤芯抽屉和琥珀仪表；保持同一原创空间与因果锚点；光线随状态变化但保持连续；<滤芯抽屉轻响><设备待机>。
镜头3：滤芯剖面微距；微距剖面证明颗粒被折叠滤材截留，净化气流吹起轻带，仪表转绿；保持同一原创空间与因果锚点；光线随状态变化但保持连续；<气流><颗粒细响><仪表移动>。
镜头4：回到原办公室广角；回到同一办公室，墙面指标转绿，员工放松并恢复工作；保持同一原创空间与因果锚点；光线随状态变化但保持连续；<设备稳定运行><办公环境恢复>。
镜头5：产品英雄式稳定近景；净化器、使用过的滤芯与清洁气流轻带同框稳定收束；保持同一原创空间与因果锚点；光线随状态变化但保持连续；<柔和气流><单一确认音>。
整体风格与画质：Original clean industrial product film, soft daylight office, transparent airflow proof and restrained unbranded typography；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只使用当前声明的原创主体、场景、因果载体和结尾；保持因果顺序与身份连续，每个阶段都必须可见地交接到下一阶段；不得复刻来源特有的人物、地点、道具、文字、品牌或分镜顺序；只使用原创画内声音与原创音乐，不复制来源音频。
```
