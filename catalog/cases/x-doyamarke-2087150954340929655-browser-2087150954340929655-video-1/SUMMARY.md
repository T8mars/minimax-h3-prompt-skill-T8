# 产品证据变体｜场景结果到机理再回人群

## 用途

从人群结果切到产品身份，再给出一次清楚的材质或机理证明，返回更广的人群结果并以稳定产品终态收束；复用既有产品证据状态机。

## 推荐输入格式

`人类结果 + 产品身份 + 1次机理或材质证明 + 返回结果 + 稳定产品终态`

## 可直接改写的简短示例

> 办公室先显示空气问题，再独立展示净化器；微距证明滤芯截留颗粒，回到放松人群，最后以设备、旧滤芯与清洁气流同框收束。

## 必须保留的结构锚点

- Establish one emotionally readable outcome related to the product.
- Isolate the product identity before technical proof.
- Return to a broader result state after proof.
- End on a clean stable product state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
