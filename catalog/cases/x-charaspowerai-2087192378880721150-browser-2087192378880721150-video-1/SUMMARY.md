# 非对称突破｜密集阻力到空间制度改变

## 用途

先建立防守目标与密集阻力场，再引入一个非对称运动力量；局部接触证明动量，广角证明推进，突破后改变空间制度，并以近景后果收束。

## 推荐输入格式

`固定目标 + 密集阻力场 + 单一非对称力量 + 3次局部接触 + 突破改变空间`

## 可直接改写的简短示例

> 被淹物流大厅里，一艘无人拖船通过三次可见接触清出泡沫障碍通道，再一次推开救援闸门，让三艘小艇依次通过。

## 必须保留的结构锚点

- Establish one fixed objective and a dense visible resistance field.
- Introduce one asymmetric force with a clear motion axis.
- Return wide to show progress toward the boundary.
- Let one breach change the spatial regime and hold the consequence.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
