# 冲撞后近战升级｜柱体损伤、身体恢复与挑战者接管

## 用途

先用身体与固定建筑面的碰撞建立可见损伤，再让同一成年角色从碎屑中恢复；第二名角色进入后，每次近身动作都必须有接触、位移或材料反馈。

## 推荐输入格式

`单一主体与连续承载面 + 至少3次可数触点反应 + 1次不可逆破裂 + 同一边界穿越 + 下层介质终态`

## 可直接改写的简短示例

> 一名成年隧道巡检员撞上泵房瓷砖柱，碎屑只从接触区释放。；一名成年安全教官沿同一标记通道进入，空间不改变。；巡检员的掌击停在命中前，裂柱与双方位置共同可读。

## 必须保留的结构锚点

- A fixed substrate receives the first visible impact.
- Damage remains after the subject recovers.
- Every exchange has contact-bound displacement or residue.
- The terminal pose retains both conflict and accumulated damage.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
