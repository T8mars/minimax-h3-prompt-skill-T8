# 乐队聚焦接力｜全场建立、成员特写与合奏回归

## 用途

先用全场建立成年乐队空间，再让主唱和三种乐器按音乐职责接管镜头；灯光和节拍保持共同轴，最终必须回到同场合奏而非独立肖像堆叠。

## 推荐输入格式

`全体建立 + 主位聚焦 + 次主位回归 + 群体节奏持续 + 回到全体合奏终态`

## 可直接改写的简短示例

> 四名明确成年沙漠布鲁斯乐手以剪影出现在琥珀仓库舞台。；滑棒吉他手和立式贝斯手各自完成一个完整乐句接力。；回到全景，四人共同完成最后一记重拍，准确标题【DUST SIGNAL】停留。

## 必须保留的结构锚点

- One stage geography and clearly adult ensemble remain fixed.
- Each focus handoff corresponds to one musical role.
- Lighting and rhythm preserve the shared performance axis.
- The final wide view recombines every established performer.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
