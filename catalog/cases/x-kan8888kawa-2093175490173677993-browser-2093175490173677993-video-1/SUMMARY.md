# 双人近景合唱｜身份交替、视线接力与同步副歌

## 用途

用两名明确成年表演者的稳定面孔与站位建立关系，主歌按视线和歌词轮流交接；副歌让两人同框同步，最终以共享停顿而非随机剪切收束。

## 推荐输入格式

`稳定原创表演者 + 3至4句原创歌词 + 每句语义图形行为 + 人物始终可辨 + 逐句升能 + 清字后的表演释放`

## 可直接改写的简短示例

> 两名明确成年灯塔守护员站在暖色电台房的一张工作桌旁。；只反打一次，由年轻守护员回应第二句原创歌词。；以共享呼吸、相互凝视和静止双人构图结束，不增加表演者。

## 必须保留的结构锚点

- Both performers are clearly adult and identity-locked.
- One stable shared location establishes the relationship.
- The refrain places both performers in one frame.
- A mutual held response closes the duet.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
