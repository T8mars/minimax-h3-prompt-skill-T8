# 扫描束环境耗竭｜局部变灰、跨景传播与有限回馈

## 用途

把一个可见扫描束设为状态传播前沿，让彩色生态按相邻区域逐步变灰；范围从花地扩展到森林与水面，终局只恢复一个有限点而非无因重置。

## 推荐输入格式

`有边界环境 + 单一连续变化前沿 + 至少2个固定地标 + 占据面积逐级扩大 + 终态广角对照`

## 可直接改写的简短示例

> 原创剪纸气候无人机用一束窄紫光扫描鲜艳屋顶花园。；灰色状态抵达温室墙时，昆虫和小型风带向外撤离。；光束只反向覆盖一个花箱，仅恢复该处，并以仍有未恢复区域的屋顶广角结束。

## 必须保留的结构锚点

- One visible moving front causes every state change.
- Affected area grows through adjacent geography.
- The effector remains spatially registered.
- Recovery is limited and visibly caused, not a total reset.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
