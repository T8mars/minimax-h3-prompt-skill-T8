# 洁面过程证据链｜包装、泵出、起泡、冲洗与肤感收束

## 用途

产品先与使用者同框建立承诺，再用泵出质地、面部起泡、水流冲洗、毛巾擦干和包装英雄镜头逐级完成可见证明。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 成年野外医护在明亮移动诊所展示原创炭灰色手部清洁泵。；双手揉搓，薄泡沫覆盖手指与手背。；展示清洁结果，再让完整泵瓶与准确短句【READY TO RETURN】共同停留。

## 必须保留的结构锚点

- One product and one user remain fixed.
- A measured dose precedes application.
- Rinsing removes the applied material.
- The final result returns to the complete product.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
