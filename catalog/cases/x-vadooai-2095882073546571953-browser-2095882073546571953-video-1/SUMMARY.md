# 膨胀巨兽追逐｜误判接近、尺度突变与障碍逃生

## 用途

先用成年守卫和灌木中的小型生物建立可控距离，再让生物连续膨胀造成尺度反转；人物的惊愕必须先于逃跑，追逐路线穿过同一村落并由可见鼓阵碰撞收束。

## 推荐输入格式

`大小尺度明确的两主体 + 共享地面 + 巨体承诺动作 + 小体型可见变线 + 无虚构胜负的共享终态`

## 可直接改写的简短示例

> 原创成年海岛制图师靠近港口花园旁一只掌心大小的条纹蜥蜴。；先展示一次从观察到惊慌的清晰表情变化，再让制图师转身起跑。；以制图师撞上三只堆叠鱼箱收束，鱼箱依次倒下，蜥蜴在其后停住。

## 必须保留的结构锚点

- One clearly adult protagonist and one original creature retain stable identities.
- Scale changes continuously in place and remains consistent through the chase.
- Both subjects share one continuous environment and lateral route.
- A visible obstacle collision closes the chase with physical consequence rather than disappearance.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
