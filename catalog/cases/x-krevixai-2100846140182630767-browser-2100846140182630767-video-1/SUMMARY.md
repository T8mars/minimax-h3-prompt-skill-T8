# 毛坯房顺序完工｜表面施工、木作、家具与照明验收

## 用途

锁定同一房间几何与机位，装修按墙面、地板、固定木作、家具和灯光的依赖顺序逐层出现；前一阶段必须保持为后一阶段的基础，最终用完整可用空间收束。

## 推荐输入格式

`固定空房＋施工依赖顺序＋家具进入＋完整验收`

## 可直接改写的简短示例

> 空水泥阅读室、暖白墙面、橡木地板、胡桃木书架、沙发和吊灯。

## 必须保留的结构锚点

- 机位和门窗几何固定
- 先完成固定施工再进家具
- 终局保留所有前置层级

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
