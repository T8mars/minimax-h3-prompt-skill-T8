# 第一视角工具调查｜雨镇抵达、器材切换与窥孔验真

## 用途

第一视角玩家先在雨雾小镇建立目标建筑，再通过室内楼梯、工具栏、双筒镜和手持探测器逐步缩小调查范围；抵达诊所走廊后，只通过一个窥孔确认人物异常。

## 推荐输入格式

`远景入口 + 跨过阈值 + 连续通行 + 局部异常检查 + 可见路线终态（不下诊断）`

## 可直接改写的简短示例

> 第一视角穿过雨湿港区，走向以圆形蓝色信标标记的原创海洋档案馆。；只切换一次手持热成像板，同一扇窗内显出一个静止暖色人影。；通过一个圆形检查孔停留门内成年档案员与闪烁蓝柜，不进入房间。

## 必须保留的结构锚点

- One first-person route establishes a distant target before any tool evidence.
- Each selected tool narrows the same location question and has a distinct readable result.
- Interior passage preserves the target and first-person orientation.
- One bounded inspection aperture provides the terminal confirmation without an unjustified entry or attack.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
