# 汉堡店警报兑现｜手机信息、豪车转场与海岸反差

## 用途

从餐馆外用餐和车辆基线开始，手机警告改变人物目标；轮胎、航拍和海岸落点压缩移动过程，远端火球验证信息，人物戴上眼镜继续饮用作为克制结尾。

## 推荐输入格式

`当下主体 + 未来自身消息 + 主动外部验证 + 局部未来环境 + 更大尺度威胁`

## 可直接改写的简短示例

> 一名明确成年的海岸工程师在原创黄色路边餐馆外品尝甜椒卷，旁边是一辆深色轿跑。；用一次轮胎转动匹配到高位道路画面，同一轿跑从餐馆驶向南湾海滩。；火光物体在远处形成一道水柱；工程师在前景微笑并克制地喝一口。

## 必须保留的结构锚点

- One clearly adult original lead, phone and vehicle persist.
- A single message redirects the route.
- The warning is verified at a non-graphic safe distance.
- The calm final action contrasts with the large background event.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
