# 双轮对话反应｜固定轴线、表情加压与悬念停顿

## 用途

在同一空间轴线内交替两名成年人的近景，每一轮由说话、停顿和无声反应组成；相似面孔和冷色环境只提供不安，终局停在未解释的表情变化。

## 推荐输入格式

`稳定双人地理 + 第一轮完整说话 + 清楚停顿 + 第二轮短回答 + 更长无声反应`

## 可直接改写的简短示例

> 两名明确成年气候巡检员穿暗橄榄制服，站在狭窄镜面观察走廊两端。；巡检员B只回答一次，同一盏红色状态灯和走廊反射保持轴线。；收紧到A受控惊惧的表情，静默停留两秒，延迟倒影仍可见。

## 必须保留的结构锚点

- Two clearly adult roles and one eyeline axis remain fixed.
- Each turn contains speech, pause and reaction.
- The second turn increases only one anomaly.
- The final reaction holds without revealing a new source.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
