# 冰封世界状态游历｜规则标记、地貌证据与静止终局

## 用途

把冰封与时间停滞设为整个环境的统一规则，通过雪花标记、冻结河流、晶体、石碑和极光逐级证明；镜头只在空间中推进，不引入人物或无因解冻，最终保留完整静止世界。

## 推荐输入格式

`复杂环境整体悬停 + 第一视角连续移动 + 至少3个冻结地标 + 局部对齐但不强称接触 + 末端只复流一次`

## 可直接改写的简短示例

> 原创霜钟徽记出现在安静钴蓝峡谷上方。；穿过三株透明矿物芦苇和两座石质时间标记，它们遵循同一静止规则。；未受扰动的白色山峰、银河与准确原创标题【THE HOUR THAT WAITED】共同停留。

## 必须保留的结构锚点

- One visible emblem introduces the environmental rule.
- Every material and landmark obeys the same suspended state.
- No character action replaces the environment as subject.
- The terminal wide frame preserves the frozen rule and key landmarks.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
