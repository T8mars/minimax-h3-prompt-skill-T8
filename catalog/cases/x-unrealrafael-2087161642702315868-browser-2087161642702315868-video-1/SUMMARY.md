# 连续推进｜重复地标计时并抵达更深通道

## 用途

在受限通道中持续前进，以重复固定地标和门洞视差作为进度时钟；接近结尾时只转向或跨越一次可见边界，并停在材质更深的次级通道，不虚构检查、诊断或隐藏威胁。

## 推荐输入格式

`连续受限通道 + 重复地标进度时钟 + 门洞视差逼近 + 单次边界跨越 + 更深次级通道终态`

## 可直接改写的简短示例

> 植物维护镜头沿根系观察沟连续前进，用编号湿度窗和门洞视差证明进度；结尾只跨越一次气闸，停在更暗的种子库次级通道。

## 必须保留的结构锚点

- Use one continuous constrained passage and stable travel axis.
- Repeat fixed landmarks as a progress clock.
- Turn or cross only once at the late visible threshold.
- End inside a materially deeper secondary passage while retaining one prior-route edge.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
