# 护肤步骤证据链｜包装轮播、取用触点与脸部回验

## 用途

固定同一成年人物和同一室内背景，依次展示包装、取用、涂抹与脸部结果；每个产品只承担一个可见动作，最终将完整组合与使用者重新同框。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 锁定一名成年陶艺师、同一暖色工作室墙面和三件原创无品牌护手产品。；打开一只膏霜罐，取出可见豌豆大小用量并涂到同一组指尖。；稳定桌面英雄镜头重新同框陶艺师、双手与三件完整包装。

## 必须保留的结构锚点

- One adult identity and one room baseline remain stable through all product steps.
- Each package is shown complete before its corresponding use action.
- The result is verified on the same body area under consistent lighting.
- The final view reconnects user, result and the complete original product set.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
