# 收藏卡发现｜货架浏览、近景验真与双人共同确认

## 用途

以两名成年顾客在收藏店浏览为基线，视线和手指锁定一张卡片；卡面近景、拿取与同伴靠近构成三层证据，终局二人带着已确认物件离开。

## 推荐输入格式

`稳定体验者与完整对象 + 独立微距质感证明 + 第一次试用/身体反应/缓冲 + 不同第二证明 + 改变后的对象终态`

## 可直接改写的简短示例

> 两名明确成年的原创制图师在霓虹档案店浏览密封路线卡。；切到卡片近景，显示原创蓝色避难所符号和三个刻口，不保留来源品牌文字。；二人交换一次微笑，把卡片封入透明套，再走向同一出口。

## 必须保留的结构锚点

- Both human subjects are clearly adult and original.
- One selected object remains traceable from shelf to hand.
- The companion confirms rather than replaces the first observer.
- The final departure preserves the verified object.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
