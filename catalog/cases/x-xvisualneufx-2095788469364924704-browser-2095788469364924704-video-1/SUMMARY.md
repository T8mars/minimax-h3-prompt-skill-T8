# 糖果赛博歌词片｜主唱锚点、甜品世界与语义字卡

## 用途

以同一成年主唱的 LED 眼镜和白色机能服锁定身份，让甜品轨道、群体滑行和镜头掠过逐步升能；准确原创歌词短句只在动作峰值出现，终局回到主唱近景。

## 推荐输入格式

`稳定原创表演者 + 3至4句原创歌词 + 每句语义图形行为 + 人物始终可辨 + 逐句升能 + 清字后的表演释放`

## 可直接改写的简短示例

> 以原创成年主唱开场：银色机能服、青色 LED 眼镜，位于漂浮柑橘甜品世界的近景。；将主唱两次精确手势与两次横向掠过原创蛋糕、柑橘雕塑的高速运动交替。；回到主唱正面 LED 眼镜近景，灯点闪一次，并在终拍停止全部背景运动。

## 必须保留的结构锚点

- One clearly adult lead performer retains face, visor and costume across every scale.
- The fantasy environment develops from the same ingredient family rather than random spectacle.
- Exact original lyric typography appears only at a verified motion peak.
- The opening close-up returns after the wide travel chapters for a clean identity lock.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
