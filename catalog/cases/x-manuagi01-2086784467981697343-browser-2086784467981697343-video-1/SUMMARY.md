# 平面重组｜图标开启档案世界

## 用途

紧凑图标先展开成角色与世界，图形密度经多个象征场景逐步升高，再用短暂状态卡打断；最后一个人物画面把持续配色与面板几何交给独立终态锁定。作为既有平面重组模板的证据变体，不新增下拉项。

## 推荐输入格式

`紧凑图标 + 稳定角色/配色 + 密度递增模块 + 孤立状态停顿 + 几何锁定`

## 可直接改写的简短示例

> 铜色种子螺旋从标本标签展开成纸艺温室世界，经过叶廊与根系高密模块，短暂停在无字检疫花结，最终重组成植物徽记。

## 必须保留的结构锚点

- Open with one compact flat icon that visibly expands into a larger graphic field.
- Keep one character silhouette, palette and panel family stable while the world modules change.
- Insert one short isolated status or negative-space state before the ending.
- Resolve the recurring palette and panel geometry into a held final lockup after the last character frame hands off.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
