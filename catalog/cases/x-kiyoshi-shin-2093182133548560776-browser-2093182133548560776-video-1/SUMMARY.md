# 微型拼装递进｜局部扣合、结构扩展与整体验收

## 用途

用双手和固定黑色工作台建立真实装配因果；小组件先形成双腿，再接入躯干、双臂和头部，每次扣合后回到整体检查，最终完整模型站立。

## 推荐输入格式

`单一原料 + 至少3种功能不同的形变操作 + 1次不可逆加工 + 成品组装 + 保留前序痕迹的微距终证`

## 可直接改写的简短示例

> 成年手工者的双手在同一软木垫上装配原创橙灰色掌心救援信标。；双腿扣入壳体后，回到一次完整物体稳定检查。；完整信标直立，按一次测试键并保持稳定琥珀脉冲。

## 必须保留的结构锚点

- One work surface and hand pair remain continuous.
- Load-bearing components assemble before upper parts.
- A whole-object check follows each major stage.
- The finished object performs one integrated proof action.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
