# 剪辑界面闭环｜导入素材、文字改写与机器人结果

## 用途

先建立视频编辑器中的机器人素材和时间线，每次光标或文字修改后都让预览区产生对应可见变化；导出后的机器人结果必须回到同一素材身份，不能以无关成片替代。

## 推荐输入格式

`明确成年原创操作者、实体输入设备和响应屏幕或机器同一地理先建立 + 每个重要虚拟或机械事件前先展示一个具体物理输入 + 至少三组不同输入—响应对应且输出不得提前 + 从选择、导航或防御升级到一个决定性结果 + 终局把结果重新连接到同一成年人物的可读反应`

## 可直接改写的简短示例

> 打开原创深色编辑器，素材为一名成年温室工程师，时间线为空。；把字幕替换为准确短句【GROWTH FOLLOWS LIGHT】，预览只显示该文字。；导出干净全屏结果，同一人物、字幕和图表均保留，再返回一次编辑器时间线。

## 必须保留的结构锚点

- One imported source identity anchors editor and result states.
- Each visible control action precedes one matching preview change.
- Added graphics supplement rather than cover the source subject.
- The final result and timeline reconnect to prove a completed causal edit loop.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
