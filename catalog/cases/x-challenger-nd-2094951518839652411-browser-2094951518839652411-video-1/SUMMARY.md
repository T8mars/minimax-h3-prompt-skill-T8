# 机械光圈角色谱系｜单人揭示、职责差异与放射群像

## 用途

用同一齿轮、管线和机械光圈作为固定角色槽，让多个成年原创人物逐一显露面孔、服装、姿态和职责物；每次只登记一人，终局把全部人物汇入放射式机械名册。

## 推荐输入格式

`固定人物区/标题/字段顺序/计数器 + 至少5个编号原型 + 每个原型同步改变主色/轮廓/姿态微动作/职责图标 + 界面全程不滑动 + 最终编号档案稳定停留`

## 可直接改写的简短示例

> 建立固定氧化铜机械光圈，包含人物槽、编号压力表和职责铭牌，用于五名明确成年原创飞艇工程师。；成年导航员、线缆医师、锅炉审计员和风帆机械师沿用相同槽位，每次只改变脸、轮廓、站姿和一件工具。；镜头拉远，五名成年人物围绕中心涡轮排列，准确原创标题【AEROWORKS CREW】出现，全部编号和工具保留。

## 必须保留的结构锚点

- One fixed mechanical aperture, portrait bay, dial and field order remain registered.
- Every clearly adult original role changes four comparison fields together: face, silhouette, stance and tool.
- One reveal interval contains exactly one adult identity and readable role evidence.
- The terminal radial roster restores every established adult, number and tool around the same central mechanism.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
