# 自拍路线小发现｜街行、侧看、品尝与带物继续

## 用途

先用稳定成年人物、街道方向和持续自拍步态建立真实路线；人物的目光和身体转向把镜头带到一个本地发现，随后用可见食物、一次完整品尝和自然反应完成体验证明，最后重新进入同一街道方向并携带消费结果继续走。

## 推荐输入格式

`同一成年自拍主体与固定路线 + 一次目光或转头动机发现 + 一个地方物品的完整嗅闻或品尝动作 + 克制身体反应且无广告台词 + 手持结果继续原路线`

## 可直接改写的简短示例

> 成年植物学家持手机以固定手臂距离沿港口栈道向前，护栏、船只和行人产生连续后退视差；同一成年人接过透明杯，先闻一次，再完整喝一口；摊位和港口仍可作为背景定位；人物手持同一杯沿原栈道方向继续走，夕阳仍在同一侧肩后，背景视差恢复

## 必须保留的结构锚点

- Keep one adult traveler, selfie distance, route direction and background parallax stable before the discovery.
- Use a visible gaze or body turn to motivate the local discovery.
- Preserve one readable bodily reaction without depending on exact dialogue.
- Resume the same route while carrying a changed state or takeaway object.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
