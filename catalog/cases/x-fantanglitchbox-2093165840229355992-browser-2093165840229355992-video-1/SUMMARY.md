# 多载具机械组装｜组件到位、功能映射与机器人终局

## 用途

先分别建立多个载具或装甲组件的外观与运动功能，再让它们沿清楚路径到达共同装配轴；每个组件只映射一个身体部位，最终形成完整机器人并停留。

## 推荐输入格式

`第0帧完整原创构造物先出现 + 第一秒完成唯一最大速度爆拆且组件顺序不变 + 各主要组件分别获得一种较慢且不同的材料或制造语法 + 至少两章之间短暂回到完整成品刷新装配记忆 + 组件逐步符号化并重组为原创身份标记而非简单恢复开场产品`

## 可直接改写的简短示例

> 建立三种原创救援组件：紧凑履带车、双旋翼无人机和白色医疗舱。；无人机旋翼折为肩部支架，中央机身成为上躯干。；完整原创救援机器人出现，短暂高亮履带、无人机和医疗舱功能后以英雄轮廓停留。

## 必须保留的结构锚点

- Every source module is established before assembly.
- Each module maps to one body function only.
- Assembly paths remain visible and non-overlapping.
- The complete robot accounts for and proves every module.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
