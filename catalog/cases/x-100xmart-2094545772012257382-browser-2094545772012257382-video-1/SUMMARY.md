# 埋沙古城揭露｜空旷基线、轮廓显形与城门抵达

## 用途

先用连续沙丘建立无人基线，再让同一区域的道路、墙体和塔楼按尺度逐层显形；镜头持续前进，最终穿过可识别城门并把外部地貌与内部花园回连。

## 推荐输入格式

`环境局部异常 + 单一身份特征 + 高位完整几何证明 + 环境尺度影响 + 低位近距离逼近`

## 可直接改写的简短示例

> 沿空旷白色盐湖盆地连续航拍前进，开场不出现建筑。；原创太阳能档案城从近到远依次升起，盆地地理不得被替换。；只穿过城门一次，以广角回连完整档案城和开场盐湖地平线。

## 必须保留的结构锚点

- One empty terrain and one continuous approach axis establish the baseline.
- Subsurface traces precede all full architectural emergence.
- One threshold converts distant discovery into physical arrival.
- The terminal view reconnects the complete revealed settlement to the opening terrain.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
