# 刻意遮断省略｜动作升级后以审查卡跳到余波结果

## 用途

先用明确成年角色和原创对手完成可读动作升级；到最大冲突前主动切入可辨识的原创遮断卡，让缺失成为叙事省略而不是伪造动作。遮断期间只保留克制声画提示，随后回到同一空间、同一人物与可验证余波，不推断被遮内容。

## 推荐输入格式

`两名明确成年原创对立主体和稳定地理先建立 + 至少三次完整可见动作逐级升级 + 最大阈值切入可辨识的原创遮断卡而非故障画面 + 遮断期间绝不展示、描述或推断隐藏动作 + 回到同一地理只呈现可观察余波并保持结果不解释`

## 可直接改写的简短示例

> 原创工业测试厨房内，两名明确成年对手厨师站在相对不锈钢工作台，先建立刀具、食材、中间出餐口和可见倒计时灯。；两人同时伸手抓盖，倒计时灯转红；镜头收紧到把手，但在任何盖子打开前停止。；回到完全相同的厨房地理，烟已落下，两份原创成品在出餐口，同一两名成年人仍在工作台旁，不解释胜负；只停留可观察余波，不复制战士、装甲、雨巷和 CENSORED 字样。

## 必须保留的结构锚点

- Establish two clearly adult-scale original figures and stable geography before escalation.
- Show at least three complete visible action beats before the interruption.
- Never depict, narrate or infer hidden action during the interruption.
- Return to the same geography and reveal only observable aftermath states.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
