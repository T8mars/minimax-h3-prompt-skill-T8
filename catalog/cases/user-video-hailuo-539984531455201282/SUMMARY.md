# 造型轮播｜身份锁定跨风格世界

## 用途

锁定同一高机位人物、脸部与核心比例，让背景系统、色彩、服装配件和道具按阶段成套切换；每轮至少改变两个风格通道但保留身份锚点，密度逐步升级后回到可读人像终态。

## 推荐输入格式

`固定主体身份与镜头关系 + 至少四个材质/版式不同的风格世界 + 每阶段改变两项风格通道 + 递增密度 + 可读身份终态`

## 可直接改写的简短示例

> 原创羊皮纸仓库内，一名黄铜发条快递员以椭圆面板、月牙胸章和折叠工具带建立身份；世界切为粉色植物控制台，路线环换成两枚透明种子仪表，前臂变为粉色护甲，脸板、体型和胸章不变；短暂经过琥珀仪器舱后进入克制紫色声学舱，快递员保留椭圆脸板和月牙胸章，佩戴听音盘并只向镜头伸手一次后停留

## 必须保留的结构锚点

- Establish one stable identity, lens relation and recurring accessory against a low-density opening world.
- Change the surrounding style world while keeping face, silhouette and camera axis stable.
- Use at least one additional world with different layout logic rather than a palette swap alone.
- Reach a denser terminal world but preserve a readable portrait-scale identity proof.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
