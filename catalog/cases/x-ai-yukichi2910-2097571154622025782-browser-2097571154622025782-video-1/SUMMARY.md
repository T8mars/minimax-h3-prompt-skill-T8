# 展览信息渐显｜角色近景、标题排版与合影回标

## 用途

固定同一原创成年风格化插画角色和黑猫，先以挥手、靠近与表情建立关系，再让展览标题、日期、时间和地点按层级渐显，最后回到角色与完整信息同框。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 让一名原创且明确成年的风格化插画师与一只黑猫在干净户外肖像中同框。；把两者重新居中于下三分之一，并在上方留出一个干净信息区。；完整信息保持时，成年插画师最后小幅挥手一次，黑猫看向前方。

## 必须保留的结构锚点

- One clearly adult figure and one cat persist.
- Information appears only after visual identity is established.
- No line covers the face.
- The final frame contains character, cat and complete lockup.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
