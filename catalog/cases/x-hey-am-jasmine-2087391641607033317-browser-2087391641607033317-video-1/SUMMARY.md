# 纪实随拍｜偶发干扰、群体片段与继续离开

## 用途

用背后手持跟拍建立一条连续公共路线，让主体自然回望并依次遇到路人绕行、店铺停留、群体小活动和轻微失误；保留不完美构图与尴尬停顿，最后让主体继续离开并以新的环境事件收束。作为既有观察者跟拍模板的新证据，不新增选择器。

## 推荐输入格式

`侧面连续跟拍 + 狭窄起点 + 行进中空间揭示 + 一次偶发横穿 + 一次克制回应 + 继续离开`

## 可直接改写的简短示例

> 成年夜班无线电技术员穿锈红工具夹克走过海岸气象站，蓝色栏杆和远处天线平台反复出现；两名成年同事查看一份无品牌贴错标签的样本，技术员出现一次小反应；技术员继续走向天线平台，只回望一次，远处警示灯独立开始旋转

## 必须保留的结构锚点

- Establish one clearly adult subject, one observer-follow axis and recurring route landmarks before the first interruption.
- Let one incidental person, object or route event force a visible path correction without a reset.
- Observe at least one compact social microevent with a readable reaction and recovery.
- Return to route continuation and end with one independent environmental event rather than a posed finale.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
