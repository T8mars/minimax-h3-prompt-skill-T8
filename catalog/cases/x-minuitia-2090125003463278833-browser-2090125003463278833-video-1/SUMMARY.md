# 地面召集天空编队｜近距确认、首领降落与乘骑离场

## 用途

先用孤立地面角色和远处空中群体建立垂直权力差，再通过一次清楚的手势或姿态让空群由散乱逼近转为有序绕行；用近距首领确认把群体回应收束到单一载体，随后让首领完成可见降落和俯身，人物登乘后以共同起飞和高位远景结束。

## 推荐输入格式

`一名成年地面召集者 + 远处空群与固定地标 + 单一信号改变群体拓扑 + 一个主载体近距确认 + 完整降落、降低与登乘接触 + 载人起飞并加入队形`

## 可直接改写的简短示例

> 成年气象指挥员站在蓝色测量桅杆旁，散布的自主织物滑翔器从远处不同天空方向接近；一架大型白色救援滑翔器脱离螺旋，两盏识别灯与指挥员目光方向完成相互确认；滑翔器载着成年人升空，重新加入织物队形，沿克制绿色极光通道进入极地远景

## 必须保留的结构锚点

- Establish one adult ground caller, a distant aerial group and one terrain anchor before close passes.
- Use one visible nonverbal signal to change the aerial topology from dispersed approach to ordered orbit or route.
- Show complete descent, stable landing, lowered posture and readable mounting contact.
- End after the mounted pair takes off and joins the broader aerial route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
