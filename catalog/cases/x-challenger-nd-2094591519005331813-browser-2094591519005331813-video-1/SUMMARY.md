# 黏土字母舞台｜成年舞者动作触发、字形飞入与终句合成

## 用途

同一明确成年动画舞者在固定彩色黏土舞台上完成连续舞步；散落字母只能在对应动作后弹起、滚动或进入构图，身份与舞台轴线不重置，结尾把全部字母拼成一个清晰原创终句。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 软珊瑚与蓝色泡棉字母房中建立原创明确成年动画编舞者：紫色短发、青色发带、奶油夹克与钴蓝长裤，人物位于舞台中心。；一次双臂上举让三枚蓝色字母从地面升起，组成准确短词【UP】；脸、发带、夹克与长裤保持不变。；她以稳定终姿把所有已用字母吸引到前景，拼成准确可读短句【MOVE TOGETHER】；同一成年人保持在文字上方可见，全部字母停止。

## 必须保留的结构锚点

- One clearly adult performer, four appearance anchors and one fixed stage axis precede all letter motion.
- Each letter group moves only after one corresponding readable dance action begins.
- Typography may cross foreground and background but cannot erase performer identity or reset geography.
- The final phrase uses the accumulated letters, remains fully readable and shares the frame with the same adult.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
