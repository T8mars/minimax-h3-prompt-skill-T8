# 真人字舞变体｜成年表演者动作驱动巨型短词与彩色模块

## 用途

同一明确成年表演者以稳定身份贯穿彩色模块，每段只用一个短词和一次动作；文字在前后景中弹跳、绕行或成为台阶，最终把人物、名称与标志收成同一字卡。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 深蓝场中，建立一名明确成年非裔拉丁裔手语表演者，铜色短发、青绿色夹克和一个原创手形小徽记；锁定脸、头发与服装。；经过珊瑚色【TURN】房间和青色【REACH】房间；她各做一次转身和伸手，每个词只穿过前景或地面之一。；同一成年人走进深蓝标题卡；手形徽记置于准确【MARA SIGNS】上方，所有文字与身体运动停止并停住。

## 必须保留的结构锚点

- Establish one clearly adult original performer with stable face, hair, outfit anchors and one compact identity symbol.
- Introduce no more than one exact short word per graphic module and pair it with one readable action.
- Escalate word scale and action amplitude without adding uncontrolled text or changing the module grammar.
- End by placing the same adult and original identity symbol inside one complete readable title card.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
