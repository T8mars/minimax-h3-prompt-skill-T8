# 结果先行广告｜终态承诺倒推证据

## 用途

先亮出清楚可读的理想结果，再把产品隔离为因果对象；用紧凑的材质或身份证据连接产品与使用状态，最后放宽到真实生活结果并停留。该案只作为既有产品证据状态机的证据变体。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 先展示护目镜带来的清晰航道结果，再倒推模块组装、佩戴与抗雾证明，最后回到佩戴者在河岸完成任务的稳定产品终态。

## 必须保留的结构锚点

- Show one desired outcome before explaining product operation.
- Isolate one product as the causal anchor for that outcome.
- Widen from product-dominant proof into the lived context.
- Hold the outcome long enough to read the relationship.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
