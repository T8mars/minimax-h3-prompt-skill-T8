# 固定试验室换灾态｜门槛进入、四种介质与中心碰撞

## 用途

用同一走廊与圆形试验室保持空间注册，逐章切换电弧、沙尘、积雪和风涡；最后让此前状态从固定方向回流并在中心碰撞。

## 推荐输入格式

`连续移动主体 + 原世界基线 + 单次全局换材 + 方向速度不断线 + 新世界终点`

## 可直接改写的简短示例

> 沿石墨色温室检修走廊进入圆形气候实验室，四个墙面风口固定。；只把活动介质依次替换为后方琥珀花粉和右侧白霜。；四种介质在一个有限亮脉冲中相遇，随后同一干燥网格与关闭风口重现。

## 必须保留的结构锚点

- One room geometry registers every state.
- Each chapter changes one dominant environmental medium.
- The central vortex follows the established chapters.
- The final reset proves the same chamber survived the collision.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
