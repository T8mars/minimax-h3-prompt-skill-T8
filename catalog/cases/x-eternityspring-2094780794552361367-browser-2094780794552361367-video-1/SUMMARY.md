# 非对称体量闪避｜共享地理、路线改写与非胜负终态

## 用途

在同一可追踪地理中建立体量悬殊的两方，让重型角色以明确承诺动作压迫路线，小型角色通过平台、转轮和桥面连续改道而非瞬移；终局保持双方同场且不凭空宣布胜负。仅迁移运动机制，不保留来源角色、服装、世界观或IP外观。

## 推荐输入格式

`大小尺度明确的两主体 + 共享地面 + 巨体承诺动作 + 小体型可见变线 + 无虚构胜负的共享终态`

## 可直接改写的简短示例

> 在同一座高架水电站检修平台上建立原创重型钴蓝维护外骨骼与小型琥珀巡检无人机；涡轮转轮、桁架与缆索桥同时构成可追踪地理。；镜头同时追踪双方绕过同一涡轮转轮：外骨骼走上层桁架，无人机穿过一个开放轮辐后从另一侧上升。；以水电站全景结束：外骨骼稳定站在平台，无人机悬停在桥后；保持体量差与共享地理，不宣布胜负，也不使用任何可识别的系列角色。

## 必须保留的结构锚点

- Two original opponents with an obvious scale difference and one shared landmark establish the baseline.
- Every heavy committed move changes the smaller figure's route through visible spatial cause and effect.
- At least one repeated landmark proves both opponents remain in the same continuous geography.
- The terminal frame contains both opponents and preserves an unresolved, nonlethal state with no franchise likeness.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
