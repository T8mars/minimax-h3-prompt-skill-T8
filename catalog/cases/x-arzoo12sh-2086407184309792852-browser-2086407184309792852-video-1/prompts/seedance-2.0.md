# 微缩闯关｜同一材质连续变形 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：生成一支原创微缩材质闯关短片：微型温室信使横穿一片巨型蜡质叶，同一叶面依次成为路面、阻力、载体和弹性过渡，最后一支全尺寸玻璃滴管只进入一次充当桥梁。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
主体定义：微型温室信使：拇指高，实用工作服与短探杆，身份和比例全程稳定；巨型蜡质叶：同一片叶子，含主脊、透明露珠、叶脉和一处窄裂口；种子标记：远端固定地标；全尺寸玻璃滴管：只在最后一段从上方进入一次。
镜头1：竖屏微距广角从叶缘推进；拇指高的温室信使站在一片巨型蜡质叶主脊上，靴子、叶缘和远端种子标记立即证明尺度，信使主动开始横穿；人物、叶面和目标地标同一连续路线；温暖晨间逆光、清晰蜡质纹理；<温室空气><细小脚步>。
镜头2：微距贴近脚步与叶面；主脊过渡为光滑露水面，信使用探杆测试后滑出两步并抓住同一片叶子的主叶脉；不换场、不新增障碍物；露珠折射明亮；<湿滑声><叶面摩擦>。
镜头3：侧向跟随叶脉移动；被抓住的叶脉弯成移动导轨并把信使向前带走，一颗透明露珠在后方滚动，远端标记始终可见；同一材料从阻力转为载体；绿色与透明高光稳定；<叶脉弯曲><露珠滚动>。
镜头4：小幅仰拍保持裂口两侧；叶脉向上弹起，把信使释放到窄裂口上方；一根半透明植物纤维在下方拉伸成可见系带；人物仍朝同一目标前进；逆光勾出纤维；<弹性绷紧><短促破风>。
镜头5：稳定微距保持两种尺度同框；一支全尺寸玻璃滴管从上方只进入一次，横停在裂口上作为桥；信使落上滴管、走到远端叶缘，并在种子标记旁稳定站立；滴管、裂口、叶缘和信使共同证明结果；玻璃冷亮高光与暖叶面平衡；<玻璃轻响><落地><音乐收束>。
整体风格与画质：原创写实微距温室冒险，材质角色逐级变化，动作轻巧但物理因果清楚；先证明人物与巨型地形尺度，再让同一叶面以连续因果承担四种物理角色；外部滴管只能在结尾进入一次，结尾必须让人物恢复自主站姿。
约束：保持人物、叶子、路线与地标连续；同一叶面按路面、阻力、载体、弹性过渡的顺序变化；滴管只在最后进入一次且只作为桥；不得复刻来源特有的人物、食物、厨房、餐具或杯具；不生成可读文字、字幕、Logo和水印。
```
