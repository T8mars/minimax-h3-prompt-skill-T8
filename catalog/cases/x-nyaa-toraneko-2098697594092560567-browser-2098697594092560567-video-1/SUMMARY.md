# 腕具启动动作态｜雨巷基线、能量刃追踪与站立收束

## 用途

同一明确成年动漫角色在霓虹雨巷先保持观察，腕部装置启动后才进入奔跑与光刃动作；地理、脸和衣装连续，最后在同一路线重新站稳。

## 推荐输入格式

`Establish one clearly adult original subject, one personal device and an ordinary environment baseline. + Use one visible device-wear or activation action as the sole switch into the heightened state. + Change performance, camera rhythm and bounded environmental accents while preserving identity and geography. + Keep surrounding public behavior plausible so the private state remains legible by contrast. + Return camera and subject motion to a stable baseline in the same environment, with device state visibly resolved.`

## 可直接改写的简短示例

> 一名明确成年的原创铜发快递员站在蓝色雨棚下。；装置启动后，她沿同一巷道冲刺并经过两个已注册标志。；她单膝落地，回望一次，再站回同一蓝色雨棚下。

## 必须保留的结构锚点

- The lead is explicitly adult and retains face, hair and clothing.
- The device activates before performance mode begins.
- Exactly one bounded energy action occurs.
- The final standing state reconnects to the opening environment.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
