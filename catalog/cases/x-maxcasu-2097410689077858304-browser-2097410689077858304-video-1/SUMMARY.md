# 微缩寿司怪对决｜城市比例、目光蓄能与正面撞击

## 用途

在微缩城市中用同一小型成年英雄和巨大寿司蜘蛛建立尺度反差；双方先对峙，寿司怪眼睛发光，英雄随后以同类光能蓄力并只冲锋一次，终局爆闪和烟柱保留双方位置，不虚构胜负。

## 推荐输入格式

`两种明显尺度 + 共享球体或令牌 + 固定目标 + 可见变线 + 单一轨迹 + 不虚构结果的反应终态`

## 可直接改写的简短示例

> 一名微缩成年维修英雄隔着模型交通街区面对一只线轴身体的巨型昆虫。；在琥珀威胁建立后，英雄的青色面罩与双手光芒依次激活。；在接触点产生一次受控青琥珀撞击闪光和两道蒸汽柱，在显示胜负前收束。

## 必须保留的结构锚点

- One clearly adult miniature hero and one giant opponent persist.
- Scale anchors remain visible.
- Exactly one charge and one impact occur.
- No winner or destruction is invented.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
