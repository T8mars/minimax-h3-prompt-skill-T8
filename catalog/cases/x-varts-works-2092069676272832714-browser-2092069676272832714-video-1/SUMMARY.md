# 角色板时装变体｜固定参考条与舞台动作持续验真

## 用途

固定角色参考条持续占据同一位置，主舞台依次用正面步态、俯拍、旋转下降、面部近景和伸手遮镜验证同一成年身份；作为既有角色板验真模板的时装舞台证据，不新增下拉项。

## 推荐输入格式

`固定角色板 + 同一原创主体 + 至少4种不同验证职责 + 广角/近景双证明 + 最终对照`

## 可直接改写的简短示例

> 原创航天机械师参考条固定在左侧：成年正侧脸、钴蓝连体服缝线、铜色腕带与白色头盔条；活动舞台中同一成年人进入中性灰机库。；进入受控俯拍吊带旋转，参考条完全不变；困难角度中头盔条、肩宽与工具手关系保持。；遮挡后揭示完整同一成年人和原创短标 BAY FOUR，未改变的参考条仍可见；不复制来源角色、黄色舞台、服装、字母与标志。

## 必须保留的结构锚点

- Keep one original reference board fixed in the same screen region throughout.
- Separate the fixed board from an active performance stage.
- After any occlusion or camera stress, return to the same board anchors and adult identity.
- End with complete adult character and board visible together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
