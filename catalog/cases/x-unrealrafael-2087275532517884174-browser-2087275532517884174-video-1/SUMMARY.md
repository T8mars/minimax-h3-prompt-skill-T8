# 连续跟随｜步态与弯曲地标共同计时

## 用途

在弯曲受限通道中使用一次不中断的后方跟随；人物步态与画面位置稳定，重复灯具、轨缝与壁肋成为可数进度时钟，隧道曲率缓慢移动消失点，最后停在明显更深的位置，不虚构门槛、偶遇或改道。

## 推荐输入格式

`单一主体 + 连续后方跟随 + 重复结构地标 + 弯曲路线视差 + 不切镜的可见进度终态`

## 可直接改写的简短示例

> 一名管线巡检员沿弯曲地下水廊连续前进，重复灯带、拱肋与接缝成为进度时钟；镜头始终后方跟随，不加入发现或跨越事件。

## 必须保留的结构锚点

- Begin with one stable rear-follow relationship inside a constrained passage.
- Use repeated fixed landmarks as countable progress evidence.
- Let passage curvature shift the vanishing point gradually.
- End at a materially farther position on the same route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
