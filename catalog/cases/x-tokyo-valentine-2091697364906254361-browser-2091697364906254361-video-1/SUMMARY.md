# 设施语义字场变体｜成年旅客选择让站牌、闸机与路线说话

## 用途

同一明确成年旅客的选择与通行让站牌、闸机、楼层、路线和建筑编号依次承担短词；文字始终注册在设施上，动作与路线连续，最终由目的地设施完成身份结论。

## 推荐输入格式

`Establish one clearly adult original subject, three identity anchors and one continuous world axis. + Bind each decisive action to exactly one short original semantic word that appears only after the action begins. + Make each word occupy, divide, reflect or redirect the physical environment rather than float as a subtitle. + Escalate typography scale and spatial depth while preserving identity, travel direction and readable action. + Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.`

## 可直接改写的简短示例

> 原创午夜海岸研究总站内，一名明确成年黑人女性穿锈色外套、提银色仪器箱；脸、辫发和前进路线稳定。；她进入只标【LEVEL 4】的电梯，穿过把准确短词【LISTEN】做进声学墙翼的走廊，并查看一个圆钟。；缆车到达悬崖观测站，门口只写【BEGIN】；回到门玻璃里同一成年人的脸部倒影并停住。

## 必须保留的结构锚点

- Establish one clearly adult original traveler, stable identity anchors and one readable route direction.
- Require a visible choice or passage action before each short word activates on a physical facility.
- Keep the same traveler and path continuous as facility scale and route information expand.
- Reach a destination surface that confirms the choice, then return to the same adult identity anchor.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
