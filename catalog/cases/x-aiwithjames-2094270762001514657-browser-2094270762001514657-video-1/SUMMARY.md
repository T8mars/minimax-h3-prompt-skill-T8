# 自拍跨城接力｜同一人物、在地动作与前景擦镜

## 用途

自拍机位和同一人物身份保持稳定，每座城市用一个地标与一个在地动作完成证明；旗帜、手掌或路过物体遮挡镜头后切换地点。

## 推荐输入格式

`同一成年自拍主体与固定路线 + 一次目光或转头动机发现 + 一个地方物品的完整嗅闻或品尝动作 + 克制身体反应且无广告台词 + 手持结果继续原路线`

## 可直接改写的简短示例

> 用手臂距离自拍跟随一名成年海洋研究员：短卷发、青绿色雨衣和方形黄铜耳环。；悬挂渔网擦过镜头，切到晴日鱼市，她只品尝一瓣柑橘。；戴手套的手只遮镜一次，揭示最终研究船甲板与准确标题【FOUR TIDES】。

## 必须保留的结构锚点

- One adult identity and selfie distance remain stable.
- Each destination has one locational proof and one bounded action.
- Food or props do not replace the identity anchors.
- The final location closes the route with the same traveler.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
