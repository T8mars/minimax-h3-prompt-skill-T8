# 伪弱势反转｜困境诱近—准备微证据—能力破局—继续上路

## 用途

先把主体放进看似无助的明确困境，让外部压力主动靠近；在真正对抗前给出两三个克制的准备微动作，把主体重新编码为有能力的一方，再用单一清楚的能力链解决问题并回到原目标路线。

## 推荐输入格式

`稳定主体与中断目标 + 可读困境 + 因困境主动靠近的外部压力 + 至少两个准备微证据 + 单一能力链破局 + 回到原载体继续路线`

## 可直接改写的简短示例

> 原创成年极地测绘员驾驶白色勘测车沿蓝色路线桩前进，车辆在雪沟旁停止，同一人物下车检查外露轮传感器；测绘员关闭舱盖，依次封紧左右袖口，再把蓝色腕部磁控器对准勘测车锚定缆线；背景人员持续靠近；测绘员解除磁控、回到白色勘测车并重启，车辆越过雪沟后沿同一蓝色路线桩继续前进，锁定设备留在后方

## 必须保留的结构锚点

- Establish one stable subject, interrupted goal and readable setback before external pressure enters.
- Let the external party approach because of the visible setback rather than appearing at random.
- Use one coherent capability chain with attributable causes and visible consequences.
- Return the same subject to the original goal carrier and visibly resume the route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
