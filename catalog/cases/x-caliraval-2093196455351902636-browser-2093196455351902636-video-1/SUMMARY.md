# 家常烹饪状态链｜备料、加热、成形与品尝证明

## 用途

把不可逆烹饪步骤按真实因果排列，原料状态只能向成品推进；同一厨师、灶台和器具贯穿，最终用装盘与一次品尝证明完成。

## 推荐输入格式

`一名明确成年原创操作者、固定空间、主材料组、主要容器与手部或工具锚点先建立 + 至少五个不可逆状态且每镜只执行一次清楚操作 + 上一状态的残留、形状、颜色、蒸汽或容器连续成为下一步输入 + 不得回到已消失的早期状态并保持数量合理 + 同一成品由同一成年人完成一次克制使用或品尝证明`

## 可直接改写的简短示例

> 原创紧凑厨房中，一名成年夜班烘焙师与面粉、香草、钢碗和标记煎锅同场。；煎锅出现一次清楚油光后，把面团压入锅中。；饼落到木板，撕开一角露出蒸汽，人物只品尝一小块。

## 必须保留的结构锚点

- Ingredient states advance irreversibly toward one dish.
- One cook, bowl, pan and counter preserve continuity.
- Each cooking action produces a readable state change.
- Plating and one restrained taste prove the endpoint.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
