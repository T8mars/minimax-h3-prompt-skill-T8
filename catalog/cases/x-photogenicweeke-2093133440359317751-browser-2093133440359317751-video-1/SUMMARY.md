# 手绘成真｜真实笔触、线稿生长与彩色成品回证

## 用途

真实手和笔先建立创作因果，让线条沿笔尖连续增长并逐步构成人物与动作；上色只发生在闭合区域，最终手离开画面并留下完整成品证明。

## 推荐输入格式

`真实载体 + 沿既有几何描线 + 同线条族跨载体 + 保留轮廓 + 手作纪念物闭合`

## 可直接改写的简短示例

> 成年书籍艺术家的手和石墨铅笔悬在空白奶油纸上。；同一线条延伸出苗盘、嫩芽与浇水壶，并证明接触关系。；铅笔完全离开，完整原创花园插画静止停留。

## 必须保留的结构锚点

- The real drawing tool is visible before the subject exists.
- Every new contour grows from the current tool contact.
- Color fills only established closed shapes.
- The tool leaves before the completed artwork holds.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
