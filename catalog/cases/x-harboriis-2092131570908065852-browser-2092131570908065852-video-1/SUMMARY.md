# 节庆物件接力｜品尝、游戏、奖品到高空景观逐级升级

## 用途

同一明确成年自拍视频主体沿一个节庆路线前进，每章用上一章获得或使用的物件触发下一活动：食物证明到场，游戏动作产生奖品，奖品抬起引导视线到高空终景，最后人物带着累积物件告别。由近物触觉逐级扩展到群体与天空。

## 推荐输入格式

`一名明确成年原创自拍视频主体、至少三项身份锚点、固定手机距离和单一路线先建立 + 至少四个活动章节且每章的获得、使用或携带物件必须触发下一章 + 购买、游戏或交换需展示动作—结果证据 + 视觉尺度从手部升到摊位或活动再到大型环境景观 + 终局回到同一自拍视频关系并保留至少一个累积物件或余迹`

## 可直接改写的简短示例

> 原创夜间科学展中，一名明确成年主持人佩戴琥珀耳夹、海军蓝外套，以固定前置手机距离沿单一灯笼路线前进。；摊位中，成年人把三块磁性片放成一个完整图案；可见结果释放一个小型三角棱镜代币到同一只手。；回到相同自拍距离，同一成年人把棱镜代币举在琥珀耳夹旁，克制告别并放下手机；不复制祭典、食物、套圈、玩偶和烟花。

## 必须保留的结构锚点

- Lock one clearly adult original vlog subject, stable handheld distance and one route direction.
- Use at least four chapters and let one acquired, used or carried object motivate each transition.
- Escalate visual scale from hand to stall or activity to a larger environmental event.
- Return to the same selfie relation with at least one accumulated object or residue for farewell.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
