# 家电能量转移｜一人失去光环、载体搬运与另一人获得

## 用途

同一室内先让角色甲拥有清楚光环，角色乙启动家电后，雾状能量沿可见吸入路径离开甲并进入机器；片刻常态确认后，能量再转移到乙，形成守恒式荒诞接力。

## 推荐输入格式

`普通环境中的明确成年主体先展示双手为空 + 双掌稳定定义收集容器 + 至少三处环境痕迹连续汇入并压成单一核心 + 只用一次手势沿既定轴线释放同一物质 + 物质重新分布到同一环境并保持可见回应`

## 可直接改写的简短示例

> 让两名明确成年的原创舞台吉祥物同处排练室；甲带有光环，乙手持无品牌空气抽取器。；甲的光环分三步减弱，抽取器腔体充满到一条标记线。；把银色雾释放到乙周围，直到乙发光；甲保持普通状态并注视结果。

## 必须保留的结构锚点

- Two clearly adult original figures remain distinct.
- One visible carrier preserves energy continuity.
- A neutral pause proves the intermediate state.
- The final recipient gains the effect while the source stays depleted.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
