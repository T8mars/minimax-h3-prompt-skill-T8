# 单次投入｜容器延迟变化与失控收束

## 用途

一个小输入在封闭系统中延迟引发可追踪的扩张，人尝试纠正后留下终态。

## 推荐输入格式

`容器＋一个投入物＋延迟反应＋纠正尝试＋终态`

## 可直接改写的简短示例

> 一名成年技师、一座桌面布料充气城市模型、一根可见总气管、一个压力表与一只上方回收气囊。

## 必须保留的结构锚点

- 只发生一次清楚投入
- 反应沿容器连续扩张
- 纠正行为与残留结果都可见

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
