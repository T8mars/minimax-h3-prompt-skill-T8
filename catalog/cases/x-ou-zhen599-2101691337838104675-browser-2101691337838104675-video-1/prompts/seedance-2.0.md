# 单次投入｜容器延迟变化与失控收束 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创15秒剧场模型工坊短片：技师轻碰气阀，微型充气城市逐级过压，检查仪表后关闭进气仍有余压，最终打开回收阀安全泄入上方气囊。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：稳定中景同时交代技师、气阀、整座桌面模型和上方回收气囊；技师轻轻碰开进气阀，只有第一栋布料屋顶从折叠态开始缓慢鼓起；气管、压力表和各建筑的连接清楚；其他房屋暂不动；中性工坊光，模型使用清晰而克制的彩色布料；<一声气阀轻响和第一段布料摩擦声>。
镜头2：沿同一气管小幅横移，不跳到第二座城市；第一屋顶越过刻度线，气压顺连接支路传递，第二和第三栋房屋依次膨胀；底座、量尺和各房屋固定，膨胀顺序可追踪；保持同一工坊光和建筑颜色；<三段分开的充气布料声>。
镜头3：中近景保留压力表和仍在上涨的模型一角；技师查看过高压力表并关进气阀；进气停止，但下游残余气体使同一条布料街道继续抬起；进气阀已关闭与下游仍鼓胀可同时看见，符合余压因果；读数警示仅用表针变化，不叠加神秘图形；<阀门关闭声和短暂的继续胀气声>。
镜头4：回到可见全模型、回收管和上方气囊的稳定广角；技师拉开泄压柄，下游残余气体顺可见回收管进入上方气囊；模型各建筑逐渐变皱、落回底座；没有房屋消失或画面重置；上方气囊胀起对应下方排气；维持清楚的材质细节，避免爆炸；<连续泄压气流声逐渐减弱>。
镜头5：正面稳住技师、放气后的模型和膨起的回收气囊；压力表回落，技师吃惊地看着皱缩城市；最终状态停留可读；气体去向仍可见，所有物体保持同一空间；中性收尾，不加品牌或文字；<一声轻轻的布料落定声>。
整体风格与画质：原创写实的剧场道具工坊微缩机械喜剧，非魔法炼金场景；一处小误操作、分阶段连通膨胀、具体仪表检查、余压造成未立即停下、回收气囊完成守恒收尾。
约束：只用一名成年技师、一座布料充气城市模型和同一条可追踪气路；关进气后只剩下游余压；泄压必须沿可见管路进入上方气囊，不凭空消失；不复制炼金角色、药水、黑锅、绿色泡沫、来源对白或字幕；无品牌水印。
```
