# 双人时装字卡｜造型轮转、姿态微动与版式回标

## 用途

高对比色卡依次呈现多组明确成年时装搭档；每组只执行一个姿态变化并与一个原创短词绑定，重复边框和节拍把独立造型收束为同一系列。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 在青色字卡中呈现两名明确成年的原创时装搭档，并显示准确短词【PULSE】。；准确短词【TANDEM】从两人身后滑过，两人各交叉一只手臂。；让搭档回到青色网格，并停留准确原创标题【TWO SIGNALS】。

## 必须保留的结构锚点

- Every depicted human is clearly adult.
- One layout grammar connects all cards.
- Typography never obscures identity anchors.
- The final card reunites the pair and series title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
