# 市场取物再入雨巷｜摊位基线、交易接触与路线续行

## 用途

同一成年旅行者在可定位市场中接近摊位、手选水果、与摊主完成一次付款交接，再沿同一方向离开拥挤市场并进入雨后窄巷；物件和路线连续证明行程没有重置。

## 推荐输入格式

`同一成年自拍主体与固定路线 + 一次目光或转头动机发现 + 一个地方物品的完整嗅闻或品尝动作 + 克制身体反应且无广告台词 + 手持结果继续原路线`

## 可直接改写的简短示例

> 跟随一名成年海洋研究员穿过有顶港口市场，接近固定柑橘摊位。；与成年摊主完成一次刷卡支付，野外包和香橼保持可读。；路线继续进入雨暗码头巷，同一研究员、包和行进方向保持。

## 必须保留的结构锚点

- One adult traveler and one directional route remain continuous.
- A selected object is visibly taken from an established stall.
- A physical foreground wipe bridges rather than resets the route.
- The terminal environment preserves traveler, carried object and travel direction.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
