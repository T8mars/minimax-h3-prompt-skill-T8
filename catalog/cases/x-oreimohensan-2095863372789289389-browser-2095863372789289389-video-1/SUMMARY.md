# 绘制带推进｜骨架、线稿、上色与角色板验真

## 用途

把完整人物限制在固定纸面和角色板区域内，按骨架、结构线、服装线、局部上色、全彩和数字扫描的顺序推进；每层保留前层轮廓，最后用同一面容近景证明身份连续。

## 推荐输入格式

`稳定主体 + 边界清楚的转换带 + 新旧状态同框 + 单向累积覆盖 + 载体退出后的完整结果`

## 可直接改写的简短示例

> 一名成年插画师在暖色纸张上，用蓝色结构线开始绘制一名原创成年植物学家角色。；用四个受控步骤填充肤色、橄榄绿夹克、锈红长裤和黑靴，姿态保持固定。；让一道青色扫描从靴子上移到头部，再以同一面容轻眨一次的近景收束，不重新设计。

## 必须保留的结构锚点

- One fixed adult character pose and proportion system persists through every drawing layer.
- Each later layer visibly preserves and refines earlier construction evidence.
- The reference board repeats the same identity across front, side and face views.
- The digital scan ends on the same completed face and supplies only one bounded living motion.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
