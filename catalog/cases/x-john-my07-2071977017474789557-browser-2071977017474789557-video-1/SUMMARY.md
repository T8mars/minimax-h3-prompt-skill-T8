# 日常跟拍｜巷道小事到回眸离开

## 用途

拍摄者在普通住区里发现并跟随同一人物，用稳定地理锚点串联几项小动作和一次偶遇；人物只对观察者做一次克制回应，随后继续离开。作为既有纪实跟拍模板的新证据，不新增选择器。

## 推荐输入格式

`侧面连续跟拍 + 狭窄起点 + 行进中空间揭示 + 一次偶发横穿 + 一次克制回应 + 继续离开`

## 可直接改写的简短示例

> 原创成年屋顶花园管理员已经坐在低墙上戴紧两只手套，同一件褪色蓝工作衫、绿色水管和白色工具门从开场可见；同一管理员把一块沙色遮阳布挂到两个框架之间，只完成一次家务动作；管理员只向观察者小幅点头一次，随后转身拿着同一杯子走进白色楼梯门

## 必须保留的结构锚点

- Begin with the subject already performing an ordinary action rather than posing for introduction.
- Use recurring landmarks and stable identity anchors to connect every small action.
- Allow only one restrained acknowledgment of the observer after routine evidence is established.
- End with the same subject continuing through the established route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
