# 触控换媒｜接触触发、状态推进与成品回归

## 用途

锁定同一对象和制作台，让一支可见工具每次接触都触发写实与二维线稿之间的媒介切换；每次切换必须同时推进一个不可逆制作状态，最终回到写实成品并保持空间注册关系。

## 推荐输入格式

`锁定工作台与对象 + 可见工具接触触发 + 写实与插画至少往返两次 + 每次切换推进不可逆制作状态 + 固定注册锚点 + 写实成品回归`

## 可直接改写的简短示例

> 未完成黄铜钟表模块位于三颗固定钢螺钉之间，白色粉笔触控笔明确接触底板；第二次接触恢复写实黄铜，齿轮组真实存在并继续增加发条；最后一次接触恢复完整真实时钟，底板、齿轮、发条、指针和表镜齐全，秒针开始稳定走时

## 必须保留的结构锚点

- Establish one bounded workspace, one primary object and one visible contact tool in reality.
- Toggle medium only at visible tool contact and preserve object registration across the boundary.
- Advance one irreversible build or preparation state after every toggle without resetting earlier progress.
- Return to photoreal reality with the completed object and original anchors visible.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
