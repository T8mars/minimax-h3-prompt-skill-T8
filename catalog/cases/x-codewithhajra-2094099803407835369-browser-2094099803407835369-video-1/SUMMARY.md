# 灯窗森林回环｜静默树屋、轨道显形与列车唤醒

## 用途

同一森林轴线上先用树窗灯光建立繁盛基线，再逐步熄灭让铁轨和雾显形；列车沿中心线穿过后，树窗重新点亮，形成路线驱动的状态回环。

## 推荐输入格式

`重复通行路线 + 固定揭幕区 + 每次完整移动遮挡 + 不同全成年原创反应场景 + 场景之间回到同一路线 + 完整终态反应`

## 可直接改写的简短示例

> 成年夜间巡护员站在灯笼旁，森林小径两侧的树洞发出琥珀光。；蓝雾聚集，一艘小型电动渡船以两盏白灯接近。；渡船离开后，树洞按反序重新点亮，同一巡护员仍在原灯笼旁。

## 必须保留的结构锚点

- One route and one observer anchor both states.
- Baseline lights change monotonically before carrier arrival.
- Interior carrier light contrasts with the exterior state.
- The final relighting restores the opening geography.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
