# 空场异常｜物质扩张与片名停留 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创15秒空天文台悬疑片头：固定望远镜上一条霜线连续扩张，最后以原创片名覆盖明确物证。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：广角先证明无人天文台、望远镜支架与其下星图的固定位置；镜头沿同一望远镜缓缓接近；原创小字幕“故事：林遥”放在暗部留白；屋顶缝口、支架螺栓和纸星图作为后续定位锚点；冷月光与低亮黄铜反光；<圆顶通风声><远处风声>。
镜头2：中近景看目镜、星图与固定螺栓；仅一颗霜晶出现在目镜边缘；第二条原创小字幕“导演：周屿”与霜晶分开；仍是同一房间同一仪器，没有人物出现；霜晶冷白与黄铜微光；<极轻的金属冷缩声>。
镜头3：沿望远镜真实连接部件短距离跟随；同一条霜线从目镜边缘沿黄铜筒体爬向圆形支架，连续可追踪，不突然在无关处冒出第二条；螺栓与纸星图位置不变；不暗示未出现的凶手或怪物；冷白霜只照亮经过处；<细微结霜声>（单薄持续音慢慢加深）。
镜头4：稳定高位看同一台结霜望远镜和星图；原创大标题“COLD MERIDIAN”作为清晰叠加文字停住，霜线不直接拼字；最终物证与开头位置一致，房间仍无人；背景稍降对比保障可读性；（音乐在片名下变轻）。
整体风格与画质：原创克制的天文台悬疑片头，以单一物证而非血腥惊吓制造不安；一个房间一台仪器一条霜线；物证连贯、两个简短职员字幕与最后片名都可读。
约束：不复制来源餐桌、梨、蝴蝶结、红色液体与原剧名；霜线连续且片名是叠字，不是霜拼出的字；不出现人物、怪物或无因果瞬移。
```
