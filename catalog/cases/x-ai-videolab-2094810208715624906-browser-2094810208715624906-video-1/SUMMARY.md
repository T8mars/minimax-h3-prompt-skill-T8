# 黑色侦探片头｜唱片母题、案件拼贴与总标题归拢

## 用途

以旋转唱片和侦探剪影建立母题，再让列车、便签、人物剪影和案件标签进入统一蓝橙紫漫画格；职员表与物证共用版式，终局归拢成可读总标题。

## 推荐输入格式

`至少三种独立材质职员表场景 + 每幕一条原创短职员表与材质动作 + 跨幕重复色形或标记 + 回到已建立材质族汇聚 + 大型原创总标题稳定停留`

## 可直接改写的简短示例

> 以一盘黑色开盘磁带开场，盘面带原创象牙色灯塔剪影，背景保持黑暗。；为每个物证章节分配固定格子和一张准确原创职员卡，文字不得越过格线。；将全部格子压缩成准确总标题【NIGHT SIGNAL】，并保留灯塔、渡轮和档案员的小型证据剪影。

## 必须保留的结构锚点

- One recurring evidence carrier opens the title system and remains traceable.
- Every vignette uses the same limited palette and registered comic grid.
- Connections between clues remain visually causal rather than decorative clutter.
- The master title contains miniature residues of the earlier evidence modules.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
