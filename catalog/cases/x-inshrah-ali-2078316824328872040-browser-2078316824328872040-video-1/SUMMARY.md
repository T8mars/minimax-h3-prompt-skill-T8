# 告别物证回环｜雨中回望、戒指落桌与空街余震

## 用途

当前雨中人物与暖色共同记忆交替，眼泪把回忆推回现实；一枚戒指落在湿桌成为关系物证，女方离场，男方追出却只面对驶过的列车和空路。

## 推荐输入格式

`观察者媒介 + 日常人物/地点 + 两个日常动作 + 外部信号改变目标 + 一次回应 + 有动机录制失误`

## 可直接改写的简短示例

> 成年地质学家戴透明雨帽站在暴雨车站外。；回到车站，她的克制表情破裂，雨水沿雨帽流下。；货运列车驶过空站台，伙伴独自停留，罗盘仍在原处。

## 必须保留的结构锚点

- The same two adults anchor present and memory.
- A recurring object bridges the time layers.
- One placed object proves the separation.
- The final empty route preserves the aftermath instead of reconciliation.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
