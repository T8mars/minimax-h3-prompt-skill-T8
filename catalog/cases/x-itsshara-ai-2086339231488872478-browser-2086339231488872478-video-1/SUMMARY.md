# 单色激活｜唯一色彩信号跨尺度接力

## 用途

先把世界压到近单色并建立多个清楚尺度，再只允许一种高饱和强调色从一个局部激活点出现；强调色必须沿可见载体逐级跨越人物、巨构和环境网络，最终形成更大范围但仍受控的系统状态，其他颜色不得争夺注意力。

## 推荐输入格式

`近单色低饱和世界 + 至少3级可比较尺度 + 唯一高饱和激活色与局部源点 + 同色沿可见载体跨尺度接力 + 保留早期锚点 + 最大环境网络稳定映射`

## 可直接改写的简短示例

> 成年技师、房间大小螺旋阀、长管廊和远端蓄水池形成四级尺度，尚无高饱和色；同一琥珀脉冲沿检修缝进入巨型螺旋阀；同一琥珀色映射完整连通水网并稳定停留

## 必须保留的结构锚点

- Reserve the world to one narrow low-saturation color family before any activation.
- Establish at least three measurable scales with persistent comparison anchors.
- Relay the same hue through a visible physical or informational carrier while earlier anchors remain recognizable.
- Resolve the accent as a stable environment-scale network or system state with no new competing color.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
