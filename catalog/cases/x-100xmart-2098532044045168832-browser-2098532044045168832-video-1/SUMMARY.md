# 深渊横移揭示｜熔岩尺度、前景锁链与远端城塞

## 用途

用一次缓慢连续横移从近处岩壁和锁链进入广阔地下峡谷；熔岩瀑布、桥梁和远端蓝光城塞依次提供尺度参照，终局停在完整深渊地理。

## 推荐输入格式

`5个熟悉尺度参照 + 每镜1个巨型原创形态 + 视点变化 + 距离逐步缩短 + 近距离终态`

## 可直接改写的简短示例

> 从地下巨型水库的一道黑色玄武岩肋和悬挂铜链后开始。；揭示三道发光水瀑和两座狭窄维修桥，作为尺度参照。；稳定在广角画面，同时包含前景锁链、裂谷、桥梁、水瀑和完整城塞。

## 必须保留的结构锚点

- One continuous camera path reveals scale.
- Foreground objects remain as registration anchors.
- The destination structure appears only after depth is proven.
- The final wide frame retains all major depth layers.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
