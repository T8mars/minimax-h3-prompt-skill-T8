# 日常取物流程｜手持零食、连续步行与柜台交接

## 用途

用同一人物、手持物和街区路线压缩一个简单日常任务：先建立边吃边停留的状态，再连续步行进入小店，与柜台人物完成物品交接，最后让新纸袋成为任务完成证据。

## 推荐输入格式

`稳定主体与目的地 + 单职责短动作 + 姿态/手中物/方向接力 + 累积准备状态 + 单向路线 + 终点结果动作`

## 可直接改写的简短示例

> 建立原创成年骑行者，在安静庭院休息并用钴蓝水瓶喝水。；用一次后跟镜头让同一成年人沿从左到右的单一路线进入维修亭。；以骑行者在亭外面对镜头收束，一手持信封，修好的自行车位于身旁。

## 必须保留的结构锚点

- One clearly adult subject keeps the same clothing, bag and route direction.
- The opening handheld object remains traceable until the destination is entered.
- The received object differs clearly from the opening object and remains readable at the end.
- The route, destination and payoff form one ordinary task without unrelated flashbacks.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
