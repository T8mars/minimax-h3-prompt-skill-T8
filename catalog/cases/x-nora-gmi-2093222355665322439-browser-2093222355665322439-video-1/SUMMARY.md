# 尺度俯冲揭示｜轨道、城市、街巷与人物连续锁定

## 用途

用一次持续尺度收缩把轨道视角依次交给云层、海岸、城区和街巷；每级都保留前一层地标方向，直到镜头在巷道人物前减速并完成身份揭示。

## 推荐输入格式

`5个熟悉尺度参照 + 每镜1个巨型原创形态 + 视点变化 + 距离逐步缩短 + 近距离终态`

## 可直接改写的简短示例

> 从原创环形卫星上空开始，朝一座极地聚居地持续俯冲。；继续下降，依次越过冰路、模块屋顶和中央温室区。；镜头减速到原创成年种子递送员的中景肖像，人物戴宽大保温兜帽、穿编织工具外套。

## 必须保留的结构锚点

- One uninterrupted scale direction links all levels.
- Each level reveals a landmark used by the next descent.
- Urban geometry narrows into one specific route.
- The camera slows before the final adult identity portrait.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
