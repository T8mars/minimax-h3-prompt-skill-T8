# 错过阈值转向｜急行路线、离站证据与新方向

## 用途

用一个清晰目的地和连续急行路线制造时间压力；人物到站时载具已经越过可进入阈值，工作人员的方向手势确认失败，人物必须停顿、判断并沿新方向离开，而不是无因果重置。

## 推荐输入格式

`一名明确成年原创主体、一个可追踪目标和连续路线 + 人物用动作与环境位移逐级证明紧迫性 + 在可见且不可逆的阈值事件发生后才确认错过 + 一名辅助角色只提供一次明确替代方向 + 主体接受信息并沿新的可追踪路线离开，身份、道具和空间关系不重置`

## 可直接改写的简短示例

> 一名原创成年植物学家穿过雨夜广场跑向玻璃渡轮码头，手持红色野外笔记本。；保持侧面中景，让植物学家停下，目视渡轮后方不断扩大的水面间隙。；经过一次可见的判断停顿后，植物学家转身收好笔记本，跑向被指示的公交车道。

## 必须保留的结构锚点

- One clearly adult traveler, one handheld urgency prop and one destination persist.
- The route to the threshold is continuous and geographically readable.
- A local authority cue confirms closure and identifies one alternative direction.
- The final action redirects the same journey without teleportation, rewind or false success.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
