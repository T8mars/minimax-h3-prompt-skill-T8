# 单目标逃生｜前后灾害交替逼近

终点始终可读，身后封闭与前方危险交替出现，以一次恢复和近失结果证明推进能力。

## 核心机制

Keep one destination visible while a single operator advances along a constrained route. Alternate obstacles from behind, ahead and the side so each requires a different physical adaptation without changing the goal. Reserve one deliberate control action for the endpoint, then prove success with a near-miss protective state that visibly intercepts the pursuing hazard.

## 推荐输入格式

`主体 + 可见终点 + 身后封闭 + 前方危险 + 一次全身恢复 + 近失结果证明`

## 简短示例

> 维修无人机朝可见气闸前进，身后隔板依次关闭，前方机械臂横扫；它完成一次全身翻转恢复，擦过护盾后进入气闸。

## 必须保留的结构锚点

- 单一终点持续可读
- 前后危险交替而非同时混乱
- 有一次完整恢复动作
- 近失结果可见并证明保护能力

## 使用方法

1. 先保留用户主体和目标，再按推荐格式补齐场景、事件链、镜头和结果。
2. 阅读 [Creative DNA](./creative-dna.json)，重新实例化变量，不做来源表面换名词。
3. 分别查看 [MiniMax H3](./prompts/minimax-h3.md) 与 [Seedance 2.0](./prompts/seedance-2.0.md) 的已验证实例。
4. GitHub 使用 GIF 快速预览；Electron 媒体包播放完整有声 MP4。
