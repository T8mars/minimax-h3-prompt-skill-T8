# 微观到世界｜生态线索扩张与片名 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创15秒极地生态纪录片片头：冰芯微生物的琥珀色线索经过实物样本标签与冰道，最终成为冰原调查路线和原创标题。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：先明确这是显微镜显示器里的放大影像：显微画面内仅一块冰芯气泡及单个微生物，画面边框提示尺度；显微画面中的气泡掠过琥珀反光；简短虚构职员字幕“资料：林舟”放在显示器画面外的暗部留白；此镜只展示显微尺度，不把宏观实物样本标签硬塞进同一焦平面；冷蓝透明冰与一个温暖琥珀小点；<轻微冰裂声><样本盒扣合声>。
镜头2：从显微显示器拉回真实实验桌，看研究员把同一冰芯放进样本盒，再沿短冰道平稳移动；到桌面尺度才看见冰芯实物标签上的同一琥珀小标记；冰道标牌重复该标记；第二条虚构职员字幕“摄影：周川”位于空墙；冰芯、样本盒、标签和冰道方向连续，不随意换物；低温环境保留一条暖色识别线；<脚踩冰面的闷响><风声渐起>。
镜头3：走出冰道先看见小研究站，再切到更高的冰原俯瞰图；同一琥珀标记成为调查路线节点，研究站仍在地图内作为尺度锚点；中间研究设施连接微观冰芯与宏观冰原；不突然跳到太空；冰原蓝白、路线琥珀色；<开阔极地风>（音乐缓慢展开）。
镜头4：稳定俯瞰冰原与小研究站，降低背景运动；原创大标题“LIVING ICE”清晰出现并停留到结尾；路线与站点可见，片名占安全留白；标题与冰原保持清晰对比；（音乐在片名下减薄）。
整体风格与画质：原创极地野外生态纪录片片头；实物样本、调查标记和冰原地图形成跨尺度线索；微观样本、短冰道、研究站与宏观冰原有明确物理承接；两条小字幕和片名都清楚可读。
约束：不复制原片番茄走廊、轨道空间站、圆形舷窗地球、原片剧名和姓名；不凭空说明倒计时或来源原声；同一冰芯和琥珀标记跨镜头保持身份，地图中保留研究站位置；微生物只在明确的显微成像中可见；实物标签等拉回桌面尺度后再出现。
```
