# 安静书写进度钟｜落笔推进、蘸墨复位与无缝续写

## 用途

用固定书桌、同一成年书写者、笔尖位置和已写行数形成进度钟；墨量下降触发一次蘸墨，笔尖必须回到原停止位置之后继续，最终以新增行证明任务前进。

## 推荐输入格式

`同一工艺物 + 一个只增不减的材料变量 + 4个阶段 + 成品揭晓`

## 可直接改写的简短示例

> 成年地图档案员坐在固定橡木桌前，面前是奶油色路线册、黄铜笔尖和绿色墨水瓶。；线条变细时暂停，同一笔尖只蘸一次绿色墨水。；笔尖抬起，三条新完成的绿色路线与同一墨水瓶共同停留。

## 必须保留的结构锚点

- One workspace, adult worker and tool remain fixed.
- Visible progress accumulates monotonically.
- The tool resumes beyond the exact prior stopping point.
- The terminal frame proves additional completed work.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
