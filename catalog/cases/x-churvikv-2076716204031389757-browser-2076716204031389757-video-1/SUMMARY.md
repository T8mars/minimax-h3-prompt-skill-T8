# 破界航线｜主体不断线穿过材质世界到达终点

## 用途

先用稳定主体和明确行进方向建立路线，单一破界动作把平面材质改写成可穿越环境；主体的朝向、速度和镜头跟随不中断，随后在新世界里经过可读地标并完成一次终点停驻。作为既有世界换材路线模板的新证据，不新增选择器。

## 推荐输入格式

`连续移动主体 + 原世界基线 + 单次全局换材 + 方向速度不断线 + 新世界终点`

## 可直接改写的简短示例

> 原创三角陶瓷勘测滑翔器带单一琥珀核心，沿深灰炭笔地图膜稳定向右飞行；同一滑翔器穿过卷曲黑雾和漂浮石墨碎片，琥珀核心始终可见；滑翔器展开两片陶瓷制动翼，完成一次对齐并锁入六边形接收槽，停留证明抵达

## 必须保留的结构锚点

- Establish one stable carrier, route direction and camera relationship before the boundary changes.
- Use one visible boundary event that causally opens the new material environment.
- Reveal and preserve one destination after the new world becomes readable.
- End with one explicit arrival action and a held terminal state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
