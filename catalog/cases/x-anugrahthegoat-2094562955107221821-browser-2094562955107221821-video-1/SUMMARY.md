# 界面能力证明蒙太奇｜输入、工具、生成结果与复盘回标

## 用途

把同一软件的输入框、工具菜单、数据收集、媒体结果、插件连接和错误复盘压缩为多个可验证章节；每个章节都先显示操作再显示结果，终局回到统一产品主张而非随机拼贴。

## 推荐输入格式

`一个原创工具或界面先建立清楚输入区 + 至少三种用途不同的输入任务依次触发 + 每种输入均对应可核验且不混淆的结果 + 界面布局与结果归属持续可读 + 终局汇总工具、能力类别和代表结果`

## 可直接改写的简短示例

> 打开原创炭黑研究工作台，以准确章节字【ASK】和一个空输入框起始。；启动一次分析状态，再显出与同一问题绑定的对比图和紧凑表格。；回到原始输入框，显示准确短句【FROM QUESTION TO VERIFIED RESULT】和完整工作台标记。

## 必须保留的结构锚点

- One persistent product interface and visual system anchor all capability chapters.
- Every chapter shows a user action before its corresponding result.
- Later tools reuse earlier query context and expose traceable source or error evidence.
- The final proposition summarizes the demonstrated chain and reconnects to the original input surface.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
