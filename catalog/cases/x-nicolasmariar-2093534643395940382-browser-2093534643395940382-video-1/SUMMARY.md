# 赛博潜入三段式｜高处抵达、能力证明与室内揭面

## 用途

用三个明确空间完成悬念：外部高处抵达、路线上一次能力证明、内部目标门槛；同一成年角色、面具与服装贯穿，只有抵达目标后才揭面。

## 推荐输入格式

`远景入口 + 跨过阈值 + 连续通行 + 局部异常检查 + 可见路线终态（不下诊断）`

## 可直接改写的简短示例

> 一名戴面具的成年信号审计员携铜线圈，落到原创雨夜中继站屋顶。；手套与面具近景中，同一门上的绿色通行灯亮起。；门关闭后才摘下面具，并把铜线圈放到桌面。

## 必须保留的结构锚点

- One masked adult identity persists across all spaces.
- The exterior arrival precedes one bounded competence proof.
- The target room is spatially distinct but causally connected.
- Identity reveal occurs only after the final threshold closes.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
