# 微表情表演｜直视、半笑、垂眼到开放回稳

## 用途

用几乎锁定的单人近景先建立稳定直视，再通过半笑、垂眼、闭眼停顿、重新抬眼和开放回稳累积一段微表演；不靠切镜、换景或大动作遮盖连续性。作为既有微表情问候模板的新证据，不新增选择器。

## 推荐输入格式

`单一人像 + 侧身开始 + 稳定直视 + 垂眼停顿 + 1次峰值表情 + 开放表情回稳`

## 可直接改写的简短示例

> 原创成年纸张修复师穿靛蓝工作外套，画面右侧保留虚化同事肩部，先稳定直视；修复师低头看画面下方修复地图边缘，只闭眼一口气；修复师短暂眨眼，较小的笑意回落到平静中性表情

## 必须保留的结构锚点

- Establish one clearly adult subject and stable direct gaze in a locked close-up.
- Use one restrained half-smile as the first countable peak.
- Return to the same gaze axis with an open attentive expression.
- Settle through one small blink or smile into a relaxed terminal hold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
