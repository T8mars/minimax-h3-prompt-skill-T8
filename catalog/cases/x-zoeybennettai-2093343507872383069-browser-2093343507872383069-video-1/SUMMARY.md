# 食材到饮品状态链｜切开、取肉、搅打与倒杯证明

## 用途

让食材的每次不可逆操作直接产生下一状态，工具、容器和液体保持因果连续；终局必须同时展示原料、饮品和明确成品状态。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 正面棚拍近景中，一刀切开原创琥珀星梨。；加入三块冰和一股定量浅茶，搅打成金色不透明饮品。；成年制作者、切开的梨、搅拌杯和成品杯停在准确短句【ONE CUT / GOLDEN READY】下。

## 必须保留的结构锚点

- One ingredient identity remains traceable.
- Each irreversible operation causes the next state.
- One viscosity proof precedes serving.
- The final hero frame reunites source ingredient, process and serving.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
