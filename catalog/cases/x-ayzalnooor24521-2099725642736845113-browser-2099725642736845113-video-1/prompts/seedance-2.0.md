# 冲击停顿｜第二角色入场与近景确认 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创20秒双机器人安全校准演示：落块急停、长停顿、第二机器人进入、短促非接触机械臂交替、首台传感器定格。
总时长约20秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：稳定广角交代顶部测试架、红框地垫和第一台机器人；轻质泡棉块从架上落到机器人前方的地垫、进入前置传感器视野；传感器可见地转向泡棉，第一台机器人随即急停，轮胎仍接地；泡棉、前方地垫、第一台机器人处于同一直行通道，落块不会从身后无提示地触发刹车；后续位置不变；明亮安全测试厅，红色地面标记清楚；<泡棉轻落地声与轮胎制动声>。
镜头2：稳定正面中景，让一侧入口保持空白；第一台机器人朝入口静止观察，泡棉仍在原地，保持一段真正安静的等待；不让第二台机器人过早出现；照明持续一致；<低电机待机声>。
镜头3：缓慢靠近第一台的前置传感器；传感器向入口轻微转动，第一台机器人位置不动；地垫和泡棉仍能定位；传感器轮廓清楚；<轻微伺服转动声>。
镜头4：侧面中景同时包含两台机器人和红框；第二台从入口滚入；双方柔性校准臂在地垫上方交替做三次近距离非接触动作，然后收回；轮胎始终着地、机械臂不碰撞、泡棉不消失；维持明亮测试照明；<短促轮胎声与伺服咔嗒>。
镜头5：定在第一台机器人前置传感器近景；它转向第二台，后景仍能看到原地泡棉、红框与第二台机器人；没有重置或多出第三台；连续照明；<电机逐渐安静>。
整体风格与画质：原创安全工业机器人校准影像，不复刻地铁冲突；急停与静止等待反差、非接触交替动作、首台传感器终景均清楚。
约束：测试块是轻质泡棉，不造成真实危险；两台机器人保持形体、地面位置与轮胎接触连续；无地铁车厢、圆瓷砖立柱、人物打斗或可辨识广告。
```
