# 颜色规则搜寻｜任务宣布、同色取物与满载回报

## 用途

先让同一成年人物和购物车建立单色搜寻规则，再用多次货架取物、购物车累积和人物反应证明规则被执行；结尾把满载结果与发起者重新同框。

## 推荐输入格式

`一名明确成年原创主体与一个清楚可见的筛选规则 + 至少三次不同类别的可验证搜寻接触 + 合格物件逐项保留且不合格物件不被带走 + 同一容器与路线连续 + 终局完整库存和人物反应共同证明完成`

## 可直接改写的简短示例

> 原创成年海洋研究员穿钴蓝夹克，推空灰色样品车进入白色实验物资库；规则是只收集蓝色物件。；同一推车和前进路线保持连续，已接受的蓝色物件始终可见，非蓝色物件留在货架。；回到同一研究员与满载推车同框，她核对三类物件并只做一次完成手势。

## 必须保留的结构锚点

- One explicit selection rule is understandable before the first pickup.
- Every accepted object visibly satisfies the same rule.
- At least three different object categories demonstrate that the rule generalizes.
- The initiating adult and the completed collection reconnect in the terminal proof frame.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
