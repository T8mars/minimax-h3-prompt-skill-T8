# 重击对轻群体反制｜诱饵让位、群体绕行与武器缠束

## 用途

先建立明确成年重型攻击者和轻量群体控制者；重击完整承诺后，轻群体避让并从攻击轨迹背后重组，逐步把进攻武器和身体缠束，最终由被反制姿态证明战术翻转。

## 推荐输入格式

`Establish two clearly adult original opponents, one heavy attack system and one light swarm system. + Require the heavy attack to commit a readable path before the swarm changes formation. + Make the swarm evade, preserve units and regroup behind the attack path to bind one functional point. + Escalate binding through the attacker's repeated force while keeping both adult identities and geography readable. + End on a stable immobilization proof with the controller unharmed and the attacker's original weapon still identifiable.`
