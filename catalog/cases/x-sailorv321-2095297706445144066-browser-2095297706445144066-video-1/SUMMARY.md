# 赤黑角色字卡轮转｜镜像手势、情绪词与终门回标

## 用途

锁定同一成年原创动画角色，用手势、转身和奔跑触发赤黑白字卡、镜像手掌与对称几何；单人与复制模块交替升级，最终让完整角色抵达一扇可读终门。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 锁定原创成年夜间递送员：白发、炭灰长外套、一只橙色手套和三角面颊标记，统一使用海军蓝、奶油白与橙色图形系统。；向前一步把人物复制进三个注册面板，面板只标记【WAIT】，每个版本保持相同面孔、外套和面颊标记。；人物独自停在橙色终门前，准确原创标题【LAST ROUTE】出现，调色、手套和路线圆环同时可见。

## 必须保留的结构锚点

- One clearly adult original character retains at least three identity anchors across every graphic module.
- Each module follows one visible body action and introduces no more than one exact short word.
- Module density may rise, but recurring palette, hand motif and circular geometry remain traceable.
- The final gate recombines duplicates and returns the complete character under one exact original title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
