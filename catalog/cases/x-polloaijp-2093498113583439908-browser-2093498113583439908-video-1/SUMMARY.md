# 季节记忆组曲｜群体活动、空场残留与个人回望

## 用途

通过同一群体的活动碎片与空场交替压缩一段季节记忆；物件和地点持续回声，最后让一名明确成年人物在起点意象前完成回望。

## 推荐输入格式

`观察者媒介 + 日常人物/地点 + 两个日常动作 + 外部信号改变目标 + 一次回应 + 有动机录制失误`

## 可直接改写的简短示例

> 四名明确成年社区剧团朋友度过一个晚秋日，红枫叶是固定锚点。；屋顶灯笼圈成为温暖群体峰值。；成年女性面对枫林停留，四名成年人的透明记忆在身后聚合。

## 必须保留的结构锚点

- One seasonal motif recurs across every chapter.
- The same clearly adult group anchors activity fragments.
- Recurring props bridge populated and empty scenes.
- One adult viewpoint closes the memory without inventing a new event.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
