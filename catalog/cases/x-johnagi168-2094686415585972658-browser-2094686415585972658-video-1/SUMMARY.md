# 点选换装闭环｜阵列基线、光标选择与单人结果

## 用途

先在同一界面建立成年模特与多套服装阵列，每次光标只点选一件，中央人物立即出现对应完整造型并保持脸、身体比例和站位；终局回到已选状态而非随机轮播。

## 推荐输入格式

`明确成年原创操作者、实体输入设备和响应屏幕或机器同一地理先建立 + 每个重要虚拟或机械事件前先展示一个具体物理输入 + 至少三组不同输入—响应对应且输出不得提前 + 从选择、导航或防御升级到一个决定性结果 + 终局把结果重新连接到同一成年人物的可读反应`

## 可直接改写的简短示例

> 建立原创换装界面，中央为成年博物馆主持人：黑色短发、金耳扣和固定中立姿态。；点击象牙晚装卡，只替换服装，脸、身体比例和中心站位保持准确。；同一人物穿锈红外套停留，三个身份锚点和已选卡清楚，不再轮播。

## 必须保留的结构锚点

- One adult identity, body geometry and central position remain fixed.
- Each single visible selection changes only the corresponding garment state.
- No unselected option appears as the result.
- The final state preserves one selected tile and its matching complete outfit.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
