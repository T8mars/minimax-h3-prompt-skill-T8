# 自拍地标路线｜街行转身、饮品停点与河岸续行

## 用途

用同一成年旅者、手持自拍距离和步行方向串联街道、地标道路与河岸；一次转身负责揭示地点，一次饮品停点完成体验证明，随后人物恢复行走并以日落地标收束。

## 推荐输入格式

`同一成年自拍主体与固定路线 + 一次目光或转头动机发现 + 一个地方物品的完整嗅闻或品尝动作 + 克制身体反应且无广告台词 + 手持结果继续原路线`

## 可直接改写的简短示例

> 跟随原创成年旅行插画师：黑色长发、白色罩衫、银色手表和牛皮纸饮品杯，以近距离手持自拍沿繁忙河岸城市路线前进。；一辆掠过的深色出租车只擦拭切换一次到河岸步道，面孔、头发、罩衫、手表、杯子和前进路线保持连续。；她放下同一个杯子，继续走三步并只回看一次，让日落钟楼占据终局背景。

## 必须保留的结构锚点

- One clearly adult traveler, one handheld selfie distance and one route direction anchor every chapter.
- A single visible turn reveals landmarks without replacing the traveler or resetting the route.
- Exactly one drink stop contains a complete sip and a restrained visible response.
- The subject resumes movement with the same cup and ends against a readable destination landmark.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
