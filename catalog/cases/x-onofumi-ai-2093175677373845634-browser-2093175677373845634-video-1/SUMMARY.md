# 汽水平面冲击广告｜罐体锚定、气泡撞击与字标归位

## 用途

锁定单一包装轮廓，用气泡、冰块、液体和大字依次证明清凉与冲击；每次图形爆发都从罐体接触或开启动作发生，最后回到完整包装。

## 推荐输入格式

`明确成年原创广告主体与至少三项稳定身份/服装锚点 + 统一纸张/撕边/墨色系统通过动作、细节或注册边缘进入 + 全身证明与至少两个材质微距接力 + 至少两种明显不同海报版式但身份和信息层级不漂移 + 短字只解释相邻证据 + 汇总已证明人物、细节和文字形成终局广告页并停留`

## 可直接改写的简短示例

> 奶油底显示原创紫色【LUMA】气泡茶罐，包装轮廓清楚稳定。；同一罐体穿过准确短词【CHILL】字卡并完成一次清楚倒杯，标签注册不变。；所有图形回收到完整LUMA罐体与准确短语【SIP BRIGHT】，停留收束。

## 必须保留的结构锚点

- One registered package silhouette anchors every beat.
- Every graphic burst starts at a visible package action.
- Copy remains short and readable during motion.
- All elements return to the complete product lockup.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
