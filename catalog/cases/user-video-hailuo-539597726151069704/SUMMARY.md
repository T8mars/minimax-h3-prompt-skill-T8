# 双支座弹性偶｜控制器驱动形变复位

## 用途

让两个图形角色分别绑定到持续可见的物理支座；每轮只改变一种可读控制参数，以共同响应、独立响应和第三种关系测试证明绑定规则，最后让两支座重新稳定并恢复可辨双角色终态。

## 推荐输入格式

`两个可见支座绑定双角色 + 共享响应 + 独立响应 + 第三种关系测试 + 所有权不互换 + 配对终态`

## 可直接改写的简短示例

> 原创磁悬观测室内，两座黄铜万向节底座位于独立同心环；A座系青色方眼种荚，B座系琥珀月牙眼种荚；两座底座沿不同半径绕中央校准标记运行一圈，两枚种荚形成耦合环绕但系绳始终分离；两座底座进入并排插槽，斜向张力释放，两枚种荚恢复成紧凑可辨形态；眼标、系绳和停靠灯同框停留

## 必须保留的结构锚点

- Establish two distinct graphic characters, each visibly bound to one stable physical support.
- Change one measurable support parameter and make both characters answer through a readable shared response.
- Apply a third materially different support relation or controller path without repeating the prior response.
- Synchronize both supports and finish with two legible characters still attached to their original sides.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
