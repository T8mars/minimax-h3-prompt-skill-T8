# 功能问答闭环｜人物疑问由设备状态完成证明 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：制作原创10秒温室功能证明短片：成年温室主管与一台紧凑灌溉机架同框，机架只有一盏琥珀待机灯和三根透明空管；主管抱臂看向画外同事。切到另一工作台的成年农艺师，查看一块掌心状态牌，只点按一次并做克制确认手势。回到完全相同的机架构图，待机灯变绿，三根透明管依次充水，主管放开一只手并露出释然表情。不得依赖可读UI文字或指定对白。。
总时长约10秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：疑问与设备同框；成年温室主管站在灌溉机架旁，琥珀待机灯和三根透明空管清楚可见；她抱臂看向画外同事；先把功能疑问绑定到具体机器，不靠字幕；暖色自然光、真实玻璃与金属；<温室底噪><机架低鸣>。
镜头2：保持设备未解状态；同一构图中主管可见说话动作，但不规定对白；琥珀灯和空管保持不变；问题成立但结果尚未出现；稳定中广角、无小字UI；<克制说话声但内容不指定>。
镜头3：远程状态检查；另一工作台的成年农艺师查看掌心状态牌，只点按一次并做克制确认手势；第二人物提供独立状态通道；中性工作台、物理状态牌；<一次点按><短确认音>。
镜头4：返回原位完成机器证明；回到完全相同的机架构图，琥珀灯变绿，三根透明管从左到右依次充水；状态变化必须可见且顺序明确；清水折射、绿色确认光；<阀门开启><水流依次进入>。
镜头5：人物解释闭环；主管放开一只手并放松表情，绿色灯、三根满管和人物反应同时停留；人和机器共同完成结论；暖光稳定收束；<机架稳定运行><轻呼气>。
整体风格与画质：原创写实近未来温室广告，暖色自然光、两名明确成年工作人员、克制表演、真实透明管路、清楚的琥珀到绿色状态变化；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
