# 画内涂鸦｜现实互动逐步绘出隐藏世界

## 用途

用第一视角真实互动作为涂鸦触发器：每次手、宠物或物件完成一个可见动作，新的线描符号就锚定在对应现实表面；符号从单个提示升级为动作回声、隐藏对象和路线，最后整套图形连接成覆盖环境的可读世界。

## 推荐输入格式

`现实第一视角互动 + 首个画内线稿回应 + 连续表面路径 + 至少三类响应图形 + 真实空间与完整绘制世界同框`

## 可直接改写的简短示例

> 原创玻璃温室内，植物学家的手套触碰一枚露水阀，一只黄铜维修甲虫靠近；阀门玻璃外壳出现一枚青色叶片线稿并停留；路线分成三条叶脉支线，其中一条以小型三角指向标记对准关闭抽屉；植物学家只打开一次，同一青色叶脉沿金属门面铺开；叶片、土槽路线、抽屉叶脉和飞蛾与新出现的阀门、云、水线符号连接到玻璃肋架和地面沟槽；甲虫、手和真实结构全部可读

## 必须保留的结构锚点

- Establish one embodied observer, one responsive subject and the first surface-bound drawing triggered by visible interaction.
- Use a second real action to extend the drawing rule onto a different local surface or route.
- Reveal one new local figure or motif that visibly inherits an earlier line family.
- End on a wider view where prior symbols connect into one coherent environment-wide drawing layer.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
