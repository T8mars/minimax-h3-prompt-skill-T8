# 产品表面交替｜整体基线、微距材质与英雄复归

## 用途

先以完整产品和柔软承托面建立轮廓，再在同一角度交替展示中性建模态与成品材质；微距只验证镶嵌、倒角和反光，最后回到完整英雄构图，禁止随机改变结构。

## 推荐输入格式

`一个原创产品与固定背景、尺度和构图参照 + 至少两种可清楚区分且可逆切换的表面状态 + 每次状态切换都回到同一主体位置 + 一次能证明真实材质细节的微距检查 + 终局返回完整产品英雄画面并锁定指定表面状态`

## 可直接改写的简短示例

> 把一枚原创双六边形端头的开口胸针戒指置于午夜蓝天鹅绒褶皱上，以中性泥模材质呈现。；推进到双端头微距，清楚展示八颗透明宝石、浅镶口和一道狭窄中央开口。；拉回到原天鹅绒褶皱上的完整香槟金戒指，并保持一次干净英雄闪光。

## 必须保留的结构锚点

- One original product geometry and one support surface remain registered throughout.
- Material-state alternation changes finish only, never topology, stone count or proportions.
- Macro views verify countable construction details rather than adding new decoration.
- The terminal full-product frame restores the opening composition in the finished material.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
