# 阳影护肤品证据链｜封装、质地、取用、涂抹与结果

## 用途

用同一暖阳、叶影和手部身份把封闭包装、开盖内料、质地取样、皮肤涂抹和最终静物串成一条证明链；每段只回答一个产品问题，所有实物动作先于对应短文案，结尾回到未移动的完整包装与清楚功能层级。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 成年手在斜向工作室光中托住石墨玻璃罐，铜环、准确【ARC MEND】和【FILL THE LINE】清楚；钢刮刀只提取一道定量矿物膏，罐体仍在边缘；封闭 ARC MEND 与修复瓷砖同框，只显示【ARC MEND】和【FILL · LEVEL · CURE】

## 必须保留的结构锚点

- Establish one closed original product, one hand identity and one lighting signature.
- Open the same container and reveal untouched contents before manipulation.
- Transfer the measured amount to one application surface and show the complete spread.
- Return to the complete closed pack and add only concise text supported by prior stages.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
