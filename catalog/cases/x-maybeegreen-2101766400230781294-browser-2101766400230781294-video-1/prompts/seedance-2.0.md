# 巨构近触｜尺度远景与微动作回望 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创15秒巨型水钟修复短片：成年修复师从宏大空间走近齿轮微小细节，再回到完整装置的远景。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：极远景稳定展示整座水钟大厅和底部很小的成年修复师；她沿金属步道朝固定齿轮盒走去，少量琥珀色校准灯一开始就已点亮；完整装置、人物与目标齿轮盒处于同一空间，先建立尺度；暗青铜与稳定暖灯形成对比；<远处均匀滴水与脚步声>。
镜头2：切到脚底与手套的近景，保持前进方向；鞋底逐步落在格栅上，一只戴手套的手接近磨损齿轮；格栅和齿轮属于开场同一装置；同一琥珀灯光落在青铜表面；<鞋底轻踏格栅>。
镜头3：稳定特写对准一个刻线齿轮和手套指尖；修复师轻触并检查一处磨损齿，停住呼吸观察，不转动或弯折任何齿；保持齿轮、指尖与外壳接触关系；灯光不因触碰才突然点亮；铜纹与轻微旧痕清楚；<轻微手套擦过金属声>。
镜头4：返回和开场同方向的极远景；修复师仍在齿轮盒旁，显得很小；水钟仍是同一座，灯持续稳定发光；位置、装置体量和已经亮起的灯全都连续，不重置；保持暗青铜与琥珀暖光；<均匀滴水声延续>。
整体风格与画质：原创写实工业文物修复短片，不复刻白鹿或发光古树；广角尺度、鞋底与手部触觉、安静停顿、回到同一大空间的层次清楚。
约束：同一成年修复师、同一大厅、同一齿轮盒；人物不复制、不换脸；开场灯已亮，禁止把触碰说成原片已验证的点灯触发；无原片白鹿、森林或品牌文字。
```
