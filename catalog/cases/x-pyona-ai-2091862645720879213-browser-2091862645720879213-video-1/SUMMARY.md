# 弱势反攻清场｜贴地恢复、水盾承压到环形冲击

## 用途

先让明确成年主体处于多人包围的可读弱势，随后用贴地低扫争取站位、近身水盾承受一次冲击，再把同一水体升级为定向水炮与环形冲击；每一级都由前一级状态留下连续水迹，终局以对手倒地和主体平静站立证明清场。

## 推荐输入格式

`明确成年原创主体在非校园环境中面对可测量的环形弱势 + 先用一次贴地动作争取位置 + 紧凑护盾在近身命中下可见变形且双方清楚 + 同一残留介质依次改向为定向反击和贴地环形释放 + 终局主体稳居原中心、对手清楚停在外圈`

## 可直接改写的简短示例

> 原创地下勘测舱中，一名明确成年救援工程师站在标记圆内，四台故障巡检无人机从已标明方位逼近；无校园造型、尚无特效。；一台无人机完整承诺近身夹击；残留尘土升起为紧凑半透明护盾，接触点清楚凹陷，成年人和无人机都可见。；尘土落回标记圆；同一成年人平静站在中心，四台无人机停在圆外，不复制校园、制服、水特效、动作和文字。

## 必须保留的结构锚点

- Use clearly adult original characters in a non-school setting and establish a measurable center-versus-ring disadvantage.
- Begin recovery with one grounded positional action before any large ability.
- Reuse the same retained medium for the focused counter and radial release.
- End with opponents displaced outward and the same adult calm at the unchanged center.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
