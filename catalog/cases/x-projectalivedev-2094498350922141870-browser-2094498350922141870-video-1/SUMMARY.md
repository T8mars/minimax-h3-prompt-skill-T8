# 俯视战场双波打击｜密集基线、空投冲击与回程齐射

## 用途

在持续俯视的策略战场中先建立大规模单位、阵地和固定目标，再用第一波空中投放制造局部缺口；镜头保留同一地理关系，第二波飞行单位沿回程路线齐射并留下更大范围余波。

## 推荐输入格式

`一个可持续找回的发光目标 + 成年机动精确角色与成年重型控场角色 + 连续镜头内至少3次方向/遮挡/结果接力 + 至少1个工具效果从发出到命中 + 威胁由外圈压到近身再改变环境 + 双角色与目标状态同框收束`

## 可直接改写的简短示例

> 建立原创桌面风格海岸防御图，两支由成年指挥官控制的舰队、三座港口设施和一座中央雷达塔清楚可见。；雷达、港口和舰队位置保持注册，一支护航队穿过缺口，防守方转向应对。；最终冲击后停留同一俯视地理，受损雷达、幸存单位和持续烟幕通道均可读。

## 必须保留的结构锚点

- One continuous overhead geography establishes objective, formations and structures before attack.
- The first strike changes a local route or defensive state instead of functioning as decoration.
- A second, distinguishable route or weapon pattern revisits the same objective with greater coverage.
- The terminal hold preserves surviving units, damaged objective and persistent aftermath on the original map.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
