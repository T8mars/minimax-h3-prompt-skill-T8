# 表面生长｜沿既有几何扩散并回收到手作载体

## 用途

先让彩色线条沿真实载体既有几何生长，再扩散成图标或材质标记但不遮掉轮廓；同一线条族连接多个载体，最终回收到手作纪念物并物理关闭。

## 推荐输入格式

`真实载体 + 沿既有几何描线 + 同线条族跨载体 + 保留轮廓 + 手作纪念物闭合`

## 可直接改写的简短示例

> 铜色刺绣线先沿陶瓷原型接缝生长，再跨四件原型形成一致功能标记，最终装订成实体材质样本册并扣上锁扣。

## 必须保留的结构锚点

- Begin the mark by tracing existing carrier geometry.
- Spread marks while preserving the carrier silhouette.
- Change carrier while retaining the mark behavior.
- Collect the journey into a handmade keepsake and physically close it.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
