# 日常路线情绪释放｜居家准备、候车推进与海边兑现

## 用途

以同一成年人物和一件随身物建立身份，从室内准备推进到候车、乘车和抵达；路线空间逐步打开，最后让随身物参与情绪释放。

## 推荐输入格式

`稳定旅行者身份/服装/方向 + 至少4个地理章节 + 每章1次本地材质接触 + 窄巷近物→社会场→移动地理→攀升全景 + 统一档案介质 + 高位稳定终景`

## 可直接改写的简短示例

> 成年装订师在安静工作室系好钴蓝围巾。；人物乘电车前进，城市墙面逐渐让位于开阔河道。；清风扬起围巾末端，人物打开成品笔记本并停在平静抵达状态。

## 必须保留的结构锚点

- One adult identity and one carried object persist.
- Each location is a plausible next point on one route.
- The carried object remains visible across handoffs.
- The destination converts the object into an emotional release.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
