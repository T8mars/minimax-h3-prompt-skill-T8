# 第一视角查岗｜遮挡失效到摆烂收口

## 用途

第一人称身体运动连续推进，遮挡每失败一次就暴露更深证据，最后以人物停止遮挡并后仰回到桌前状态收口。

## 推荐输入格式

`第一人称观察者 + 固定工作区 + 至少2次遮挡失败 + 物证到面部交接 + 停止遮挡的结尾`

## 可直接改写的简短示例

> 第一人称温室查验：学徒先用记录板遮住发光托盘，盖板又推出报警传感器；镜头从物证抬到脸，学徒停止遮挡并平静浇水。

## 必须保留的结构锚点

- Use one continuous embodied first-person observer whose height and distance changes come from physical movement.
- Require at least two concealment attempts that each expose a deeper contradiction.
- Hand off from object proof to a sustained facial or bodily reaction.
- End with a visible behavior change rather than a third reveal.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
