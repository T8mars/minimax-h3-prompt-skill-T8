# 尺度球局｜共享球体串联反差挑战

## 用途

用一个持续可见的球体把尺度反差对手、固定目标和动作阶段串在同一场地：控球建立规则、巨体封锁空间、小体型改变路线、抛物线把挑战推向目标，最后以双方可见反应收束但不臆测得分。

## 推荐输入格式

`两种明显尺度 + 共享球体或令牌 + 固定目标 + 可见变线 + 单一轨迹 + 不虚构结果的反应终态`

## 可直接改写的简短示例

> 硬币大小的配送机器人控制发光珠，巨型充气守门体封锁桌面通道；机器人变线并把珠子抛向悬空铜环，结尾保持双方和目标同框，不在未确认时宣称成功。

## 必须保留的结构锚点

- Establish two clearly different scales, one shared token and one fixed target in the same arena.
- Use repeated token control to prove who currently owns the action.
- Show one readable token trajectory toward the fixed target.
- End on a visible shared reaction state and only claim success if the target result is directly shown.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
