# 输入—屏幕—结果—反应｜实体操作与虚拟反馈逐拍闭环

## 用途

先建立成年玩家、实体控制器和屏幕同框关系；每个虚拟动作前必须先看见一次具体输入，屏幕反馈随后发生，玩家再给出清楚可辨的人物反应。用选角、移动、反击和胜负四级闭环升级，终局只确认结果与人物，不补写来源中未出现的再开一局。

## 推荐输入格式

`明确成年原创操作者、实体输入设备和响应屏幕或机器同一地理先建立 + 每个重要虚拟或机械事件前先展示一个具体物理输入 + 至少三组不同输入—响应对应且输出不得提前 + 从选择、导航或防御升级到一个决定性结果 + 终局把结果重新连接到同一成年人物的清楚可辨的人物反应`

## 可直接改写的简短示例

> 原创夜间温室控制室内，一名明确成年技术员、触觉控制台和展示三条种植区的玻璃墙同框建立。；依次展示三组不同对应：拉杆向下后通风口关闭，摇杆向左后机械臂左摇，按下带护罩按钮后授粉扫描器下降；绝不让输出先于输入。；回到同一成年人松开控制器并克制地舒一口气，绿色通道仍可见；不复制来源街机、游戏、机柜、角色与品牌。

## 必须保留的结构锚点

- Establish one clearly adult operator, physical controls and response display together.
- Show each important physical input before its matching virtual response.
- Escalate from setup and navigation to one decisive result state.
- End by reconnecting the result to the same adult's readable reaction.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
