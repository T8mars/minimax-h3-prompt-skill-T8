# 美容功效证据变体｜成年用户基线、取量、使用、触感与持瓶回扣

## 用途

同一明确成年用户先展示问题基线和产品，再用可见取量、单次使用、触感与动作结果逐级证明功效；最后回到同一脸、同一产品和稳定结果，避免只靠口播。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 原创窗光下，一名明确成年皮革工匠与一只干燥开裂棕色工作靴、一个无标签磨砂护理瓶同时出现；脸、靴子和光线方向稳定。；不做跳切重置，她用保留的同一剂量连续三次擦过靴子左侧鞋头和侧片。；回到同一成年人持同一护理瓶站在靴子旁，处理区与未处理区同框可读；无标志、宣称和额外文字并停住。

## 必须保留的结构锚点

- Establish one clearly adult original user, one label-free product and a visible pre-use state in the same light.
- Show a measured dose leaving the same product and arriving on a visible hand or tool.
- Prove the result through touch, movement and consistent lighting rather than a disconnected beauty cut.
- Return the same adult, product and treated state in one stable closing frame.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
