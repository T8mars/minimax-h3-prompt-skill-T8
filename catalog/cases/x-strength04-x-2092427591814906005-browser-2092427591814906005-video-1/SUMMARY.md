# 蓄能清场回稳｜手部微光、通道突进与人物复位

## 用途

在拥挤通道中先用手部微光提示准备，再让每次能量爆发绑定一个清楚身体动作；逐步扩大清场尺度后，人物回到正面步行基线。

## 推荐输入格式

`明确成年原创主体、可读对手和稳定地面关系先建立 + 每次先完整承诺物理轨迹并真实接触 + 能量、尘屑、毛发、布料或灯光只在接触后局部短促响应 + 通过对手数量和反馈半径升级但轮廓始终清楚 + 终局效果归零并在同一空间稳定持有主体`

## 可直接改写的简短示例

> 成年夜班技术员正面穿过拥挤维护通道。；低位支撑与肩部接触触发第一次短磁脉冲。；障碍清除后，同一人物恢复原正面步行，青光完全消退。

## 必须保留的结构锚点

- The baseline walk and crowd geography are established first.
- A small hand signal previews the capability.
- Escalation moves along one corridor direction.
- The final state returns to the original walk with no residual glow.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
