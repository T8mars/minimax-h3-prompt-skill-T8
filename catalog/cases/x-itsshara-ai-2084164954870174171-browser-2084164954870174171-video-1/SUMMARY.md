# 服务改造｜私域工序到公开身份回归

## 用途

让角色以明确的不合身或受损状态进入一个专业服务空间，由服务者通过可见测量、工具接触和阶段性工序完成改造；必须保留一次合身确认和角色主动整理，最后回到公开空间，以步态和他人反应证明功能与身份同时改变。

## 推荐输入格式

`成年客户的可见缺陷基线 + 专业服务空间与服务者 + 评估和至少2种可见工具或手工介入 + 身份与身体注册连续的分阶段改造 + 专业验收和客户主动调整 + 公开空间功能与旁观反应证明`

## 可直接改写的简短示例

> 成年骑手穿雨裂下坠背带进入，成年技师面对检查，密封测试载荷明显拖低肩线；在保持骑手身份、比例、站姿和载荷连续的前提下，分阶段装上银色反光肩带、加固缝线和黑色扣具；骑手挺直稳定骑行，载荷不再摇摆，另一名成年骑手只点头认可一次

## 必须保留的结构锚点

- Establish an adult client's visible baseline problem inside or immediately before a professional service space.
- Show specialist assessment plus at least two visible tools or manual interventions.
- Include professional fit verification and one self-directed client adjustment.
- Return to a public context where posture, movement and at least one observer response register the change.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
