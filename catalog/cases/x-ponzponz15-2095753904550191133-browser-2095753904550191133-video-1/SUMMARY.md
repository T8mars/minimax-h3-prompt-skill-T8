# 海报空间重组｜人物层、对话块与品牌页回环

## 用途

保持同一竖版海报的文字区、人物和红蓝对话块，让人物从平面层获得轻微空间关系；一个对话块前移承担信息转场，随后全部元素归回版式并收束到品牌色页。

## 推荐输入格式

`紧凑图标 + 稳定角色/配色 + 密度递增模块 + 孤立状态停顿 + 几何锁定`

## 可直接改写的简短示例

> 建立原创竖版海报【MAKE TOGETHER】，包含四名成年创作者和珊瑚红、蓝色对话块。；让蓝色对话块向前移动直至铺满画面，并显示准确短句【BUILD ONE MORE】。；让一枚珊瑚色对话形状擦屏，进入带准确标志【MAKEROOM】的珊瑚蓝渐变尾卡。

## 必须保留的结构锚点

- One persistent poster grid defines every element's home position.
- All human figures are clearly adult and remain tied to their original graphic blocks.
- The complete poster must visibly reconstruct before the end card.
- Exact original title and logo remain readable and are not inferred from source text.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
