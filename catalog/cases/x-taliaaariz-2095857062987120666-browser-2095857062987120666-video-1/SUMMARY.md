# 户外肖像微表情｜正面微笑、举花回应与侧望回稳

## 用途

固定同一湖岸人物、花束和中景构图，只用呼吸、一次举花、一次眨眼和缓慢侧望构成微表情弧；背景水光与丝带提供轻微环境响应，禁止突然换姿或换人。

## 推荐输入格式

`单一人像 + 侧身开始 + 稳定直视 + 垂眼停顿 + 1次峰值表情 + 开放表情回稳`

## 可直接改写的简短示例

> 用稳定竖版中景拍摄原创成年陶艺师：浅蓝连衣裙，手持纸花束，站在银色湖边。；空手抬起一次，轻触脸旁的一片纸花瓣，再放回花束。；以克制的四分之三侧面收束，花束居中，原始山水线保持不变。

## 必须保留的结构锚点

- One clearly adult identity, wardrobe, bouquet and camera position remain fixed.
- Only small facial, hand, breathing and head actions drive the performance.
- Environmental motion remains secondary and physically gentle.
- The final profile preserves the same subject, prop and landscape composition.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
