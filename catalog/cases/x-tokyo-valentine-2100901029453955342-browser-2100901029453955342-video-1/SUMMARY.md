# 不可能任务改解｜受阻尝试、整体抬起与见证反应

## 用途

先建立物件与底座不可分的挑战规则，角色完成一次失败尝试；随后不改变规则而改用整体抬起的解决方式，独立见证者用近景反应确认反差。

## 推荐输入格式

`固定挑战物＋失败尝试＋整体解法＋见证反应`

## 可直接改写的简短示例

> 两名成年工坊对手、锁入陶瓷底座的黄铜杠杆、一次整体举起。

## 必须保留的结构锚点

- 物件与底座始终不分离
- 常规方法先明确失败
- 见证者确认反常解法

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
