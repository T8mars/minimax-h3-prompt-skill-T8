# 计划对照｜固定分镜条见证材质制作链

## 用途

让静态分镜条在下方持续可读，上方执行区严格按计划顺序推进原料处理、材质变化、成型、切开和终态；每一步都在同一布局中留下可比结果，最后用成品特写和计划末项闭合。作为既有固定计划条模板的新证据，不新增选择器。

## 推荐输入格式

`持续可读的计划板 + 独立执行区 + 计划顺序推进 + 至少三项可见状态变化 + 计划与终态同框`

## 可直接改写的简短示例

> 下方五分之一完整显示五格无文字图标计划条，上方执行区建立原创白陶瓷根系舱、钴蓝凝胶瓶和苔藓托盘；窄铜加热器只沿接缝通过一次完成热封，同一根系舱随后翻入苔藓托盘，封线和凝胶仍可追踪；成品根系舱、封线、钴蓝凝胶和苔藓托盘与下方未变化的最后一格图标同时可见

## 必须保留的结构锚点

- Establish one complete static plan strip and a separate live execution field at the opening.
- Keep the plan strip unchanged and readable while every live state advances in its order.
- Reserve one decisive reveal that verifies an internal or completed property.
- End with the finished result and the unchanged terminal plan cell visible together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
