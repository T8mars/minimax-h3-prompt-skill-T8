# 拉面状态链变体｜原料、切配、汤锅、沥水、装碗与品尝连续证明

## 用途

同一明确成年原创厨师和同一厨房中，原料经过切配、入锅、试味、煮面、沥水和装碗不可逆推进；每一步保留上一状态痕迹，最终以完整成品和成年人品尝证明闭环。

## 推荐输入格式

`一名明确成年原创操作者、固定空间、主材料组、主要容器与手部或工具锚点先建立 + 至少五个不可逆状态且每镜只执行一次清楚操作 + 上一状态的残留、形状、颜色、蒸汽或容器连续成为下一步输入 + 不得回到已消失的早期状态并保持数量合理 + 同一成品由同一成年人完成一次克制使用或品尝证明`

## 可直接改写的简短示例

> 原创阳光海岸厨房内，一名明确成年女厨师穿深蓝围裙；同框建立一个空蓝碗、生荞麦面、切片蘑菇、海藻、汤底和一枚鸡蛋，各工位可读。；同一成年人只试味一次正在煨煮的汤，同时同一荞麦面在右锅变软；两口锅位置和空蓝碗保持。；她把汤倒在面上，加入保留的蘑菇、海藻和鸡蛋，再夹起一口并展示完整面碗；同一成年人、厨房和成品停住，不加品牌文字。

## 必须保留的结构锚点

- Establish one clearly adult original cook, one kitchen, one ingredient inventory and empty serving vessel.
- Show each irreversible material change through visible tool contact and retained ingredients.
- Drain and transfer the same cooked noodles into the previously established vessel without reset.
- Add retained toppings and end with the same adult presenting or tasting the complete dish.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
