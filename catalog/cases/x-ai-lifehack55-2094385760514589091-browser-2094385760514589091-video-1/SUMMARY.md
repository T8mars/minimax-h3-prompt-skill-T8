# 黑白红动作字场｜身份锁定、短词碰撞与角色回标

## 用途

锁定同一成年动画角色，用滑行、俯冲、踢击和落地逐拍触发黑白红短词、网格与圆环；每个字效都回应可见动作，终局回到人物和主标题。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 锁定原创成年动画单车递送员：银发、琥珀眼、海军蓝夹克和珊瑚红长裤，置于象牙色标题网格。；一次脚跟转向触发珊瑚圆环，一次受控跳跃把圆环拆成三个标有【TURN】的斜向面板。；圆环复原，人物回到象牙海报框，准确标题【NIGHT LINE】停留。

## 必须保留的结构锚点

- One adult character identity anchors every graphic module.
- Each bounded body action visibly precedes one typography response.
- Detail shots reconnect to the complete character before the next module.
- The final lockup reunites character, palette, graphic motif and one exact title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
