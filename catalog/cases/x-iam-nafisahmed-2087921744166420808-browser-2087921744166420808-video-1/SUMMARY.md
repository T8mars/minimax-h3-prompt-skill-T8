# 未来来信｜私密警告被外部世界兑现

## 用途

用一个私密记录装置先给出来自未来自身的警告，再让主体主动转向可核查的外部窗口；先以熟悉城市的异常版本证明时间错位，最后让更大天空证据出现，使警告从信息升级为现实威胁。

## 推荐输入格式

`当下主体 + 未来自身消息 + 主动外部验证 + 局部未来环境 + 更大尺度威胁`

## 可直接改写的简短示例

> 原创极地观测站内，年轻制图师打开一只霜封圆筒，筒身日期比当前晚八十年，手套和地图桌清楚可见；年轻制图师离开地图桌，走向唯一一道观测穹顶狭缝，桌、圆筒和狭缝保持连续；研究塔建立后，巨大的黑色环影横过极光，画面同时保留制图师、狭缝、塔群与环影，不解释也不攻击

## 必须保留的结构锚点

- Establish one private proof record with a visibly impossible future origin.
- Bind the record to a future version or unmistakable continuation of the present subject.
- First reveal a familiar environment in a clearly altered future state.
- Introduce one larger external anomaly only after the environment confirms the time shift, and end unresolved.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
