# 天体事件改写路线｜新光源、障碍生成与航向适配

## 用途

用一个可见天体事件改变既有空间条件，让障碍和路线从同一事件连续生成；载具与镜头保留方向，最终以成功穿越证明适配。

## 推荐输入格式

`连续移动主体 + 原世界基线 + 单次全局换材 + 方向速度不断线 + 新世界终点`

## 可直接改写的简短示例

> 原创勘测滑翔器在单一淡月下穿过平静高层大气。；弯折云带凝结成一串旋转冰环，横跨原有前进路线。；滑翔器离开最后冰环进入开阔天空，两个极光核心与改写后的云路仍可见。

## 必须保留的结构锚点

- One route and carrier exist before the world event.
- A visible global event changes the route conditions.
- Carrier direction and recurring landmarks preserve geography.
- The exit proves adaptation while the changed world persists.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
