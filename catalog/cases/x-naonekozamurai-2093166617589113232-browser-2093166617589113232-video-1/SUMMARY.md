# 单图产品扩展｜完整鞋先现、材质爆拆与英雄复归

## 用途

先显示完整产品作为注册基线，再把鞋底、鞋面、系带和轮廓拆成独立证明章节；所有组件保持同一黑格坐标，最后重新组成完整产品英雄镜头。

## 推荐输入格式

`第0帧完整原创构造物先出现 + 第一秒完成唯一最大速度爆拆且组件顺序不变 + 各主要组件分别获得一种较慢且不同的材料或制造语法 + 至少两章之间短暂回到完整成品刷新装配记忆 + 组件逐步符号化并重组为原创身份标记而非简单恢复开场产品`

## 可直接改写的简短示例

> 黑色坐标网格先显示一只完整原创炭灰荧光绿攀岩手套。；细荧光绿线沿每个组件边界追踪。；所有证明回到完整双手套英雄构图，无文字停留。

## 必须保留的结构锚点

- The complete product appears before decomposition.
- Every macro remains registered to the baseline grid.
- Duplication creates a controlled product pair.
- All components return to a complete hero composition.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
