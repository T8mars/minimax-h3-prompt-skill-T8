# 动画快炒状态链｜抛料、火焰、翻锅与食客见证

## 用途

让同一成年厨师、同一口锅和同一批可辨食材贯穿全片：抛料形成钩子，火焰与翻锅完成不可逆烹饪，食客反应验证过程，最后盛入一只固定碗完成成品证明。

## 推荐输入格式

`一名明确成年原创操作者、固定空间、主材料组、主要容器与手部或工具锚点先建立 + 至少五个不可逆状态且每镜只执行一次清楚操作 + 上一状态的残留、形状、颜色、蒸汽或容器连续成为下一步输入 + 不得回到已消失的早期状态并保持数量合理 + 同一成品由同一成年人完成一次克制使用或品尝证明`

## 可直接改写的简短示例

> 原创成年夜市厨师把蘑菇、彩椒和豆腐抛到同一口黑钢炒锅上方。；用两次连续翻锅和一次锅铲横扫，把哑光生食材转成有光泽的熟制混合物。；把完整菜品倒入一只蓝纹碗，并保持一秒清晰俯拍英雄镜头。

## 必须保留的结构锚点

- One adult cook, one wok and one ingredient set persist through the entire state chain.
- Raw, heated, mixed and plated states remain visually distinguishable and irreversible.
- Crowd reaction occurs in the same stall and witnesses the real preparation.
- The terminal bowl contains the same cooked ingredients and receives a stable proof shot.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
