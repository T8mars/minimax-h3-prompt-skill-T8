# 困倦晨间复位｜打哈欠、刷牙失误与毛巾清醒

## 用途

固定手机机位记录一个可读晨间任务：困倦基线、挤牙膏失误、短暂自我整理、毛巾擦脸和状态复位，人物身份与浴室位置不变。

## 推荐输入格式

`一名明确成年原创主体以至少三项身份锚点先完成一个普通触觉任务 + 用一个真实前景物、门框或建筑边缘过渡到独立休息地理 + 准确展示一次慢呼吸和至少两项头发、服装、植物或光线微响应 + 呼吸期间摄影只做克制慢推或静止 + 同一成年人复位后沿既定方向穿过可见出口`

## 可直接改写的简短示例

> 一名困倦成年灯塔管理员站在固定工具间镜头前，手持工作手套。；她揉眼并扎起散发，手套仍放在长凳上。；她放下围巾、戴好手套，朝不变镜头清醒点头。

## 必须保留的结构锚点

- One person, camera and room remain fixed.
- A small task error proves fatigue.
- One foreground cloth transition is task-motivated.
- The final state change is shown by action and expression.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
