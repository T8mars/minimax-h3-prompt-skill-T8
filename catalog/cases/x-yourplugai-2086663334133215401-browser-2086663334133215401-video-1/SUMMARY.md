# 饮品感官跃迁｜搅拌基线、吸饮触发与包装回归

## 用途

同一杯饮品先在现实环境被搅拌和吸饮，吸管动作触发背景跃迁；人物体验后返回干净棚拍，并用完整杯身和短句完成产品回归。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 成年天文馆向导在安静大厅搅拌原创紫色柑橘饮品。；吸饮期间只把背景变成缓慢星图穹顶和漂浮柑橘球。；重置到浅色摄影棚，完整原创杯放在黑玻璃台上，准确短句【TASTE THE NIGHT】停留。

## 必须保留的结构锚点

- One person and one cup remain registered.
- A visible sip triggers the state change.
- Reaction follows the completed sensory action.
- The clean studio return restores the full package.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
