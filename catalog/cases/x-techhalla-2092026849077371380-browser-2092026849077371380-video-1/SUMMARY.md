# 车库写实格斗｜工具接触、车辆遮挡与近身反制

## 用途

先以写实伤势、工具与停车位建立实体冲突，再让车辆、烟雾和近身遮挡承担转场；每次反击都从清楚接触开始，终局以短促异常材质作为结果反馈。

## 推荐输入格式

`明确成年原创主体、可读对手和稳定地面关系先建立 + 每次先完整承诺物理轨迹并真实接触 + 能量、尘屑、毛发、布料或灯光只在接触后局部短促响应 + 通过对手数量和反馈半径升级但轮廓始终清楚 + 终局效果归零并在同一空间稳定持有主体`

## 可直接改写的简短示例

> 成年打捞工站在叉车旁，握一只重型钩具并显出疲态。；双方回到同一条标线通道，完成一次落地踢击与格挡。；最终手套接触只释放短促磁性铁屑，随后回到真实身体姿态。

## 必须保留的结构锚点

- Physical injury, tools and geography read before stylization.
- Vehicle occlusion motivates the location change.
- One tool struggle proves leverage at close range.
- The abnormal effect is brief feedback after contact, not a substitute for action.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
