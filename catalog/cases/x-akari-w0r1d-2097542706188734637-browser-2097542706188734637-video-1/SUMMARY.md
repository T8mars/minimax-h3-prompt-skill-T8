# 蛋料理工序链｜切分、混合、回填与摆盘证明

## 用途

以同一位原创成年动画厨师、同一砧板和同一批熟鸡蛋建立工序连续性；切开、取黄、混合、裱花回填和撒料均不可逆，最后用整盘成品证明全部步骤。

## 推荐输入格式

`固定处理表面 + 多工具单一职责 + 层层累积 + 单次揭除 + 两种独立验收`

## 可直接改写的简短示例

> 一名原创且明确成年的动画厨师在同一块蓝色砧板上切开六枚熟鸡蛋。；加入一勺香草酱，搅拌至蛋黄变成均匀馅料。；依次撒一次红色与绿色配料，再拉宽证明同一托盘上十二份成品。

## 必须保留的结构锚点

- One clearly adult cook and one ingredient batch persist.
- Every state change is visible and irreversible.
- Counts remain consistent from halves to tray.
- The final tray proves completion.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
