# 庭院喂狗微任务｜进食基线、等待观察与轻触收束

## 用途

在固定低机位中保持同一成年照料者、狗、食盆和庭院位置，先完整记录进食，再让人物等待、观察并做一次轻柔接触；取走空碗后，狗留在原位完成安静终态。

## 推荐输入格式

`一名明确成年原创主体以至少三项身份锚点先完成一个普通触觉任务 + 用一个真实前景物、门框或建筑边缘过渡到独立休息地理 + 准确展示一次慢呼吸和至少两项头发、服装、植物或光线微响应 + 呼吸期间摄影只做克制慢推或静止 + 同一成年人复位后沿既定方向穿过可见出口`

## 可直接改写的简短示例

> 固定低位广角记录成年夜班面包师、年长店犬和安静装卸院中的一个蓝色水碗。；狗、水碗、院门和人物跪姿保持连续，不切镜也不重置机位。；人物带碗离开，最后停留同一条狗在院门旁安静休息。

## 必须保留的结构锚点

- One adult caregiver, one animal, one vessel and one fixed place remain continuous.
- The animal's bounded eating or drinking task reaches a visible completion state.
- One gentle contact follows completion and precedes cleanup.
- The final quiet state separates removed vessel from the resting animal and proves closure.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
