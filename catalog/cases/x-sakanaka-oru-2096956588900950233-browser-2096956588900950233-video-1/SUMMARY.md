# 浮游伙伴环绕｜人物立姿锚点、肩侧穿行与近身回应

## 用途

固定同一成年动漫人物、粉发耳机、青色外套和白色棚景，让黑色青尾伙伴从肩后出现、绕过胸前和手臂、贴近脸侧，再回到人物身后；人物只用眼神、眨眼和小幅手势回应。

## 推荐输入格式

`一名明确成年原创主表演者和一个原创微型伙伴 + 固定舞台与连续尺度参照 + 主体手势先发生、微型伙伴沿可追踪路线回应 + 一次完整环绕与手掌或近身落点 + 终局同框同时证明两种尺度、两个身份和共同姿态`

## 可直接改写的简短示例

> 建立一名原创成年动画声音勘探员：玫瑰色头发、圆形耳机、青色外套和方形野外背包。；让伙伴绕过胸前移向右前臂，勘探员双脚保持落地。；让伙伴从右肩后方离开，恢复开场全身构图，并保留一次柔和微笑。

## 必须保留的结构锚点

- One clearly adult character and all identity anchors persist.
- One companion follows a complete traceable orbit.
- Character reactions remain small and temporally follow proximity.
- The terminal full-body frame restores the opening spatial balance.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
