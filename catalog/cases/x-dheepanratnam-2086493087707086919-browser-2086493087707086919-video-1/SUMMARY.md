# 升级讽刺｜新物登场旧爱被移走

先建立对旧物的真诚依恋，再让升级与移走同时发生；群体把掌声转向新物，最后用完全认真的制度化终态保留未解决的反差。

## 核心机制

First make an existing object feel sincerely valued, then bind one restrained subject to it through a specific physical attachment. Introduce the upgrade and remove the valued object in the same spatial event so progress and loss are inseparable. Redirect the surrounding group's genuine enthusiasm to the replacement while the attached subject remains visible but unattended. Finish with completely earnest institutional closure, preserving the unresolved attachment so the satire comes from the image logic rather than a wink or joke.

## 推荐输入格式

`被珍爱的旧物 + 一个具体依恋动作 + 新旧同时进出 + 群体掌声转移 + 真诚但不解决依恋的终态`

## 简短示例

> 纸艺温室里，毛毡园丁珍爱旧雨量计，折纸知更鸟在底座筑巢；自动气象塔进入时旧雨量计同时被推出，知更鸟仍随旧物离场，园丁真诚鼓掌，最后停在无文字的太阳徽记终态。

## 必须保留的结构锚点

- 先证明旧物被真诚珍爱
- 用一个具体身体动作锁定依恋
- 新物进入与旧物移走必须同镜同时发生
- 群体掌声转向新物且不回应被移走者
- 结尾保持制度化真诚并保留未解决依恋
