# 不可见边界验真｜碰撞、手测与改道离开

## 用途

先用一条视觉上完全畅通的路线建立通行预期，再让明确成年角色在同一轴线上遭遇一次不可见阻断；必须完整显示接近、接触和身体回弹。角色先检查受影响部位，再回到碰撞点以手掌进行一次受控测试，让边界通过触感与涟漪证据显形；结尾角色明确改道离开，边界仍留在原路径。

## 推荐输入格式

`明确成年原创角色、看似可通行路线与稳定轴线先建立 + 只发生一次不可见接触且连续显示接近、接触与回弹 + 角色先检查受影响部位 + 回到准确接触点做一次受控手掌复测 + 只在接触周围用冷凝、粒子或涟漪局部显出透明平面 + 证据触发明确改道且边界保持固定`

## 可直接改写的简短示例

> 成年维修工程师位于看似完全空旷的洁净室中央路线，侧通道与地面导轨可见；工程师摸左肩并观察同一空处，姿态从惊讶回到判断；工程师收手、夹上琥珀改道标记并进入侧通道，结尾同时保留膜位置和新路线

## 必须保留的结构锚点

- Establish one clearly adult original traveler, a simple route and a stable axis that visibly predicts free passage.
- Use exactly one uninterrupted unseen contact and preserve approach, contact and bodily recoil.
- Return to the same location for one controlled palm test and localize the boundary response around contact.
- End on a clear rerouting decision while the confirmed boundary stays fixed in the original path.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
