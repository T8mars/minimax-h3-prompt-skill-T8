# 平面物件落地｜打断表演与收拾恢复 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创十秒纸偶小剧场：成年表演者触动平面圆点，圆点落成实体，她收拾后恢复表演。
总时长约10秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：固定正面中景，人物、板和地面同框；成年表演者轻巧操纵纸偶，六个圆点平贴板上；同一人、同一板，圆点起初固定；柔和室内光、米白和素蓝；<轻纸张声>。
镜头2：不切镜，手、板和落地位置同框；她挥手划过板面，六个圆点依次变厚脱离，各自落成小圆片；先挥手后掉落，每片有落地接触；同一室内光；<六次轻小碰地声>。
镜头3：轻微下俯仍看见同一人和板；她停住、惊讶、蹲下，将六片收进浅托盘；人物和圆片位置连续；同一色温；<托盘轻响>。
镜头4：回原正面中景；她站起来恢复起初的纸偶动作并微笑，圆片都留在托盘；板上空槽不自动复原；米白与素蓝持续；<纸偶轻响>。
整体风格与画质：原创现实纸偶剧场，不复制桌面；二维到实体的因果清楚，六片逐个落地，身份和空间连续。
约束：只用无品牌几何圆点，无系统或应用图标；同一成年表演者全片一致；收拾与恢复表演在镜头内完成。
```
