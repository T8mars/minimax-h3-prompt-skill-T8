# 遗迹战士预告｜步行基线、武器苏醒与远景使命落版

## 用途

同一成年原创战士以脚步、服饰纹章和弯刀保持身份；壁画剪影补充过往，手触刀柄后刃口只亮一次，随后人物走向远景遗迹并以原创片名收束。

## 推荐输入格式

`固定主角与关系锚点 + 公共世界扩展 + 私人脆弱阶段 + 物理危险升级 + 独立原创片名终卡`

## 可直接改写的简短示例

> 跟随一名明确成年的沙漠档案师的靴子踏过阳光下玄武岩尘土。；门外显出山谷档案遗迹，她的手停在一把弯曲野外刀上方。；让她走向山谷，并在地平线落下准确原创片名【ASH ARCHIVE】。

## 必须保留的结构锚点

- One clearly adult original protagonist remains continuous.
- Three identity anchors recur across detail and wide shots.
- Scale expands from body evidence to destination.
- Only original title, costume and mythology are used.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
