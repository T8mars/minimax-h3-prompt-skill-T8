# 能量物越界再稳定｜室内激活、环境替换与原位回收

## 用途

让一个手持能量物先在封闭空间积累状态，越界时由同一物体把环境改写为开放世界；人物与道具保持连续，最后返回原位并稳定。

## 推荐输入格式

`连续真实环境 + 可见选择工具 + 至少三次局部对象改写 + 原位空间配准 + 一次整片环境改写`

## 可直接改写的简短示例

> 成年档案修复师坐在地下室桌前，手持一枚掌心大小的琥珀地图石。；同一人物和地图石进入由等高线光绘出的广阔盐原路线。；回到原地下室桌面，石头熄灭，一条琥珀线安全留在纸质地图上。

## 必须保留的结构锚点

- One bounded object establishes the initial state.
- Its visible activation precedes the environment rewrite.
- Containment reverses the expansion through a visible action.
- The origin returns with one controlled residue proving change.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
