# 空街回望追逐｜孤立基线、远端人影与巷道逼近

## 用途

同一成年人物先在空街反复回望建立寂静异常，远处人影从单个增加为群体并开始接近；人物确认威胁后沿狭窄巷道逃跑，追逐者在背景持续缩短距离。

## 推荐输入格式

`明确成年原创主体和一个小型可重复前景任务先建立 + 背景危险至少经过三档接近等级升级且方向可读 + 每次危险后双手与视线都回到同一任务物 + 早期只做最小避让并把最大身体位移保留给一次近接峰值 + 危险过去后重新执行原任务而非庆祝或击败威胁`

## 可直接改写的简短示例

> 成年勘测员穿黄色夹克站在空旷雾港，反复检查身后寂静水面。；堆放货箱旁再出现两个人影，勘测员转身并确认三者。；到达锁住的网门时，追逐距离继续缩短，不切走也不凭空出现救援。

## 必须保留的结构锚点

- An empty baseline and one repeated backward check establish the unresolved threat question.
- The first distant figure appears on the already established background axis.
- The escape route preserves pursuers in the same background geography.
- The terminal obstacle converts pursuit into a measurable unresolved distance without false resolution.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
