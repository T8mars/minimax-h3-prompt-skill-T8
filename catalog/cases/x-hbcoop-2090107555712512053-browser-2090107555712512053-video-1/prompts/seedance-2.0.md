任务：制作原创15秒观测站主标题片头。俯拍象牙色地形等高线，在三线交点放置一个琥珀测量点。钢制制图笔沿一条等高线移动并揭示原创短职员表 CREATED BY LENA ORR。让相同交点在精确屏幕坐标匹配成深色穿孔吸声墙，一束窄光扫过并揭示第二条原创职员表 STARRING NOA VENN。回到俯拍，一枚原创黄铜音叉位于琥珀陶瓷圆盘中心。两只手套只把圆盘掰开一次，琥珀陶瓷纹理铺满画面，大型原创主标题 NORTH ARRAY 清楚显现并稳定停留。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：平面注册与第一职员表；俯拍象牙等高线，三个稳定交点和琥珀测量点先清楚出现；钢制制图笔沿线揭示原创文字 CREATED BY LENA ORR；工具、文字和注册几何保持同框；象牙纸面、黑线、单点琥珀；<笔尖划过><纸面轻响>。
镜头2：精确匹配到实体面板；保持地图末帧，在同一屏幕坐标把等高线交点匹配成深色穿孔吸声墙；窄光扫出原创文字 STARRING NOA VENN；交点位置不能漂移，材质必须明显改变；深灰实体墙、克制白字；<低频空间鸣><光扫掠过>。
镜头3：颜色锚点接收主题物；回到俯拍浅色注册面，一枚原创黄铜音叉位于同一琥珀圆形锚点中心；音叉和圆形先完整可读；黄铜与琥珀陶瓷；<黄铜轻振><陶瓷低响>。
镜头4：一次实体开裂；琥珀圆形变成包围音叉的陶瓷盘，两只中性手套对称进入，只把圆盘掰开一次，音叉保持中心；不得第二次破裂或替换主题物；陶瓷裂纹清楚、无碎片飞溅；<陶瓷开裂><短暂停顿>。
镜头5：材质铺满并锁定主标题；琥珀陶瓷纹理铺满画面并平整成标题底，大型原创文字 NORTH ARRAY 清楚显现并稳定停留；标题出现后不得再发生事件；琥珀底、象牙白字、高字距；<低音收束><完全停留>。
整体风格与画质：原创可触现代主义片头设计，象牙等高线纸面、深色吸声建筑、克制琥珀锚点、精确注册匹配剪接、微距材质和高度可读原创排版；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
