# 候车纸片线索｜飘落、拾取、细看与照片回标

## 用途

在同一候车站台锁定一名成年旅客和一张白色纸片；纸片先独立飘落到长椅，人物注意、拾取并连续靠近检查，最后以纸上人物照片和她的迟疑表情共同收束。

## 推荐输入格式

`紧急干预 + 隐藏风险 + 可视证据 + 有动机镜头交接 + 简短反应`

## 可直接改写的简短示例

> 让一名原创成年制图师在渡轮旁等候，一张折叠路线卡被风吹向长椅。；她走两步，只拿起同一张路线卡一次，渡轮保持在身后。；揭示卡片上的一幅褪色灯塔图，再回到她克制的疑惑表情，卡片与渡轮保持注册。

## 必须保留的结构锚点

- One clearly adult subject, one paper object and one station remain continuous.
- The object lands before attention and attention precedes pickup.
- Inspection preserves object identity and spatial orientation.
- The final reaction is supported by a readable object detail.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
