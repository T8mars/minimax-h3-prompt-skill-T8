# 微缩队伍餐桌任务｜环境巨物、绳索协作与人手中断

## 用途

以餐桌常物建立巨大尺度，三名成年微缩队员从地图规划、绳索滑行、攀爬吸管到捆绑薯条依次协作；真实人手只在终局进入一次，打断他们的成果并证明尺度关系。

## 推荐输入格式

`静态标准物开场校准 + 微型日常 + 校准物保持不动 + 不同外部执行物只进入一次 + 局部状态改变与反应同框`

## 可直接改写的简短示例

> 三名原创微缩成年维修员在咖啡馆桌面、巨大玻璃胡椒研磨器旁研究蓝图。；三人依次攀爬一根红色吸管，每一步都保持手和靴子的可见接触。；一只正常尺度的成年人手只进入一次，拿走玉米条后离开，三名维修员留在松弛绳索旁。

## 必须保留的结构锚点

- Exactly three clearly adult miniature workers retain identity and scale.
- Each task step uses visible tools and contact.
- A full-size hand enters only once at the terminal interruption.
- The slack rope proves the direct consequence of the removed object.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
