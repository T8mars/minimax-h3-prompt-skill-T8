# 水晶心递近｜物件展示、镜头遮挡与双手回礼

## 用途

同一成年角色在固定粉紫棚景依次举起两颗虹彩水晶心，让物件从胸前靠近镜头并产生短暂遮挡，再分别回到双手；人物始终直视镜头，终局以双心并列和微笑确认赠礼。

## 推荐输入格式

`稳定体验者与完整对象 + 独立微距质感证明 + 第一次试用/身体反应/缓冲 + 不同第二证明 + 改变后的对象终态`

## 可直接改写的简短示例

> 一名原创成年珠宝师在胸前举着一片青色水晶叶并直视镜头。；让同一片水晶叶退回胸前，露出不变的面容和银色服装。；把两片水晶叶对称举在脸旁，以一次轻微微笑和稳定对视收束。

## 必须保留的结构锚点

- One clearly adult identity and fixed environment persist.
- The first object remains the same through approach and retreat.
- The second object is added rather than substituted.
- The final state clearly shows both gifts.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
