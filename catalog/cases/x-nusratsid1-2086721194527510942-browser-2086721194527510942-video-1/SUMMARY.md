# 信息逼近｜远端警告压缩到当前空间

## 用途

先让远端信息给出模糊空间警告，主体据此检查一个仍为空的方向；第二条信息必须更精确地把发送者位置压缩到主体当前空间，最后只保留转身前的反应与未揭示威胁。

## 推荐输入格式

`独处主体 + 远端模糊警告 + 空场验证 + 当前盲区精确警告 + 不揭示来源的反应`

## 可直接改写的简短示例

> 原创射电望远镜控制室内，一名夜班技术员独自在固定控制台前，北阵列观察缝、墙钟和她唯一的影子先建立；技术员只检查北阵列，碟面和维护路为空，灯保持熄灭，不出现人物或移动物；技术员发现第二道影边，停止动作并开始向控制台一侧转头，发送者始终不揭示

## 必须保留的结构锚点

- Establish stable local geography before any message changes its meaning.
- Use one bounded first message that warns about a direction but keeps the sender remote or ambiguous.
- Use a second message to locate the sender inside the subject's current blind spot.
- End on a held reaction or beginning turn before the sender is revealed.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
