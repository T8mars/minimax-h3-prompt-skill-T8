# 黑橙角色动作卡｜身份板复位、武器挥扫与英雄锁定

## 用途

锁定同一成年原创动画角色的橙黑发色、服装与重型工具；白底身份板和黑橙文字场反复复位，每次只放行一个挥扫或持械姿态，终局回到完整角色板。

## 推荐输入格式

`同一原创角色或机器 + 固定图形身份卡 + 至少2段不同动作证明 + 图形复位分隔 + 后段能力升级 + 动作轮廓回收到最终全身锁定`

## 可直接改写的简短示例

> 在干净身份板上建立一名明确成年的原创打捞队长：铜黑双色头发、工装长裤和磁力破拆工具。；她完成一次横向破拆挥扫；一道琥珀弧跟随工具头后消失。；回到完整全身身份板，破拆工具落地，并显示准确原创标记【VANTA / SALVAGE CAPTAIN】。

## 必须保留的结构锚点

- One clearly adult original identity remains fixed.
- Graphic resets separate proof chapters.
- All detail cards map to the same tool geometry.
- The final hero card uses only original copy and design.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
