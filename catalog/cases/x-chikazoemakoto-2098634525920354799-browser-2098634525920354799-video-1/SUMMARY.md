# 花田舞姿升能｜分身、换装、花环与升空终拍

## 用途

同一成年舞者在花田持续舞动，分身、彩色换装、发光花环和龙卷依次提高视觉能量；身份与地理不变，最终升空作为单一峰值。

## 推荐输入格式

`Establish one clearly adult original fashion subject with at least three stable identity anchors. + Rotate distinct style modules while changing only declared wardrobe, accessory, palette and typography variables. + Bind every module to subject action, camera movement and foreground motion while preserving identity. + Insert one authored low-density pause after the maximum-intensity phase. + Return prior modules as a compressed recall and finish on the same adult in one stable hero frame.`

## 可直接改写的简短示例

> 一名原创成年节庆编舞者在蓝色野花田开始独舞。；推进到躯干景别，她的炭灰连衣裙只变化一次，成为青珊瑚节庆外套。；同一光环向上拉伸，把人物抬升一个身高，并以清楚全身姿态停留。

## 必须保留的结构锚点

- One clearly adult performer remains identifiable.
- Every escalation is triggered by continuing choreography.
- Wardrobe changes once while face and body stay fixed.
- Exactly one levitation peak closes the sequence.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
