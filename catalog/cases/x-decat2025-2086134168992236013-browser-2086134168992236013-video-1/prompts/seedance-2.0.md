# 程序错位｜扫描到实物双确认 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：生成一支原创博物馆程序喜剧：超大黄铜机械象认真完成保护修复接收流程，连续暴露尺寸失配，X光先显示同一工具箱内六只折叠纸蛾，随后同一箱体打开并让相同纸蛾实体出现，与机械象同框完成双重确认。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
主体定义：大型机械象：抛光黄铜、外露齿轮、动作礼貌克制；蓝色工具箱：尺寸很小，内部装有六只折叠纸蛾；修复接收区：地面定位线、量体门、标本托盘、柜式X光。
镜头1：正面广角建立完整接收流程；大型机械象严肃站在定位线、量体门和工作台之间，修复人员安静等待；各程序锚点清楚；黄铜、蓝色工具箱、灰白房间；<齿轮待机><安静室内声>。
镜头2：工作台近景；机械象用象鼻把小蓝工具箱放入标准托盘，箱子合适但象鼻占满台面，主体礼貌停住；同一箱体清楚；中性工作灯；<托盘轻碰>。
镜头3：量体门中景；机械象尝试通过，肩部齿轮同时碰边，测高臂无法下降，提示灯闪烁；它退回并折耳保持体面；不增加新笑点；单一柔红提示点；<两侧轻碰><克制提示音>。
镜头4：柜式X光与屏幕插入；同一工具箱扫描后，单色影像先显示内部六只折叠纸蛾，机械象缓慢回头看；不推断纸蛾功能；屏幕、工具箱和主体关系清楚，屏幕无需可读文字；单色扫描影像；<扫描低鸣>。
镜头5：工作台实体近景；同一蓝箱从内部打开，相同六只纸蛾展开、升起并停在箱体旁；机械象俯身观察，箱体、纸蛾和大主体同框；实体出现只确认扫描结果，不执行维修或解释动作；黄铜与纸白收束；<箱扣打开><纸翼轻响><克制吸气>。
整体风格与画质：原创写实博物馆程序喜剧，黄铜机械结构、清楚合规步骤和扫描到实体的双重确认；不合尺度的主体认真执行熟悉程序，每步暴露一次适配失败；检测影像先揭示嵌套对象，同一对象随后实体出现并与主体同框。
约束：保持机械象、同一蓝色工具箱和接收区轴线连续；每个镜头只推进一个程序步骤或一个尺度失配；先扫描显示六只纸蛾，再由同一箱体实体出现，不赋予维修功能；结尾必须让箱体、纸蛾和机械象同框，不生成可读文字、字幕、Logo和水印。
```
