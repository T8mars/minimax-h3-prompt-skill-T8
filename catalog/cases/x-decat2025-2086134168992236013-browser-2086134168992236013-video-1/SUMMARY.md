# 程序错位｜扫描到实物双确认

超尺度主体认真执行熟悉程序，扫描先揭示嵌套对象，随后同一对象实体出现完成双确认。

## 核心机制

Place one visibly mis-scaled subject inside a familiar step-by-step procedure and require sincere compliance. Let each successive checkpoint expose a different physical fit failure while the subject preserves dignity. Use imaging to reveal a nested counterpart inside one bound container, then physically expose the same counterpart and hold both scales plus the main subject's reaction so the physical reveal independently confirms the scan.

## 推荐输入格式

`超尺度主体 + 熟悉程序 + 3个不同尺度失配 + 扫描先显示嵌套对象 + 同一对象实体出现并同框`

## 简短示例

> 巨型纸艺飞蛾认真通过行李安检，托盘、传送带和扫描门连续出现尺度失配；屏幕先显示箱内的小纸蛾，开箱后同一只小纸蛾实体飞出，与大飞蛾同框。

## 必须保留的结构锚点

- 主体与程序尺度明显失配
- 至少三个不同失配证明
- 扫描先于实物揭晓
- 实物必须是扫描中的同一对象且两种尺度同框

## 使用方法

1. 先保留用户主体和目标，再按推荐格式补齐场景、事件链、镜头和结果。
2. 阅读 [Creative DNA](./creative-dna.json)，重新实例化变量，不做来源表面换名词。
3. 分别查看 [MiniMax H3](./prompts/minimax-h3.md) 与 [Seedance 2.0](./prompts/seedance-2.0.md) 的已验证实例。
4. GitHub 使用 GIF 快速预览；Electron 媒体包播放完整有声 MP4。
