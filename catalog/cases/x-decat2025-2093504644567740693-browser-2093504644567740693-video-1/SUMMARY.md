# 微小接触激活巨构｜符号点亮、同心扩展与空间门户

## 用途

先在稳定遗址中建立一个可触摸符号，让一次明确接触成为唯一触发；能量从局部符文沿同心结构扩展成巨大空间状态，终局保留人物反应与已改变环境。

## 推荐输入格式

`连续真实环境 + 可见选择工具 + 至少三次局部对象改写 + 原位空间配准 + 一次整片环境改写`

## 可直接改写的简短示例

> 成年洞穴制图师站在石质档案室的一枚掌心黄铜等高线盘前。；细线从近到远穿过三圈同心地环并依次激活。；人物反应、完整发光地形球与下方原始圆盘共同停留。

## 必须保留的结构锚点

- One bounded object establishes the inactive baseline.
- One visible contact is the sole trigger.
- The adult and origin marker preserve scale and geography.
- The terminal frame holds origin, transformed environment and reaction.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
