# 散叶成灵鸟｜粒子聚合、展翼升空与光尘消散

## 用途

把同一组叶片和光粒作为唯一材料载体，从森林微小旋涡逐步成形为完整鸟体、展翼与升空，终局重新散回粒子并保留森林基线。

## 推荐输入格式

`微小材质锚点 + 可见触发 + 至少两级尺度扩张 + 最大世界保持 + 沿同一谱系精确回收原点`

## 可直接改写的简短示例

> 浅蓝纸纤维在暗色档案大厅地面聚成一个小旋涡。；完整纸鹤在书架之间展翼，层叠纸羽清楚。；纸鹤重新散成纸屑，落回同一个空地标记。

## 必须保留的结构锚点

- One material family drives every phase.
- Form growth remains monotonic and readable.
- The flight path preserves the established environment axis.
- The terminal dissolution returns material to the original location.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
