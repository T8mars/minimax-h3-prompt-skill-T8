# 室内暴走破界｜骑乘基线、障碍冲撞与彩窗出口

## 用途

先在高约束室内建立骑手与坐骑，再让坐骑连续加速、冲撞墙面和长椅改变路线；终局只用一个巨大出口释放速度，并留下破损空间作为后果。

## 推荐输入格式

`同一载具与路线轴 + 至少三种逐步收窄障碍 + 唯一最窄门槛 + 开阔空间释放`

## 可直接改写的简短示例

> 一名明确成年原创动画递送员保持银色辫发和蓝色披风，骑白色机械鹿置于玻璃温室大厅。；一次肩部撞击打破薄石膏隔墙，留下清楚鹿形开口。；机械鹿与递送员只从该窗口冲入开阔日光，留下受损大厅和一条清楚路线。

## 必须保留的结构锚点

- One adult rider and one carrier remain attached.
- Every impact alters the established interior route.
- Escalation moves from narrow obstacles to one final opening.
- The terminal release preserves the origin space as aftermath.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
