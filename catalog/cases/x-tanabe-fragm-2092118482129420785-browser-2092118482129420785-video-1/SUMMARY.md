# 扁平民间故事变体｜章节换色、物件接力与结局回收

## 用途

同一扁平图形语法用背景换色切分五个故事职责，关键物件跨章接力人物、伙伴、对抗和归返，最后用成组角色与终局符号完成压缩叙事。

## 推荐输入格式

`统一平面手工材质舞台、发现者、封闭发光容器、成年主角与天体目标先建立 + 主角从同一材质容器展开 + 原有层面折叠为社区章节且至少两组见证者送来象征物 + 累积物只触发一次受控全画面材质爆展并露出夜层 + 主角沿可见材质路径升向既定目标 + 终局大全景同时保留目标、地面见证者与至少两个前序空间锚点`

## 可直接改写的简短示例

> 扁平赭色场中，原创黄铜罗盘像小书一样打开，揭示身穿青绿色外套的明确成年极地信使；保持简洁剪纸形状。；背景依次切青绿、紫罗兰和绿色；同一路线片逐一招募成年无线电工程师、成年雪橇机械师和成年医护，每段只加入一名伙伴。；信标转为暖金色；回到赭色，四名成年人站在打开的罗盘旁，罗盘显示完整发光路线徽记；不加文字并停住。

## 必须保留的结构锚点

- Establish a flat original story world with one emblematic object that reveals the protagonist.
- Use a distinct background color and one object duty for each chapter.
- Compress travel and confrontation into readable silhouettes without changing the graphic grammar.
- Return the group and transformed object to a simple final emblem that proves resolution.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
