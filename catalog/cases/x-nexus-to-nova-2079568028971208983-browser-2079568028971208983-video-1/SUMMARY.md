# 机器前潜伏揭示｜遮挡基线、人物逼近与红警反打

## 用途

先让大型机器和吊链占据前景，蒙面成年人物从后景逐步靠近并保持低姿态；当手触工作台时，环境从冷蓝突变为红警，机器下反打完成威胁揭示。

## 推荐输入格式

`明确成年主体 + 双手空无一物基线 + 单次触发 + 单一道具分段装配 + 立即功能兑现 + 环境累积回应 + 道具持续存在与终态回扣`

## 可直接改写的简短示例

> 在暗青档案实验室建立悬挂扫描器和垂落电缆环，开场不出现清楚人物。；修复师蹲下伸向文件托盘，电缆环保持纵深。；从扫描器下方低位反打，同一修复师后撤，托盘内一张密封页面升起。

## 必须保留的结构锚点

- Foreground machinery establishes the baseline space.
- One adult approaches through the established depth layers.
- The alarm state follows that action.
- The low reverse angle reveals the same person and a concrete result.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
