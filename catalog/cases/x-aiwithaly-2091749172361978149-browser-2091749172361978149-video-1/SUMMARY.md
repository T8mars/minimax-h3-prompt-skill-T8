# 洗衣任务到喘息复位｜装载、完成证明与阳台收束

## 用途

同一成年人物把衣物从床边篮筐装入洗衣机，等待并取回干净衣物，再在窗边展开、折叠和归置；任务完成后用短暂停顿与开阔视野完成呼吸复位。

## 推荐输入格式

`一名明确成年原创主体以至少三项身份锚点先完成一个普通触觉任务 + 用一个真实前景物、门框或建筑边缘过渡到独立休息地理 + 准确展示一次慢呼吸和至少两项头发、服装、植物或光线微响应 + 呼吸期间摄影只做克制慢推或静止 + 同一成年人复位后沿既定方向穿过可见出口`

## 可直接改写的简短示例

> 一名成年修复师把档案工作间的五块亚麻防尘布收进一辆蓝色推车。；指示达到完成后，把同一批防尘布取回蓝色推车。；她在开阔视野旁停留一次呼吸，再把完整折叠堆放回原货架区域。

## 必须保留的结构锚点

- One adult, one bounded task and one inventory remain continuous.
- Each task action visibly changes the inventory state.
- The open-view pause follows completion rather than interrupting it.
- The final return places the completed inventory at its intended destination.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
