# 雨夜线索追入｜街道建立、门锁突破与仓库对峙

## 用途

一名成年调查者沿雨夜地点链追踪：街道基线、门锁操作、仓库空场、目标出现、走廊追逐与双人终态；每次推进保留湿地反光和方向。

## 推荐输入格式

`被追主体 + 单一追逐轴线 + 一次紧凑阻断 + 立即步行→更快载具交接 + 持续加速结尾`

## 可直接改写的简短示例

> 成年水务巡检员沿雾港通道走向蓝色泵房信标。；进入积水泵厅，在涡轮后方揭示一名成年维修工。；全景收束，两名成年人被一台损坏水泵分隔，准确标题【PRESSURE LINE】出现。

## 必须保留的结构锚点

- One adult investigator follows one recoverable route.
- Each threshold is opened by a visible action.
- The pursued figure remains spatially ahead.
- The terminal wide frame locates both adults and the route payoff.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
