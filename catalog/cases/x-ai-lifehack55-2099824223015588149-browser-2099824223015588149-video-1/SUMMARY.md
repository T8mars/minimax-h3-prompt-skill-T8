# 图形赛道｜穿越圆门、障碍升级与单人收束

## 用途

同一主体把抽象图形空间当作路线，跨门、分解障碍、最终独立展示结果。

## 推荐输入格式

`单一主体＋可穿行图形路线＋圆门＋两障碍＋成果定格`

## 可直接改写的简短示例

> 一名成年钴蓝工作服递送员、一个琥珀发光包裹、米白几何展厅、抽象条形墙、钴蓝圆门、两道泡棉安全挡板、发光展示台。

## 必须保留的结构锚点

- 主体身份跨空间不变
- 图形成为真实可走结构
- 终点结果与单人姿态稳定

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
