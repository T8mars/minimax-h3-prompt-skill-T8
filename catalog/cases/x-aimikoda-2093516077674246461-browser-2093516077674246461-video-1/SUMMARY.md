# 激励短句动力排版｜语义层级、动作词推进与终句锁定

## 用途

把一段原创激励语拆成五个语义阶段，小字提出情境，大字只承担一个行动词；字重、位置和进入方向随含义升级，最终完整句子稳定停留。

## 推荐输入格式

`原创完整短句 + 固定语义分段 + 每段可读文字与独立物理行为 + 连续载体交接 + 逐级升能 + 整句静止锁定`

## 可直接改写的简短示例

> 炭黑底先显示小号准确句【THE MAP IS NOT READY】。；准确短语【WALK TO IT】跨三条上升基线排列，每个词对应一步。；完整准确原创句【ONE CLEAR STEP MAKES A ROUTE】展开并静止停留。

## 必须保留的结构锚点

- Every phase carries one semantic function.
- Scale and direction express the meaning of the active words.
- Earlier text may leave restrained registration traces.
- The full terminal statement receives a stable readable hold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
