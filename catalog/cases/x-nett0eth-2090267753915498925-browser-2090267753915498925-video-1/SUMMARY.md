# 扁平角色字卡轮转｜同一企鹅贯穿多种运动语法

## 用途

同一扁平角色以稳定轮廓、配色和名称结构贯穿扁平字标、眼部宏观、三联剪影、环形字带、长词地面、语义短词卡、网格空间和终局字标；每段只让一个版式动作承担信息功能，最后回到完整角色与名称锁定。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 黑与奶油色场组装准确【FOLIO】书本字标，揭示奶油机身、青绿面罩和红色书脊灯的成年比例机器人；准确立体【SORT】沿对角线延伸，三个缩小的同一机器人沿字面单向移动；青绿面罩与红色书脊灯短暂宏观，拉回同一完整机器人并落入【FOLIO】书本标志

## 必须保留的结构锚点

- Establish one stylized character with stable silhouette, palette, face marks and a compact original name field.
- Use at least four modules with genuinely different layout logic while limiting each to one new short word or field.
- Preserve identity through flat cards, macro scale and shallow 3D space, including one repetition or verification phase.
- Return from fragments or details to the full character and original name field for a stable hold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
