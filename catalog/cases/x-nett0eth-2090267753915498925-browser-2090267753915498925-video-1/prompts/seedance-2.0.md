# 扁平角色字卡轮转｜同一企鹅贯穿多种运动语法 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：制作原创13.7秒动态图形身份片，主角为成年比例机器人图书管理员 FOLIO，稳定特征是奶油色机身、青绿色面罩和一条红色书脊灯。先出现带书本符号的准确【FOLIO】紧凑字标，再揭示同一完整机器人。依次轮转三联剪影核对、环形准确短词【INDEX】、三个小机器人沿立体【SORT】轨道移动、主机器人把一本书放到【STACK】字母上的扁平卡片，以及让【RETURN】成为目的书架的浅景深网格空间。始终保留奶油、青绿、红色身份锚点。用一次面罩和书脊灯宏观特写，再回到完整机器人并稳定落入 FOLIO 书本标志，不增加其他文案。。
总时长约14秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：字标与完整角色先锁定；黑与奶油色场组装准确【FOLIO】书本字标，揭示奶油机身、青绿面罩和红色书脊灯的成年比例机器人；三项身份锚点从此不变；黑、奶油、青绿、红色；<书页合拢><短识别音>。
镜头2：剪影核验与环形短词；同一机器人进入三联剪影核验，再站在只写【INDEX】的环形字带中央，字带只旋转一次；轮廓和面罩始终清楚；扁平正交卡片；<三次卡片切换><一圈纸带声>。
镜头3：立体长词成为运动轨道；准确立体【SORT】沿对角线延伸，三个缩小的同一机器人沿字面单向移动；重复角色必须保持同一身份；浅2.5D字轨、克制阴影；<轨道滚动><三次轻触>。
镜头4：一词一动作并进入网格空间；主机器人把一本书放到【STACK】字母上，再进入让【RETURN】成为目的书架的浅景深网格房；每个短词只绑定一个可读动作；扁平卡到白色网格空间；<书本落位><网格展开>。
镜头5：细节回到完整字标；青绿面罩与红色书脊灯短暂宏观，拉回同一完整机器人并落入【FOLIO】书本标志；不得增加新文案，最终完全停住；高可读终局锁定；<细节脉冲><纸页终止音>。
整体风格与画质：原创扁平到2.5D角色动态图形，干净黑色与奶油色场，青绿和红色点缀，稳定机器人身份，准确极简文字，清楚几何转场和克制纹理；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
