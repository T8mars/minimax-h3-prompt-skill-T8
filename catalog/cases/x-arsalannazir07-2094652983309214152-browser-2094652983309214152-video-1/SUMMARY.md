# 违规者自摔反制｜偷取、逃跑失衡与目击者追加惩罚

## 用途

固定高位观察视角先见证一个违规者从成年人身后偷走物件并逃跑，随后违规者自行失衡倒地；被偷者走近取回物件，再用重复但受控的动作完成喜剧惩罚并离场。

## 推荐输入格式

`两名明确成年原创角色与一件归属清楚的物品 + 一次非暴力违规夺取和可追踪逃离 + 违规者因自身路线失误发生安全可恢复的喜剧跌倒 + 原主人取回物品并只做一次安全反制 + 双方状态清楚后离场`

## 可直接改写的简短示例

> 固定高位住宅窗视角中，成年单车递送员悄悄从成年花店主推车上拿走一个红色包裹。；松散配送带缠住后轮，只造成一次低速受控摔倒，包裹完整滑到路缘。；花店主带包裹离开，递送员尴尬坐起，故障自行车仍在原位。

## 必须保留的结构锚点

- One fixed witness view shows the violation before any retaliation.
- The exact stolen object remains visible through approach, flight, fall and recovery.
- Recovery of the object precedes the bounded comic retaliation.
- The terminal state separates recovered owner, stopped violator and persistent aftermath.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
