# 冻结修复｜事故悬停、唯一修复者到全域复流

## 用途

先建立拥挤空间的正常运动和一个完整物件，再让一次事故同时拆散物件并冻结环境；只允许一名专业角色继续移动，按可追踪顺序回收组件、重建物件并完成交付，最后全域只复流一次。

## 推荐输入格式

`完整物件与正常环境基线 + 一次事故拆散并冻结 + 唯一移动专业角色 + 同一组件可追踪回收与重建 + 完成交付后一次全域复流`

## 可直接改写的简短示例

> 原创轨道温室、成年封装工程师、完整陶瓷种子胶囊以及正常运动的技术员、灌溉雾和机械工具；工程师依次收回三颗种子、同一条营养胶和上半外壳；工程师把复原胶囊交还成年植物学家，交付完成后实验室只恢复一次

## 必须保留的结构锚点

- Show a complete target object and at least two independent environmental motion classes before the accident.
- Use one visible accident to create maximum disorder and suspend all non-specialist motion.
- Recover separated component families in traceable source-to-destination order and rebuild the same object.
- Complete one service handoff before one global resumption in the original geography.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
