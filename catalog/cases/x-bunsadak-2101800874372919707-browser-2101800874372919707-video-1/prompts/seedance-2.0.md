# 三角色同拍｜固定阵形与同步转向 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：原创15秒三台测量机器人同步动作展示：三机排队、转向、抬臂、整齐回位。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：固定正面全景，三台与地面标记全在画内；三机按橙、白、蓝顺序等距站立，各自在自己的圆点上原地交替抬脚踏步三次；恰好三机、不重叠，各自踩实地面；清晰工业展台光，哑光蓝绿背景；<三组细小机械脚步声>。
镜头2：保持全景与地面可见；三机同时向右转九十度，再各自原地交替抬脚两次，脚底不离开自己的圆点范围；左中右顺序持续，关节硬质机械运动；同一展台光；<同步关节轻响>。
镜头3：正面稳定中远景；三机转回正面，同时抬起短臂再放下；三种颜色与身份不混乱；清楚看见色块；<三次轻节拍>。
镜头4：仍固定正面全景，停住最后动作；三机再共同转向后回正，各自双脚回到圆形标记并同步停止；恰好三台，无增减，无悬浮；标记与脚底清楚；<最后三声落脚同时收束>。
整体风格与画质：原创工业展台机械群舞，不模仿兔子与礼服舞台；三机身份稳定、间距稳定、转向同步、结尾脚底着地。
约束：仅三台机器人，橙白蓝顺序固定；不出现动物、礼服或红幕；不用原片具体音乐或舞步复制。
```
