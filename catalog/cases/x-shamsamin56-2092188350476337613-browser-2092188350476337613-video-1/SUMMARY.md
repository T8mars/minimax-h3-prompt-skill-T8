# 可见光标选择器变体｜固定网页控件同步切换产品与世界

## 用途

固定网页结构和可见光标保持不变，每次只选择一个新选项，并同步替换英雄产品、配色、纹理与少量说明；最后回到完整选择界面证明所有状态属于同一系统。

## 推荐输入格式

`固定选择菜单 + 固定数据区 + 固定主视窗 + 至少4个原创对象 + 每次可见选择 + 同步字段更新 + 一个定义动作`

## 可直接改写的简短示例

> 展示原创模块化台灯桌面配置器；固定左侧选项栏、中央台灯视口、右侧材质说明和一个可见光标。；依次悬停【PAPER】与【METAL】；灯罩材质、环境色和一种背景图案同步改变，灯座、摄影机和界面网格固定。；拉回完整四选项界面，保持【STONE】明确选中，同一台灯以最终状态停住。

## 必须保留的结构锚点

- Establish one persistent interface, one visible pointer and one default subject state.
- Allow one pointer selection at a time and change all declared state channels together.
- Vary palette, material, environment accent and concise label without adding uncontrolled channels.
- Return to the complete interface and hold one clearly selected final state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
