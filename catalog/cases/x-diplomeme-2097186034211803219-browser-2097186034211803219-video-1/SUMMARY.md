# 美妆自拍实证｜正脸口播、包装同框与单次涂抹

## 用途

固定同一成年人物、卧室镜面和竖屏自拍机位；人物先口播，再让盒装与管装产品同时同框，完成一次唇部涂抹，并以产品在手的妆效近景回到结论。

## 推荐输入格式

`出镜测评者 + 未开封产品 + 完整内容展示 + 一个产品专属微距证据 + 一次完整使用 + 产品与反应同框`

## 可直接改写的简短示例

> 一名原创成年陶瓷设计师在暖色工作室房间里，以竖屏手持镜头直接口播。；保持人物、包装与管体三者同框一个口播句，标签、涂抹头和面部都清楚。；以一次轻微转头展示完成唇色，闭合管体仍位于脸颊旁收束。

## 必须保留的结构锚点

- One clearly adult host, one room and one product set persist.
- Packaging is shown before application.
- The applicator returns to its original package.
- The final result and product remain visible together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
