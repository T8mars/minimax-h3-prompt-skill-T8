# 善意载体接力｜小动作跨人物传递到情绪兑现

## 用途

用一个可辨识帮助动作作为载体，让不同人物在同一城市路线中接力；每次帮助同时解决眼前问题并引出下一位，最终回到明确的情绪结果。

## 推荐输入格式

`稳定主体与目的地 + 单职责短动作 + 姿态/手中物/方向接力 + 累积准备状态 + 单向路线 + 终点结果动作`

## 可直接改写的简短示例

> 成年面包师在市场外把干毛巾递给淋雨的自行车递送员。；顾客截住滚动水果箱，避免撞到推婴儿车的家长。；清洁工把捡到的手套还给最初面包师，完成实用善意闭环。

## 必须保留的结构锚点

- One practical helping action is visible in every beat.
- The recipient becomes the next helper.
- A shared route preserves spatial continuity.
- The last help returns value to the opening participant.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
