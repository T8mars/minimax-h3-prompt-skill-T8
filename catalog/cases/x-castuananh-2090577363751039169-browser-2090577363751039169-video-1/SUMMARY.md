# 威胁接力反转｜救援改写层级并重启追逐

## 用途

先让成年主体与第一层威胁发生清楚冲突，再让更大威胁从同一空间介入并直接终止旧敌；主体利用短暂空档逃向可见救援者，但救援者的攻击只造成一次暂时压制。主体取得新工具后与救援者共同反击，结尾仍保留更大威胁的活动迹象，让每次解围都同时打开下一层危险。

## 推荐输入格式

`明确成年受伤主体、第一层威胁和救援方向同场建立 + 更大第二层威胁直接移除旧敌并继承追逐目标 + 伤势或疲劳状态持续到至少两名成年救援者 + 首次救援只暂时压制并暴露可用工具 + 主体取得工具加入共同防线 + 更大威胁复起并在下一次撞击前停留`

## 可直接改写的简短示例

> 成年研究员在蓝色冰沟中跛行，两名成年守卫位于前方，小型分节穴兽挡住路线；研究员保留跛行姿态靠近守卫，大型捕食者沿已建立冰沟逼近，两名守卫发射光缆；研究员加入两名守卫并举起发射器，捕食者体内裂纹重新发光并抬头，三人共同瞄准

## 必须保留的结构锚点

- Establish one clearly adult vulnerable protagonist, a first-order threat and a visible rescue direction in one geography.
- Let a larger second-order threat directly remove the first threat and immediately inherit pursuit of the same protagonist.
- Make the rescuers' first intervention only temporarily suppress the larger threat while exposing one usable tool.
- Let the protagonist acquire the tool and join collective defense before the larger threat resumes movement or re-enters.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
