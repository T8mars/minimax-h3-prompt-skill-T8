# 天体语义字场变体｜成年观测者让轨道、脉冲与引力成为文字

## 用途

同一明确成年观测者以眼神、手势与身体轴触发轨道、脉冲和引力短词；文字成为可测量的天体结构，并在尺度升级后回到同一人物与单一结论。

## 推荐输入格式

`Establish one clearly adult original subject, three identity anchors and one continuous world axis. + Bind each decisive action to exactly one short original semantic word that appears only after the action begins. + Make each word occupy, divide, reflect or redirect the physical environment rather than float as a subtitle. + Escalate typography scale and spatial depth while preserving identity, travel direction and readable action. + Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.`

## 可直接改写的简短示例

> 原创暗色海洋实验室中，一名明确成年东亚海洋学家穿白色工作服站在圆形黑水池旁；锁定脸、短发和水池坐标。；她单次挥手，准确短词【TIDE】与【DEPTH】分别成为同一池内的上升圆环和向下刻度。；所有等高线收回成她眼旁一滴水；同一成年人面对镜头，准确终局词【RETURN】在她身后细圆环内落稳。

## 必须保留的结构锚点

- Establish one clearly adult original observer and fixed celestial coordinate anchors.
- Require a visible gaze, hand or body action before each exact semantic word appears.
- Escalate from body-scale diagrams to cosmic scale while preserving observer identity and coordinate continuity.
- Collapse the celestial system back to the same observer and one readable terminal word.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
