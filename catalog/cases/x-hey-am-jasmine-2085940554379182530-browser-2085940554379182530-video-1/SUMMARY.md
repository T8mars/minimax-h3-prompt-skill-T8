# 纪实跟拍｜旧城行走到轻微回应

## 用途

拍摄者在旧城日常中发现并跟随人物，稳定地理锚点串联篮子、狗、花和远景；人物只做一次轻微回应并继续离开。作为既有纪实偶遇模板的新证据，不新增选择器。

## 推荐输入格式

`侧面连续跟拍 + 狭窄起点 + 行进中空间揭示 + 一次偶发横穿 + 一次克制回应 + 继续离开`

## 可直接改写的简短示例

> 原创雪地小站里，拍摄者发现年长钟表匠已提黄铜箱行走，开场不看镜头；发车铃响且蒸汽越过月台，他停止检查并看向拱门，镜头短暂呼吸对焦；他离开，雪地曝光轻微溢出，对焦在空月台上迟到

## 必须保留的结构锚点

- Begin with discovery of a subject already in an ordinary route.
- Use recurring landmarks to maintain one geography.
- Allow exactly one restrained acknowledgment.
- End with departure and mild operator imperfection.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
