# 停时失误复位｜倾倒冻结、手势归杯与日常继续

## 用途

先建立安静日常动作，再让杯体倾倒与液体同时冻结；人物发现异常后用一个明确手势把杯与液体按原轨迹复位，最后恢复阅读证明事故被关闭。

## 推荐输入格式

`完整物件与正常环境基线 + 一次事故拆散并冻结 + 唯一移动专业角色 + 同一组件可追踪回收与重建 + 完成交付后一次全域复流`

## 可直接改写的简短示例

> 成年档案员坐在阳光橡木桌旁，面前是打开的账册和玻璃墨水瓶。；她发现停住的泼洒，张开手掌朝向墨水。；档案员放下手继续书写，同一账册与干净吸墨纸保持可见。

## 必须保留的结构锚点

- An ordinary baseline precedes the accident.
- Object and fluid freeze in a readable intermediate state.
- The reversal restores the exact registered placement.
- Resumed routine proves closure without adding a second event.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
