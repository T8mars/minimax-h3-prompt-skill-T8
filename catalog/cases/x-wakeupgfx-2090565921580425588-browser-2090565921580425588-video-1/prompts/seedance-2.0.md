# 角色字卡动作片头｜身份锚点、语义动作与模块轮转 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：制作原创15秒角色字卡片头，主角为明确成年的自行车递送员 ARC MIRA，稳定特征是方形眼镜、青色头盔条纹和橙色夹克。先组装紧凑的 ARC MIRA 定位针标志，再依次揭示同一张脸和全身。轮转四个图形模块：人物沿【ROUTE】骑行，捏下刹车把【BRAKE】压缩，从斜置字母【CLIMB】上攀过，把包裹穿过【DELIVER】的字腔。始终保持同一轮廓、面部锚点、青橙配色和定位针几何。用三张编号递送员肖像做一次身份核对，最后人物只跳一次并落入完整 ARC MIRA 定位针标志，碎片清场后准确停留。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：名称标志与身份锚点；象牙底组装原创【ARC MIRA】定位针标志，推进到成年递送员的方形眼镜、青色头盔条纹和橙色领口；先锁定名称与三项稳定身份特征；象牙、青色、橙色、深海军蓝；<纸片拼合><短促定位音>。
镜头2：动作沿短词发生；同一递送员在深蓝字卡上沿大型【ROUTE】基线骑行一次；文字完整可读，动作只服务一个词；扁平编辑字卡、清楚全身轮廓；<链条轻响><轮胎划过字面>。
镜头3：两种模块各一词一动作；人物捏刹车使【BRAKE】压缩，再从斜置【CLIMB】字母上攀过；每模块不增加其他文案，身份锚点不变；青橙配色、纸张和描边字切换；<刹车咬合><手脚落字>。
镜头4：空间模块与身份核验；2.5D包裹房中，【DELIVER】成为实体前景框，人物把包裹穿过字腔；随后出现三张编号同人肖像；空间变化后必须明确验证同一身份；克制纵深、编号肖像板；<包裹滑入><三次卡片翻页>。
镜头5：角色归入完整主标；人物从肖像条只跳一次并落入完整【ARC MIRA】定位针标志，碎片清场并完全停住；名称、角色和符号同时可读；高对比终局锁定；<一次落地><短主标终止音>。
整体风格与画质：原创高级角色动态图形，清楚编辑字卡，有限青橙象牙色配色，稳定的成年风格化身份，准确短文字，克制2.5D景深和有触感的纸张转场；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
