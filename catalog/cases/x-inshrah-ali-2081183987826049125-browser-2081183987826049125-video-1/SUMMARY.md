# 抵达庆祝升级｜奔入人群、蛋糕峰值与城市烟花

## 用途

主角先奔入等待人群，蛋糕和烛光集中注意，舞蹈、自拍、碰杯和共同许愿逐层扩展参与范围，终局拉远到屋顶与城市烟花。

## 推荐输入格式

`安静旅人 + 步行转奔跑 + 延迟目的地揭示 + 环境庆祝 + 人路目的地同框`

## 可直接改写的简短示例

> 成年海洋生物学家抵达黄昏码头，成年队友正在等待。；一次团队合影、一次举杯和一段短集体步扩展参与。；镜头远拉，完整码头依次亮起，近海研究船以灯光回应。

## 必须保留的结构锚点

- One arriving adult remains the emotional anchor.
- A shared focal object gathers the group.
- The group reconverges before the peak.
- The terminal wide view proves destination and collective payoff.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
