# 异质航行｜维修出发到巨尺度揭示

## 用途

先用维修准备建立载具与成员，再让同一载具在不相容材质环境中持续航行；近景证明操控，远景证明速度与尺度，最后用巨尺度环境或生命体重构旅程大小。

## 推荐输入格式

`载具与操作员 + 出发前准备 + 明确启动 + 不相容介质持续航行 + 近/远尺度证明 + 巨尺度揭示`

## 可直接改写的简短示例

> 两台维护机器人先检修三角磁吸履带车并完成磁足自检；启动后穿越像潮汐一样流动的铝箔带，用近景证明适应、远景证明规模，最后揭示巨型压实机。

## 必须保留的结构锚点

- Establish one carrier, its crew and a visible readiness task before departure.
- Show an unambiguous engine or control engagement followed by departure.
- Alternate local control proof with wider speed-and-scale proof.
- Use a late giant-scale environmental, living or working-form reveal to reframe the journey's scale.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
