# 单角图形舞台｜动作短句、发辫擦镜与循环回标

## 用途

固定一个成年风格化角色的面孔、服装与樱桃识别符，让姿势、长发弧线和短字卡按节拍互相交接；终局回到开场标题与完整站姿。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 建立原创成年动画电台主持人：钴蓝辫发、银色夹克和柠檬徽章，背景显示准确标题【ZEST】。；三个全身节奏姿势与柠檬圆形、准确短词【TUNE】交替。；准确ZEST字场回到完整人物周围，自信终姿停留。

## 必须保留的结构锚点

- At least three identity anchors remain fixed.
- Character motion physically motivates each graphic handoff.
- Foreground hair or costume motion performs the wipes.
- The opening graphic motif returns with the full character.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
