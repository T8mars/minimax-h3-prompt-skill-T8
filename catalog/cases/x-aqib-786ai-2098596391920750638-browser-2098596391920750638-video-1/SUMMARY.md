# 孤城围攻决断｜行进基线、无人机收网与迎战定格

## 用途

从雨夜空城和同一成年战士的独行路线开始，无人机由远到近汇聚；头盔警报确认威胁后，人物转身举起装备，停在行动前的明确决断状态。

## 推荐输入格式

`威胁或失效状态 + 责任主体 + 准备动作 + 校准确认 + 一次决定性动作 + 可见后果 + 主体或结果终版锁定`

## 可直接改写的简短示例

> 先建立空旷雨光港口大道，再让一名成年信号巡查员走入画面。；无人机增加到九架并形成可读包围圈，街道和信标方向保持。；巡查员只转身一次，举起脉冲盾，在不虚构攻击结果前停住。

## 必须保留的结构锚点

- One clearly adult subject and one destination axis persist.
- Threat count and proximity increase monotonically.
- Exactly one final decision gesture occurs.
- The sequence stops before inventing victory or injury.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
