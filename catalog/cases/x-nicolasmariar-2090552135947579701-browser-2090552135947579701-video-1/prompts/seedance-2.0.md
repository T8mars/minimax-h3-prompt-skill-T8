# 地下轨迹破土｜尺度反转、追逐穿越与空场余波 — Seedance 2.0

```text
任务：制作原创15秒盐碱地追逐。两名明确成年测绘员穿白色工作服、肩部有青色识别带，沿三根橙色传感桩组成的路线奔跑；黑色设备拖车和远处风塔建立普通尺度。一条晶体隆起在他们身后的盐壳下移动，先顶起松散盐粒，再把白色地表压裂成逐渐加宽的轨迹。低位后跟镜头同时保留成年人、传感桩和地下轨迹。到第三根传感桩时，一只原创分节矿物滑行兽从同一裂线破土，半透明石板甲片和四片宽大贴地鳍完整可见，并与两名成年人同框证明比例。它沿既定桩线路线追近，成年人转向设备拖车。滑行兽和成年人离开近景后，镜头停在破裂盐壳、悬浮青色矿尘、三根传感桩和风塔上。不得出现来源人物、蚂蚁解剖、乡村道路、储罐、沙漠怪兽片引用或来源摄影路线。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：成年人和路线地标建立尺度；两名成年测绘员沿三根橙色传感桩奔跑，黑色设备拖车和远处风塔保持可见；白色工作服与青色肩带锁定身份，地标不得消失；正午盐地、白青橙配色；<急促脚步><旷野低风>。
镜头2：地下轨迹分两级增强；晶体隆起先顶起盐粒，再把白色盐壳压裂成加宽移动线；成年人、传感桩和轨迹必须保持同一地理；细盐粒、青色晶尘、裂纹；<地下摩擦><盐壳开裂>。
镜头3：同一裂线交给完整破土实体；第三根桩旁，原创分节矿物滑行兽从裂线破土，完整甲片和四片贴地鳍与两名成年人同框；用人物、桩、拖车和风塔共同证明尺度；半透明石板甲、强日光边缘；<地表爆裂><低沉矿物共振>。
镜头4：大型实体沿既定路线追近；滑行兽沿传感桩路线移动，两名成年人转向黑色拖车，裂开的地表连续保留；不得瞬移、换向重置或更换人物服装；低位跟拍、持续裂线；<贴地重击><奔跑加速>。
镜头5：行动离场后保留物理余波；成年人和滑行兽离开近景，画面停在破裂盐壳、悬浮青尘、三根桩、拖车和风塔；结尾不得恢复干净地表或新增袭击；空场高日照、青尘缓落；<远去震动><尘粒落下>。
整体风格与画质：原创写实矿物科幻，正午盐碱地，白、青、橙现场配色，低位路线地理清楚，地表物理分级推进，大型实体尺度连贯，手持紧张感克制；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
