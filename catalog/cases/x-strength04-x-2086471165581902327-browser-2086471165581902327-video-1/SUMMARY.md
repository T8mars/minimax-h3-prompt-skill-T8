# Threshold-to-Passage Field Inspection

先用远景锁定一个有后果的入口，一次剪辑跨过阈值，再以连续跟随建立身体可感的通行；一个局部材料信号打断前进，检查后只展示可见路线状态，不虚构诊断。

## 核心机制

A purposeful scale view identifies one threshold, a decisive crossing turns it into embodied travel, coordinated participants inspect one local cue, and the ending shows only a visible route state.

## 视觉与节奏风格

环境尺度明确；一次阈值切换；连续空间方向；移动灯光揭示材料；局部检查后保持不确定性。

## 适用范围

- 野外考察、工业巡检、科学纪录、后台技术和基础设施短片
- 强调路线、材料、工具和人机协作的 15 秒段落

## 不适合

- 开场风景与内部路线无关
- 频繁跳切导致方向丢失
- 根据一个信号就宣称危险、安全或诊断结论

## 使用方法

1. 阅读 [Creative DNA](./creative-dna.json)，先画入口、路线、信号与终点。
2. 改变环境类别、团队拓扑、工具关系、信号物理、运镜载体和结尾状态。
3. 直接查看 [MiniMax H3](./prompts/minimax-h3.md) 与 [Seedance 2.0](./prompts/seedance-2.0.md) 已验证实例。
4. GitHub 查看 GIF；Electron 媒体包播放完整有声 MP4；作者上下文见原帖。
