# 道具携带者主动共享｜遮蔽物到位后完成亲密确认

## 用途

先让一个等待者暴露在清楚天气压力下，再让较小的道具携带者从画外进入；以道具覆盖范围作为可见进度条，靠近后先让遮蔽物同时覆盖双方，再用一次克制的身体贴近确认关系，结尾保持共同庇护状态而不是继续动作。

## 推荐输入格式

`等待主体在清楚环境压力下暴露 + 帮助者携带已激活保护道具且覆盖边界先进入 + 沿单一轴线靠近直到双方进入同一保护区 + 先完成共同保护再发生情感动作 + 只用一次克制接触确认关系并保持外部压力可见`

## 可直接改写的简短示例

> 奶油色小机器人停在损坏充电柱旁，琥珀沙尘横穿无覆盖平台；巡检车继续靠近，布边阴影向小机器人移动；巡检车用磁吸侧板与小机器人连接一次，二者在布下静止

## 必须保留的结构锚点

- Establish one waiting subject, one visible environmental pressure and an uncovered state before help arrives.
- Let the active protective prop enter before or with the helper and keep its coverage boundary visible.
- Complete protection before using an affiliative gesture.
- Use exactly one restrained contact and hold while pressure remains outside the cover.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
