# 见证者退场｜前景横穿到远端巨构

## 用途

以近处见证者建立尺度，镜头离开前景后让一次近景运动带出远方目的地。

## 推荐输入格式

`前景见证者＋远端目标＋近景横穿＋远景停留`

## 可直接改写的简短示例

> 清晨货港，一位成年线路工程师，安全栏杆，对岸同一座巨型悬索转运桥，近处三辆小型自动巡检车。

## 必须保留的结构锚点

- 远端目标先有锚点
- 前景移动有独立层次
- 最终远景清楚交接尺度

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
