# 云门巨兽逼近｜人类剪影、雾中显形与鼻端停留

## 用途

用固定崖台与多个人类剪影建立尺度，巨型生物从云层中逐步显出眼睛、鳞片和头部；它只完成一次缓慢靠近并在接触前停下，保留敬畏张力。

## 推荐输入格式

`完整宏大目的地、可读接近路线与至少三名明确成年旅行者或载体在开场同现 + 全程保持单一目标方向和稳定目的地身份 + 旗帜、灯光、服装或载体等群体锚点重复形成仪式节奏 + 行进与克制前推、轻微升高共同让地标尺度层单调增加 + 终局目的地主导但仍保留至少两个旅行者或路线锚点`

## 可直接改写的简短示例

> 三名明确成年天文学家站在银色云海上的玄武岩天桥。；它靠近一次，琥珀镜片、层叠矿物板和两枚冠鳍逐渐清楚。；机器在距天桥一个身位处停下，不发生撞击，保持安静尺度对照。

## 必须保留的结构锚点

- Human scale anchors appear before the giant subject.
- The giant emerges progressively from an occluding medium.
- Camera geography remains stable enough to compare scale.
- The final near-contact state stops before impact.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
