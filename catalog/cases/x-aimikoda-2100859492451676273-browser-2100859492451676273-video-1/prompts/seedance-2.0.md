# 人物装备归属｜局部切片到全身动作 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：创作原创15秒雪崩搜救训练短片：一名成年队员和一支探杆先同框，随后用不同局部验证装备归属，单次插杆后以全身工作姿态确认结果。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：中景稳定建立人物、工具和标记坡面的关系；一名成年训练员右手持一支完整探杆，面容和工装从开头就可见；同一人物与同一支探杆同框建立归属，坡面标记作为后续锚点；多云雪地自然光，石板灰与橙色工装清楚可辨；<低风声><靴底压雪>。
镜头2：先切近右手与探杆握点，再切左肩无线电，沿原行进方向短跟拍；她走近唯一的训练标记，探杆尖端、握手和无线电各提供一个不同的装备线索；每个局部保留同一坡面或工装的一部分，工具形状和右手握点不跳变；保持同一冷日光和雪地曝光；<装备轻碰><脚步压雪>。
镜头3：腰部高度固定视角同时容纳双手、探杆全长和雪面接触点；她只把探杆插入训练标记雪面一次，探杆保持笔直，雪面在触点轻微压实；一个连续接触动作，不用无因闪切代替插杆过程；金属与雪的接触边界清楚；<探杆伸展声><单次触雪声>。
镜头4：平稳拉开至全身与完整探杆同框并停留；同一成年训练员站在已插好的探杆旁，右手、左肩无线电、工装与靴子都能对应早前局部；只保留这一名队员、一支探杆和同一训练坡面，不出现对手或新的工具；冷日光保持稳定，橙色工装为唯一强调色；<持续低风><装备细微摩擦>（稀疏低鼓在全身确认时收束）。
整体风格与画质：原创写实雪地职业训练片，不复制来源动画人物或武器造型；工具归属、一次可见接触和最后全身结果均清晰；每镜只执行一个主要运镜。
约束：人物成年身份、工装、右手握点、无线电和探杆形状全程稳定；不出现战斗、刀剑、品牌、字幕或水印。
```
