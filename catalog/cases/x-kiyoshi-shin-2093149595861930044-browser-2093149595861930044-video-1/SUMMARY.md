# 手绘逐层完成｜骨架线稿、细节闭合与彩色成品

## 用途

让真实手和铅笔成为唯一生成工具，结构线、脸发、服装和颜色按依赖关系逐层出现；每一笔从接触点增长，终局留下完整插画。

## 推荐输入格式

`真实载体 + 沿既有几何描线 + 同线条族跨载体 + 保留轮廓 + 手作纪念物闭合`

## 可直接改写的简短示例

> 成年插画师的手正在细化一幅原创成年自行车机械师的浅色结构草图。；夹克、工具带、自行车轮和落地双脚被补全为连贯线稿。；车轮旁增加三枚小型运动标记，铅笔完全离开，完整页面停留。

## 必须保留的结构锚点

- The physical drawing tool remains visible.
- Every contour emerges from current tool contact.
- Color waits for closed line regions.
- The tool exits before the finished artwork holds.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
