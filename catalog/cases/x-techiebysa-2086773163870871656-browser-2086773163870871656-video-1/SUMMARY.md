# 对话喜剧｜双轮停顿与无声回击

## 用途

稳定正反打中完成两轮说话，用一个清楚停顿隔开，最后回到第一人做无声表情或姿态回应。

## 推荐输入格式

`稳定双人地理 + 第一轮完整说话 + 清楚停顿 + 第二轮短回答 + 更长无声反应`

## 可直接改写的简短示例

> 两名夜班博物馆保安保持桌轴，甲说警报异常，停顿后乙只回一句；再回甲无声看向空展柜并定住。

## 必须保留的结构锚点

- Keep one stable table axis and matching eye lines.
- Make the first speaking turn visibly complete before one readable pause.
- Insert a silent expectation slot after the second turn.
- End on the first subject's non-speaking response without an additional speaking turn.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
