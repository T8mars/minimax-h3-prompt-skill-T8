# 动画片头混合接力｜角色锚点、数字字卡与街景推进

## 用途

同一角色身份在平面海报、巨型数字、街景和车辆模块中连续出现；每一模块只引入一个版式信息，并用动作或遮挡把角色交给下一场景，最后回到总片名。

## 推荐输入格式

`明确成年原创广告主体与至少三项稳定身份/服装锚点 + 统一纸张/撕边/墨色系统通过动作、细节或注册边缘进入 + 全身证明与至少两个材质微距接力 + 至少两种明显不同海报版式但身份和信息层级不漂移 + 短字只解释相邻证据 + 汇总已证明人物、细节和文字形成终局广告页并停留`

## 可直接改写的简短示例

> 原创成年屋顶递送员肖像与准确红黑标题【NIGHT SHIFT】同场建立。；人物进入钴蓝电车站，一辆经过车厢擦镜交给街道奔跑动作。；同一肖像、07和准确标题NIGHT SHIFT归入稳定终局字卡。

## 必须保留的结构锚点

- One identity system anchors flat and spatial modules.
- Each module introduces one title or number field.
- The city module preserves character anchors.
- The final card consolidates the repeated portrait, number and title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
