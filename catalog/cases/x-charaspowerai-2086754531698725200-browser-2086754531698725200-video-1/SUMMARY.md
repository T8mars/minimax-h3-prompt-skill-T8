# 材质字效｜云层成字再见光

## 用途

同一物理材质先形成短字、稳定可读，再沿原过程逆向散回自然状态。

## 推荐输入格式

`单一物理材质 + 短词聚合 + 可读停留 + 同物理逆转 + 无字完整复位`

## 可直接改写的简短示例

> 正上方实验盘中铁屑沿磁力线聚成NORTH，稳定可读后用同一粒子物理逆向散开，最后恢复为指南针周围的同心磁场。

## 必须保留的结构锚点

- Use one continuous physical material field before, during and after the word.
- Form one short high-legibility word through visible material aggregation.
- Reverse using the same material physics that formed the word.
- Return to a coherent non-text field with the original anchor still readable.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
