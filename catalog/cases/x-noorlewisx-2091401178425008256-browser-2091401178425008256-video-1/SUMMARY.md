# 昼夜底妆证明｜街景基线、持妆跨时与包装收束

## 用途

同一成年女性和同一底妆结果从日光街道过渡到夜间烛光长廊，以近脸、脚步和环境变化证明跨时稳定；终局完整气垫包装和人物共同收束，正式模板替换来源品牌。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 锁定原创成年小提琴指挥：黑色短发、银项链和海军蓝长裙，置于浅色晨间柱廊。；通过一个门口把同一步态带入琥珀夜间长廊，身份和妆容不变。；完整展示虚构气垫【LONG ARC】，再与同一人物同框，准确短句【MORNING TO LAST NOTE】停留。

## 必须保留的结构锚点

- One adult identity and one applied result anchor both time states.
- A continuous movement or threshold links daylight and night.
- One complete original package appears after the human proof.
- The final frame reconnects person, persistent result, package and one exact claim.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
