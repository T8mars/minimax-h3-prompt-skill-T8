# 环绕字带时装变体｜同一成年表演者被原创短词逐拍编舞

## 用途

同一明确成年表演者以面部、发型、麦克风与服装锚点贯穿，环绕字带和巨型短词只随一次对应表演动作进入；每章一个原创词，人物与文字互相遮挡但不丢身份。作为既有角色动作字卡轮转的时装现场证据，不新增下拉项。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 原创明确成年口语表演者登场：银色短辫、琥珀脸颊点、钴蓝夹克和黄铜指示棒，居中站在竖向黑米舞台。；表演者用指示棒向下利落切一次，原创短词 CUT 沿该线分开；随后侧移一步，TURN 旋转成地面平面。；所有文字回到同一平面，同一成年人站在原创短标 LINE FOUR 旁稳定停留；不复制来源人物、粉发、麦克风、可见文字、时装版式和字体。

## 必须保留的结构锚点

- Lock one clearly adult performer with at least four stable identity and prop anchors.
- Use one new original short word and one corresponding performance action per module.
- Repeat prop, palette and stage axis while word geometry changes.
- End with the same adult and one original short mark in a still composition.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
