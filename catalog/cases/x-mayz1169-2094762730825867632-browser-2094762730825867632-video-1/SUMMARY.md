# 设定板实演｜常驻参考条、机甲动作升级与设计回证

## 用途

把角色概念板固定为持续参考层，同一成年机甲角色从步行、结构展开到武器动作逐级实演；每个动作都能回查到板上的轮廓、配色和部件。

## 推荐输入格式

`持续可读的计划板 + 独立执行区 + 计划顺序推进 + 至少三项可见状态变化 + 计划与终态同框`

## 可直接改写的简短示例

> 让一名原创成年救援机甲驾驶员位于常驻下方参考条上方，参考条展示正面、背面和工具轮廓。；从背部展开两支折叠救援臂，并与下方参考轮廓对齐。；回到全身检验姿态，下方参考条不变，并完成终局停留。

## 必须保留的结构锚点

- One clearly adult original character remains continuous.
- The reference strip stays visible and registered.
- Mechanical deployment precedes the tool test.
- The final pose reconnects the moving design to its concept evidence.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
