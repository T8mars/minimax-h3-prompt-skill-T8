# 极端职业符号落入日常｜身份揭示到休假松弛

## 用途

先在高度普通、忙碌且有多人反应的日常空间建立秩序，再让一个只靠轮廓就能读出极端职业的访客携带行李进入。围观反应放大威胁预期，访客随后用一次身份揭示和一串极普通的日常动作重写角色意义；结尾用可读休假标记和放松姿态把反差固定下来。

## 推荐输入格式

`普通机构与群体日常节奏先建立 + 极端职业轮廓携一个固定旅行物进入并由周围成年人先反应 + 一次身份揭示后立刻用普通行政物替代预期高风险动作 + 同一访客被吸收到机构日常流程 + 可读休假状态标记与一个放松动作共同收束`

## 可直接改写的简短示例

> 成年顾客在薄荷绿洗衣店整理衣物，铜色压力服潜水员提蓝色旅行袋出现在玻璃门口；潜水员抬起铜色头盔露出疲惫成年面孔，接待员递出洗衣认领表；潜水员喝柑橘水，把写有“岸上休假”的卡片放在蓝袋旁并靠入椅背

## 必须保留的结构锚点

- Establish the ordinary institution and its group rhythm before the extreme-role visitor enters.
- Give the visitor one persistent travel object and a profession-readable silhouette while surrounding adults react first.
- Show the same visitor absorbed into one repetitive everyday routine with institutional anchors intact.
- End on one readable off-duty status token and one relaxed action in the same routine space.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
