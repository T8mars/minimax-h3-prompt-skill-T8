# 灯火引出海光｜孤崖基线、光泡汇聚与眼部回标

## 用途

从月夜海崖和远处灯塔建立孤独尺度，同一成年守塔人提灯走近；少量青蓝光泡从海面出现并逐级围绕人物，暖灯与冷光保持双锚，终局推进到一只眼睛被同色光点点亮。

## 推荐输入格式

`近单色低饱和世界 + 至少3级可比较尺度 + 唯一高饱和激活色与局部源点 + 同色沿可见载体跨尺度接力 + 保留早期锚点 + 最大环境网络稳定映射`

## 可直接改写的简短示例

> 让一名原创成年信号守护者站在风暴水库上方，手持一盏琥珀色检修灯。；他抬起琥珀灯一次后，从水线释放六枚青色信号光泡。；推进到单眼近景，让虹膜中出现一个青色反光点，同时保留面部与暖灯溢光。

## 必须保留的结构锚点

- One clearly adult keeper, lantern and cliff persist.
- The gesture visibly triggers the accent light.
- Warm and cool anchors never swap roles.
- The final eye detail is causally linked to the same light family.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
