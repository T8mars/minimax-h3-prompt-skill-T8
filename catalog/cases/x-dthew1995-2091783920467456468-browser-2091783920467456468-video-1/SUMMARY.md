# 连续脱险变体｜追车、铁轨倒计时、遮挡假安全与更大威胁

## 用途

明确成年人在共享地理中同时面对尾随威胁、前方障碍和侧向倒计时；一次大遮挡制造假安全，但遮挡清除后同一威胁以更大尺度或更近位置重现。

## 推荐输入格式

`同一逃生方向 + 至少两种局部危险 + 可见恢复 + 临时安全载具 + 更大尺度终端威胁`

## 可直接改写的简短示例

> 原创暴风山地维修路上，一名明确成年扫雪车司机坐在橙色驾驶室内，沿同一下坡轴逃离滚动黑色冰体。；成年人加速越过第一条轨道，冰体从后方逼近、电车从侧面逼近；清楚显示三段距离同时缩短，不用任意跳切。；最后一节车厢离开后，保留的冰体在车库屋顶上方以更大尺度出现并滑向停车；撞击前让驾驶室里的同一成年人可见并停住。

## 必须保留的结构锚点

- Establish one clearly adult original subject, one pursuing threat and a readable escape axis.
- Add a second physical hazard from a different direction without abandoning the shared geography.
- Use one large moving occluder to create a plausible but temporary safety assumption.
- Clear the occluder and reveal the retained threat at a larger or closer scale in relation to the same adult.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
