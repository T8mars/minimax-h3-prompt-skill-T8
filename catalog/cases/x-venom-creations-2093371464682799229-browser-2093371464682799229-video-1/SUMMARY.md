# 睡眠微动状态｜固定身份、呼吸证据与安静回稳

## 用途

用极少动作证明角色仍处在持续状态：固定构图下只允许呼吸、眼睑和指尖等微变化，光线与寝具提供连续性，终局保持克制而不强行制造事件。

## 推荐输入格式

`一名明确成年原创主体以至少三项身份锚点先完成一个普通触觉任务 + 用一个真实前景物、门框或建筑边缘过渡到独立休息地理 + 准确展示一次慢呼吸和至少两项头发、服装、植物或光线微响应 + 呼吸期间摄影只做克制慢推或静止 + 同一成年人复位后沿既定方向穿过可见出口`

## 可直接改写的简短示例

> 一名明确成年原创动画夜班递送员睡在海军蓝小床上，旁边只有琥珀舱灯。；一次慢呼吸、一次眉间放松和一次指尖松开构成三个有限微动作。；最终两秒保持同一睡姿，不新增事件、文字或镜头运动。

## 必须保留的结构锚点

- One clearly adult identity remains fixed.
- Micro-actions are individually observable and low amplitude.
- No dramatic dream event is inferred without evidence.
- The terminal state returns to the same quiet baseline.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
