# 生活触点旅行｜屋顶出发、街巷互动与私密纪念

## 用途

用同一人物与手持跟拍连接多个日常触点；每章都通过一次可触摸互动进入下一地点，最后把途中小物变成私密纪念。

## 推荐输入格式

`稳定旅行者身份/服装/方向 + 至少4个地理章节 + 每章1次本地材质接触 + 窄巷近物→社会场→移动地理→攀升全景 + 统一档案介质 + 高位稳定终景`

## 可直接改写的简短示例

> 手持跟随一名成年陶艺学生从工作室阳台出发。；摊主递来一只温热纸杯，人物边走边品尝。；回到工作室，同伴把丝带系在成品杯柄上，人物回头微笑。

## 必须保留的结构锚点

- One identity-locked adult carries the full route.
- Each chapter begins with one tactile interaction.
- Locations progress along one plausible journey.
- A small encountered object becomes the closing keepsake.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
