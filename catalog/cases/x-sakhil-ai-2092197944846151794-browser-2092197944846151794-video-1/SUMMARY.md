# 三人群舞锁步｜中心领舞、队形推进与同步手势收束

## 用途

用中心领舞和两名后排建立三角队形，动作从躯干波动扩展到同步前进与手势；镜头只做缓慢逼近，最终三人同时定格证明节奏一致。

## 推荐输入格式

`有边界表演区 + 明确成年多主体基线 + 站立到地面接触升级 + 每人独立留痕家族 + 轨迹只增不减 + 俯拍路径证明 + 完整队形收束`

## 可直接改写的简短示例

> 三名成年博物馆技术员在空置装卸展厅组成浅三角队形，领舞最靠近镜头。；三人沿同一地面缝线同步前进，三角间距不变。；三人回到紧凑三角形，同时锁定最终手肩姿势，镜头完成缓慢逼近。

## 必须保留的结构锚点

- A lead and rear pair establish one stable triangle.
- Rear performers echo one beat after the lead before synchronization.
- The camera uses one slow push rather than competing movement.
- All performers finish one identical gesture on the same beat.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
