# 单道具技巧阶梯｜基础循环、空中升级与英雄回位

## 用途

锁定一名成年表演者和一件长道具，以基础旋转建立节拍，再依次加入换手、腾空、环境接触与抛接；每级建立在前一级上，终局回到稳定英雄姿势。

## 推荐输入格式

`持续基础动作 + 3种高级技能 + 每次不同功能机位 + 节奏/接触声连续 + 回到基础动作`

## 可直接改写的简短示例

> 成年夜间救援教官持橙色伸缩杆站在湿润仓库屋顶。；增加一次跨过标记通风口的低位腾跃，长杆全程可见。；完成一次短抛接后，人物在同一通风口旁回到开场守势。

## 必须保留的结构锚点

- One adult performer and one prop remain identity anchors.
- A repeatable base loop is proven before escalation.
- Environmental effects occur only at visible contact.
- The prop returns to the opening guard state.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
