# 双载具间距｜同轴移动与安全错位 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：创作原创15秒封闭山谷维护演示：一辆蓝色缆车和一艘琥珀色维护飞艇同向前往上站，垂直间距收窄后安全拉开。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：广角稳定先同框两载具、索道与远处上站；蓝色缆车沿索道向上站前进，琥珀色维护飞艇在上方同向飞行；山坡与上站固定；一上一下的初始间距清楚；原创自然日光、蓝与琥珀配色；<山谷风><缆索机械声><低声推进器>。
镜头2：沿缆车侧面短距离跟拍，始终同时看见飞艇与索道；飞艇缓缓降低高度但保持同向，影子逐步接近缆车车顶；不交叉索道，不变成迎面而来；缆车外形不跳变；保持同一日光与山坡方向；<推进器音高轻微下降>。
镜头3：稳定侧视同时保留飞艇底缘、缆车顶缘和一条看得见的空气间隙；飞艇影子扫过车顶，到最低点后停止下沉，没有碰撞；两个实体边界始终分开，乘客没有受伤或惊险动作；真实阴影对应同一太阳方向；<缆索连续运行><低推进声>。
镜头4：拉至广角，缆车、飞艇和上站在同一地理中停留；飞艇恢复高度并继续同向，缆车不中断地驶向上站；终局空气间距比最低点明显更大，保持安全非接触结果；同一山谷日光；<推进器音高回升>（低频节拍随安全分离舒展）。
整体风格与画质：原创山谷工程演示短片，重点是相对位置和安全间距，而非赛道追逐；每镜保持两载具的同向轴和固定上站；最近处必须仍见空气间隙，末镜证明已安全拉开。
约束：仅一辆缆车、一艘飞艇和一个上站；不碰撞、不复制来源红赛车和黑直升机，不把飞艇放在索道上；不出现品牌、字幕或水印。
```
