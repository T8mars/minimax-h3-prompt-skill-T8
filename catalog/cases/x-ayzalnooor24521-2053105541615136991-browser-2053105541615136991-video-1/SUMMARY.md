# 舞步生墨｜足底触发、身体带流与山水终态

## 用途

脚掌首次接触纸面产生墨迹，随后身体旋转持续拖带黑墨，并逐步加入红、蓝、金流线；终局人物淡出而累计轨迹保留为完整山水画。

## 推荐输入格式

`有边界表演区 + 明确成年多主体基线 + 站立到地面接触升级 + 每人独立留痕家族 + 轨迹只增不减 + 俯拍路径证明 + 完整队形收束`

## 可直接改写的简短示例

> 成年书法表演者的靴子落到空白石膏地面，只产生一个钴蓝颜料池。；每次长杖挥动只延长已有带状轨迹，不生成断裂痕迹。；人物停止，全部累计线条沉降为原创风图壁画。

## 必须保留的结构锚点

- The first visible contact creates the trail.
- The performer remains the sole motion source.
- Color additions follow distinct contacts.
- The terminal artwork preserves the accumulated movement history.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
