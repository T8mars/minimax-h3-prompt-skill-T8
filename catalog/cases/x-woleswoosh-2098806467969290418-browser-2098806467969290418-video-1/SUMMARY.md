# 屋顶夺械撤离｜伏击逼近、武器接管与门槛逃生

## 用途

同一成年女性先借设备掩体观察追兵，追兵进入近距后她完成一次夺械；武器使用只为打开撤离窗口，探照灯与爆点保持远端，终局穿过屋顶门槛离场。

## 推荐输入格式

`被追主体 + 单一追逐轴线 + 一次紧凑阻断 + 立即步行→更快载具交接 + 持续加速结尾`

## 可直接改写的简短示例

> 一名明确成年的广播工程师躲在空调机旁，一名装甲安保演员穿过屋顶。；她引导对方手腕，夺下一件道具发射器，让对方坐倒但不受伤。；她到达维修门，只进入一次并关门，探照灯扫过空屋顶。

## 必须保留的结构锚点

- One clearly adult original lead and one exit persist.
- The pursuer commits before the single disarm.
- The acquired tool changes access rather than becoming spectacle for its own sake.
- The final closed threshold proves escape.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
