# 手势边界换媒｜局部窗口、多形态验真与回归

## 用途

双手先画出可控边界，只让框内区域切换媒介；多种几何反复证明注册规则，后段扩大覆盖后主动收回并回到原状态。

## 推荐输入格式

`明确成年原创控制者 + 稳定环境锚点 + 可见双手边界 + 替代媒介 + 至少三种几何/覆盖区 + 晚段大覆盖峰值 + 回归确认`

## 可直接改写的简短示例

> 一名成年温室研究员在固定机位中用双手拉出琥珀色窗口；只有窗口内部变成青色植物剖面线稿，窗口依次变成横框、竖框和斜框，后段覆盖半张脸与叶片，再收成一条细线消失，真实白花张开一片花瓣。

## 必须保留的结构锚点

- 激活前先建立一名明确成年原创控制者、稳定环境和可见的空闲双手。
- 双手几何必须先于换媒形成，活动边缘始终绑定指尖或手部边线。
- 替代媒介严格限制在移动边界内部，边界两侧空间精确注册，外部保持基线状态。
- 至少用三种几何或覆盖区证明同一规则；最大覆盖留到后段，再主动收回并以原媒介反应或残留确认结束。

## 使用方法

1. 保留用户给出的主体与目标。
2. 补齐环境、双手边界、替代媒介、几何证明、峰值、回归与声音。
3. 同时改变来源身份、服装、环境、边缘、媒介、精确动作、反应和声音表面。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并核对全部结构锚点。
