# 单角材质轮转｜身份锚定、玻璃晶体与宇宙状态变换

## 用途

锁定同一成年幻想角色的脸、银发、眼睛和轮廓，在玻璃、晶体、星云与白色织物状态间依次轮转；每次只改变一种材质或世界槽位，终局回到完整身份。

## 推荐输入格式

`固定主体身份与镜头关系 + 至少四个材质/版式不同的风格世界 + 每阶段改变两项风格通道 + 递增密度 + 可读身份终态`

## 可直接改写的简短示例

> 建立原创成年天文台守护员：黑色卷发、单侧琥珀眼标与钴蓝斗篷。；只把玻璃平面转为浅色矿物棱镜，同一人物保持稳定。；白色纸带替代星空后，回到钴蓝棱镜环中的完整守护员。

## 必须保留的结构锚点

- At least three identity anchors are established first.
- Each beat changes one material or world slot only.
- Scale expands without replacing the subject.
- The final state returns to the complete identity and one retained motif.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
