# 角色板节拍｜环境切换不丢身份

固定角色板持续在场，实景区域连续换环境并用不同动作、尺度和机位验证同一身份；作为既有角色卡验真模板的第二来源，不新增下拉项。

## 核心机制

Keep one compact identity board visible as a persistent verification anchor while the live evidence field changes through several environments. Each new field must prove a different behavior, scale or camera relation of the same subject; return to a readable board-plus-live-image composition often enough that variety never outruns identity.

## 推荐输入格式

`原创主体 + 固定角色板 + 至少4个环境 + 每处不同验证动作/尺度/机位 + 最终角色板与实景对照`

## 简短示例

> 陶瓷信使与固定角色板持续对照：依次进入包装间、窑炉、釉料实验室和雨中装卸区，每处证明不同动作与机位，最后在展厅与同一角色板完成对照。

## 必须保留的结构锚点

- 角色板全程保持同一布局
- 同一身份跨至少四个环境稳定
- 每个环境承担不同验证职责
- 结尾角色板与最终实景同时可读

## 使用方法

1. 先保留用户主体和目标，再按推荐格式补齐场景、事件链、镜头和结果。
2. 阅读 [Creative DNA](./creative-dna.json)，重新实例化变量，不做来源表面换名词。
3. 分别查看 [MiniMax H3](./prompts/minimax-h3.md) 与 [Seedance 2.0](./prompts/seedance-2.0.md) 的已验证实例。
4. GitHub 使用 GIF 快速预览；Electron 媒体包播放完整有声 MP4。
