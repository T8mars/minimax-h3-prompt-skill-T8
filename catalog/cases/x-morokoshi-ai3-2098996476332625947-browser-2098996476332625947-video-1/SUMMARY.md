# 运球不掉线｜前景体育动作与后景火箭升空反差

## 用途

固定原创成年运动员的连续运球任务，摄影沿发射设施低位跟随；后景火箭由静止、点火到升空逐级扩大，但人物始终回到同一控球节拍。彻底移除来源真人身份。

## 推荐输入格式

`明确成年原创主体和一个小型可重复前景任务先建立 + 背景危险至少经过三档接近等级升级且方向可读 + 每次危险后双手与视线都回到同一任务物 + 早期只做最小避让并把最大身体位移保留给一次近接峰值 + 危险过去后重新执行原任务而非庆祝或击败威胁`

## 可直接改写的简短示例

> 一名原创、明确成年的航天训练教练沿标记服务道开始稳定运球。；点火光出现、白色蒸汽扩散，教练仍保持同一换手节奏。；拉到广角，让成年教练、弹跳篮球、升空轨迹和服务道同时清楚可读。
