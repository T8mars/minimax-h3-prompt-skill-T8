# 共享色彩信号变体｜保护物先改变两人，再以同心波恢复城市

## 用途

灰色城市中只允许一个彩色保护物作为信号源；两名明确成年人先完成共享动作，颜色才从接触区沿同心边界扩散，并逐级激活周边同类物体与更大环境。作为既有单色跨尺度激活接力的关系触发证据，不新增下拉项。

## 推荐输入格式

`近单色低饱和世界 + 至少3级可比较尺度 + 唯一高饱和激活色与局部源点 + 同色沿可见载体跨尺度接力 + 保留早期锚点 + 最大环境网络稳定映射`

## 可直接改写的简短示例

> 原创单色夜间铁路场在细雨中建立，两名明确成年夜班工人分开站在暗色站台灯之间；只有一盏便携加热灯呈琥珀色。；两人在灯的小型暖光区停一拍，琥珀色只保留在灯与共同手套上，雨和铁路场仍为中性色。；宽景保持琥珀灯与标线已激活，但同一两名成年人和原加热灯仍在中心可读；不复制雨伞、广场、水印和挑战文字。

## 必须保留的结构锚点

- Establish a neutral environment and exactly one colored aid object.
- Require two clearly adult original people to complete one sharing or joint-use action before activation.
- Use repeated surrounding objects as an intermediate scale before architecture or environment changes.
- End with the originating pair and aid object still readable inside the changed environment.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
