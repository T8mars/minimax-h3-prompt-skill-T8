# 道具反复失控｜展开失败、短暂恢复与飞走收梗

## 用途

同一人物和同一道具在固定雨街中反复尝试：错误形态、手动修复、短暂成功再升级失控；最后让道具脱离并带走人物完成明确笑点。

## 推荐输入格式

`固定角色关系 + 三轮准备/动作/后果/反应 + 场景复位 + 后果逐轮升级 + 最大结果同框`

## 可直接改写的简短示例

> 一名明确成年动画递送员穿橙色雨衣，站在积水仓库门口，身旁是青绿色包裹车。；一次手动复位让车棚短暂正确展开，她继续推行两步。；车辆驶出画面，递送员在后方追赶，原门口与一个旋转车轮留在画面。

## 必须保留的结构锚点

- One character, prop and location remain fixed.
- Every new attempt follows a visible failure.
- Escalation changes prop behavior without resetting history.
- The final departure pays off the repeated failures.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
