# 延迟载体释放｜进入—静置—开启—扩散

## 用途

让一个密封载体通过外部流程进入可信空间，并在一段清楚的静置或时间变化后从内部开启；隐藏内容物随后扩散，并在整个环境尺度留下可见后果。

## 推荐输入格式

`可信边界 + 密封载体 + 可见入场流程 + 延迟状态变化 + 无可见操作者的开启 + 隐藏内容释放 + 环境尺度后果`

## 可直接改写的简短示例

> 原创玻璃温室接收区，黄铜地面输送带把一个密封哑光陶瓷种子库送过透明气闸，后方是整齐闭合的植物行列；生长灯从黄昏切换为紫色夜间模式，种子库位置、接缝、地面轨道和闭合植物全部保持一致；无人机沿三条分支路径扩散，花朵从种子库向远处玻璃墙依次开放，打开的载体始终留在起点

## 必须保留的结构锚点

- Use a visible external process to admit one sealed carrier through a trusted boundary.
- Establish the carrier intact and inert inside the bounded destination.
- Open the carrier only after the delay, show no opening operator and let concealed contents emerge.
- Let the released contents produce one visible environment-scale consequence.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
