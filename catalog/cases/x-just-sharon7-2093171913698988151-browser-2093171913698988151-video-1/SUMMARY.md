# 可见光标身份编辑｜拖拽改位、像素转换与人物连续

## 用途

让一个持续可见的光标成为唯一编辑因果；每次点击或拖拽只改变位置、尺度或图形介质中的一个槽位，同一人物身份在所有变化中保持可辨。

## 推荐输入格式

`固定选择菜单 + 固定数据区 + 固定主视窗 + 至少4个原创对象 + 每次可见选择 + 同步字段更新 + 一个定义动作`

## 可直接改写的简短示例

> 成年博物馆讲解员进入原创展览版式画布，一个巨型箭头光标持续可见。；一次点击只把背景变为蓝色半调网格，脸、制服和尺度不变。；光标释放，完整讲解员卡片与控件、注册标记共同停留。

## 必须保留的结构锚点

- One visible cursor persists as the sole editing agent.
- Each gesture changes exactly one named slot.
- Interface registration survives every transformation.
- The final state retains the cursor and completed layout as proof.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
