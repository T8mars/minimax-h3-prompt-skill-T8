# 层压可颂状态链变体｜揉压、包油、折叠、切卷与烤色证明

## 用途

同一工作台、面团、黄油、擀杖、刀具和烤盘持续锁定；面团依次经历包油、折叠、层压、切片、卷形、入盘、刷面和烤色等不可逆状态，终局掰开同一批成品证明层次与拉丝。

## 推荐输入格式

`一名明确成年原创操作者、固定空间、主材料组、主要容器与手部或工具锚点先建立 + 至少五个不可逆状态且每镜只执行一次清楚操作 + 上一状态的残留、形状、颜色、蒸汽或容器连续成为下一步输入 + 不得回到已消失的早期状态并保持数量合理 + 同一成品由同一成年人完成一次克制使用或品尝证明`

## 可直接改写的简短示例

> 建立原创成年烘焙师的双手、冷色大理石台、黑麦面团长方片、绿色香草黄油片、枫木擀杖与同一只深色烤盘。；同一层压面片再擀一次，准确切成六个三角形，并把每个三角卷成一个螺旋放入同一烤盘。；在烤盘上方掰开其中一个，证明绿色香草层与蒸汽，再把两半放回其余五个旁边，不替换批次。

## 必须保留的结构锚点

- One adult hand identity, one work surface, one dough, one fat layer, one rolling tool and one tray persist.
- Each beat performs one irreversible food-state operation and inherits visible material traces from the prior state.
- The oven transition returns the same tray and positions with a plausible baked-state change.
- The terminal split uses one item from the verified batch and exposes internal layers without substitution.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
