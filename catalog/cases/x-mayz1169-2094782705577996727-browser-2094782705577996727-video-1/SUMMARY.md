# 像素偶像角色板变体｜设定页复归与舞台身份验真

## 用途

固定一张包含正背面、色板、配饰和局部特写的角色设定板，在每次舞台姿态、近景、转身或道具展示后重新出现；用设定页持续核验同一成年身份，并在终卡让完整人物、原创名标与角色板共同可见。

## 推荐输入格式

`固定角色板 + 同一原创主体 + 至少4种不同验证职责 + 广角/近景双证明 + 最终对照`

## 可直接改写的简短示例

> 为原创明确成年街机作曲人【MIRA】建立固定角色设定板：银色双丸子头、一缕钴蓝刘海、琥珀眼、紫色飞行夹克、黑色百褶长裤与白色菱形胸针；包含正面、背面、侧面、色板和四个细节框。；脸部近景和一次朝镜头伸开手掌之前必须先回到设定板，核验同一缕刘海、眼睛、夹克领和菱形胸针。；终局让角色板与人物共同出现在准确原创主标【MIRA / NIGHT PATCH】旁；身份锚点和文字全部静止。

## 必须保留的结构锚点

- One persistent identity board occupies a stable screen region and never changes its reference content.
- The board provides at least front, back, side, palette and detail proofs for one clearly adult identity.
- Face, hair, costume, accessory and body proportions stay consistent across full-body and close views.
- The final frame contains board, complete adult and one original readable identity mark together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
