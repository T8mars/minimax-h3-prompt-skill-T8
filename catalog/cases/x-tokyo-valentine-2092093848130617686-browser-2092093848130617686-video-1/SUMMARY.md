# 庆典词语实体化｜一词一动作一材质结果的逐章升级

## 用途

同一明确成年主持人贯穿多个庆典模块，每章只引入一个原创短词、一件道具和一次动作；动作必须让文字发生对应的物理变化，如吹灭、膨胀、展开或点亮。通过重复舞台轴与配色保持身份，最后把所有庆典状态汇入一个原创祝福主标。

## 推荐输入格式

`一名明确成年原创主持人以至少三项身份锚点和稳定舞台轴贯穿 + 至少四个模块且每章只引入一个原创短词、一件道具和一次动作 + 动作必须把文字变成对应物理状态 + 重复至少两个身份或版式锚点并让尺度从手持升到舞台 + 终局主持人、材料余迹和原创祝福主标共同稳定可读`

## 可直接改写的简短示例

> 原创明确成年科学展主持人登场：银色侧辫、钴蓝翻领、六边形琥珀徽章，居中站在黑米舞台并拿一块棱镜。；短词 FLOAT 位于折纸条上；同一成年人启动一台桌面风扇，纸条升起构成字母体积，脸、侧辫与徽章可见。；同一主持人、一道棱镜光谱、一片纸花瓣和金属圆环围绕原创祝福 OPEN NIGHT 汇合，清楚停留，不复制来源文字、人物、道具和庆典版式。

## 必须保留的结构锚点

- Lock one clearly adult original host with at least three identity anchors and one stable stage axis.
- Use exactly one new original short word, one prop and one action per module.
- Repeat at least two host or layout anchors while material scale grows.
- End with host, selected material residue and one original greeting mark together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
