# 伪装任务反转｜道具递送、身份揭示与连续突围

## 用途

让同一成年人物带着明确任务物奔跑并受阻，先以伪装身份承受追击；任务物安全落位后才揭示真实身份，再以连续近身动作完成突围。

## 推荐输入格式

`稳定主体与中断目标 + 可读困境 + 因困境主动靠近的外部压力 + 至少两个准备微证据 + 单一能力链破局 + 回到原载体继续路线`

## 可直接改写的简短示例

> 成年酒店技术员穿正式服务伪装，双手携一只密封银色维修箱前进。；在身份揭示前，先把箱子安全放到有标记的控制柜旁。；用一次格挡、一次肘部改向和一次关门动作清出路线，最后在安全箱旁停留。

## 必须保留的结构锚点

- One mission object remains protected through the pursuit.
- The disguised identity remains stable before the reveal.
- The reveal preserves the same adult face and body.
- The final actions clear the route and return to the secured object.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
