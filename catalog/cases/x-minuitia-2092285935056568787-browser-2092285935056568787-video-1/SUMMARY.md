# 全域冻结回溯｜唯一行动者触发环境复流

## 用途

先让整个环境在一次灾变中同时悬停，只保留一个行动者继续移动；行动者接触一个可辨识微物后，所有碎片沿原轨迹逆行并恢复为完整终态。

## 推荐输入格式

`完整物件与正常环境基线 + 一次事故拆散并冻结 + 唯一移动专业角色 + 同一组件可追踪回收与重建 + 完成交付后一次全域复流`

## 可直接改写的简短示例

> 建立成年修复师与正在进水的玻璃档案馆。；修复师找到并触碰一枚悬浮黄铜目录牌。；档案馆恢复干燥完整，人物与空间锚点保持一致并停留。

## 必须保留的结构锚点

- One readable disaster state precedes the freeze.
- Exactly one subject remains mobile.
- Every displaced element retraces rather than respawns.
- The ending proves a restored coherent environment.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
