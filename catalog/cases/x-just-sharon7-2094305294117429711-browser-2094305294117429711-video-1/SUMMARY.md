# 动作触发漫画字效｜角色锁定、冲击字与海报定格

## 用途

锁定同一动画角色，用奔跑、落地与姿态变化逐拍触发撕纸、莲花、唱片和冲击字；终局把累计图形回收到人物海报。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 锁定原创成年动画递送员：银色短发、琥珀面罩、钴蓝夹克和白靴，置于珊瑚纸面。；一次受控屈膝落地触发准确冲击词【CLACK】，海军蓝棋盘同时在双靴下展开。；完整人物回到钴蓝海报框，准确标题【NIGHT ROUTE】停留。

## 必须保留的结构锚点

- One character identity anchors every graphic chapter.
- A visible action precedes each graphic response.
- Detail shots reconnect to the complete body.
- The final poster reunites character, palette and title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
