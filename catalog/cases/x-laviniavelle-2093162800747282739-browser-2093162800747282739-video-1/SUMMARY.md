# 地铁冲撞格斗｜环境碰撞、恢复动作与近身反制

## 用途

先让人物与固定地铁立柱发生真实碰撞，再用碎片、尘雾和身体恢复连续交接到近身格斗；每次反击从清楚接触开始，最后以朝镜头的一拳结束。

## 推荐输入格式

`明确成年原创主体、可读对手和稳定地面关系先建立 + 每次先完整承诺物理轨迹并真实接触 + 能量、尘屑、毛发、布料或灯光只在接触后局部短促响应 + 通过对手数量和反馈半径升级但轮廓始终清楚 + 终局效果归零并在同一空间稳定持有主体`

## 可直接改写的简短示例

> 成年车站机械师撞上固定玻璃时刻表墙，只产生局部裂纹。；成年破坏者沿已建立站台通道逼近。；机械师以戴手套手掌朝镜头推进，破坏者退出通道，画面结束。

## 必须保留的结构锚点

- One fixed environment anchor proves the initial impact.
- Recovery occurs in the same damaged location.
- Every counter has grounded visible contact.
- The final direct action follows a resolved spatial exchange.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
