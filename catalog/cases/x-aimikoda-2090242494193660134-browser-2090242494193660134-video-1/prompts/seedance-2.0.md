# 定版角色谱系｜同字段框架区分多种原型 — Seedance 2.0

## Prompt

```text
任务：制作原创六人轨道维修档案谱系：全程锁定一套深色任务界面，左侧为人物区，右上为职责标题，下方保持三行短指标，并使用01/06到06/06顺序计数。依次展示导航员、舰壳焊接员、生物过滤维护员、系绳驾驶员、辐射医护员和碎片分析员。每人必须同时拥有不同主色、宇航服轮廓、一个克制工具微动作和原创职责图标，所有界面锚点都保持完全对位。最后稳定停在碎片分析员06/06档案。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：固定任务档案01/06；成年导航员穿修长钴蓝宇航服，用两指描出一条路线弧；左人物区、右上职责标题、三行指标、下方图标和计数固定；第一张先教会观众字段顺序和比较规则；黑色界面、钴蓝细线、克制发光；<轻触界面><短促导航提示音>。
镜头2：同注册02/06；成年舰壳焊接员穿宽厚琥珀压力服，放下一次紧凑焊接面罩并转动冷态工具；只替换人物和职责数据；主色、轮廓、动作与焊缝图标协同变化；琥珀主色、厚重轮廓、固定网格；<面罩卡扣><工具转动>。
镜头3：同注册03/06与04/06；翠绿生物过滤维护员轻检叶片舱，随后白青系绳驾驶员收紧腕部卷盘；每张都保持相同裁切和字段位置；两张连续证明不同职责仍由同一分类框架约束；翠绿到白青，界面位置不动；<舱盖轻响><卷盘收紧>。
镜头4：同注册05/06；成年辐射医护员穿深红屏蔽围裙，用扫描器扫过前臂徽章一次；动作短而可读，职责标题不得被动画遮挡；深红警戒点、层叠防护轮廓；<扫描短音><徽章确认>。
镜头5：最终档案06/06；紫色碎片分析员穿棱角观测服，在放大镜下旋转一块透明碎片并稳定停留；最终编号、人物、标题、指标和图标全部同框，不切拼贴；紫色分析光、透明碎片高光、固定档案框；<碎片轻转><完成提示音>。
整体风格与画质：原创高级轨道任务档案，固定黑色界面注册、克制发光数据图形、六名明显不同的成年专员、主色/轮廓/工具/职责协同编码、短暂可读停留；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
