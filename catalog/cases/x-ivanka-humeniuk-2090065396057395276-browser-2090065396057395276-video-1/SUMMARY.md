# 多人商品一致性｜常驻参考板与角色接力实证

## 用途

先把原创商品、至少三名明确成年角色和各自身份锚点集中写入一条常驻参考板；主画面依次让角色在不同场景完成商品展示、接力与使用动作，参考板始终作为视觉核验基准。每次换人或换景都保留同一包装比例、标志位置和主色，最后让全部角色与商品同框，再切到无歧义包装终局。

## 推荐输入格式

`常驻注册参考板同时包含至少三名明确成年角色和同一原创商品 + 每名角色至少三项身份锚点 + 商品几何/比例/配色/标志位置固定 + 主画面依次完成单人展示、群体运动、一次使用动作与一次材质结果微距 + 每次换人换景都可对照核验 + 全员同框后交给孤立商品终局并停留`

## 可直接改写的简短示例

> 左侧固定参考栏同时展示三名成年探险厨师和同一 NORTHLEAF 琥珀茶罐，主画面由银辫角色A在储藏室展示茶罐；角色B接过同一茶罐并把茶叶倒入透明玻璃壶，其他两人保留在景深中；完整三人同框交接到象牙台面上的同一 NORTHLEAF 茶罐和三片鲜叶，包装完全稳定并停留

## 必须保留的结构锚点

- Register one persistent reference board containing the original product and at least three clearly adult character identities before the first scene change.
- Give each adult at least three stable identity anchors and give the product stable geometry, proportion, color allocation and mark position.
- Insert one macro material or result proof that is causally linked to the same product.
- Reunite all adults before handing off to one clean isolated product lockup and readable hold.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
