# 多人商品一致性｜常驻参考板与角色接力实证 — Seedance 2.0

这是 Creative DNA 的一个已验证原创实例。使用时应重新实例化主体、场景、道具和风格，同时保留案例的因果结构锚点。

## Prompt

```text
任务：制作原创15秒 NORTHLEAF 茶叶多人广告。画面左侧始终保留一条固定注册参考栏，同时展示三名明确成年探险厨师和同一只哑光琥珀茶罐：成年角色A是银色长辫、靛蓝围裙、圆框眼镜；角色B是黑色短卷发、锈色围裙、黄铜领针；角色C是剃短发、奶油围裙、绿色护腕。茶罐始终保持圆柱比例、琥珀罐身、象牙罐盖和居中叶片标志。主画面依次表现角色A在储藏室展示茶罐、三人在营地厨房同行、角色B把茶叶倒入玻璃壶，以及热水中叶片舒展的微距证明。三人最后共同举杯，再交接到孤立 NORTHLEAF 茶罐和三片鲜叶的终局，清楚停留。参考栏位置不得变化，不增加其他文字。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：常驻参考栏与全部身份先锁定；左侧固定参考栏同时展示三名成年探险厨师和同一 NORTHLEAF 琥珀茶罐，主画面由银辫角色A在储藏室展示茶罐；三人各三项身份锚点、茶罐比例和标志位置从此不变；暖白储藏室、琥珀罐、靛蓝围裙；<布料轻动><茶罐轻放>。
镜头2：群体运动检验连续性；三名成年人在营地厨房中同向行走，参考栏保持原位置，脸、围裙、配饰和茶罐可直接比对；不得新增人物或改变包装；暖木、克制锈色和奶油色；<脚步接力><轻微厨房环境声>。
镜头3：商品接力与使用动作；角色B接过同一茶罐并把茶叶倒入透明玻璃壶，其他两人保留在景深中；手部交接前后罐身、罐盖与叶片标志一致；透明玻璃、琥珀茶叶、锈色围裙；<罐盖开启><茶叶落入玻璃>。
镜头4：材质结果微距证明；微距观察同一壶内茶叶遇热水后舒展，再回到三名成年角色克制举杯；微距必须由前一使用动作直接产生；热水折射、叶片纹理、温暖蒸汽；<注水><细小气泡><杯沿轻碰>。
镜头5：群体交给产品终局；完整三人同框交接到象牙台面上的同一 NORTHLEAF 茶罐和三片鲜叶，包装完全稳定并停留；参考栏和主画面不得再引入新信息；高可读包装、充足留白；<短收束音><环境声稳定>。
整体风格与画质：原创高端多人商品广告，干净温暖的探险厨房环境，克制琥珀、靛蓝与锈色配色，常驻注册身份板，稳定虚构包装和可触饮品微距摄影；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
