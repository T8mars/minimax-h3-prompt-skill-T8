# 平面重组｜讲解人物与纸片信息节拍

## 用途

固定讲解者轮廓与纸片图形族，通过信息卡、人物复制和版式密度变化逐步重组，最后用已建立的纸片与轮廓收束为终版；与官方纸拼贴能力及既有平面模板重合，因此只作证据变体。

## 推荐输入格式

`紧凑图标 + 稳定角色/配色 + 密度递增模块 + 孤立状态停顿 + 几何锁定`

## 可直接改写的简短示例

> 原创黏土纸艺气象台上，一名黏土气象员与三张灰蓝赭黄云形卡建立在奶油色网格，不使用来源文字；加入一个偏移的同一气象员副本用于降雨比较，身份与网格不变；同一人物、云卡和网格重建为非对称矩形野外报告封面，不加入新文字

## 必须保留的结构锚点

- Establish one stable presenter silhouette and bounded card vocabulary.
- Reorganize information using only established shapes, palette and presenter identity.
- Simplify once before the final reconstruction.
- Resolve established elements into a held final lockup without source copy.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
