# 日常规则具象后果｜提醒出现、忽视停顿与清理行动

## 用途

在同一日常空间先给一个简单可执行提醒，让成年风格化角色明确忽视；后果以可见实体逐步占据空间，只有完成对应清理动作后才允许恢复。

## 推荐输入格式

`从原创符号阵列内部低位穿行 + 揭示与阵列绑定的更大实体或系统 + 外部手或操纵器进入且周围标记保持稳定 + 只移动一个可识别标记并显示接触 + 以更大系统的单一克制状态变化证明后果`

## 可直接改写的简短示例

> 原创成年夜间插画师坐在杂乱书桌旁，小型蓝色计时器指向准确提醒【SAVE YOUR WORK】。；三只透明纸蛾从红色图标长出，各携一块未完成画面。；碎片回到页面，图标变绿，计时器克制点头确认。

## 必须保留的结构锚点

- One simple rule is visible before it is ignored.
- The subject performs a clear refusal or delay.
- The consequence remains in the same daily geography.
- Only the matching corrective action restores order.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
