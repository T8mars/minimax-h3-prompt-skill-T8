# 个人设备状态开关｜普通环境在佩戴后进入表演模式再归稳

## 用途

先建立明确成年人、个人设备和普通公共环境；一次清楚佩戴或启动动作改变人物步态、环境节奏和摄影能量，但地理与身份不变，最终通过关闭或静止证明状态切换。

## 推荐输入格式

`Establish one clearly adult original subject, one personal device and an ordinary environment baseline. + Use one visible device-wear or activation action as the sole switch into the heightened state. + Change performance, camera rhythm and bounded environmental accents while preserving identity and geography. + Keep surrounding public behavior plausible so the private state remains legible by contrast. + Return camera and subject motion to a stable baseline in the same environment, with device state visibly resolved.`

## 可直接改写的简短示例

> 原创清晨渡轮总站内，一名明确成年南亚通勤者穿苔绿色外套，手持小黄铜节拍器；后方人群正常行走。；接下来四步与克制琥珀地面倒影和一次前景立柱擦镜对齐；总站、脸、外套和周围行人路线不变。；她合上节拍器；光带停止，摄影机落稳，同一成年人恢复正常行走，环境不变；不加文字品牌并停住。

## 必须保留的结构锚点

- Establish one clearly adult original subject, one personal device and an ordinary environment baseline.
- Use one visible device-wear or activation action as the sole switch into the heightened state.
- Keep surrounding public behavior plausible so the private state remains legible by contrast.
- Return camera and subject motion to a stable baseline in the same environment, with device state visibly resolved.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
