# 沉睡主角反差｜静态前景锚点与同伴灾难升级

## 用途

把一名明确成年主角的沉睡状态固定为持续前景任务，同伴在周围经历跳鱼、激流、隧道和操舵危机；危险不断升级但主角只保留呼吸微动，最后回到平静水面。

## 推荐输入格式

`明确成年原创主体和一个小型可重复前景任务先建立 + 背景危险至少经过三档接近等级升级且方向可读 + 每次危险后双手与视线都回到同一任务物 + 早期只做最小避让并把最大身体位移保留给一次近接峰值 + 危险过去后重新执行原任务而非庆祝或击败威胁`

## 可直接改写的简短示例

> 一名明确成年的河道制图师睡在宽阔芦苇筏上，一名成年向导观察水道。；木筏进入蓝色矿洞，水流和摄影速度同步提高。；驶入平静晨光水池；向导松懈坐下，睡者只翻身一次后继续沉睡。

## 必须保留的结构锚点

- All human subjects are clearly adult.
- The sleeping state is proven through restrained micro-motion.
- The guide performs all active recovery actions.
- The final calm state preserves the original comic contrast.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
