# 林间初遇｜远距发现、试探接近与双向安全确认

## 用途

先由成年旅者在林地发现蜷缩生物，双方保持距离并以目光和小动作试探；接触只发生一次，生物抬头回应，终局以共同安全空间而非强行抱持收束。

## 推荐输入格式

`侧面连续跟拍 + 狭窄起点 + 行进中空间揭示 + 一次偶发横穿 + 一次克制回应 + 继续离开`

## 可直接改写的简短示例

> 一名明确成年的野外植物学家发现一只小型苔翼生物睡在倒下的雪松上。；她把一只摊开的手掌放到木头旁，不主动触碰，并静止一拍。；拉到广角，让植物学家与生物共同停在雪松旁同一片阳光中。

## 必须保留的结构锚点

- One clearly adult human and one original creature persist.
- Distance closes monotonically without a jump cut substitution.
- Exactly one voluntary contact confirms trust.
- The ending preserves both identities and the established forest location.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
