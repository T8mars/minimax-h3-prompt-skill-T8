# 加油站固定广角互动｜迎镜表演、坐上车身与同伴入画

## 用途

固定轻微倾斜的广角机位记录一名成年人物从车旁靠近镜头、连续做表情和手势，再后退坐上同一车身；第二名成年人从侧后方进入并靠近，画面由单人表演变成双人空间关系。

## 推荐输入格式

`侧面连续跟拍 + 狭窄起点 + 行进中空间揭示 + 一次偶发横穿 + 一次克制回应 + 继续离开`

## 可直接改写的简短示例

> 固定低位轻倾广角在原创蓝色服务车旁，场景是安静公路充电站。；她后退并坐在同一车辆保险杠上，屏幕方向和机位几何不变。；两名人物、保险杠、线缆和充电桩共同停留，递送员转向机械师，单人表演转成相遇。

## 必须保留的结构锚点

- One fixed observer frame establishes person, carrier object and environment before the approach.
- The first adult's foreground performance preserves the background spatial anchors.
- A second adult enters from established background geography rather than appearing through a reset.
- The final shared frame converts solo display into a readable two-person encounter.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
