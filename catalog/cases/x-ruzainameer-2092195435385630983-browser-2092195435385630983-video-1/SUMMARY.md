# 接触触发尺度生长｜小型陪伴物入介质后长成巨体

## 用途

先建立明确成年人、小型非人陪伴物和可测量环境尺度；陪伴物接触介质后，涟漪、体积和水体位移连续升级，原身份特征保留，最终由同框巨体完成尺度证明。

## 推荐输入格式

`Establish one clearly adult original person, one small nonhuman companion and measurable environment scale. + Use one visible contact with a declared medium as the sole transformation trigger. + Keep recognizable companion features and displaced medium continuously visible during growth. + Make environment reaction scale with body growth while preserving the adult's position and geography. + End with the same adult and transformed companion in one readable frame that proves final scale.`

## 可直接改写的简短示例

> 黎明原创浅盐池旁，一名明确成年北非植物学家穿赭色野外外套，手里托着掌心大小的黄铜种子机器，带三片蓝色叶翼。；三片叶翼和中央黄铜核心保持可见，身体在透明水下扩大；盐粒与水从原接触点连续向外位移。；拉成广角并停住，明确成年植物学家与完整变形生物同框，掌心装置身份仍可辨，不加文字和品牌。

## 必须保留的结构锚点

- Establish one clearly adult original person, one small nonhuman companion and measurable environment scale.
- Use one visible contact with a declared medium as the sole transformation trigger.
- Make environment reaction scale with body growth while preserving the adult's position and geography.
- End with the same adult and transformed companion in one readable frame that proves final scale.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
