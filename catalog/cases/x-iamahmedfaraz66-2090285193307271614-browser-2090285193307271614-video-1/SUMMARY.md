# 采摘一口实证｜环境基线、成熟选择、品尝与离场

## 用途

真实画面是单一采摘任务而非七镜家庭蒙太奇：人物进入植株区，选择一颗成熟果，向镜头展示、吃下并带篮离场。

## 推荐输入格式

`出镜测评者 + 未开封产品 + 完整内容展示 + 一个产品专属微距证据 + 一次完整使用 + 产品与反应同框`

## 可直接改写的简短示例

> 成年温室管理员带小帆布袋进入香草床。；把同一枝薄荷举向镜头，叶缘和纹理清楚。；同一管理员沿开场通道离开，帆布袋和薄荷仍在手中。

## 必须保留的结构锚点

- One person and one selected item remain bound.
- Selection follows visible inspection.
- Reaction follows the sensory test.
- Departure closes the original task route.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
