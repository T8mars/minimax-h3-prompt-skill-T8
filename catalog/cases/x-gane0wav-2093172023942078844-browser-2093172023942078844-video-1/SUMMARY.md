# 植物材质片头｜物种切片、粒子生长与总标题归拢

## 用途

用多个植物物证承载分章标题，每段只让一种生长或散逸材质完成转场；重复单色纸面、日期和细线注册，最终归拢成完整总标题。

## 推荐输入格式

`至少三种独立材质职员表场景 + 每幕一条原创短职员表与材质动作 + 跨幕重复色形或标记 + 回到已建立材质族汇聚 + 大型原创总标题稳定停留`

## 可直接改写的简短示例

> 原创石墨标本卡显示干蕨与准确短词【TRACE】。；纸尘揭示准确短词【CULTIVATE】，网格和日期始终注册。；三种材质痕迹汇入准确总标题【FIELD NOTES】，档案卡停留。

## 必须保留的结构锚点

- Each vignette contains one concrete botanical evidence object.
- Material growth begins on the visible object contour.
- Each chapter uses a distinct material behavior.
- All traces converge into one readable master title.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
