# 见证窗不切换｜对峙、越界位移与能量碰撞留在同一场 — Seedance 2.0

## Prompt

```text
任务：制作原创15秒轨道训练场短片，全程通过一扇固定控制室窗观察。两名明确成年的动能安全工程师分别穿钴蓝和琥珀工作服，在标记通道两端对峙，三名成年技术员在护栏后见证。钴蓝工程师释放一次非致伤压力推力，把琥珀工程师推到编号泡沫屏障并留下明显凹痕。两人回到原通道标记，凹痕必须保留。随后形成相反的蓝色和琥珀场环，沿同一中心轴释放，碰撞扩成无害白色蒸汽并覆盖控制室窗。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：固定见证窗建立完整场地；通过控制室窗同时看到两名成年工程师、通道轴线、编号泡沫屏障和护栏后三名成年技术员；所有后续动作都必须能回到这套地理；冷灰训练场、钴蓝与琥珀服装；<控制室低鸣><场地提示音>。
镜头2：位移连接实体后果；钴蓝工程师释放一次非致伤压力推力，琥珀工程师跨过既定间距撞入编号泡沫屏障，留下深凹痕和轻泡沫尘；起点、运动路线、落点和残余必须连续；泡沫尘不过曝、凹痕清楚；<压力释放><泡沫受压>。
镜头3：返回同场并保留损伤；两名成年人回到原通道标记，控制室窗构图恢复，编号屏障的凹痕和碎屑仍然存在；环境不得重置；固定高位视角、残余清楚；<脚步归位><警示低音>。
镜头4：相反蓄能沿同一轴线；钴蓝角色形成蓝色场环，琥珀角色形成琥珀场环，姿态与发射方向沿原中心线相对；能量方向先可读，再允许释放；蓝琥珀双场克制发光；<两种低频上升音>。
镜头5：碰撞覆盖原见证窗；两种场在中心相遇，扩成无害白色蒸汽，从训练场向控制室窗铺开并完全遮挡；结尾仍属于同一见证边界，不切独立爆炸；白色实体蒸汽、边缘带蓝琥珀余光；<场碰撞><蒸汽撞窗>。
整体风格与画质：原创写实近未来安全演示，固定见证窗、明确成年参与者、标记训练场、累积泡沫屏障凹痕、克制场色与实体蒸汽结果；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
