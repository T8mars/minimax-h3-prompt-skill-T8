# 几何通道角色MV｜身份钩子、环形穿越与模块复归

## 用途

以同一动漫成年角色的眼、手、发色和服装为身份锚点，在圆环、方块、网格和色块模块间快速穿越；每个模块只承担一个动作，终局回到完整角色。

## 推荐输入格式

`原创成年风格化角色的至少三项稳定身份锚点与紧凑原创名称标志 + 至少四种版式逻辑不同的图形模块 + 每模块最多一个新短词或身份字段 + 角色用一次语义动作跨过/击中/占据/揭示文字 + 显式身份核验 + 角色进入完整名称与符号标志并稳定停留`

## 可直接改写的简短示例

> 用一只琥珀眼、银色耳机弧与调音旋钮上的指尖建立原创成年电台工程师。；一个波形方块与一个黑色网格模块围绕稳定面孔、夹克和耳机轮转。；青色旋钮环回到完整人物和两个注册回声剪影周围，停留收束。

## 必须保留的结构锚点

- At least three identity anchors precede the module changes.
- Each geometry module carries one action only.
- Color wipes change the field, not the identity.
- The opening ring motif returns around the full subject.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
