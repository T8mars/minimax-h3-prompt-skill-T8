# 平面饮品证据链｜包装锚定、开启因果与倒杯落版

## 用途

用一个注册稳定的原创包装贯穿平面广告，开启动作先触发气泡与冰，随后倒杯证明液体状态，最后所有图形回收到完整包装与短标语。

## 推荐输入格式

`结果先行画面 + 原创产品身份 + 组装/状态证据 + 佩戴或使用证明 + 环境化结果终态`

## 可直接改写的简短示例

> 象牙底建立原创钴蓝【CITRA】气泡水罐，平面轮廓稳定。；CITRA以一条连续液流倒入带棱透明杯。；完整罐体与满杯回收到准确原创短句【OPEN THE DAY】旁。

## 必须保留的结构锚点

- One registered package silhouette anchors every beat.
- Graphic effects begin at visible package actions.
- All copy is short, exact and readable.
- The final lockup reunites package, serving and promise.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
