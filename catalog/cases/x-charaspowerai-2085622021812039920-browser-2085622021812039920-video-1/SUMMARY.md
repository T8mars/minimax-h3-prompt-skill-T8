# 材质字效｜霜花成字再归位

固定竖直玻璃先建立清晰基线，霜晶从同一表面长成一个短词，保持可读后融成真实水珠，最终恢复开场窗口形成闭环。

## 核心机制

Start from a calm material baseline, generate one localized disturbance from that same material, assemble the disturbance into one short readable word, hold it long enough for verification, then let gravity or flow dissolve every letter back into the original surface. The ending must visually match the opening state closely enough to support a clean loop.

## 推荐输入格式

`固定镜头 + 单一材质基线 + 同材质形成1个短词 + 可读停留 + 同一物理法则溶解 + 回到开场`

## 简短示例

> 夜间温室竖直玻璃保持清晰，霜晶沿四条成核路径形成 THAW，短暂停留后由下方暖风融成水珠流走，最后恢复同一铜锁扣和虚化叶片构图。

## 必须保留的结构锚点

- 先保持无字的固定材质基线
- 所有字母由同一材质形成
- 全片只出现一个可读短词
- 用同一材料法则完成溶解
- 镜头和空间锚点回到开场状态

## 使用方法

1. 先保留用户主体和目标，再按推荐格式补齐场景、事件链、镜头和结果。
