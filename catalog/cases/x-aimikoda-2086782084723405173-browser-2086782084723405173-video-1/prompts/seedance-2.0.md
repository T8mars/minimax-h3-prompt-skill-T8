# 对话反应｜冷静回答引爆大笑 — Seedance 2.0

## Prompt

```text
任务：文本生成一支原创15秒短片：双人固定地理里先交代第一轮，再给第二人短回答，最后把镜头交回第一人的长反应。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：稳定双人中景；两名原创月球地质学家隔着样本台坐定，甲指向透明盒中轻微振动的矿石并开始第一轮说话；双方座位、眼线和盒子从开场固定；冷白实验灯与矿石微光；<仪器底噪><第一轮人声开始>。
镜头2：继续保持双人地理；甲说完原创问题：{房间安静时它也应该哼吗？}乙保持双手不动并等待；建立明确回应空位；光线稳定；<第一轮人声结束><短暂停顿>。
镜头3：切乙的中近景；乙检查一次仪表、抬一边眉并回答原创台词：{只有在它知道我们正听时。}回答立即结束；眼线和道具连续；仪表冷光；<第二轮短回答>。
镜头4：切回甲的中景；甲不再说话，僵住后双手抱住头盔并缓慢向后退离样本，前景矿石继续振动；把回答交给非语言反应；矿石微光保持；<椅垫压缩><呼吸>。
镜头5：稳定长停留；甲后仰定住、双手仍抱头盔、视线锁定透明盒，乙在画面边缘保持平静，不再增加台词；改变后的姿态完成收口；实验室光线不变；<设备底噪><无新增人声>。
整体风格与画质：Original polished lunar-lab conversation, stable seated geography, restrained performance, practical sample-table props, clean shot-reverse-shot, quiet dry comedy；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：保持两名原创地质学家、固定座位方向和同一样本盒；严格两轮说话后接更长的无声反应；指定对白是原创实例内容，不是来源证据；不得复刻来源系列人物、服装、房间、计数争论、饮杯动作、大笑、Logo或水印。
```
