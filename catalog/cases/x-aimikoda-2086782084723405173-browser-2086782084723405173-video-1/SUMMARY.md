# 对话反应｜冷静回答引爆大笑

## 用途

双人固定地理里先交代第一轮，再给第二人短回答，最后把镜头交回第一人的长反应。

## 推荐输入格式

`稳定双人地理 + 第一轮完整说话 + 清楚停顿 + 第二轮短回答 + 更长无声反应`

## 可直接改写的简短示例

> 两名月球地质学家先用双人镜头建立地理，乙给出一句短回答，镜头回甲做更长的无声抱盔后仰反应，不增加第三轮台词。

## 必须保留的结构锚点

- Establish both subjects and seating geography before singles.
- Keep the second speaking turn compact and visibly complete.
- Return to the first subject for a longer non-speaking physical reaction.
- End on a changed held posture with no additional speaking turn.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
