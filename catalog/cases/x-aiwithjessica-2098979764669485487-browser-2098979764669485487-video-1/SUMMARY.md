# 冷静仪式对抗乱局｜前景微动作与后景冲突升级

## 用途

把同一成年女性的克制点火、吸气和行走固定为前景任务，后景人群冲突由站立、推搡到倒地逐级升级；人物只做一次必要闪避并回到冷静节奏。

## 推荐输入格式

`明确成年原创主体和一个小型可重复前景任务先建立 + 背景危险至少经过三档接近等级升级且方向可读 + 每次危险后双手与视线都回到同一任务物 + 早期只做最小避让并把最大身体位移保留给一次近接峰值 + 危险过去后重新执行原任务而非庆祝或击败威胁`

## 可直接改写的简短示例

> 一名明确成年的夜间巡查员身穿石墨外套，在一排蒙面舞台工人前冷静点燃一支线香。；舞台工人进入编排好的推搡与倒地接力，巡查员保持居中静止。；她放下已经熄灭的线香，从恢复静止的人群中穿过，不再回头。

## 必须保留的结构锚点

- One clearly adult original lead remains calm and identifiable.
- A small foreground ritual never loses continuity.
- Any physical conflict is non-graphic and choreographed.
- The ending returns attention to the lead's completed ritual.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
