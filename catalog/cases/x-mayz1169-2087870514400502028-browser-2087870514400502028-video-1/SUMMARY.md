# 平面重组｜角色海报到嘉年华版式

## 用途

角色与角形平面模块先建立固定图形族，再通过高密信息重组、短暂中性复位和终版版式回收完成一条视觉回路；只作为既有平面几何重组模板的证据变体。

## 推荐输入格式

`紧凑图标 + 稳定角色/配色 + 密度递增模块 + 孤立状态停顿 + 几何锁定`

## 可直接改写的简短示例

> 原创剪纸植物档案页上，纸艺策展员轮廓与三枚苔绿赭黄三角种子标签建立在奶油色纤维网格；再加入两个非对称面板和植物线图，但不引入新图形族，主体身份持续；同一轮廓、标签和网格重建为非对称矩形植物志封面，不加入新母题

## 必须保留的结构锚点

- Establish one stable silhouette and one dominant graphic anchor.
- Increase layout density using only established motifs and palette.
- Use one brief low-information reset before the final build.
- Resolve the established motif family into a held final lockup.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
