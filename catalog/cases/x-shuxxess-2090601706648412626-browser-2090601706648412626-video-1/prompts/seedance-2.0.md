# 实用整理确认关系｜接触、退开与双向微反应 — Seedance 2.0

## Prompt

```text
任务：制作原创15秒安静演出前准备场景。在同一后台侧翼，一名明确成年舞台经理留银色短发、穿深灰开衫并戴绿色腕带，面对一名明确成年歌手；歌手是铜色卷发、奶油色衬衫和深蓝马甲。一只领夹麦克风明显歪斜，线缆偏离马甲接缝。使用稳定胸部以上双人镜头。舞台经理用双手完成一次连续动作：把麦克风转正、压平线缆并固定一个夹扣；歌手保持不动，但视线跟随双手。夹扣和线缆清楚对齐后，经理停顿并退开。先展示歌手一次克制呼气和眼神放松，再展示经理一个很小的回应点头。最后回到两名成年人同框，舞台灯从侧面溢入，已对齐麦克风仍然可见并稳定停留；不需要对白。。
总时长约15秒，仅控制整体信息密度，不分配逐镜头秒数。
镜头1：双人关系、装备问题和共用轴线先建立；成年舞台经理与成年歌手在后台同框，歪斜麦克风和偏离接缝的线缆清楚可见；银色短发、铜色卷发、服装颜色和手部归属固定；暖后台光、深灰奶油蓝；<后台低响><远处舞台声>。
镜头2：一次连续双手动作解决问题；经理转正麦克风、压平线缆并扣合夹子，歌手身体不动但视线跟随；不得加入其他触碰或更换装备；手部近景、金属夹扣；<线缆摩擦><夹扣轻响>。
镜头3：完成状态先停顿再退开；麦克风垂直、线缆贴平、夹扣闭合，经理停一拍后双手离开并退一步；完成证据出现前不得分离；整齐接缝、双人距离增加；<短暂静默><衣料轻响>。
镜头4：被帮助者给出克制微反应；歌手轻轻呼气，眼周稍微放松，画面下缘仍保留已对齐麦克风；不编造对白或夸张情绪；暖侧光、安静近景；<轻呼气>。
镜头5：帮助者回应并回到共同准备状态；经理小幅点头，随后两名成年人回到同框，舞台侧光与麦克风完成状态共同停留；结尾不新增接触或台词；稳定双人轴线、舞台光溢出；<远处舞台提示音><声音收束>。
整体风格与画质：原创克制二维剧情动画，温暖后台实用光，深灰、奶油和蓝色配色，成年身份稳定，手部与装备动作准确，双向近景安静；保持因果顺序、主体连续和每镜单一主要运镜；只迁移抽象机制，不复刻来源表面。
约束：只实现当前声明的原创实例，不加入未声明的人物、道具、地点、文字或镜头顺序；全程保持已声明主体、材质载体和空间锚点稳定；不复刻来源特定身份、服装、场地、品牌、原文、图形或构图。
```
