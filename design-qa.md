# Design QA — narrow API Workbench header

## Visual truth

- Existing T8 desktop visual system: black/acid-green palette, compact outlined controls, Chinese-first labels, and the current three-step workbench.
- Defect reference: the 760 × 760 result view where repository links and header actions competed for one row, causing Chinese capability and API labels to stack vertically.
- Intended state: preserve the same controls and hierarchy while keeping every header label horizontal and inside the dialog.

## Implementation evidence

- Viewport: 760 × 760 CSS pixels at device scale factor 1.
- State: video workbench, result step, Chinese locale, AI Workshop selected.
- Full-view capture: generated by `test/workbench.e2e.cjs` after the responsive fix.
- Focused comparison: before/after images were combined and inspected together at identical viewport and state.

## Findings and fixes

| Area | Before | Fix | Result |
| --- | --- | --- | --- |
| Header actions | Capability and API labels stacked vertically | Header actions receive a dedicated compact row below 820 px | Passed |
| Repository links | Consumed scarce narrow-header width | Hidden in the narrow workbench header; still available in the main app | Passed |
| Control bounds | Labels could visually escape their intended horizontal shape | Added no-wrap/horizontal writing rules and automated geometry assertions | Passed |
| Template preview | Could still be loading during comparison | Existing GIF loader preserved; fallback remains available | Passed |

## QA history

1. Captured the reported 760 × 760 defect state.
2. Applied responsive rules within the existing design system.
3. Re-ran the full workbench journey at desktop and 760 px widths.
4. Compared before and after in one side-by-side image.
5. Added regression assertions for dialog overflow, control bounds, horizontal writing mode, and no-wrap behavior.

## Final result

Passed. The narrow workbench keeps all primary actions readable, horizontal, and within the dialog without changing desktop behavior.
